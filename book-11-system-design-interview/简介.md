# 第十一册简介：大模型系统设计面试

## 本书定位

本册训练读者在有限面试时间内，把一个开放的产品或平台问题转成可讨论、可推演、可比较的系统方案。读者先澄清目标和约束，再估算流量与资源、画出请求和状态流、选择组件与数据边界，最后检查可靠性、安全、质量、成本和回滚，并解释方案为什么适合当前假设。

本册是以案例为主的系统设计面试教材，不是云厂商部署手册，也不试图替代每个技术领域的完整原理书。ChatGPT 服务、训练与推理平台、RAG、Agent、多模态、实时语音、视频生成、评估、标注、安全审核、模型路由和缓存都作为练习同一套设计方法的场景。

## 为什么需要这本书

模型和算法知识不能自动变成系统方案。面试官还会追问请求如何进入系统、状态由谁保存、队列和 GPU 如何扩展、模型或工具失败时怎样降级、结果质量如何验证，以及数据权限、成本和延迟之间如何取舍。只画方框而不说明流量、状态和失败路径，无法证明方案能工作。

## 适合读者与前置知识

本册适合准备系统设计轮或工程深挖的候选人，尤其是已经做过 RAG、Agent、推理服务、训练或评估项目、但还不熟悉白板表达的人。建议具备 Python 和机器学习/大模型基础，了解 API、数据库、缓存、队列及基本分布式服务概念；先完成第三册项目实战会更容易把项目细节转成设计回答。

## 学完后应具备的能力

1. 从题目中澄清用户、工作负载、业务目标、功能范围和非功能约束。
2. 用请求量、并发、输入输出长度、存储增长和延迟预算估算系统规模，并标出假设。
3. 设计 API、组件边界、数据流和状态所有权，说明同步/异步路径及生命周期。
4. 根据工作负载选择模型、硬件、队列、缓存、检索或执行组件，并说明替代方案。
5. 覆盖质量评估、权限与安全、可观测性、过载、故障恢复、灰度和回滚。
6. 在追问中根据新约束更新设计，清楚说明收益、成本、风险和尚未验证的假设。

## 范围与边界

本册讲面试中的问题拆解、容量推演、架构表达和跨领域系统案例。它不展开训练算法、推理 kernel、完整评估统计、安全治理、数据工程、Agent runtime 或工具协议的全部技术细节：分别转读第五至第九册、第十七册、第二十册、第二十二册、第二十三册和第二十四册。第三册侧重交付可运行项目；本册把项目升级为有约束、有备选、有失败路径的架构回答。第二十三册深入 AI Infra 平台工程，本册用训练/推理平台题练习面试设计，不替代其硬件、网络、集群和平台实现。第十册训练研究证据判断；第十二册再处理简历、项目表达和整体求职策略。

## 阅读路径

- **完整路径**：先读第一章建立统一答题方法，再读第二至第十三章中的共同服务、平台和应用案例，最后用第十四章练习综合追问。
- **推理与平台设计**：第一、二、四、十三、十四章；需要底层 serving 细节时转读第六册、第二十三册和第二十四册。
- **应用系统设计**：第一、二章后，按题目选择 RAG、Agent、多模态、语音或视频章节，再用第十四章做跨场景练习。
- **质量与治理平台**：第一章后读评估、数据标注、安全审核和模型路由章节；评估方法及数据/安全深讲分别转读第七、九、八册。

## 各章概要

- **第一章 系统设计方法论**：把开放题目转成需求、工作负载、容量估算、架构图、风险和取舍。
- **第二章 设计 ChatGPT 服务**：沿多轮请求生命周期分析 API、上下文、会话状态、流式响应和故障处理。
- **第三章 设计训练平台**：围绕数据、实验、作业编排、资源、产物和团队隔离组织训练工作流。
- **第四章 设计推理平台**：处理模型加载、调度、批处理、并行、缓存、扩缩容和服务目标。
- **第五章 设计 RAG 系统**：连接文档摄取、索引、检索、证据组装、生成和质量反馈。
- **第六章 设计 Agent 平台**：设计模型循环、工具调用、状态、权限、审批和可恢复执行。
- **第七章 设计多模态助手**：协调文本、图像、音视频输入、模型路由和跨模态响应。
- **第八章 设计实时语音助手**：围绕双向流、分段处理、打断、会话状态和端到端延迟取舍。
- **第九章 设计视频生成服务**：处理长时异步作业、GPU 资源、媒体资产和结果交付。
- **第十章 设计评估平台**：组织数据集、运行、grader、trace、对比和持续回归。
- **第十一章 设计数据标注平台**：管理标注任务、人工队列、质量控制、数据权限和可追溯性。
- **第十二章 设计安全审核系统**：设计风险检测、策略执行、人工升级、申诉和审计链路。
- **第十三章 设计模型路由与缓存系统**：在模型能力、延迟、成本、负载、缓存和故障回退间做决策。
- **第十四章 系统设计面试题**：用综合题检查需求澄清、容量推演、追问应对和方案表达。

# 01：书册定位与全书架构

本模块决定每册服务谁、承担什么读者结果，以及书系怎样形成可读的路线。凡定位、范围、跨册分工或目录的实质判断，先按模块 03 做册级联网研究；不能从现有目录、旧笔记或记忆直接得出结论。

## 一、建立书册契约

每册定位应明确：

- 目标读者及真实前置；“适合初学者”不能代替前置说明。
- 读者完成本册后能解释、判断、实现或评估什么。
- 本册集中回答的中心问题及其主要任务类型，如课程学习、项目实践、机制解释或参考查询。
- 本册必须覆盖的范围、明确不覆盖的内容，以及前置和后续入口。
- 各章如何共同交付本册结果，哪些构成必读路线，哪些内容确有价值时可作为选读或查询。

这些是定位决策项，不是简介模板。简介应帮助读者判断是否适合、怎样阅读、读完能做什么，并用自然叙述说明各章职责。

本项目当前对前三册的定位假设如下，专题册另按自身目标建立契约。任何定位或跨册分工任务都须先按模块 03 研究，再确认或调整此表；它不能限定外部扫描，也不能因已有目录而默认正确。

| 书册 | 读者台阶 | 主要问题 | 讲解重点 |
| --- | --- | --- | --- |
| 第一册：核心主线 | 懂基本机器学习或深度学习，初次系统学习大模型 | 输入怎样经过模型、训练、生成和验证？ | 建立整体图景，解释核心概念和必要机制 |
| 第二册：进阶与研究判断 | 已掌握第一册主线或具备同等基础；章节声明额外前置 | 目标、架构、数据、系统和预算改变时，结果为何不同？ | 用推理和证据解释方法、实验与取舍；有价值的研究深度可作选读 |
| 第三册：实战手册 | 懂基本模型概念和 Python，准备实现项目 | 怎样实现、测量、排错并留下可复核结果？ | 交代输入、状态、实现、输出、评估和交付；必要理论先简要回顾 |

这里的“进阶”描述书系中的知识台阶，不表示专家是核心读者。进阶主题若属于本册承诺，仍要沿已声明前置讲清；只有超出承诺的扩展才作为选读。

## 二、全书系路线与跨册分工

书系需说明读者可从哪里开始、各册如何衔接、哪些路线适合补基础/专题/项目/查询，以及跳读会缺少什么。册号不自动代表阅读顺序。不同册可以面向不同基础，不要求读者把全书系当成同一种教材连续精读。

每个重要主题应有一个完整主讲位置。其他册可以为本册目标做必要回顾、展示新的应用或链接深入内容；若多册都从定义到机制完整讲解，应明确各自新增的读者结果或重新划分职责。不能为消除重复，把本册承诺所需的解释推给别册。

书型决定组织重点：课程型书籍按前置和能力增长组织；项目型书籍可由持续任务串起概念与实践；参考型书籍应提供稳定分类和交叉入口；解释型专题沿问题、机制和证据展开。混合书型须标明主导阅读路线，不能让教程、解释、操作与规格条目混成无法辨认的路径。

## 三、研究后再对照现有结构

研究范围由书系目标、目标读者和领域确定。简介、目录和相邻书册只能帮助界定对象，不能限定搜索主题或预设最终结构。按模块 03 分别研究：

1. 领域的重要知识、能力目标、前置依赖、核心与进阶主题、新进展和争议。
2. 相近读者任务的教材、课程框架、样章、教学设计指南和相关学习研究。

先建立外部主题与能力表，再对照现有书册。对每个候选记录其读者结果、重要性、前置、来源及证据边界，并决定完整主讲位置、必要回顾、选读/查询入口、其他书册承接或不纳入的理由。教学样本说明某书或课程怎样组织，不自动证明这种安排适用于本书；学习效果主张需直接相关的研究支持。

可用以下问题形成定位矩阵，不要求所有书册采用相同目录：

| 维度 | 决策问题 |
| --- | --- |
| 读者与前置 | 谁会读？开始前要会什么？缺口去哪里补？ |
| 学习结果 | 读完能解释、判断、实现或评估什么？ |
| 本册职责 | 本册集中回答什么问题，承担哪种主要任务？ |
| 主题范围 | 哪些必须进入主线？候选主题最终由哪里承接？ |
| 路线与依赖 | 依赖哪些章节/书册，后续能进入哪里，跳读缺什么？ |
| 跨册分工 | 哪册完整主讲？其他册重复出现时增加了什么结果？ |
| 证据与不确定性 | 决策依据是什么？哪些仍有争议、过时风险或待核？ |

若候选主题服务本册目标、有独立可检查的读者结果，且范围与前置足以连贯讲解，必须安排独立章节或连续篇章，不能为维持原章数塞入旧章。其余候选也要有去向或有依据的不纳入理由。

## 四、从目标到目录

将书册能力逐层映射为章节结果，再映射为核心知识和依赖。目录应让读者看出为什么先学什么、每章交付什么、后文怎样使用，而不是只罗列术语。

设计和复核时确认：

1. 书册目标能追踪到章节；每章有中心问题、读者结果和前后交接。
2. 必读路线满足依赖；选读或查询入口只有在能增加读者价值时设置，并说明跳读影响。
3. 同一主题有完整主讲位置；相邻章节分工清楚，不重复完整教学。
4. 读者不必跳到别册才能理解本册核心承诺；必要前置在本册得到简要解释并提供深入入口。
5. 单章无法兼顾必要覆盖和连贯深度时，扩展或拆成连续章节，标明每篇的结果、边界、依赖和过渡。

简介、目录和正文须同步兑现同一契约。它们承担不同作用：简介说明适合谁、解决什么、怎样读；目录呈现路线和章节职责；正文真正交付知识。

## 五、书册审视流程与完成条件

1. 写明目标读者、前置、读者结果、领域和任务，限定研究边界。
2. 按模块 03 独立研究领域知识和组织经验，记录检索范围、来源和边界。
3. 先建外部主题/能力表，再映射现有书册与章节；不要让旧目录限制发现。
4. 逐册确认定位、章节职责、跨册主讲位置、路线和所有候选去向。
5. 根据证据决定保留、增补、拆分、合并、迁移、另册承接或不纳入。
6. 沿主线及必要的专题/查询路线复核前置、跳读和回接。
7. 将研究证据写入 `research/`，将结构决定、修改、状态和遗留事项写入 `progress/`，同步简介、目录和导航。

只有当读者契约清楚、重要外部候选均有去向、跨册重复与前置断层已处理、结构变化有证据和理由、简介目录与正文相符时，才可标记书册架构审视完成。仍有可能改变定位的未核问题时，继续研究或保留未完成状态。

# 书册定位与全书架构

> 本文件是《项目写作规范》的正式细则模块。原规范章节编号保留，供跨模块引用；本模块与总纲共同构成完整规范。

## 1. 宗旨：让每册书成为书系中的一个完整部分

### 1.1 项目目标与读者

本书系面向希望系统准备大模型算法、工程、推理、Agent 和 AI Infra 相关岗位的读者。读者应逐步能够理解核心概念和技术动机，用公式、代码和例子解释机制，比较方案的收益与代价，定位失败，完成实践，并区分论文结论、公开接口、工程经验、实测结果和未经验证的推测。

默认读者具备一定 Python、机器学习或深度学习基础，但不假定熟悉完整的大模型体系。正文围绕同一问题逐层深入：从问题直觉、必要术语和中间步骤起步，用完整例子及适当图表解释机制，再延伸到专家关心的假设、证据、实现差异、取舍、失败和适用范围。初学者与专家共用一条解释链；既保留核心内容所需的铺垫和深度，也避免重复写成两版或突然堆叠术语。

### 1.2 每册的书册契约

每册都必须说明自己解决的读者问题，以及为何不能被相邻书册替代。开始精修前，应形成一份清楚的书册契约：

- 目标读者与必要前置知识；
- 读者读完后能解释、判断或完成什么；
- 本册纳入和不承担的范围；
- 本册类型，以及它和相邻书册、配套资料的分工；
- 从本册进入后续内容的交接路径。

二十四册应组成有层次的学习体系，而不是把主题分散成一套词典。百科、索引、题库和术语表可以承担查找功能，但不能代替主书对重要机制的连续解释。正文负责讲清，百科负责索引，题库负责追问，练习负责验收，项目负责迁移，论文索引负责提供证据入口，术语表负责统一命名。

### 1.3 简介、目录与正文各自的责任

简介须交代本册缘起、对象、读者所得、边界与读法，并简述各章问题、主线作用及前后衔接。每章完成即更新简介中的短摘要，供读者和维护者识别定位、导航全书；不复述正文或照抄目录。目录呈现可执行路径、主题依赖、能力递进及主线/选读。每篇 Markdown 正文须有明确问题与功能，各节围绕该问题展开并承上启下。

一册书可以是线性教材、专题手册、项目路径或参考工具书。它不必一律按线性课程组织，但必须按自己承诺的方式组织：教材要有学习递进，手册要有任务入口和流程，参考书要有稳定分类与交叉导航，项目书要能从目标走到验证。


## 2. 主流程：先找准定位并稳定骨架，再逐章精修正文

以“册”为精修单位：先完成以下架构审视，方可称整册精修。错字等局部修改按影响范围处理；若发现定位、目录、章节边界或主线问题，须返回相应架构步骤。

### 2.1 固定审视顺序

1. **先定本册定位。** 依据简介、目录、BOOK_SERIES.md、ROADMAP.md 及邻册简介/目录，明确读者与前置、能力目标、边界、类型、独特价值和前后交接；核验简介与目录承诺，定位不清先定契约。本阶段仅参考章名和摘要，不通读正文。
2. **按定位做册级联网扫描。** 循读者目标、边界和目录盲点设问，查近期综述、原始论文、官方文档、技术报告及可信工程资料，识别影响主线的新方向/缺口；按证据质量、成熟度、持续价值、前置依赖、边界匹配和跨册重复评估。不得唯新、唯热或凭搜索结果增章；候选可并入、列选读、转交他册或暂不纳入，均记理由。扫描依据定位、简介、目录、章名及简明章节地图，不通读全书；仅覆盖关系难判时抽查相关片段并记因由。
3. **定册级架构，稳骨架。** 结合契约、简介、目录、章节地图和扫描结果，决定增章、重排、拆并、迁移或收束。章节地图仅记各篇作用、依赖、交接，可由目录、章名和摘要整理；本阶段不逐篇通读或作章级扫描。符合定位且足成独立主线者应增章，否则记保留骨架之据。骨架稳定后校准简介、目录及章节入口。
4. **骨架既定，逐章通读、扫描并定处理方式。** 每轮只处理一章：审中心问题、知识量、主线、前置、重复、跳转、例子和承接，再按本章范围定向扫描。决定保留精修、修改/重写、增补讲次/小节、拆分、合并或迁移，并记录候选、证据、理由。若影响册级边界或章节关系，返第 2–3 步。
5. **依决定深入精修，务求讲透。** 按第 3.3、4 节处理篇幅、背景、机制、推演、例子、边界、公式、代码、图表、引用和配套资料；勿因上下文或单轮工作量压成摘要。每章完成（含新增、拆分章）即更新简介短摘要，说明核心问题、主线作用与前后衔接。跨轮按阶段/章节推进，已定、待办和下一步入口记入 `progress/`；不重复装入全书正文，不以删减正文求一次完成。
6. **逐章完成后整册复读。** 沿简介、目录及主路径复读，核查章节衔接、节奏、篇幅、图表、读者承诺和邻册边界。

审阅、决定、状态、内容去向、风险和交接均记入 `progress/`；联网新知及来源证据记入 `research/`。进度须含已完成范围、当前决定、未解事项和下一步入口，以便分阶段续作。每经上下文压缩/摘要或新会话恢复书籍工作，续作前须从头重读本规范，不可凭摘要或记忆。稳定后的读者承诺须落到简介、目录及章节入口。

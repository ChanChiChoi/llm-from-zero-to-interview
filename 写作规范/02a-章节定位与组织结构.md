# 02a：章节定位与组织结构

本模块读取当册书的总纲，理解整册的中心思想、读者、知识范围和深度，通过联网研究收集具体知识，再组织为全册大纲。每册的有效产出必须写入 `写作规范/全套书不同册的章节大纲结构/<book-目录名>/目录.md` 和对应的 `序号-主题.md` 章节大纲文件；不能只在对话、进度记录或研究记录中提出结构而不更新这些设计文件。产出包含完整的章节与小节标题，以及一段说明各部分中心思想和应覆盖知识点的文字，交给模块 02 展开。

01 决定书册定位与内容承诺，不提供目录；02a 约定各部分讲什么、围绕什么思想、知识怎样分配及标题如何组织。02a 应提供支撑后续核验的研究抓手，如关键术语、机制、方法及其关系；小节内部的教学锚点、叙述步骤、例子、公式、图与代码由 02 决定。02a 的段落是中心思想与知识范围说明，不是正文草稿或讲解方案；可以明确需要达到机制理解、关键推导或工程分析中的哪种知识深度，但不将深度要求改写成固定教学步骤。

02a 承担结构上的全局规划与前瞻判断：既要看各章怎样共同组成一册书，也要看整章内部的知识层次、前置、重点和分工。应预判 02 按各小节中心思想展开后，能否形成完整、聚焦、相互衔接的章节。不能只交付几个宽泛标题，把知识拆解、重点确定与结构补全留给 02；中心思想段落是每个小节明确的写作任务，不是笼统的主题提示。

## 一、两种工作方式

### 1. 基于总纲生成新的大纲

主要输入是 `全套书不同册的章节大纲结构/<book-目录名>/总纲.md` 及用户对本轮任务的要求。完整读取总纲，理解整册围绕什么思想展开、为谁写、要覆盖什么、讲到什么程度。

随后联网收集与本册相关的关键词、术语、概念、方法、机制及应用问题，整理它们的关系，再设计完整的章节、小节和必要的下级标题，为各正文部分写一段中心内容。此方式不以旧章节作为组织骨架，也不先凭记忆列目录再搜索佐证；不要求为了生成新大纲而通读旧正文。

### 2. 基于总纲和当前章节修正大纲

输入包括当册总纲、现行目录、已有章节大纲和当前章节正文。先完整读取总纲及本轮涉及的当前章节，理解已有中心内容、实际覆盖和组织方式；不能只看标题便判断内容充分或不足。整册修正须逐章读取，局部结构修正须读取受影响章节，并核对相关上下游内容。

再根据总纲联网研究，既重新核查现有核心主题，也发现必要的新知识，判断当前章节的中心思想、范围和组织是否仍然成立。不能只搜索旧文没有的内容，并默认旧文中已有的知识和分工都合理。以当前章节为修正基础，有依据地保留、调整、增加、删除、拆分或合并；不是把所有章节自动推倒，也不是只在旧结构末尾添加几个术语。

产出完整的修正版目录和本轮涉及的完整章节大纲，所有正文部分都应有与新结构一致的中心内容段落，不能只交付修改建议或新增标题。已有合理内容应融入修正版；若需要改变总纲的定位或核心承诺，先返回 01 处理。

两种方式都必须联网研究。区别在于是否以当前章节为修正基础，不在于是否研究，也不在于最终产出是否完整。

## 二、从整册思想出发收集知识

### 先理解总纲，再确定检索范围

将总纲中的定位、读者起点、核心任务、覆盖范围、深度及跨册边界联系起来，形成对整册的整体认识。总纲中的主题是研究方向，不是封闭的关键词名单；联网发现本册承诺所需但总纲未逐项列出的知识，仍需纳入候选。

### 联网收集知识材料

按[模块 03](03-研究与证据管理.md) 和[联网数据来源](联网数据来源.md)开展研究。论文、官方技术资料、高质量博客、课程 notes、讲义、教材及源码按问题组合使用。高质量博客与 notes 应进入首轮检索，用于理解机制、发现知识联系和适合读者的组织思路，不能只在读完论文后用来润色。

收集内容可以包括：

- 核心关键词、术语、缩写、中英文名称及同义或历史称谓。
- 重要概念、方法、算法、模型、系统组件和它们解决的问题。
- 方法机制、数据与计算流程、关键假设、适用条件和局限。
- 评估、实验、实现和工程环节，以及有教学价值的失败问题。
- 必要前置、易混概念、方法间的关系、稳定基础和相关新进展。
- 相近读者任务的课程、教材、博客和 notes 如何组织知识及衔接理解。

为重要发现保留来源、含义、关联和支持边界。技术定义与关键主张核对能直接支持它们的原文；摘要和模型总结只能提供线索。同类材料的目录与讲解方式可以参考，不能整份照搬，也不能据此宣称某种安排必然更有效。

“足够多”以能支撑本册范围和深度为准，不设术语数量或来源数量配额。核心领域、必要前置、主要方法关系及适用边界尚不清楚时继续研究；已有材料足以形成有依据的结构时，可以开始组织。不可为了搜集数量把无关热点塞进本册。

研究与组织可以往返。初步分章后，如果发现某个主题只有名称没有实质内容、某些知识关系不明，或存在无法分配的必要知识，应回到资料中补查并调整结构。不能把第一轮检索所得当成固定边界，也不要求穷尽领域后才开始编纲。重要缺口已处理、补查不再改变核心组织判断时，再形成交付版本。

整册的广泛搜索不能代替章内深入挖掘。初步确定章节后，针对每章的核心主题继续检索其内部知识方面与相关术语；形成小节后，再核查是否遗漏重要组成、前置关系或实际问题。利用课程单元、教材详细目录、系列博客、notes 和工程资料发现大主题内部的层次，不停留在综述摘要和几个常见方法名称。搜索所得是否需要独立标题，要结合总纲深度和实际内容关系判断。

## 三、把知识材料组织成章节与标题

### 整理含义和关系

合并同义词，辨认上下位概念，区分概念、方法、流程环节、应用和评估，梳理前置、因果、推导、对比及任务关系。关键词是组织原料，不是直接生成标题的名单；一个术语不必单独成节，一个小节也可以解释多个密切相关的知识点。

基于总纲确定核心、支撑、扩展、查询或不纳入的内容。修正模式还要将这些外部发现与实际正文对照，区分充分讲解、部分覆盖、仅提及、缺失、重复或过时。研究不应被旧标题限制，旧文中合理的关系也不能因外部材料没有相同标题就被忽略。

### 先组织全册，再细化章内

先把总纲的中心思想转为全册的组织主线：整册通过哪些相互关联的主题形成完整认识，这些主题各自承担什么作用、为什么需要相互承接。可以围绕共同问题、机制关系、能力依赖或任务过程组织，不机械采用“背景—目的—意义—定义”的统一模板，也不把资料分类直接当作书的结构。

在这条主线下聚合知识，确定各章的中心思想、范围和前后交接，再设计章内标题。全册主线统领章的中心思想，章的中心思想统领小节，小节共同支撑所属章，而不是各自成为互不相关的术语介绍。标题顺序服从知识依赖和主题关系，不服从搜索结果顺序；这里不安排小节内部的叙述步骤。

各章共同兑现总纲，避免多个章重复完整主讲同一知识，也避免读者必须跳到后文才能理解当前主线。明确完整主讲与必要回顾的位置，具体回顾如何写由 02 决定。新增主题确需独立展开时可以增章；单章无法兼顾必要覆盖和连贯深度时可以拆分，不为保持旧章数压缩核心解释，也不按篇幅机械切章。

中心思想实质重复、没有足够独立内容的章节，可以合并或并入相关章；但不能仅因它是必要前置、暂时搜到的材料少或预计篇幅短就合并。重要基础也可以独立成章，先判断是否研究充分及是否需要集中建立认识。拆分与合并以知识关系和读者需要为依据，不能将知识点数量、篇幅或术语数量直接换算成章数。

### 章节要有足够的内部展开

章是承担一项相对完整主题的知识单元，不是几个术语的概览，也不是把多个复杂方法各列一个标题就算完成。章的中心思想之下，应有足以支撑范围与深度的内容层次，让读者沿知识关系逐步建立认识。小节承担其中有区别、值得独立展开的知识方面；下级小节进一步划分该方面内部的重要组成或问题。章、节和下级节的范围应逐层具体，而不是只有标题变长、知识仍挤在一起。

不默认每章只安排四至六个概览小节，也不设置统一最低节数。复杂主题只有少数宽泛标题、中心思想段落却塞入多个独立大主题时，必须继续研究和细化，不能将结构工作留给 02。在粗略合并与有内容依据的细分之间，优先选择能让 02 聚焦的细分，并使用下级标题保留共同上位主题。“避免碎片化”只针对空洞拆分、重复与失去联系，不是少设标题、合并不同问题的理由；充分展开与不凑数量应同时成立。

章内细化按以下过程完成：

1. 从本章中心思想识别需要分别展开的知识方面，而不只罗列方法名。
2. 对各方面继续研究其内部概念、关键组成、机制环节和实际问题，补足读者从声明前置进入所需的知识联系。
3. 将有独立中心思想和实质知识范围的内容组织为小节；若小节还包含多个需要分别展开的方面，继续设置下级标题。
4. 沿标题与中心思想连续阅读，检查是否突然从概念跳到复杂方法、从方法名跳到结论，或将实现、评估与取舍压在一句“相关应用”中；有缺口则补查并重新组织。
5. 合并只是在重复、仅起过渡作用或没有独立知识内容的标题，使层次充分而不零碎。

针对算法或工程主题，可以从问题与前置、对象与组成、内部机制、实现相关知识、评估、资源取舍、适用条件和失败问题等方面继续发掘。它们是发现知识的方向，不是要求每章照抄的一套标题，也不是规定讲解形式。是否纳入以及独立成节，取决于本章中心思想、总纲深度与研究结果。

例如某章需要深入讨论偏好优化，仅列“PPO”“DPO”“其他方法”并为每项写一句概述，通常还不足以表达完整知识结构。应研究这些主题内部哪些知识方面需要独立组织、哪些可以共用、哪些属于方法比较与工程判断，再形成相应层级；不能简单为每个算法复制同一组子标题。02a 只明确这些知识方面及其中心思想，伪代码、贯穿实例、公式等具体讲解方式仍由 02 决定。

并列标题应处于相近的知识层次、采用协调的划分依据，避免把一个领域与另一个领域的局部细节随意并列。上下级不能只是重复换词，下级范围应属于上级主题。标题可以直接用知识名称，也可以结合问题、作用或关键关系命名，不要求统一句式。层级深度和小节数量可以不同：标题细化的是知识任务，02 仍自主决定各任务内的讲解形式与正文表达。

## 四、产出：标题大纲与中心内容段落

### 文件与职责

产出统一写入 `全套书不同册的章节大纲结构/<book-目录名>/`：

- `总纲.md`：01 的输入产物，02a 不在其中编写目录。
- `目录.md`：02a 的全册标题总览，列出完整章节与小节层级，链接各章大纲文件；各章的中心内容概述可以随章标题列出。
- `序号-主题.md`：02a 的各章详细大纲，包含完整编号标题，以及各正文部分的中心内容段落。

各章大纲文件保存详细设计，`目录.md` 汇总同一套标题，不另行维护一套不同的结构。修订时同步标题、编号、层级、文件链接及受影响的中心思想；发生拆章、合章或内容迁移时，同时处理原位置和新位置，避免重复或遗漏。

新建模式交付全册目录和全部章节大纲。修正模式交付完整的现行目录，以及本轮受影响章节的完整大纲文件；同时核对未修改部分的衔接。不能把局部修正称为全册大纲已重新设计。

### 一段话说明中心思想与知识点范围

中心思想说明“一组知识共同围绕什么核心认识或问题”，知识范围说明“为形成这项认识，需要涉及哪些方面”。前者不是术语集合，后者也不是与中心思想无关的清单。两者在一段话里自然联系，不要求分别写成字段，也不提前替正文证明结论。

每章先用一段话说明本章中心思想与主要知识范围，各小节同样写出自己的中心思想及应涵盖的知识点，必要时说明知识关系、深度和分工边界。深度承接总纲，例如区分理解目标含义与掌握关键推导；这属于知识要求，不是指定讲解形式。

中心思想段落还应在有助于限定范围时，给出足够具体、可继续检索和核验的研究抓手，例如关键术语、方法/机制名称、组成对象、关键变量或有意义的对比关系，并说明它们与本节中心问题的联系。抓手应来自本轮研究和本册语境，不为凑数量堆名词；不是每段都必须列术语，也不要求另设“关键词”字段。判断标准是：02 能否据此识别需要进一步查证的概念与关系，而不必重新猜测本节具体讲什么。

研究抓手不是正文脚本。02a 不规定用哪个具体案例或类比、按什么叙述顺序展开、展示哪些中间步骤，也不预写公式推导、图表布局或代码。02 应继续核验大纲中的知识抓手，并自主选择适合读者的教学锚点和表达形式。可以写“本节聚焦 A 与 B 在 C 条件下的关系及其边界”，不应写成“先用某案例引入，再逐步计算 A，最后画图总结”。

中心思想段落要足以限定本小节的焦点，同时为必要细节留出展开空间。不能仅写“全面介绍某算法及相关实践”，也不能将机制、多个独立工程问题、评估与方法比较全挤进一段清单，期待 02 自行决定主次。知识任务过载时回到标题层级细分，各小节分别写清中心思想与知识方面，再从整章角度检查是否完整、连续且没有无意重复。

段落应写出具体的知识范围，不能只用“介绍某概念、帮助读者理解原理”填充；也不能仅列术语或把标题换句话说。不要求每段机械包含相同要素，不强制填写目的、背景、意义和使用场景。不要写成“先举一个例子，再画流程图，最后推导公式”等讲解方案，也不写定义解释、公式推导、教学代码或示例正文。

如果某个上级标题下还有下级标题，上级段落概括统领思想，下级段落分别说明各自的知识范围，不能重复同一段话。只有组织分组作用的标题只需说明其统领范围，不要求安排独立正文。

以下仅为一章中两个小节的局部片段，用于展示格式与段落粒度，不是完整章节，也不表示两节即可支撑这一章。内容为教学设定，不是经过研究的真实书册大纲：

```markdown
# 第 1 章 偏好数据与奖励建模

本章围绕人对回答的比较怎样成为模型训练可用的信号，连接偏好数据与奖励建模两个主题。涉及回答比较、偏好标注、奖励模型及评分的含义，形成对数据与评分关系的认识；策略更新由后续章节承担。

## 1.1 偏好数据：同一个问题下怎样比较回答

偏好样本的核心是有条件的回答比较，而不是脱离问题的好坏标签。本节围绕这一认识，涉及 prompt、chosen、rejected 的关系，以及标注标准、样本覆盖和标注分歧，使数据的表达与信息边界成为一个完整主题。

## 1.2 Reward Model：把回答比较变成整条回答的分数

奖励模型将回答比较关联到模型评分，评分与人类偏好之间的联系是本节的中心。知识范围包括模型输入与输出、偏好训练目标、分数的含义及适用边界，与前节的数据主题相承接，具体策略优化算法另行组织。
```

实际交付必须补齐全章的知识层次，不可照搬上述片段作为完整大纲。需要更细层级时，使用 `### 1.2.1 …` 等标题，并为相应部分补上中心思想与知识范围，不能仅为保持示例的简短而省略必要小节。

## 五、交给 02 与完成条件

交接给 02 时明确有效总纲、全册目录和待编写章节大纲的路径。02 根据各小节中心思想、知识点范围和研究抓手继续联网核验、扩充知识，并自主决定教学锚点、讲解形式、叙述步骤和正文内容；这些都不属于 02a 的产出。

还须核查章内挖掘是否充分：核心主题内部的重要知识方面已经形成适当层次，没有用少数宽泛标题掩盖未研究的内容，没有让一个小节包揽多个需要分别展开的大主题，也没有靠空洞拆分凑数量。不能仅因已有若干小节或目录看上去整齐，就标记全章大纲完成。

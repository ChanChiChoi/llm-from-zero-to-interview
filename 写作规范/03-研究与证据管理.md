# 研究与证据管理

> 本模块规定外部研究、证据范围和引用记录。技术事实与结构决定必须有可追溯依据；书籍审阅和修改历史记入 `progress/`，不记入 `research/`。

## 5. 资料研究与证据管理

### 5.1 研究范围与免做条件

核心技术结论、重要知识扩写/重写、书系/书册/章节范围变化，以及模型、论文、benchmark、框架、API、训练和部署等时效内容，必须先联网查阅原始资料。结构研究早于详细目录设计、拆并决定和正文改写；外部扫描用于发现领域知识、依赖和组织经验，不是为现有目录找佐证。

只改错字、格式或不影响主题、结构、结论的局部措辞，可免做新扫描。同一问题的研究仅在范围、时间窗和关键版本仍适用时复用；快速变化领域出现新版本或新证据时补查。既有简介、目录、正文和本地笔记只能界定研究对象，不能代替外部资料或限定主题清单。联网受阻时只记暂定判断与待查问题，不得将结构方案称为最终结论。

### 5.1.1 共用研究流程

书册定位/组织、章节定位/组织和章节正文实质编写/修订都必须按以下研究原则核对外部资料，范围与资料深度按任务调整：册级侧重领域与书型组织，章级定位侧重主题、前置和教学组织，正文修订侧重方法机制、事实、效果主张及有价值的知识补充。纯错字、排版、公式渲染等不改变知识含义的局部修改可免新检索；公式语义、适用条件或结论有变化时须复查依据。

1. **界定对象与读者**：写明目标、能力结果、大致主题和需核对的时间范围；不把现有标题当作完整候选清单。
2. **独立扫描两类资料**：一类梳理领域知识、机制、前置、评估、边界、近期变化及争议；另一类查相似读者任务的教材样章、课程和教学研究，了解组织方式及适用条件。
3. **核验关键判断**：打开论文、标准、官方文档或教材原文，检查具体段落、数据、方法或样章。新主题的学科资料须支持其定义、机制、边界或重要性；组织资料须支持它与读者任务和能力顺序的关系。主张某种编排提升学习效果时，另需直接相关的学习研究。不能仅靠摘要、单篇论文、单本目录或社交帖定结构。
4. **建立外部主题表并对照书稿**：在查看现有目录前，记录候选主题、读者结果、前置、来源、成熟度/时效和主题关系；再标记正文覆盖充分、仅提及、缺失、重复、前置不足、过时或超出目标。
5. **决定去向并检查路线**：标明由本章/本册主讲、必要回顾、选读/参考入口、其他章节/书册承接或不纳入，并说明证据与读者理由。检查缺口、重复、前置断层和读者跳转。

### 5.1.2 书系和书册级研究

在确定每册定位、全书目录或跨册分工前：

- 扫描知识框架、课程/能力框架、综述、关键论文、标准和官方资料，区分稳定基础、核心能力、进阶主题、跨领域联系、时效变化和争议；快速变化主题记录检索日期，并兼看仍有效的基础来源。
- 选择目标读者与任务相近的教材、课程和教学设计资料，记录样本面向谁、解决什么任务、如何安排前置与主线、必读/选读/查询。目录只能证明该书这样组织，指南只能证明其提出建议，效果主张须有相称的学习研究。
- 逐项决定在书系中的主讲位置、回顾点、参考入口或不纳入理由，并核对全书能力路线和前置关系。若主题服务本册目标、能形成独立可检查的结果，且范围与前置足以支持完整连贯讲解，必须新增章节或连续篇章。
- 未发现新主题也要记录扫描范围、时间窗、主要来源类型和现有结构仍满足目标的理由。停止条件是新检索不再带来会改变结构的重要主题；这不代表穷尽全领域。

### 5.1.3 章节级研究与结构审视

书册骨架稳定后，逐章执行：

1. 界定本章服务的书册能力、目标读者、大致主题和时间范围；单章任务也要先读清本册目标。
2. 扫描本章主题的基本概念、主要问题、方法/机制、任务、评估、工程环节、边界和前置；时效内容查当前版本，基础机制回溯关键来源，并留意现有目录外的候选主题。
3. 查相似读者任务的教材章节、课程单元和教学研究，比较其前置、范围、结果及相邻内容，并记录适用读者与限制，不照搬目录顺序。
4. 完成外部主题图后再对照正文和相邻章，标记讲清、仅提及、缺失、重复、前置不足、过时或不属于本章目标，并检查全书交接。
5. 确定中心问题、读者结果、真实前置、必需主线、支撑内容以及（如有价值）选读与后续入口；按目标决定保留、扩写、拆分、合并、迁移、新增或不纳入，并说明证据和读者理由。
6. 检查每节是否服务结果、顺序是否符合依赖/任务、读者能否看见承接、高价值候选是否有去向。若发现改变书册分工或路径的内容，返回书册级研究，不在章内消化。

达到独立成章条件的新主题必须独立成章或形成连续篇章，不能因旧章尚有篇幅、原章数或改动成本而塞回旧章。只改正文表达且不改变主题、结构或结论时，可按 §5.1 免做新研究扫描。

### 5.1.4 检索、证据记录与完成门槛

- 使用中英文关键词、同义词、缩写及旧称/新称。把领域知识检索与组织经验检索分开；示例检索角度包括 `topic + survey/standard/original paper`、`audience + textbook sample/syllabus/learning outcomes`。按主题迭代，不要求机械使用全部组合，也不要过早用过多限定词排除结果。
- 先宽口径发现术语和关键来源，再沿参考文献、被引资料、官方版本记录和课程链接追查。新资料改变主题图或提出反例时，更新检索词再查。
- 记录平台/资料库、实际检索词、日期、语言、时间窗/版本、筛选条件和未覆盖范围。PRISMA-S、Cochrane 是系统综述规范；本项目借用透明记录和迭代检索，不要求把每次审视做成系统综述。
- 摘要、AI 总结和二手文章仅作线索。重要来源要查原文，核对作者、日期/版本、范围、方法和限制；引用链不能替代阅读。

首次进行教材/课程组织研究时，可参考[起步来源](参考资料/研究组织与学习设计入门来源.md)；这些资料帮助提出问题，不替代当前主题的直接证据。

每轮研究至少记录：

| 项目 | 内容 |
| --- | --- |
| 问题与范围 | 判断目标、读者、覆盖主题及暂不研究的内容 |
| 检索记录 | 日期、平台、完整检索词、语言、时间窗/版本和筛选条件 |
| 来源卡 | 标题/链接、作者或机构、日期/版本、类型及实际阅读范围 |
| 证据说明 | 来源支持与不支持什么、条件、强弱及来源冲突 |
| 未解边界 | 无法访问、版本不明、来源矛盾或待核事实 |

最终结构决定前确认：领域与组织经验均已扫描；关键来源已读原文且支持范围明确；基础、近期变化、前置和交叉关系已进入主题表；现有章节的缺口、重复和跳转有处理；达到独立成章条件的主题已安排；范围、来源限制、分歧和未解问题已记录；继续搜索不再带来会改变决定的重要主题。未达门槛时只能报暂定结论和缺失证据，不能称结构审视已完成。

### 5.2 证据类型与结论范围

| 来源类型 | 可以支持 | 不能单独支持 |
| --- | --- | --- |
| 论文、技术报告 | 方法定义、实验设置、作者报告的结果和限制 | 当前线上接口行为或普遍生产性能 |
| 官方文档、模型卡、发布说明 | 已公开的能力、参数、配置和产品说明 | 未披露的训练细节或内部机制 |
| 教材、样章、教学/内容设计指南 | 实际组织方式或明确提出的建议 | 对所有读者有效，或建议已由因果研究证实 |
| 课程框架、能力模型 | 建议覆盖的范围、核心与选修层次 | 对本书读者、岗位或篇幅的自动适配 |
| 学习研究与综述 | 指定读者、材料、任务下的效果或限制 | 脱离条件对所有学科和读者的普遍效果 |
| 固定 revision 源码 | 指定版本的实现路径 | 所有版本或生产部署结果 |
| benchmark / harness | 指定任务、环境、工具和评分口径下的结果 | 裸模型的一般能力 |
| 本地实验、教学代码 | 声明环境和输入下的观察 | 论文、模型或生产复现 |
| 社区文章、榜单、社交信息 | 候选方向与观察线索 | 未经交叉核验的确定事实 |

重要判断尽量用不同类型来源交叉核验。记录分歧、不可访问资料和未解决问题；证据不足时降低确定性、缩窄结论或标为待核验。不得从单个模型、配置、effort、provider、harness、数据集或环境外推整个模型家族或生产场景。

### 5.3 引用与研究记录

引用应贴近结论并直达论文版本、官方页面、固定 revision、release 或具体 benchmark。来源须支持所在句子的实际含义；正文说明证据为何相关、支持到哪里，不让读者从链接清单自行拼结论。`research/` 保存联网发现的新知识点及来源、日期/版本、证据边界、分歧和待核项；书籍定位、修改决定、审阅历史和交接只记在 `progress/`。

涉及数字时核对指标、分母、数据集、配置、硬件、测量条件和时间；条件不近似时说明不可比因素。教学数值须标为示例或假设，不能写成论文、产品或生产实测。闭源模型要区分官方披露、外部评测、实现推断和社区猜测。

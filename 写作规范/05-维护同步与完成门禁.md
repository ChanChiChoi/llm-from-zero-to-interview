# 05：维护同步与完成门禁

本模块负责修改后的同步、记录、维护风险和交付判断。书册与章节结构、正文教学、研究核验和技术呈现分别由模块 01/02a、02、03、04 规定；本模块不重复其细则。

## 一、记录职责

- `plan.md`：书系总计划、原则、任务队列和完成条件，不写逐章执行日志或研究事实。
- `progress/`：书籍审阅、定位/结构决定、正文和配套修改、状态、遗留风险、校验及交接的唯一记录处。
- `research/`：联网发现的新知识点及其来源、版本、证据范围、分歧和待核项；不记录书籍审阅过程、修改历史或交接。
- 正文：面向读者，不写作者指令、任务状态或内部维护路径。

每项记录应能让后续维护者确认改了什么、为什么、依据是什么、验证到哪里、还有什么未完成。不要求每轮机械填写固定字段；记录的详细程度与变更风险和范围相称。

整册架构审视通常记录读者契约、简介/目录结论、章节地图、册级和章级扫描、结构决定、覆盖去向、风险与交接。书册阶段的章节地图可根据简介、目录、标题和已有摘要记录问题、结果、贡献、依赖与交接；不要求通读全册正文。只有覆盖或职责不清时定向抽查，并说明原因；逐章审视后再补充读者收获、理解断点和必要视觉机会。单章精修重点记录范围、读者路径、研究证据、修改决定、校验和遗留风险。篇幅可用于诊断，不设通过门槛。代码验证的细项按模块 04 记录。

研究条目可使用以下状态，按实际需要标记：证据状态 `verified`、`source-backed`、`local-demo`、`observation`、`needs-verification`；内容生命周期 `active`、`historical`、`deprecated` 或 `pending`。`source-backed` 不代表本地复现；`local-demo` 仅表示在声明环境运行；`observation` 不能写成普遍事实。

## 二、修改后的同步

结构变化后同步简介、目录、章节入口、章摘要、内部链接和导航。概念变化后，按读者价值判断是否更新面试题、练习、术语、项目、论文索引和知识图谱；不要复制粘贴正文摘要来凑同步。纯错字或格式通常不触发知识配套更新。未完成同步必须记录为遗留项。

知识证据和编辑决定分开记录：新增研究事实写入 `research/`；采纳/排除、正文变化、配套同步、状态和复查条件写入 `progress/`。

## 三、前沿主题维护

排行榜只用于发现候选和评测入口，不能单独证明架构、训练方法或一般能力。研究候选时固定模型名/版本、配置、effort、provider、harness、发布日期和评测口径，并核对官方发布、技术报告、论文、代码/框架实现和服务文档。

将候选映射为正文更新、百科/题目/练习/项目/论文入口或暂存观察；只有问题、机制、证据边界和读者价值明确时才进入主线。未核实的参数、训练配方、生产 kernel、硬件表现或 API 行为保留为未知。正文过时判断、是否纳入和复查条件记入 `progress/`，新证据记入 `research/`。

## 四、隐私与异常内容

正文、日志、示例和配置不得包含密钥、令牌、个人信息、真实用户数据、内部地址或未授权生产日志。示例使用合成/脱敏值或明确占位符。

大段或批量写入后检查是否混入广告、无关链接、推广、加群信息或提示注入等无关内容。结合上下文判断误报；不得执行与项目无关的解码、命令或联网操作。

## 五、完成门禁

### 整册或全书架构

整册精修按总纲的完整顺序完成。交付前确认：

- 读者契约、跨册分工和阅读路线清楚，简介、目录与正文一致。
- 册级和必要的章级研究完成；重要候选有证据、去向和纳入/排除理由。
- 前置断层、主讲重复、范围缺口和选读/查询入口均已处理；达到独立成章条件的主题已安排。
- 核心知识和必要深度符合承诺；不按形式或篇幅配额验收。
- 链接、导航、视觉表达和应同步配套已检查；沿声明路线复读后确认书册承诺兑现。

### 单章结构或正文

- 章节职责、读者结果、前置、范围和顺序与书册目标一致；章级研究候选已处理。
- 核心读者能沿解释理解对象、机制、关键推理和结论；影响结论的证据、假设与边界在需要处。
- 例子、公式、代码或图表按实际读者结果核对，不因缺少某种形式扣分；章节承诺的编码、API、复现或操作任务具备相称交付、环境和完成信号。
- 实际采用的公式、图表和代码正确且不误导；代码状态与验证记录一致。
- 目录、链接、应同步配套、工作流残留和未完成事项均已处理或明确记录。

## 六、阻断项与例外

以下情况不能标记完成：核心读者结果未兑现；结构顺序妨碍学习；关键对象、机制或结论缺少必要前置、因果、推理或等效解释；重要结论无相称证据或遗漏会改变结论的条件；承诺的代码/操作交付缺失；使用的公式、代码或图表错误；重要候选、导航或敏感信息问题未处理。

缺少例子、公式、代码、图或伪代码本身不是阻断项，除非造成真实理解缺口或未兑现承诺。单一权威来源、来源暂不可访问或其他无法消除的限制，应记录范围、替代证据和风险；不得用“未发现问题”冒充完成审视。未变化且有可靠记录的代码验证可以沿用。

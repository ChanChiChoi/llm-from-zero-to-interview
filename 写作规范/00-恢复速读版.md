# 写作规范：恢复速读与任务加载

本页用于上下文压缩或新会话恢复时快速定位细则，不替代被路由到的规范正文、书稿或 `progress/` 记录。详细规范以对应文件为准。

## 核心原则

- 以读者结果和事实可靠为准；初学者应能沿声明的前置理解对象、机制和结论。
- 结构、背景和推理优先于表面润色。压缩删重复，不删必要前置、因果、中间结果、证据或边界；超出单章承载时扩写或拆分。
- 例子、伪代码、公式、代码、图表、类比和专家扩展按读者卡点选用，不是配额；示例模板是参照，可调整、合并或不用。
- 方法讲解按需交代问题背景、目标、相关旧方法及不足、当前回应、流程、证据和限制；有具体内容且便于定位时，可显式标出背景、目的、解决的问题、意义、适用场景和优缺点，不要求填满栏目。
- 影响结论的前提、证据和限制必须讲清。新事实按模块 03 核查；公式、代码、图表按模块 04 核查。
- 书册定位/组织、章节定位/组织、章节正文实质编写/修订都必须按各自范围联网研究：书册查领域与书型组织，章节定位查主题/依赖/教学组织，正文修订核对方法、事实、效果并判断知识扩充。纯错字、排版、公式渲染等不改知识含义的局部修正可免新检索。

## 按任务加载

| 任务 | 顺序 |
| --- | --- |
| 全书统一精修或重定书册范围 | 模块 01 → 模块 03 书册级联网研究 → 模块 02a 章节定位/组织 → 模块 03 章级联网研究 → 模块 02 正文实质编写/修订及联网校对 → 模块 04（涉及公式、代码、图表时）→ 模块 05 |
| 只审书册定位、组织或跨册分工 | 模块 01 → 模块 03 书册级联网研究 → 模块 05 对应验收 |
| 只审章节定位、职责或内部结构 | 模块 01（影响册级分工时）→ 模块 03 章级联网研究 → 模块 02a；需要实质改正文再读 02 + 模块 03 正文核验 |
| 章节内部实质重写，且定位、职责、范围和结构已确认 | 模块 02 + 模块 03（联网校对核心事实、方法主张，并判断知识扩充需要）+ 已确认的章节契约和进度记录；公式/代码/图表读模块 04，交付时读模块 05。可跳过模块 01 和 02a。仅错字、排版、公式渲染等不改语义的局部修正，可免模块 03 |
| 只改公式、代码、图表或配套/维护 | 模块 04 或 05 的相关部分；同时改正文解释时读模块 02 |

整册或跨模块任务按完整顺序读取；局部任务读取表中所需模块的相关完整章节。若发现范围、职责、依赖或重要结论变化，返回相应上游步骤；范围不清时读全部相关模块。

## 恢复步骤与记录位置

1. 上下文压缩或新会话恢复书籍工作时，先读本页和对应 `progress/` 交接记录。
2. 按任务表读取相应细则；全书精修或本规范跨模块修改时，再完整阅读总纲与涉及模块。不要只凭摘要改写正文或判断事实。
3. 书籍决定、修改、状态和交接写入 `progress/`；联网发现的新知识及来源证据写入 `research/`；总计划和任务队列写入 `plan.md`。

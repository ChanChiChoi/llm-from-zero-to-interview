# 写作规范：恢复与任务路由

本页用于会话恢复和任务分流，不替代规范正文、书稿或 `progress/` 交接记录。先确定任务改变的是书册结构、章节结构、正文内容还是呈现/维护，再读取对应文件。

## 恢复顺序

1. 读取本页和相关 `progress/` 交接记录。
2. 按任务路由读取完整的相关规范章节；跨模块或范围不清时，读取总纲和所有涉及模块。
3. 按相应模块研究、修改、验证并记录。摘要不能代替需要核对的规范或进度原文。

若用户明确要求不读取既有 `progress/`，遵守该要求，并按可用材料独立完成本轮工作。

## 任务路由

| 任务 | 必读与顺序 |
| --- | --- |
| 整册/全书架构或跨册分工 | 01 → 03 册级研究 → 01 稳定书册骨架 → 03 章级研究 → 02a 逐章结构（按需）→ 02 正文（涉及实质改写时）→ 04（涉及图表、公式或代码时）→ 05 |
| 章节职责、范围、顺序、拆并 | 03 章级研究 → 02a；影响书册目标或跨册分工时先读 01；随后按需读 02、04 和 05 |
| 已定结构章节的实质正文写作/修订 | 02 → 03 正文核验；涉及图表、公式、代码时读 04；交付同步读 05 |
| 只改错字、格式或不改语义的局部表达 | 对应模块；通常可免新研究。若同时属于整册/结构审视，仍执行上游流程 |
| 只处理图表、公式、代码或引用 | 04；若同时改变正文解释，增加 02；交付同步读 05 |
| 配套资料、记录、交接与验收 | 05；内容/事实有变化时再读对应模块和 03 |

涉及书册定位、章节结构或正文知识含义的实质工作都须按模块 03 联网研究。书册级研究关注领域和书型组织，章级结构研究关注主题、依赖和教学组织，正文研究关注事实、机制、效果及知识缺口。仅不改变知识含义的局部修正可免新检索。

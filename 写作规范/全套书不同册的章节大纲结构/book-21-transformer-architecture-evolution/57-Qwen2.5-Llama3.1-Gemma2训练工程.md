# 第五十七章大纲：Qwen2.5、Llama 3.1 与 Gemma 2：开放权重模型的训练工程

本章以 2024 年公开的 Qwen2.5、Llama 3.1 与 Gemma 2 为固定案例，讨论开放权重模型的训练工程可以从哪些公开材料中观察。读者应能比较各报告披露的数据规模与处理、tokenizer、训练阶段、基础设施和发行条件，并区分权重可取得、训练配方可复现、数据可审计和许可证可用这些不同事实。本章不把版本间自报 benchmark 排成架构排名，也不声称训练语料或完整配方已经开放。

## 57.1 先锁定版本与“开放”的对象

本节明确三个固定证据对象及其时间范围，并把“开放权重”限定为可取得特定模型权重。权重、模型配置、tokenizer、训练代码、原始数据与清洗流程、评测记录和使用条款是不同的发布物；公开其中一部分不能自动推出其他部分也公开。各系列的模型卡、论文和许可证按确切版本读取，避免由系列名称推断同一训练做法或相同使用条件。第 54 章主讲 LLaMA 家族的架构演进，第五册详讲数据、tokenizer、预训练与后训练机制，第 59 章负责一般模型横向比较。

## 57.2 Qwen2.5：数据配比、专业数据与分阶段训练

本节围绕 Qwen2.5 报告所述的训练扩展，说明从 Qwen2 报告的 7 万亿 token 增至 18 万亿 token 只是规模变化的一部分，还包括数据筛选与混合、代码和数学领域数据、不同尺寸的模型系列，以及预训练与后训练分阶段安排。需要区分开放权重的稠密模型与报告中面向托管服务的专有 MoE 型号；也要按尺寸核对发行许可。报告披露的过滤和数据类别不等于可下载的完整语料或可逐项复现的配比，长上下文训练阶段也不能直接等同于所有推理接口的有效能力。

## 57.3 Llama 3.1：tokenizer、数据规模与训练系统可靠性

本节依据《The Llama 3 Herd of Models》的版本说明，明确论文标题虽为 Llama 3，但其中结果对应 Llama 3.1。围绕 405B 稠密模型与 15.6 万亿文本 token，说明 128K 词表、非英语数据与数据清洗、训练数据混合和 scaling-law 试验怎样共同进入训练工程；报告还描述了从 8K 序列预训练到 128K 持续训练，以及大规模并行、故障检测和 checkpoint 恢复等基础设施。字符/token 压缩比只代表论文指定样本，不替代中文、代码或其他语种的独立测量。数据配比和 tokenizer 的一般原理回链第五册，Llama 各代的 block 配置回链第 54 章与第 17 章。

## 57.4 Gemma 2：小模型以知识蒸馏改变训练信号

本节比较 Gemma 2 的 2B、9B 与 27B 训练路径：报告分别给出 2、8、13 万亿 token 的预训练规模，说明 2B 和 9B 采用来自较大教师模型的知识蒸馏，而 27B 从头训练。解释蒸馏与只拟合单个观测下一个 token 的训练信号有什么不同，并指出该策略是报告中这两个尺寸的具体选择，不是所有小模型的普遍配方。报告对数据来源的描述以英语为主，并不证明其具有最强多语言能力；模型权重、数据说明和当前适用的 Gemma 条款应分别核对。蒸馏的一般训练机制回链第五册相关章节。

## 57.5 三组公开资料能支持什么，哪些仍未知

本节把三个固定版本放在同一证据维度下比较：披露了哪些数据与训练阶段、可取得哪些模型产物、哪些过滤细节或原始语料仍无法从所引材料复现，以及许可证如何因系列和尺寸而异。FineWeb 作为对照说明，公开训练数据集、处理代码和消融结果会进一步提高数据处理的可检查性，但不能据此推断三个模型内部采用了同一方法。不同报告的模型尺寸、数据、评测和许可证各不相同，所以只总结有直接依据的训练工程选择，不作总体质量、开放程度或效率排名；一般比较协议与模型选择留给第 59 章。

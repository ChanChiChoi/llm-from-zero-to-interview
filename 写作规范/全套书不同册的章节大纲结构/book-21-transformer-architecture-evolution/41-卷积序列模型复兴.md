# 第四十一章：卷积序列模型在 LLM 中的复兴可能性

本章围绕卷积在现代语言模型中的三种不同角色展开：在 attention 前加入局部邻域混合、以长卷积承担序列混合算子、以及把门控卷积与 attention 组成混合主干。读者应能区分固定相对位移滤波与 query-key 内容寻址，说明训练时全序列卷积和自回归增量计算的成本路径，并按具体模型与训练/评测条件判断卷积证据的范围。本章聚焦卷积机制、代表性 LLM 设计与证据边界；Hyena 算子细节由第三十九章主讲，早期混合算子由第四十章主讲，跨架构选型由第四十二章承担。

## 41.1 卷积复兴的三个层级

本节区分短程因果卷积、长程因果卷积和卷积参与的混合主干：短卷积以共享的位移权重整合邻近 token，长卷积将滤波范围扩至整段序列，混合模型则把卷积、门控、状态更新或 attention 放在同一信息路径的不同位置。内容对比卷积按相对位置固定混合与 attention 按 query/key 内容形成读取权重的差异，并指出扩大理论感受野并不自动提供任意历史位置的精确寻址；第三十九章的 Hyena 递归和第四十章的早期混合设计作为前置，不在此重复推导。

## 41.2 局部深度卷积怎样为 attention 注入邻域信息

本节说明深度卷积如何对每个通道独立聚合当前与相邻历史位置，以及残差卷积怎样把这一局部修正加回原表示。内容聚焦在 Qwen3 研究中将 Conv1D 放在 Q/K/V 投影之后、attention 计算之前的设计：邻近 token 先影响 query、key、value 表示，再由标准 attention 继续进行全局交互；覆盖位置消融、kernel-size 与残差模块消融的实际结论，不把作者提出的局部组合解释当成已被单独证明的普遍机制。

## 41.3 长卷积怎样进行全序列混合

本节说明固定因果滤波器怎样通过按相对位移共享的系数汇总长程历史，以及显式长核、结构化或隐式生成核的参数化差异。内容涉及直接计算与 FFT 因果线性卷积、补零与循环回绕的区别，以及长核学习中核平滑正则化的作用；以 H3 中用长卷积替换 SSM 核的实验说明长卷积可成为序列混合层，同时明确该语言模型仍保留 attention 层，详细 Hyena 核生成和阶递归仍归第三十九章。

## 41.4 混合主干中的门控卷积：StripedHyena-7B

本节以 StripedHyena-7B 说明卷积复兴如何表现为完整模型中的混合信息路径。内容说明该发布包含 base 与 chat 模型，模型将 attention 与 Hyena operator 中的门控卷积组合；引用作者发布的 ZeroScrolls 结果时保留零样本任务和分项表现，指出部分任务领先、部分任务落后，且整体结果不能把贡献单独归给卷积。FIR 窗口状态与 IIR 定长状态仅作为该模型的滤波表示实例，不推广为所有卷积架构的固定实现。

## 41.5 全序列训练与逐 token 生成的计算差异

本节比较局部有限核、覆盖全序列的长核及其递归等价表示在完整序列训练和自回归生成中的工作量与状态需求。内容按 batch、通道、序列长度和核宽区分朴素卷积的乘加规模与 FFT 线性卷积的序列项，解释长卷积 FFT 的补零长度及常数/工作区边界；同时说明有限局部核逐 token 计算可保存最近输入，而长 FIR 的窗口随核宽增长，只有具备特定结构的滤波器才可能改写为定长递归状态。本节讨论架构带来的成本，不展开 serving 调度或通用 kernel 优化。

## 41.6 现有证据支持什么，尚未证明什么

本节对齐三类证据的模型结构、训练数据/预算和评测任务：Qwen3 上的局部深度卷积、保留 attention 的 H3+LongConv 语言模型、以及作者发布的 StripedHyena-7B 混合模型。内容呈现可复核的平均分或困惑度结果及其条件，说明单项任务可能下降、作者报告与独立复现的区别，并记录 Qwen3 预印本摘要和参数表对额外参数比例的不一致。结论限定为卷积可以提供有用的局部先验、充当混合模型中的长程算子或与 attention 互补；这些证据并未建立纯卷积主干普遍替代现代 Transformer 的结论。

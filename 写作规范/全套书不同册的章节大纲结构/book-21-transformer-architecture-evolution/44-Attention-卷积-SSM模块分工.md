# 第四十四章：Attention + Convolution + SSM 的模块分工

本章围绕序列历史如何被保存、读取和重新混合，比较卷积、状态空间模型（SSM）与 Attention 的结构偏置和组合位置。读者应能从局部模式、长流压缩和显式内容寻址等任务需求提出架构假设，并判断证据是否支持这些假设；“局部、长程、全局”只作初步提示，不能代替机制和任务分析。卷积的具体算子与代表模型由第四十一章展开，Attention–SSM 融合细节由第四十三章展开，外部检索交给第四十五章。

## 44.1 “局部—长程—全局”只能作粗略提示

本节用历史表示和读取方式区分模块，不把模块名称直接等同于任务职责。卷积按相对位置混合邻近或长距离输入；SSM 将前缀递归写入状态；Attention 根据当前 query 对可见的 key/value 计算读取权重。内容说明感受野、状态压缩和显式读取是不同维度，任何一条路径都不能仅凭理论结构推出已学会某项能力或具有普遍性能优势。

## 44.2 卷积：同一种算子可做局部补充，也可做长核混合

本节区分有限窗口的因果深度卷积与覆盖长序列的卷积核，说明二者虽共享相对位移上的核权重，却在作用范围和嵌入主干的位置上承担不同工作。以 Qwen3 在 Q/K/V 投影后、Attention 聚合前加入局部卷积，以及 H3+LongConvs 以长卷积替换 SSM 核同时保留 Attention 层为结构例子；实验条件和卷积/Hyena 机制细节由第四十一章负责。

## 44.3 SSM：用递归状态保存前缀的任务相关信息

本节说明 SSM 将历史输入转成随时间递归更新的状态；在状态维数固定的结构中，运行状态不随历史 token 数逐项增长，但历史细节是否仍能由该状态恢复取决于模型学到的表示。区分固定线性时不变系统与 Mamba 式输入依赖选择，说明状态可以依据当前输入选择性传播或遗忘信息，同时避免把 SSM 简化为只保存趋势或无条件失去精确信息；S4 与 selective scan 的推导留在第二十九至第三十五章。

## 44.4 Attention：按 query 访问当前可见的历史表示

本节说明 Attention 以 query 与 key 的兼容度形成权重，并对相应 value 加权；在因果 full attention 中，当前位置可直接读取 mask 允许的前缀位置，窗口或稀疏 mask 会改变这一集合。内容区分“存在到历史位置的读取路径”和“训练后能准确找回所需内容”，并指出模型内部的 key/value 历史不等于能够检索尚未进入上下文的外部材料。

## 44.5 融合位置决定路径怎样相互修正

本节比较模块作为层内修正、序列混合算子替换或跨层交错时的信息路径差异。Qwen3 的局部卷积先改变 Attention 的 Q/K/V；H3+LongConvs 展示长卷积与保留的 Attention 层共存；Attention 与 SSM 的层间串接、层内并行细节回链第四十三章。内容不假定所有架构都要同时装入三类模块，也不把不同位置的算子合称为一种混合 block。

## 44.6 围绕任务需求提出假设，再用证据检验

本节把局部组合、长流状态维护和对特定历史位置的精确读取转成可检验的任务假设，再通过匹配规模、训练数据和预算的对照、模块消融及任务切片观察各路径的实际贡献。报告质量和计算代价时要绑定模型、数据、上下文、实现与测量阶段；总体分数、复杂度阶数或一个模型案例都不能建立通用模块排名。尚未进入模型上下文的文档由第四十五章讨论外部检索路径。

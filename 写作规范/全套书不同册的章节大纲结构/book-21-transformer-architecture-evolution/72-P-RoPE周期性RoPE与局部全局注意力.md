# 第 72 章 P-RoPE：周期性 RoPE 与局部/全局注意力

本章聚焦 Periodic RoPE（P-RoPE）如何把局部滑窗中的 RoPE 位置索引改成周期索引，以及 Harmonic Periodic RoPE（HP-RoPE）怎样通过频率选取消除周期边界的旋转不一致。读者需要区分位置相位与 attention 的可见集合，理解 P-RoPE 的 wrap error、HP-RoPE 的代数条件，并判断 MiniWin 的局部 P-RoPE/全局 NoPE 组合和实验结果可以支持哪些结论。第 18 章负责一般 RoPE 与长上下文扩展，第 64 章负责 NoPE 与隐式顺序，第 67 章负责 Llama 4 的 iRoPE 及其局部/全局路径，第 65 章负责混合历史路径的一般比较；本章不重复这些主线，也不展开 serving/cache 运维。这里的 P-RoPE 指该论文中的 Periodic RoPE，不是只对部分 head 维度旋转的 partial RoPE。

## 72.1 位置索引与可见范围是两个设计轴

本节建立本章分析所需的边界：RoPE 改变 query/key 的位置相位，SWA mask 改变 query 能读取哪些历史位置。前者可能影响可见项之间的相对位置打分，后者直接限定可达范围；仅替换位置方案不等于扩大上下文。还须区分不同文献中容易混淆的 P-RoPE、partial RoPE 与 iRoPE 名称，避免从缩写推断相同机制。

### 72.1.1 RoPE 把相对偏移带入注意力分数

围绕标准 RoPE 的二维旋转对、不同频率及 $R_t^{\mathsf T}R_s=R_{t-s}$ 关系，说明位置通过旋转作用于 query/key，并使注意力分数包含相对偏移。其表达的是模型可据以计算的相位关系，不保证长于训练长度时的行为，也不规定哪些 token 被 mask 允许读取。一般 RoPE 及扩展谱系由第 18 章主讲。

### 72.1.2 滑动窗口 mask 限定单层可以直接读取的位置

以宽度 $W$ 的 causal SWA 为对象，界定位置 $t$ 可读的局部前缀集合，并说明改 RoPE 公式不会改变这个集合。该区别为理解 P-RoPE 的作用范围和 MiniWin 的全局层提供共同坐标；局部/全局混合结构的完整比较归第 65、67 章。

### 72.1.3 P-RoPE、partial RoPE 与 iRoPE 名称不同

本章的 P-RoPE 是 Periodic RoPE，按位置模窗口宽度循环复用旋转表；partial/fractional RoPE 通常指仅旋转 head 的部分维度；iRoPE 在第 67 章中按 Meta 的公开口径描述局部 RoPE 与全局 NoPE 的层间安排。三者解决的问题和变换对象不同，不能互换缩写释义或实验结论。

## 72.2 P-RoPE 复用窗口内的位置旋转表

本节从位置函数和窗口边界关系解释 P-RoPE 的核心设计。周期索引使局部层只需 $W$ 个相位，不再随文档绝对长度增长；但它也让窗口边缘两侧的某些 token 对使用与真实间距不同的相对旋转。章节应把“索引不再外推”和“相对位置是否仍正确”分开分析，说明该方案的收益来源及代数误差。

### 72.2.1 用周期索引代替不断增长的位置索引

本节围绕 $\varphi(t)=t\bmod W$ 及以 $R_{\varphi(t)}$ 替换 $R_t$ 组织内容。旋转表重复长度恰好与 causal SWA 的窗口宽度相关，位置处理成本不改变可见 mask；读者应理解模型仍在各 token 的 query/key 上应用旋转，只是相位索引进入有限集合。

### 72.2.2 未跨周期边界时，编码偏移仍是真实距离

当 query 与 key 的位置落在同一周期内时，模运算前后的相位差等于真实滞后 $d=t-s$。该情形说明表项被重复使用本身并不会必然引入错误；误差取决于 query-key 对是否跨越周期边界，而不是文档绝对长度这一单一变量。

### 72.2.3 跨边界时，相对偏移会从 $d$ 变成 $d-W$

当 query 与 key 位于相邻两个周期而仍处于同一局部窗口内，周期相位差会成为 $d-W$。标准几何 RoPE 频率一般不满足 $R_W=I$，于是该 pair 取得 $R_{d-W}$ 而非 $R_d$；同一真实距离会随窗口起点得到不同旋转，这就是 P-RoPE 的 wrap error。机制分析应明确这是旋转层面的不连续，不据此直接断言端到端任务必然失败。

## 72.3 HP-RoPE 让旋转周期与窗口宽度对齐

本节说明 HP-RoPE 的目标不是再增加一个窗口，而是选取与 $W$ 对齐的 RoPE 频率，使移动一个完整窗口等价于单位旋转。它从代数条件直接消除跨边界时 $d$ 与 $d-W$ 的算子差别。频率表同时决定窗口内位置分辨率；实现该恒等式不等于保证模型信息保留或在更广任务上优于其他扩展方法。

### 72.3.1 让一个窗口宽度对应单位旋转

本节围绕 $R_W=I$ 解释 $R_{d-W}=R_dR_{-W}=R_d$，并指出该条件须对所有旋转维度成立。它把问题从“模型是否学会适应窗口边界”收束为“位置旋转表本身是否在宽度 $W$ 后闭合”。

### 72.3.2 谐波频率使每个窗口完成整数圈

说明论文将每组频率设为 $\theta_i'=2\pi m_i/W$、$m_i\in\mathbb{Z}$，并在示例配置 $W=256,d_h=96$ 中令 $m_i=48-i$。该配置展示整数周数如何生成有限的频率集合及不同通道的周期；它是论文实例，不是对任意模型都适用的默认频率表。

### 72.3.3 边界误差消失，不代表所有长程困难都消失

本节划清 HP-RoPE 的理论边界：它让周期位置索引与窗口周期在旋转算子层面一致，但局部层仍只能访问 $W$ 个位置，跨窗信息依赖其他全局路径；模型任务质量、训练分布与计算/存储成本仍需实测。不能把边界误差消除写成真实上下文长度无限或所有 benchmark 提升。

## 72.4 MiniWin 组合周期局部位置与全局 NoPE

本节把 P-RoPE/HP-RoPE 放回论文实际模型，解释局部与全局路径分别承担的结构角色，并据此限定实验归因。局部层带窗口 mask 与位置变换；全局层用 NoPE 让前缀位置能够在该层直接交互。这里仅复述理解研究比较所需的结构，不重复第 64、65、67 章对 NoPE、混合层和 iRoPE 的完整讲解。

### 72.4.1 局部层用 SWA 与一种 RoPE 变体配合

本节说明 MiniWin 的局部层只在宽度 $W$ 的前缀内做 causal attention，三种实验变体的差别是这些层使用标准 RoPE、P-RoPE 还是 HP-RoPE。该路径提供局部次序与距离信号，但不直接读取窗口之外的 token。

### 72.4.2 全局 NoPE 层负责跨窗口直接交互

全局层在整个因果前缀上执行 attention，且不对 query/key 施加显式位置旋转。因果 mask 仍规定前缀方向，输入 hidden state 也可携带前序局部层形成的位置信息；NoPE 的通用机制和限制由第 64、67 章承担。本节只说明该路径为何让 MiniWin 不止由局部 SWA 组成。

### 72.4.3 论文比较的是一个具体的八层配置

本节记录论文的八层配置：每组三个局部层接一个全局层，重复两次，共六个局部层和两个全局层；窗口 $W=256$，attention head dimension 为 $96$。这组配置限定实验结论的架构范围，不将该层比写成通用最优 schedule。

### 72.4.4 有限位置表不等于无限资源

本节区分位置索引范围与完整模型处理长输入的资源需求。P-RoPE/HP-RoPE 限制局部层的位置表索引；MiniWin 的全局层仍处理整个前缀，attention 和逐位置 cache 的资源需求也不会因周期旋转自动消失。论文标题中的“infinite context”是机制动机，不是无限长任务能力或有限资源保证。

## 72.5 v2 实验说明了什么

本节按同一 MiniWin 架构中的对照实验解释作者结果，区分局部位置方案的组件比较、边界机制诊断与端到端长上下文测试。所有数字需保留模型规模/配置、训练长度、评测类型与版本条件；研究为 arXiv v2，结论不能代替更大模型和独立复现。

### 72.5.1 控制比较把差异限定在局部位置编码

说明模型以长度 $768$ 训练，另有到 $1536$ 的 continue-pretraining；同组模型使用相同数据与日程，只替换局部窗口层的位置编码。评测包括 packed hold-out、训练外连续文本和英/中文 passkey；测试期 NTK/YaRN 变体与不做插值的 P-RoPE/HP-RoPE 应分开说明。

### 72.5.2 16k 结果属于 MiniWin 的实验条件

本节按指标解释论文报告的 16k 结果，包括 packed/novel text perplexity 与 passkey top-1；说明样本长度、语料和任务组成，不把 format-free passkey 命中泛化为复杂文档理解或一般推理能力。P-RoPE 与 HP-RoPE 的比较也不能只摘最有利的单个数值。

### 72.5.3 边界移动诊断支持 HP-RoPE 的代数解释

说明论文如何固定已训练层的 Q/K/V 并平移周期表起点，测量 attention logits 与分布变化；再用真目标/干扰 needle 跨边界的条件比较观察 P-RoPE 的窗口相位效应。HP-RoPE 的近浮点不变性支持 $R_W=I$ 的代数预测；这些诊断结果与整体任务准确率是不同证据层次。

### 72.5.4 有限实验不等于无限上下文结论

汇总预印本、八层 MiniWin、训练至 768/1536、评测至 16k 和有限任务集的外推边界。不能从无界位置索引、单一 passkey 结果或窗口周期恒等式推出生产模型已支持无限上下文；后续仍需扩大模型与 benchmark，并分别考察位置、可见范围、信息保留和资源约束。

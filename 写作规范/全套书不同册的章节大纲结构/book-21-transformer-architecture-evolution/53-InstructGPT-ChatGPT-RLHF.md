# 第五十三章大纲：InstructGPT、ChatGPT 与 RLHF 对架构使用方式的改变

## 本章定位

本章属于第二十一册的模型演进时间线，回答后训练如何让生成式预训练模型更适合按指令和多轮对话使用。主线是预训练模型与指令任务的行为差距、InstructGPT 的示范和偏好流程、实验结果的评价边界，以及 ChatGPT 发布期对话入口的作用。重点区分内部架构、后训练行为和产品交互。

本章不重复第五册关于 SFT、奖励模型、PPO、DPO 等算法和工程配方的完整讲解；不把产品体验当作 Transformer 结构证据；不把偏好比较解释为事实性、安全或人类价值的充分验证。reasoning RL 与 RLVR 的演进由第五十八章承接。

## 53.1 生成式预训练与用户任务之间的缺口

解释 next-token 预训练目标与可靠指令完成之间的差异。避免将 base model 描述成完全不能回答指令；应说明预训练目标没有直接保证遵循用户意图、格式、拒答和不确定性表达。引出后训练作为行为适配。

## 53.2 InstructGPT：用示范和偏好塑造回答

用一张表呈现 SFT、偏好比较/奖励模型和 PPO 的训练信号、行为作用及不能保证的属性。说明 InstructGPT 以 GPT-3 模型为基座，训练方法改变回答行为；算法细节回链第五册第十一章。

## 53.3 实验结果支持什么，又不能说明什么

引用论文在 API prompt 分布上的人类成对偏好结果，包括 $175\mathrm{B}$ InstructGPT 相对 $175\mathrm{B}$ GPT-3 的 $85\pm3\%$ 结果及相对 few-shot GPT-3 的 $71\pm4\%$ 结果，并限定模型尺寸、prompt 分布和评价方法。说明特定标注群体所表达的偏好不代表普遍人类价值；模型仍会犯事实错误，且部分公共 NLP 能力存在回归。

## 53.4 ChatGPT：把多轮对话变成主要使用入口

以 2022 年 11 月发布说明为历史证据，说明初始 ChatGPT 基于 GPT-3.5 微调，采用与 InstructGPT 相近但有数据收集差异的方法；训练者扮演用户和助手并参与偏好比较。区分发布期的对话界面与模型内部架构，并标明该说明不代表当前产品的完整技术情况。

## 53.5 改变了使用方式，不等于更换了架构

总结内部 block、后训练行为分布和产品系统的不同层次。补充 RLHF 的早期历史：Ziegler 等（2019）和 Stiennon 等（2020）先于 InstructGPT 研究语言模型偏好微调和摘要任务中的人类比较/RL。将 reasoning RL/RLVR 交给第五十八章，不在此重复展开。收束为“预训练提供通用续写、示范建立指令行为、偏好调整回答选择、产品接口支持多轮使用”的历史结论及代理目标边界。

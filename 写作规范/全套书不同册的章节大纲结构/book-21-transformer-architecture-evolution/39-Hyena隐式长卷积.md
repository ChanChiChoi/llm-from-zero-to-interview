# 第三十九章：Hyena：隐式长卷积与长序列建模

本章围绕 Hyena 如何把长程因果卷积与输入依赖门控组合成注意力替代算子展开。读者从已理解因果卷积、线性投影、FFT 和前面章节的 SSM/H3 出发，读完应能写出 Hyena 的阶递归，说明隐式滤波器如何将核参数量与序列长度解耦，判断 FFT 的复杂度收益何时可能转化为实际速度，并准确陈述原论文与后续关联回忆实验各自支持到哪里。本章聚焦算子和论文证据；卷积家族的通用归纳偏置由第四十一章展开，早期混合架构由第四十章承接，跨路线选型由第四十二章负责。

## 39.1 长卷积怎样提供全局序列混合

本节说明短因果卷积的有限感受野、长核因果卷积的全序列传播，以及卷积核按相对位移共享权重的 Toeplitz 结构。内容对齐显式长核与 dense self-attention 的序列长度成本，指出长感受野表示远处位置有影响路径，不等于每个 query 都对所有历史 token 计算独立内容相似度。

## 39.2 Hyena 递归：投影、卷积与门控交替

本节说明输入经过线性投影和短卷积后形成 value 流与多条门控流，随后按阶交替执行因果长卷积和逐点乘法门控。内容覆盖 order-$N$ 递归、各阶滤波器与投影的对应、该结构形成数据控制算子的方式，以及原论文对 Hyena 与 GSS、H3 特例关系的说明；不把不同论文中的参数化和完整 block 视为完全相同。

## 39.3 隐式滤波器与位置尺度

本节说明 Hyena 如何以位置编码、浅层前馈网络和 window 函数生成每个位置的长核响应，并解释指数衰减 window、跨通道衰减差异与高频周期激活在论文设计中的作用。内容比较逐位置显式学习与函数式参数化，说明参数量不必随滤波长度线性增长，但生成核仍需按目标长度计算；参数解耦也不自动保证超训练位置外推稳定。

## 39.4 FFT 长卷积的计算与复杂度

本节说明因果线性卷积如何借助补零后的循环卷积和 FFT 计算，重点交代补零对避免首尾回绕的作用。内容区分单次长卷积的序列长度复杂度、Hyena 阶数/通道数、输入投影和短卷积成本，并解释 FFT 的渐近复杂度、工作区与硬件利用率之间的关系；论文算子基准不直接代表完整模型或所有序列长度上的端到端收益。

## 39.5 数据控制矩阵与 attention 的结构边界

本节将 Hyena 写成输入投影生成的对角门控矩阵与长卷积 Toeplitz 矩阵的交替乘积，说明其数据依赖来自门控流，长滤波器自身则由位置及可学习参数生成。内容比较它与 query-key 配对及 softmax attention 的信息混合路径，区分全局可达、内容条件化和精确关联提取；不从结构差异推断 Hyena 必然无法或必然能够完成通用检索。

## 39.6 原论文结果及后续证据边界

本节整理原论文在合成关联回忆、The Pile 语言建模和算子速度测试中的结果，注明序列长度、词表、模型规模、训练 token、批量、kernel 和对照对象等关键条件。内容同时纳入后续机制研究在另一套合成任务、上下文长度和 Hyena 配置下报告的结果，说明这些发现与原论文不能直接视为同条件复现或互相否定；结论限于具体实验，不泛化为对架构家族的性能或检索保证。

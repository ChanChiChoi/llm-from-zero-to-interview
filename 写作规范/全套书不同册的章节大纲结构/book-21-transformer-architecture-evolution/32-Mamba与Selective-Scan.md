# 第三十二章：Mamba：Selective State Space 与 Selective Scan

本章围绕 Mamba 如何让有限状态随输入内容调整写入、保留和读出展开。内容从固定参数 LTI SSM 的内容选择缺口出发，说明 Mamba 如何由当前层输入生成时间步长、输入投影和读出投影，使离散状态递归变为随位置变化的仿射更新；再解释这些更新为何仍可按顺序组成结合运算并通过前缀 scan 求得。随后说明局部卷积、选择性 SSM、门控支路怎样组成 Mamba block，并把合成任务的证据限制在对应任务设置内。硬件实现和训练/推理成本、精确检索与 ICL 局限、Mamba-2 与跨架构比较分别交由第三十三至三十六章。

## 32.1 固定状态传播为何需要内容选择

第二十九至三十一章说明，固定参数的线性时不变 SSM 可以用递归或固定卷积核表示，但同一转移规律会作用于每个位置。若需要依据 token 内容决定哪些输入应进入状态、哪些干扰应被忽略，单靠时间位置固定的传播规则缺少这种条件化能力。本节以 Mamba 原论文的 selective-copying 任务界定问题：被记住 token 的位置会变化，模型必须依据当前内容选择，而不只是追踪固定间隔；这一受控任务提供机制动机，不代表通用语言理解结论。

## 32.2 输入依赖的 Δ、B、C 如何改变状态递归

Mamba 在每个位置根据 SSM 层的当前输入生成正时间步长 $\Delta_t$、状态输入投影 $\mathbf{B}_t$ 和读出投影 $\mathbf{C}_t$，而状态转移参数 $\mathbf{A}$ 保持为结构化可学习参数。本节以原论文的零阶保持离散化说明时间步长如何形成逐位置离散转移；知识范围包括输入依赖的参数生成、各参数对状态转移/写入/读出的作用、由固定 LTI 到时间变化递归的关系，以及单状态稳定模态中时间步长与门控的教学性对应。该对应依赖给定的简化参数，不能把多维状态的选择机制缩成单一二值开关。

## 32.3 仿射更新的结合律与 Selective Scan

每个位置的选择性更新可以表示为从旧状态到新状态的仿射变换。连续两个位置的变换有明确的顺序组合规则，且该组合满足结合律，因此可用并行前缀 scan 同时求出多个位置的状态；矩阵乘法/逐元素状态转移仍须保持原序，结合不等于交换。由于 $\Delta_t,\mathbf{B}_t,\mathbf{C}_t$ 随内容改变，时间变化的系统不再具有一条共享全序列的固定冲激响应卷积核，递归扫描成为序列计算路径。本节覆盖仿射组合、前缀结果与逐步递归的对应，以及训练整段输入和生成时递归更新的概念差别；融合 kernel、内存层次和实测效率由第三十三章展开。

## 32.4 Mamba block 的整体数据路径

Mamba 将序列状态变换与门控前馈路径组织在同一 block 中：输入投影产生主支路和门控支路，主支路经过短因果卷积与激活后进入 selective SSM，状态输出由门控支路调制，再经输出投影返回 block 维度，并与外层残差结构衔接。知识范围包括各支路的数据来源和汇合位置、短卷积与选择性状态分别承担的作用，以及 Mamba block 与独立 SSM 层、传统 Transformer MLP/Attention block 的区别；不把教学图示规定成所有 Mamba 变体完全相同的配置。

## 32.5 选择性机制的证据和边界

原论文的 selective-copying 和 induction-head 合成任务用于检验输入依赖状态更新是否能解决特定受控序列任务；它们不能证明 Mamba 可任意寻址全部历史，也不构成对所有语言任务或 Transformer 的普遍胜负结论。本节收束本章的机制认识：输入条件化改变有限状态如何接收与读取信息，scan 提供计算这些时间变化更新的并行代数路径；实际 kernel 效率由第三十三章讨论，精确检索与 ICL 边界及总体替代证据由第三十四、三十六章处理，Mamba-2 的状态空间对偶由第三十五章处理。

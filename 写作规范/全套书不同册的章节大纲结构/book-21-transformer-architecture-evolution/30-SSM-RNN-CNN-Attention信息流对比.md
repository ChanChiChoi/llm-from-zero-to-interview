# 第三十章：SSM、RNN、CNN、Attention 的信息流对比

本章在因果序列预测这一共同前提下比较四类序列层：过去的信息存在哪里，当前位置通过什么路径获得它，训练与逐步生成分别怎样计算。读者应能区分固定递归状态、有限卷积感受野和按 query 访问可见历史的 attention；理解固定线性时不变 SSM 为何同时有递归与卷积视图；并把图上的可达路径、信息能否保留、任务上能否正确读出分开判断。S4/Mamba 的专项机制和全套替代架构选型由后续章节负责。

## 30.1 RNN 与 SSM：通过递归状态传递历史

本节说明普通 RNN 用共享参数把前一时刻隐状态与当前输入合并为新状态，非线性门控变体改变更新规则但仍沿递归状态传递历史。SSM 也可逐步更新固定形状状态，但固定 LTI SSM 的状态转移和读出具有特定线性时不变结构，不能与一般 RNN 或输入依赖的 selective SSM 混称。固定 LTI 条件下的卷积视图只改变批量计算路径，不会为历史添加按位置寻址的显式槽位；S4 的参数化细节交给第 31 章。

## 30.2 CNN 与 Attention：有限感受野和显式可见历史

本节解释因果时序卷积只连接其核、层数与 dilation 所覆盖的过去位置，层叠可以扩大感受野，但范围外输入不会影响该层输出。Attention 则由当前位置的 query 对 mask 允许的历史 key 计算权重，再聚合对应 value，因此在结构上提供逐位置的内容相关访问；该路径不保证选对证据或可靠恢复事实。本节区分卷积的拓扑可达性与 attention 的显式历史访问，并将“可访问”与“已学会正确使用”分开。

## 30.3 远处信息经过什么路径

本节把同一远距历史查询放回四种信息流，比较递归链、卷积感受野与 attention 直接可见边分别意味着什么，并指出路径较短不等于信息保留或任务成功。各结构的历史载体、取用方式及可达边界共同说明，图上存在路径并不能推出历史细节仍可分辨或任务回答正确。

## 30.4 训练并行与生成状态不是一回事

本节区分完整序列已知时的训练计算与自回归生成：CNN 和 attention 可并行处理多个已知位置，通用递归更新存在跨时间依赖，固定 LTI SSM 可使用递归或卷积路径；生成阶段则按 token 依赖顺序推进，RNN/SSM 携带状态、CNN 缓存有限历史激活、attention 通常保留已访问位置的 K/V。结尾总结这些结构差异不提供普遍速度排名，并交接到 S4、Mamba、广义架构比较和混合模型章节。

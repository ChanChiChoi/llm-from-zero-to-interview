# 第十八章：RoPE 长上下文扩展：插值、频率缩放与训练

## 章节契约

- **定位：** 承接第十七章对具体模型位置配置的比较，解释预训练 RoPE 模型怎样通过位置映射、频率分配与继续训练扩展上下文，并教读者辨认不同扩展声明的证据范围。
- **前置：** 读者已理解 Transformer 的自回归注意力、RoPE 中按位置旋转 Q/K 的基本关系和上下文窗口概念；第七章已讲位置表示与 RoPE 的相对位置几何。本章只短暂唤回这些概念，不重推二维旋转、RoPE 全族、attention/cache 工程或长上下文行为评测。
- **离章结果：** 读者能解释线性位置插值、NTK-aware/Dynamic NTK、YaRN 与非均匀位置扩展在“改变哪些位置/频率、是否继续训练”上的差别；能区分配置长度、训练长度、位置映射范围和具体任务上的有效上下文；能将长上下文结果绑定到固定模型、训练方案和评测任务。
- **边界：** 第七章承担位置编码基础；第十一章承担 KV cache 容量与运行时状态；第十三章承担长距离证据使用、位置敏感现象及评测设计；第十九章承担滑动窗口和稀疏连接；第二十章承担 attention kernel 与显存执行；第六册和第二十四册承担 serving。近期 iRoPE 等架构机制由本册第六十七章等专题继续展开。
- **本册设计依据：** 当前未见单独的第二十一册章节大纲总索引文件；本章依照本册简介、现行目录、架构审计的册级契约及第十七章交接进行章节设计。

## 正文编号大纲

### 18.1 位置映射范围不等于有效上下文

从第十七章的模型配置对比接入：位置函数为每个位置产生可用于注意力的旋转坐标，但模型训练时见过的长度、推理配置允许的长度、扩展后的位置映射和指定任务上的有效长度是四种不同描述。简短唤回“位置相位随位置变化、Q/K 交互带有相对位置”，把问题落到超出训练范围的新相位及模型适配上；将 Lost in the Middle、证据位置任务和任务级评测交给第十三章，将输入预算与 cache 容量交给第十一章。

### 18.2 Position Interpolation：把新位置映回训练区间

本节围绕 PI 的关键转换展开：目标位置按目标长度与训练长度之比线性缩小，使新坐标落回预训练位置区间。说明它为何比直接把未见位置送入原 RoPE 更稳定，也解释所有相对距离同时被压缩、近邻间隔随之变小的代价。将 PI 论文的 LLaMA 模型范围、最长 32K 设置和少量微调结果限定为作者实验，不把它们写成普遍外推定律。

### 18.3 NTK-aware 与 YaRN：按频率分配位置变化

本节比较 PI 统一缩放与频率分组/差异缩放的思路。NTK-aware 作为社区提出的 base 调整启发式，尝试让不同频率按不同幅度变化；Dynamic NTK 将缩放和当前序列长度关联；NTK-by-parts 按频率区间在原频率与插值频率之间过渡。YaRN 的论文定义在此基础上加入 attention logit 温度缩放，需区分论文机制、论文中报告的训练效率和某个模型库/配置的实现细节。动态策略的 cache 状态实现回到第十一章。

### 18.4 从手工频段规则到非均匀与长度自适应映射

本节说明统一比例和预设频段分组为什么继续发展为逐维、逐位置处理。LongRoPE 以搜索的非均匀因子及渐进扩展为例，并说明短上下文恢复步骤；ICLR 2026 的 MrRoPE 以 mixed-radix 视角统一频率变化方案并提出渐进映射；NeurIPS 2026 的 Jet-Long 将局部 RoPE 保真与动态长程映射组合，展示另一种长度自适应方案。它的缓存校正与内核路径只交代位置机制解释所需的边界，具体状态一致性及性能归因分别回到第十一、二十章。各方案的测试结论绑定论文模型与实验，不根据最大长度数字排名。

### 18.5 位置坐标之外：训练如何让模型适应长序列

本节把“改位置映射”与“让权重适应变化后的输入分布”分开讲。以 Llama 3 技术报告为具体训练实例：报告记载 RoPE base frequency、逐阶段扩长上下文，以及针对该模型采用的长/短上下文恢复判据和训练 token 规模；随后与 LongRoPE2 的混合位置/窗口训练及 ICML 2026 位置扰动自蒸馏对照，说明方法可以改变权重训练、样本长度和位置稳健性。结果只按公开报告或会议论文中的固定模型与任务陈述。

### 18.6 怎样比较位置扩展方案与上下文声明

本节收束前文，按扩展倍率、频率/位置如何变化、训练与数据成本、短上下文保持、测试任务和模型版本对照 PI、NTK/Dynamic NTK、YaRN、非均匀/动态映射及位置训练方法。读者应能追问“在什么 checkpoint 上、见过多长训练样本、目标位置如何映射、是否更新权重、在哪些长度与任务上通过了什么指标”，而不是把配置上限或 needle 单测等同于通用长程推理能力。详细的任务位置控制和能力解释转交第十三章，位置方法与 cache、稀疏 attention、kernel 的系统交互分别链接第十一、十九、二十章；NoPE 与 iRoPE 回链第六十四、六十七章。

## 表达形式与维护边界

- 保留 PI 位置缩放关系作为唯一必需公式，用于解释位置索引如何回映到训练范围；NTK/YaRN/搜索方法通过频率示意或对照表解释，只有确有助于比较时才加公式。
- 使用一张方法对照表，列出变化对象、训练方式和证据绑定条件；不复制整章 benchmark 规划表、cache 检查清单或 serving 性能表。
- 正文不提供 Python RoPE 内核、KV cache golden replay、精度单元测试或 kernel benchmark，因为本章不承诺实现这些任务；相关实现由第十一、二十章承担，模型能力评测由第十三章承担。
- 引用原论文、固定版本技术报告或正式会议页面，并在长度/效率主张附近解释支持范围。2026 新研究以选定示例呈现，不声称方法已经形成通用共识。

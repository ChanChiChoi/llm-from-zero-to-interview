# 第二十四章：Linear Attention 的基本思想和核技巧

## 章节契约

- **前置：** 理解 scaled dot-product attention、Q/K/V、因果 mask、序列长度复杂度和向量/矩阵乘法；能够阅读求和记号。第十章已介绍 dense attention 的成对计算，第十一章解释逐 token KV cache；需要时可回看这两章。
- **离章结果：** 能从有限维 kernel 特征分解推导归一化 attention 的求和重排；说明因果前缀如何由分子状态和归一化状态递推；辨认线性复杂度依赖的固定维度与成本范围；区分精确重排、替代 kernel 与 softmax 近似；解释有限状态保存与逐 token KV cache 的信息访问差别。
- **本章职责：** 以核特征分解为主线，解释线性 attention 怎样把 query-key 成对求和转为可递推的历史状态，并限定这种变换的归一化、计算复杂度和信息保留含义。
- **边界：** 第十章负责 dense attention 和 FlashAttention 的计算/显存差别；第十一章负责 KV cache 的生命周期与显式容量；本章只建立线性状态与 KV cache 的对照。第 25 章主讲 Performer、FAVOR+、随机特征和近似误差；第 26—28 章承担稀疏 attention 与高效路线的比较；第 29—30 章主讲 SSM/RNN/CNN 的状态动力学。本章不展开服务回滚、并发调度、kernel 基准或外部检索实现。
- **研究依据：** 旧稿 25 个小节反复讲解核分解、递推、分母、状态容量与训练/推理成本，并混入 Performer 误差、代码、运行时回滚、并发和外部检索。现行完整设计以核分解和因果状态为中心，把 Performer 误差交第 25 章、KV cache 分工回第 11 章、SSM 动力学交第 29—30 章；证据见[线性 Attention 核分解与状态研究记录](../../../research/linear-attention-factorization-state-2026-11-20.md)。

## 正文编号大纲

### 24.1 注意力权重依赖什么

本节围绕标准因果 attention 的归一化加权和，界定线性 attention 想重写的运算对象。内容包括 query/key 的成对相似度、softmax 权重、value 加权与因果前缀范围，并把序列长度增长时的成对计算与历史汇总问题连接起来；dense attention 的实现优化留给第十章。

### 24.2 核特征分解如何改变求和顺序

本节说明相似度函数可写成有限特征向量内积时，分子和分母为何都能利用结合律把 query 从历史求和中提出。中心是精确重排与相似度定义之间的关系：对于已选定且可因子分解的 kernel，运算可代数等价；这本身不保证 kernel 与标准 softmax 相同。

### 24.3 因果 attention 如何成为前缀状态

本节把求和重排对应到随 token 更新的分子状态和归一化状态，说明二者的累积量、递推关系、形状与 query 读出之间的联系。因果 mask 使当前位置只汇总有效前缀；若缺少分母状态，就不能保留归一化权重的含义。

### 24.4 线性长度从哪些维度得来

本节解释固定特征宽度、key/query 维度与 value 维度下，前缀状态更新如何使核心 attention 运算关于序列长度线性增长，并区分特征映射、状态更新、投影和其余模型运算。还界定增量解码的固定形状状态与训练时并行前缀计算、反向中间量的内存要求；渐近复杂度不直接推出特定硬件上的速度或整模型内存优势。

### 24.5 有限特征与 softmax 的边界

本节围绕正值归一化和有限特征表示，区分直接定义另一种 kernel 与近似指数点积 softmax。内容包括 softmax kernel 精确表示的无限维性质、有限特征需要作出的选择、非零归一化分母的条件及数值保护对函数定义的影响。FAVOR+ 的随机特征构造和误差分析由第 25 章专门承担。

### 24.6 定长状态保留什么，又不能直接取回什么

本节界定累计状态可对当前 query 提供的 kernel 加权 value 汇总，以及固定维度状态未逐项保存每个历史 key/value 所带来的访问边界；再与第十一章 KV cache 和第 29—30 章 SSM/RNN 状态动力学区分。有限状态的大小本身不足以推出具体任务的回忆质量，也不能把所有递归架构统称为线性 attention。

# 第 64 章 NoPE：没有显式位置变换，不等于没有顺序

## 章节任务

本章界定 NoPE 所指的位置路径，并说明没有显式位置变换时，顺序线索仍可能怎样进入因果或混合 Transformer。先区分 attention 的置换等变性与因果 mask 的前缀可见性，再联系前序局部混合/递归状态向全局 NoPE 层传递近期性。读者需要把顺序判断、相对距离或近期性、绝对位置索引拆成不同能力，理解它们各自需要的证据与测试；NoPE 不自动保证长上下文长度外推。Kimi K3 作为固定版本案例，用来说明 MLA 的 Q/K 可不直接施加位置变换，同时由交错 KDA 提供位置敏感和近期性处理。MLA 内部计算归第 63 章，混合层总体安排归第 65 章，RoPE 与长上下文扩展归第 67 章，Kimi K3 全模型证据归第 88 章。本章不重讲通用 serving 状态协议或 cache 生命周期。

## 64.1 NoPE 描述的是显式位置路径

本节澄清 NoPE 是对一条网络路径的位置注入方式所作的描述，不是对模型顺序能力的结论。需要区分绝对位置嵌入、RoPE 对 Q/K 的旋转、相对位置偏置等显式方法，以及因果可见性或上游表示携带的隐式线索；不同来源使用 NoPE 一词时，还须按其定义确认范围。

### 64.1.1 省略显式信号，不等于抹掉已有线索

说明某层的 token 表示和 query/key/score 没有直接接收显式位置特征，并不意味着该层输入没有位置相关信息。因果 mask 仍可限制可见前缀，先前的局部混合或递归更新也可能把顺序信息写进 hidden state；因此需要分别描述显式位置变换与已有的隐式线索。

### 64.1.2 先看路径范围，再描述整个模型

NoPE 可以只应用到某种 attention 层或分支，不能从单一路径推断整网都没有位置处理。混合架构中，位置线索可能由一类层建立，再由另一类全局 attention 读取；具体报告需明确其 Q/K、score 和其他模块分别采用什么方式。

## 64.2 无位置 attention 的置换性质与因果 mask

本节从 self-attention 的置换等变性建立对照，再说明 causal mask 如何通过固定前缀可见集合打破任意置换对称。中心区别是：attention 内容交互是否具备位置特征，与模型是否因因果结构而对序列顺序敏感，不是同一问题。

### 64.2.1 没有位置差异时，attention 对输入置换等变

定义 token 表示矩阵、位置置换和 attention mask/偏置，说明当输入行及 mask 同步置换时，输出会按相同方式置换；没有位置特征且无位置相关 mask 时，标准 self-attention、逐 token 前馈层、归一化与残差组合保持置换等变。等变不等于输出完全不变，而是模型不因任意排列获得额外位置编码。

### 64.2.2 因果 mask 固定了前缀方向

因果 mask 将未来位置排除，使每个位置读取不同长度的前缀。只改变 token 排列而保持三角 mask 固定时，任意置换对称不再成立；mask 可提供方向及前驱数量相关线索，但本身不等价于显式的相对距离 score 偏置。该结构能否形成可用的位置表示，仍是与训练和模型结构相关的经验问题。

## 64.3 顺序线索怎样进入 NoPE 层

本节比较全局因果 NoPE attention 与混合架构中 NoPE attention 可能依赖的输入线索。重要的是区分 mask 造成的前缀不对称，与上游局部或递归层传来的时间/近期性表示；具体机制和成熟度按来源区分。

### 64.3.1 因果可见性可以形成隐式位置表示

概述因果语言模型在无显式位置编码设置下可从 hidden state 中读出某种位置表示的研究。Haviv 等人的 probing 观察及关于可见前驱数量的解释支持“位置线索可由因果计算隐式形成”，但作者的机制说明是推测，结果绑定其模型规模、任务和训练设置，不能推成普遍精确的位置定位能力。

### 64.3.2 局部混合与递归更新能传递近期性

说明滑动窗口 attention、门控线性 attention 或递归状态可能先在表示中形成局部邻近/近期性，再由后续全局 NoPE 的 Q/K 读取。2026 年 arXiv 预印本提供一种残差流近期性向全局 logits 传递的理论和特定规模实验证据；该结果是近期研究线索，应注明预印本状态和实验边界，不改写为所有混合结构的已定律。

## 64.4 NoPE 能做什么，必须按任务区分

本节把顺序判断、相对距离/近期性与绝对位置索引作为不同读者任务，并据此讨论评测设计与长度外推。单一 accuracy、短序列交换题或最大上下文窗口均不足以代表这些能力的共同表现。

### 64.4.1 顺序、距离和绝对位置需要不同的测量

分别说明交换事件顺序、改变间隔与干扰、返回精确位置索引所检查的能力；指出三类任务不能彼此替代。测量需控制内容和模板，改变顺序、相对距离、绝对位置及上下文长度；若要归因线索来源，需要对已知模型路径做匹配消融，仅凭输出行为不能证明具体架构内部机制。

### 64.4.2 NoPE 的长度泛化不是无限外推

总结 ACL 2024 的因果 NoPE 长度泛化研究：在论文设定下，NoPE 对部分未见长度具有优势，但仍存在上下文边界和 attention 分布干扰问题。将具体结果限制在论文模型和任务，不把它推广为 NoPE 普遍优于显式位置方法或可无限外推；RoPE 及长上下文扩展路线交由第 67 章主讲。

## 64.5 Kimi K3：MLA 的 NoPE 与 KDA 的位置路径

本节用 Kimi K3 v2 报告把通用概念落到模型的具体路径：MLA 层的 Q/K 无显式位置变换，交错 KDA 层承担位置敏感和近期性混合，MLA 保留全局内容交互。该事实属于模型披露，不能仅凭整模型长上下文结果归因 NoPE 的独立效果。

### 64.5.1 MLA 不直接给 query/key 施加位置变换

按 Kimi K3 报告说明 NoPE 的适用范围以及 KDA 与 MLA 的公开分工；强调“该 MLA 路径没有直接施加位置特征”不等于“其输入 hidden state 无位置信息”或“整个模型没有位置机制”。对 MLA latent 与 gate 的解释链接第 63 章，对混合层作用链接第 65 章。

### 64.5.2 一百万 token 窗口不能归因于 NoPE 单项

Kimi K3 报告将长上下文扩展与位置处理、长数据构造和渐进训练共同描述。仅从模型达到的窗口长度，无法分离 NoPE 的因果贡献；没有针对 NoPE 单项的匹配消融时，应保留归因边界，并将全模型证据回链第 88 章。

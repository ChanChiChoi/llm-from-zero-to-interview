# 第四十六章：Memory-Augmented Transformer 与长期记忆架构

本章围绕模型怎样把过去输入变成后续计算可访问的状态，比较外部 K/V 缓存、与主干解耦的读取网络、潜在情景记忆和模型内部递归状态。读者应能沿写入、寻址、读取和融合路径解释代表架构的差别，并判断这些状态面向长文档、事实更新还是连续交互；“长期”不预设跨用户、跨会话的应用记忆服务。第十一章负责标准推理 KV cache，第十四章负责序列状态记忆的概念，第十五章负责外部语料检索，第四十九章负责 Agent 记忆与运行状态；本章只展开记忆状态作为模型架构组件时的信息流、训练耦合和证据边界。

## 46.1 模型架构里的记忆：表示被留到何时、供谁读取

本节区分当前上下文中的原始 token、当前生成过程复用历史 K/V 的推理缓存，以及跨片段或步骤进入后续模型计算的记忆状态。记忆可保存逐 token 表示、潜在情景编码或递归状态，作用范围由具体架构决定；它既不自动等于参数中学到的知识，也不等于外部语料检索或 Agent 保存的用户事实。内容承接第十四章的状态概念，并与第十一、十五、四十九章划清对象和生命周期。

## 46.2 记忆如何写入、读取并参与预测

本节以过去信息编码成状态、状态写入或更新、当前输入寻址读取、读出结果融合到模型计算这条路径组织共性问题。覆盖记忆表示、更新时机、寻址方式、融合位置和反向传播边界；指出不同方法不共享统一的向量库、写入阈值或融合公式，也不假定模型输出会自动持久化。后续小节各自填充具体机制，不在这里预设一种通用实现。

## 46.3 Memorizing Transformer：以外部 K/V 缓存访问旧 token

本节说明 Memorizing Transformer 如何在局部因果注意力之外，用 query 对外部缓存中的过去 K/V 做近似 kNN 选取，再以注意力读取并通过学习门控融合两路结果。涉及按片段追加 K/V、容量达到上限后丢弃旧项、非可微缓存造成的旧新表示漂移，以及论文按长文档顺序处理并清空文档级状态的范围。书籍、长网页、数学、代码和证明任务结果均绑定论文所用模型、数据和训练设置，不外推为跨会话个人记忆能力。

## 46.4 LongMem：分离历史编码与记忆读取

本节比较同一网络负责产生 K/V 与读取 K/V 的耦合设计，以及 LongMem 冻结 backbone 作为历史编码器、用可训练残差 SideNet 读取和融合记忆的分工。说明 SideNet 如何查询过去片段的 K/V 并与当前表示联合处理；分离组件旨在减少训练时缓存表示的陈旧问题，不意味着消除所有检索或状态失效。长文本建模与多示例 in-context learning 是论文任务范围，ChapterBreak 等报告结果不可泛化到任意长上下文任务。

## 46.5 Larimar：用情景记忆快速更新事实

本节说明 Larimar 将输入编码为潜在表示，通过读写权重把情景写入固定形状的关联记忆矩阵，再由读出结果条件化语言模型解码。覆盖训练阶段对编码器、读写机制和解码器的联合学习，及推理阶段以一次线性记忆更新写入新事实而不做梯度微调；将事实编辑和选择性遗忘任务与原文检索、用户画像及通用隐私删除区分。作者报告的准确率、速度和忘却结果均限定在论文的模型和基准设置。

## 46.6 MemT-1.0：把递归状态作为原生记忆

本节介绍 2026 年预印本 MemT-1.0 的模型内 memory block：保留选定 Transformer 层的原始注意力，加入并行 memory attention；训练得到的 hyper memory 参数在线固定，动态 local memory state 则依据交互内容以 Gated DeltaNet-2 稳定 token 级更新。说明固定配置下状态大小不随历史 token 逐项累积的架构含义，以及压缩状态与逐 token K/V 索引的取舍。速度和持久存储数字绑定 BEAM、Nano 模型、128K 历史、两张 GPU、batch 1 和固定输出长度；新预印本不构成跨架构的普遍效率证据。

## 46.7 按表示、更新和任务比较架构边界

本节对齐各方法保存的对象、写入频率、读取粒度、融合位置、状态增长和实验任务，帮助读者判断架构路径改变了什么及需要承担的代价。评估分别检查长文本信息使用、多示例上下文学习、事实更新与遗忘、噪声/冲突记忆和资源消耗；不同论文任务与协议不能合并为总体排名。最后区分第十一章当前请求 KV cache、第十五章外部语料 RAG、第四十九章 Agent 运行状态和本章模型内部可持续访问状态，说明增加一条信息路径不保证读对或答对。

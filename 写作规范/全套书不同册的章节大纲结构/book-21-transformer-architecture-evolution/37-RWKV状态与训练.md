# 第三十七章：RWKV：RNN 式状态与 Transformer 式训练

本章说明 RWKV 如何把时间混合写成可递归传递的加权 key-value 状态，同时让已知序列中的投影与状态计算适配整段训练。讲解以 RWKV-4 的 WKV 为基线，再区分 RWKV-5 Eagle、RWKV-6 Finch 和 RWKV-7 Goose 对状态形状、衰减和更新规则的改动。读者应能说明 time-mixing 与 channel-mixing 各自承担什么信息流，复述一条版本对应的状态更新，并判断“状态不随序列长度增长”究竟约束了什么。本章不承担 serving 状态生命周期、通用长上下文检索评测或跨架构选型流程；这些分别由系统书册、第三十四章/第四十五章和第四十二章承接。

## 37.1 RWKV 的设计目标：整段训练并行，生成时递归传状态

本节界定 RWKV 所处理的结构取舍：标准自注意力在每个位置显式访问此前 token 的表示，而递归网络将历史汇总进状态；RWKV 以时间混合的加权 key-value 更新连接两者，目标是在训练时利用整段序列计算、在自回归生成时按 token 传递状态。这里的“Transformer 式训练”指位置投影和序列算子可并行化，不表示 RWKV 保留了完整 self-attention 或消除了时间依赖。

## 37.2 RWKV-4 的 Time-mixing 与 Channel-mixing

本节限定在 RWKV-4，说明 token shift 如何把当前 block 表示与上一位置表示混合，再生成 receptance、key 和 value；time-mixing 以 WKV 聚合时间信息，并由 receptance 门控读出。Channel-mixing 则在每个位置上执行带 squared-ReLU 的通道变换与门控。两条子层路径共同构成 block，但只有 time-mixing 的 WKV 状态承载跨位置的加权历史；channel-mixing 不能被误认为另一种历史检索。

## 37.3 WKV：带衰减和当前项加权的归一化状态

本节给出 RWKV-4 逐通道 WKV 的归一化加权和及其 numerator/denominator 递归。内容范围包括 key 对历史权重的影响、逐通道时间衰减、当前 token 的 time-first bonus、receptance 的输出门控，以及“读出当前项”和“写入供后续位置使用的状态”之间的区别。还说明数值稳定辅助状态为何出现，并明确该公式对应 RWKV-4，不能作为后续矩阵状态版本的统一方程。

## 37.4 并行训练与递归推理：同一算子的两种执行方式

本节把位置投影、按序列扫描的 WKV 计算和自回归生成时的状态更新放在同一计算关系中。训练可在已知 token 序列上批量计算投影，并用 scan 或专用实现处理递归依赖；推理则在每个新 token 到来时读取并更新层状态。核心是同一因果更新可以有不同执行形态，位置间仍存在依赖，故“并行训练”不等于每个位置彼此独立。

## 37.5 RWKV-5/6/7：从矩阵状态到可修正记忆

本节按版本追踪状态表示和更新规则：RWKV-5 Eagle 把每头状态扩为矩阵并使用固定的逐通道衰减；RWKV-6 Finch 将 token shift 与衰减改为输入依赖；RWKV-7 Goose 使用广义 delta 更新，使旧状态可按通道衰减并沿移除 key 方向修正，再通过 replacement key 写入新关联。矩阵状态由 receptance 读取，后接各版本的归一化、bonus 和门控。正文说明矩阵状态所表达的 key-value 关联与各版本改动，不把 v6 的动态插值或 v7 的 delta 状态回写到 v4 方程中。

## 37.6 固定状态的含义、版本证据与 RWKV-8 边界

本节限定“固定状态”只表示状态占用不随已处理 token 数继续累加；状态仍随层数、通道/头维度和版本改变，矩阵状态尤其不能简称为对模型维度也很小。压缩状态不等于显式保存全部历史 token，也不能仅凭状态形状推出检索任务必然成功或失败。最后按截至 2026-11-23 的官方材料区分 RWKV-8 的实验性 DeepEmbed、ROSA 与 v4—v7 的 WKV 状态方程，并标明没有据此外推统一架构定义或普遍性能结论。

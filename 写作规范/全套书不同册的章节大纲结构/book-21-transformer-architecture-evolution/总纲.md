# 第二十一册总纲：Transformer 架构详解、升级变种与未来架构演进

## 定位与类型

本册是 Transformer、替代序列架构与现代大模型架构的专题教材。主线围绕信息如何在模型内部流动、状态如何表示、架构改变了哪些计算/内存/通信代价，以及公开证据能支持怎样的结构判断。历史模型与近期模型案例用于说明具体版本的设计，不把产品名称、榜单、API 行为、serving runtime 或 Agent harness 当作模型内部结构。

## 目标读者与前置

读者已理解基础 Transformer 和 next-token prediction，能够阅读常见线性代数记号、模型配置字段与论文图表。本册不假设读者有训练 frontier 模型或部署大规模 serving 的经验；关键符号、结构和版本边界仍须在需要处解释。

## 读者结果

读者能够复述 Transformer 的信息路由与并行优势；估算 attention、KV cache、MoE 和替代状态机制的主要成本；比较 attention、线性/稀疏注意力、SSM/RNN、卷积、检索/记忆与混合结构的计算、表达、数据访问和硬件约束；分析模型论文、模型卡和固定版本配置中公开与未公开的架构信息；区分结构变化、训练配方、权重压缩、推理实现和评测结果各自的因果范围。

## 内容范围与深度

本册从标准 Transformer 的结构组件与信息流出发，逐步解释注意力、FFN、归一化、位置和 mask，继而讨论并行性、表达能力、上下文状态、稀疏计算与执行、MoE、线性注意力、SSM/RNN/CNN、混合架构及模型谱系。对需要判断的技术，说明对象、运算或状态、计算与存储路径、适用条件及证据边界；对比较主张，保留任务、模型、训练、软硬件和测量口径。近期模型专题仅收录可核验的结构事实，并按论文、模型卡、公开配置和固定版本实现区分证据类型。

深度以读者能解释机制、估算主要代价、辨认适用边界和评估架构主张为准。对跨阶段算法需保留必要前置、关键步骤和因果，不将复杂方法压成孤立公式；硬件性能不能由渐近复杂度或参数数字直接推出。

## 跨册分工

- 第一册从零实现并讲清标准 Transformer；第二册提供有限篇幅的架构总览。
- 第五册主讲训练配置、目标与损失、分布式训练、预算和稳定性；本册保留这些内容与架构的交界，不重复完整训练 recipe。
- 第六册与第二十四册主讲推理部署、服务引擎、kernel、runtime、调度和完整性能测试；本册解释架构造成的计算/内存/通信约束，不提供第二套 serving 手册。
- 第十五册主讲多模态模型与输入编码；第十六册主讲 reasoning 方法；第十七册与第二十册主讲 Agent 行为、harness 和运行时。本册仅保留能说明模型内部结构或信息流的交界案例。

## 内容边界与证据要求

结构事实以指定论文版本、官方模型卡、配置或固定 revision 为对象；来源未披露时记录为未知，不从家族名、API、服务延迟、benchmark 或外部行为反推内部架构。性能比较需对齐任务、质量、数据、模型版本、实现、硬件、负载和计时口径；实验结果不得超出其条件。研究证据和编辑决定分别写入 `research/` 与 `progress/`，正文只解释读者需要理解的内容。

# 书册总纲与章节大纲

本目录保存各册当前有效的写作设计，按仓库的 `book-*` 目录名建立子目录。

- `总纲.md`：由 [01 书册定位与全书架构](../01-书册定位与全书架构.md) 产出，说明本册定位、读者、范围、深度与内容要求，不包含目录或章节划分。
- `目录.md`：由 [02a 章节定位与组织结构](../02a-章节定位与组织结构.md) 产出，说明完整章节编号、标题、必要的篇级分组和各章职责。
- `序号-主题.md`：由 [02a 章节定位与组织结构](../02a-章节定位与组织结构.md) 产出，说明该章完整编号标题大纲，以及每个正文部分要讲的核心主旨。

工作顺序为：01 形成书册总纲，02a 据此研究和设计各章，02 按确认的大纲研究并展开正文。已有总纲或大纲修订后仍保存完整的现行版本。

本目录不存放修改流水账、进度或交接，这些写入仓库 `progress/`；联网发现的新知识及来源证据写入 `research/`。未经过研究和确认的书册不预先生成总纲。

# 第四章：模型架构与初始化：把目标约束变成可训练的网络

本章围绕训练前架构决策如何同时影响能力、计算、状态存储和服务成本展开。读者应能从模型配置解释数据流与参数规模，比较位置编码、归一化、FFN、注意力和 MoE 方案，并判断初始化及结构变化是否适合目标约束；架构原理的完整谱系由第二册和第二十一册主讲，本章聚焦训练配置和预算转换。

## 4.0 架构选择是一张预算转换表

架构变量会转化为参数、FLOPs、显存、缓存、通信和能力风险。本节把“选模型”定位为约束下的方案决策。

## 4.1 先写清目标和硬约束

同一个模型规模标签可能对应不同结构和资源行为。本节要求先定义任务、训练预算和部署限制，再比较候选架构。

### 4.1.1 同一个“7B”可以是不同系统

参数总数不能完整描述稀疏激活、上下文、词表和存储布局。本小节说明规模标签的遗漏项。

### 4.1.2 约束表

训练时限、设备、吞吐、服务上下文和质量目标共同限定可行架构。本小节明确约束需具备测量口径。

### 4.1.3 历史脉络：为什么 decoder-only 占据主流

Decoder-only 结构的统一自回归接口适合大规模生成训练和任务迁移。本小节只说明相关机制背景与适用范围，不将流行度当作普遍最优证明。

### 4.1.4 把书系分工写进训练方案

训练方案需使用本章必要的结构描述，同时把深层架构机制、服务和平台设计交给对应书册。本小节限定第五册的讲解边界。

## 4.2 Decoder-only Transformer 的数据流

Decoder-only Transformer 将 token 表示经过因果注意力、FFN 和残差层逐层转换为下一 token logits。本节建立参数和张量讨论所需的前向路径。

### 4.2.1 Causal self-attention

因果 mask 限制每个位置只能读取其前缀。本小节说明 Q/K/V、注意力分数与因果可见性的关系。

### 4.2.2 为什么接口统一很重要

统一的输入输出接口便于串接层、训练目标和生成服务。本小节说明接口一致性如何降低工程耦合。

### 4.2.3 Encoder-only 和 encoder-decoder 的边界

不同 Transformer 家族使用不同信息流和任务目标。本小节比较其训练适用范围，避免把架构名称视为单纯实现差异。

## 4.3 参数量账本：从配置看规模

模型配置中的 hidden size、层数、head 和 FFN 中间维度共同决定主要参数量。本节分项核算 attention、FFN 和共享权重。

### 4.3.1 基本变量

参数估算需要明确层数、宽度、head 数、词表和 bias 等配置。本小节统一符号及计数口径。

### 4.3.2 Attention 参数

Q/K/V/O 投影的输入输出形状决定 attention 参数规模。本小节说明不同 head 布局如何影响矩阵尺寸。

### 4.3.3 FFN 参数

FFN 中间维度、门控分支和投影数决定每层主要计算与参数。本小节比较普通 MLP 与 gated FFN 的计数差异。

### 4.3.4 总参数近似

将 attention、FFN、embedding、norm 和输出层合并得到模型规模近似。本小节说明共享权重与忽略项如何改变结果。

### 4.3.5 规模变量之间的取舍

宽度、深度、词表和上下文会以不同方式影响表达能力和资源需求。本小节比较它们的非等价扩展。

### 4.3.6 手算一个 block：参数下降比例不等于缓存下降比例

逐项手算一个 Transformer block，区分权重参数变化与 KV/cache 形状变化。本小节说明不可用单一参数比例推断服务成本。

## 4.4 参数量和训练 token 的匹配

模型参数与训练 token 共同影响给定计算预算下的学习程度。本节介绍粗略计算关系及其对训练目标、数据质量和部署的依赖。

### 4.4.1 训练预算的第一阶关系

Dense 模型的参数数与 token 数可构成一阶 FLOPs 估算。本小节说明估算边界和长序列、稀疏路由等附加计算。

### 4.4.2 能力模型与部署模型可能不同

训练阶段的能力目标与服务阶段的延迟、缓存和精度限制可能要求不同架构取舍。本小节说明二者需通过目标任务和部署条件共同验证。

## 4.5 RoPE：在 Q/K 几何中加入位置

RoPE 通过对 query 和 key 施加位置相关旋转，使注意力分数携带相对位置信息。本节说明其训练配置中需要关注的频率、位置范围和上下文扩展。

### 4.5.1 频率表如何确定

旋转频率决定不同维度对位置变化的尺度响应。本小节说明频率配置与可表达位置范围的关系。

### 4.5.2 二维旋转

相邻维度构成二维旋转平面，位置通过角度进入表示。本小节明确旋转操作对 Q/K 分量的作用。

### 4.5.3 相对位移的性质

Q/K 的位置旋转使内积能依赖位置差而非仅依赖绝对坐标。本小节说明这一性质的条件及模型仍需从训练中学会使用位置。

### 4.5.4 长上下文扩展：从插值到非均匀频率搜索

位置插值和频率重标定以不同方式调整训练外位置行为。本小节比较方法动机、评测需求与不可直接外推的质量风险。

## 4.6 RMSNorm、Pre-Norm 与残差流

归一化和残差路径影响信号传播与深层网络训练稳定性。本节说明常见 norm 结构的功能及其规模扩展含义。

### 4.6.1 RMSNorm

RMSNorm 按均方根尺度归一化激活，而不减去均值。本小节说明计算式、参数和实现差异。

### 4.6.2 Pre-Norm 和 Post-Norm

归一化相对于子层的位置改变残差与梯度经过网络的路径。本小节比较两种结构及其训练稳定性条件。

### 4.6.3 残差尺度

多层残差相加会影响激活幅度和梯度传播。本小节说明尺度控制与初始化如何共同作用。

### 4.6.4 深度扩展与宽度扩展是不同问题

增加层数与增加 hidden size 会改变不同的计算、激活和信号传播约束。本小节避免把参数量等同的配置视为等价。

## 4.7 SwiGLU：门控 FFN 的参数和计算

SwiGLU 通过门控路径调制中间表示，改变 FFN 的参数与计算结构。本节说明机制、维度选择和与标准 FFN 的预算对照。

### 4.7.1 机制

门控分支与内容分支逐元素组合，再投影回模型宽度。本小节说明门控如何进入 FFN 的前向计算。

### 4.7.2 为什么 FFN 中间维度要重新校准

额外投影改变每层参数数量，不能照搬普通 FFN 的中间宽度。本小节说明在相近参数或计算预算下的维度调整。

### 4.7.3 边界

SwiGLU 的结构选择不能单独保证收敛或下游质量。本小节说明其依赖初始化、优化、硬件实现和目标模型验证。

## 4.8 MHA、MQA 和 GQA：把注意力质量换成缓存成本

注意力头共享方式影响 KV cache 容量、带宽和可能的质量表现。本节将训练结构与自回归推理缓存联系起来。

### 4.8.1 KV cache 账本

KV cache 大小由层数、上下文、batch、KV head 数、head 维度和 dtype 决定。本小节建立可复算的容量关系。

### 4.8.2 三种结构的取舍

MHA、MQA 和 GQA 在 query 与 key/value 头共享程度上不同。本小节比较缓存收益、并行实现和需要验证的能力差异。

## 4.9 上下文长度：训练分布和运行成本的共同约束

上下文窗口上限不代表模型能可靠使用远端信息，长度还会改变训练和服务成本。本节分开讨论训练 attention 与推理 cache。

### 4.9.1 训练与推理的不同成本

训练长序列主要增加 attention 计算、激活和通信压力，推理则持续占用 KV cache 与带宽。本小节要求按阶段使用不同资源账本。

### 4.9.2 长上下文的有效能力

有效上下文需要在不同位置、干扰和跨文档任务上验证。本小节说明窗口配置与远端检索能力不是同一结论。

## 4.10 MoE：总容量与 active 计算分开记账

MoE 用稀疏路由选择部分专家参与每个 token 的计算，但模型仍需存储并调度完整容量。本节解释路由负载、通信和 overflow 的系统边界。

### 4.10.1 Dense 与稀疏路由

Dense FFN 对每个 token 执行同一组参数，MoE 则选择 top-k 专家。本小节区分总参数、active 参数和共享组件。

### 4.10.2 路由和负载均衡

门控网络把 token 分派给专家，路由偏斜会造成热点和设备负载不均。本小节说明辅助平衡项与观测指标的用途。

### 4.10.3 代表方案各自解决了什么

不同 MoE 方案在路由、共享专家、负载均衡或通信上采用不同设计。本小节以机制和条件比较代表路线，不把名称当作性能结论。

### 4.10.4 Capacity 和 token overflow

专家容量上限决定溢出 token 的丢弃、重路由或缓冲行为。本小节说明容量系数和 overflow 对训练目标及质量的影响。

### 4.10.5 MoE 的工程边界

稀疏计算可能换来更大权重驻留、all-to-all 通信和复杂调试。本小节说明实际收益须结合设备拓扑与 profiler 判断。

## 4.11 初始化与稳定性：让第一步更新处在可控尺度

初始化设定前向激活和反向梯度的初始尺度，结构改动也会改变原有稳定性条件。本节说明初始化原则与继续训练风险。

### 4.11.1 方差直觉

层间矩阵乘法可能放大或缩小激活方差。本小节说明初始化与层宽、激活函数和网络深度的关系。

### 4.11.2 残差输出和深度

残差分支的初始尺度影响深层网络叠加后的信号稳定性。本小节说明输出投影和深度扩展的关联。

### 4.11.3 新 token 和词表变更

新增词表行的初始化需与已有 embedding/输出头及训练数据对齐。本小节说明初始化只提供起点，后续学习仍需验证。

### 4.11.4 从 checkpoint 继续训练

继续训练需匹配结构、权重、优化器状态和数据位置。本小节说明更改配置后哪些状态可以沿用，哪些须重建或复核。

### 4.11.5 架构变更后重新验证稳定性

维度、路由、norm 或位置策略变化都会影响既有数值路径。本小节要求在目标数据和实现上重新做稳定性检查。

## 4.12 训练前架构账本：从配置推到可行性

架构配置应转成参数、FLOPs、显存与服务缓存的显式账本。本节把前述机制用于训练前可行性判断。

### 4.12.1 从形状计算参数与训练预算

逐层配置可推导参数量及主要计算项。本小节说明如何将输出与 token 预算相连并保留估算边界。

### 4.12.2 从 head 数计算 KV 和长序列预算

Head 布局、层数、batch 和上下文共同决定 cache 与 attention 中间量。本小节区分推理缓存和训练 score/激活占用。

### 4.12.3 把 MoE 和服务成本放回账本

MoE 的总容量、active 计算、路由通信与缓存成本需分别记录。本小节将训练规模判断与服务并发约束整合。

## 4.13 架构故障的最小排查路径

架构故障应先用配置和张量形状定位，再逐步验证数值、路由和实际吞吐。本节建立低成本排查顺序和复现记录要求。

## 4.14 资料边界与延伸阅读

延伸资料用于追踪架构原始机制、长上下文方法和模型报告。本节要求区分通用定义、特定实现与公开案例结论。

## 4.15 章节练习：从纸面配置走到小规模验证

练习要求读者从配置推算结构成本，并为关键改动提出验证实验。

### 练习一：参数账本

读者应按给定模型形状分别估算 attention、FFN、embedding 和总参数。

### 练习二：GQA 缓存账本

读者应计算不同 KV head 配置的缓存容量并说明未计入项。

### 练习三：RoPE 长度实验

读者应区分位置插值方案和长度能力评估，提出匹配的长上下文测试。

### 练习四：Pre-Norm 与初始化

读者应分析归一化、残差尺度与初始化的依赖关系。

### 练习五：MoE 路由

读者应区分总容量和 active 计算，并设计负载及 overflow 观测。

读者应为结构调整列出稳定性、质量、资源和恢复状态的回归项。

## 4.16 本章小结

总结架构决策必须同时对应目标能力和资源账本，并将读者引向第五章的目标与训练循环。

# 第九章：训练稳定性与调试：从异常现象到根因定位

本章把稳定性调试组织为一条以时间、首个异常对象和可证伪假设为索引的证据链。读者应能建立健康基线，区分 loss spike、NaN、梯度、数据、精度、分布式同步和 checkpoint 连续性问题，并用最小反事实验证原因；第六章解释优化器机制，本章只在观察和诊断层面调用它们。

## 9.0 稳定训练不是一条光滑的 loss 曲线

训练稳定性包含数值、系统和能力等多种状态，偶发波动也可能携带重要证据。本节确立稳定性判断不能简化为单条曲线平滑。

## 9.1 健康基线：先知道什么是正常

故障诊断要先有可比较的正常训练状态和配置。本节说明基线应覆盖多个指标、明确 step 定义并保留可复现实验设置。

### 9.1.1 基线不能只有一条 loss 曲线

Loss 不能呈现梯度、吞吐、数据组成和能力回归的全部状态。本小节说明基线需有互补观测。

### 9.1.2 用训练账本定义一个 step

Step 需明确对应样本、token、micro-step 还是 optimizer update。本小节统一诊断指标的横轴口径。

### 9.1.3 基线应保存配置

配置、数据、软件版本和运行拓扑用于解释曲线变化。本小节要求将观测绑定到可追溯的运行对象。

## 9.2 第一次异常：把时间轴作为主索引

异常开始的时间点可与 batch、学习率、通信和 checkpoint 事件对齐。本节说明如何构造时间线并检查有效 loss 分母。

### 9.2.1 有效 token loss 的分母

变长样本和 mask 会改变每个窗口实际参与损失的 token 数。本小节说明分母错误如何制造假异常。

### 9.2.2 异常指示量

Loss、梯度范数、更新幅度、吞吐和非有限计数可组合成预警信号。本小节说明阈值应以基线和噪声范围为参照。

### 9.2.3 四个阶段的有限性检查

前向输出、loss、反向梯度和 optimizer 更新可分别检查有限值。本小节说明分阶段检查如何定位首个坏状态。

## 9.3 从异常曲线建立证据链

曲线关联能提出候选原因，但不能单独证明因果。本节说明结合时间、层级和反事实将现象变成可验证假设。

### 9.3.1 时间、层级和反事实

异常开始时间、模型层/模块和受控对照共同缩小故障范围。本小节说明三种索引的互补作用。

### 9.3.2 异常组合

多项指标同时或先后异常有助于区分数值、数据与系统问题。本小节说明组合模式需绑定观察条件。

## 9.4 Loss spike：有限的异常也需要解释

有限 spike 与非有限值不同，仍可能反映数据或更新机制变化。本节说明如何定义窗口异常、设计对照并保留解释边界。

### 9.4.1 spike 和 NaN 不是同一件事

Spike 表示有限 loss 突增，NaN/Inf 表示数值不再有效。本小节说明两类事件需不同排查路线。

### 9.4.2 基于窗口的候选检测

基于历史窗口和基线可定义候选 spike 指示量。本小节说明检测阈值只负责触发检查，不等于根因判定。

### 9.4.3 三组对照

固定 batch、学习率/更新对照和恢复状态对照可区分数据与优化路径。本小节说明每类实验回答的问题。

### 9.4.4 修复动作的边界

降低学习率、裁剪或跳过 batch 可能缓解表现但也可能掩盖根因。本小节要求报告修复验证范围和副作用。

### 9.4.5 代表研究如何解释和处理 loss spike

研究工作可提供具体机制假说和实验示例，但结果依赖模型、数据与训练条件。本小节比较不同研究所支持的结论。

## 9.5 NaN、Inf 和第一个坏张量

非有限值应沿计算图追到最早产生位置，而非只在最终 loss 处处理。本节说明原因、检查点和累积窗口影响。

### 9.5.1 常见原因

过大更新、低精度溢出、坏输入和非法运算可能产生 NaN/Inf。本小节列出候选机制并强调不能凭症状断定。

### 9.5.2 保留第一个坏值

异常被后续归约或跳步覆盖前应记录首发张量、索引和输入。本小节说明诊断信息的采集要求。

### 9.5.3 累积窗口中的异常

梯度累积可能延迟异常暴露或使局部坏值在同步后扩散。本小节说明逐 micro-step 检查的作用。

## 9.6 梯度爆炸与梯度过小

梯度范数和相对参数更新量揭示优化信号的不同失常方式。本节区分过大、过小、零梯度和累积结果。

### 9.6.1 全局梯度范数

全局范数汇总所有参数梯度大小，但不能显示局部异常分布。本小节说明按层/组诊断的补充价值。

### 9.6.2 相对参数更新量

更新量相对权重大小可显示参数是否发生过大或过小移动。本小节说明它与梯度范数的区别。

### 9.6.3 梯度消失与零梯度

极小或恒零梯度可能来自路径、mask、冻结状态或数值范围。本小节说明按模块和输入路径排查。

### 9.6.4 梯度累积的最终梯度

累积结果受分母、缩放、同步及裁剪顺序影响。本小节要求检查实际更新前的梯度而非单次局部梯度。

### 9.6.5 深层信号传播也会影响训练稳定性

深度网络中的残差、归一化和初始化改变梯度传播。本小节说明何时需要回到架构与激活尺度解释。

## 9.7 数据、token 和 loss mask

训练曲线异常可能源于目标内容或监督范围变化，而非优化器本身。本节从输入样本、监督比例和长度/来源切片核查数据。

### 9.7.1 常见数据异常

损坏文本、错误模板、异常长样本和标签错误会改变梯度信号。本小节说明训练前后的数据异常迹象。

### 9.7.2 有效监督比例

参与 loss 的目标 token 比例决定实际训练信号密度。本小节说明监督比例变化会造成总体 loss 口径漂移。

### 9.7.3 逐样本 decode

还原 token 序列并检查模板、角色和目标位置可发现编码协议错误。本小节说明抽样复核方式。

### 9.7.4 按来源和长度切片

按数据来源、领域和长度分组可定位局部故障。本小节说明总体平均可能掩盖少数切片。

## 9.8 学习率、优化器和 scheduler

更新规则和状态恢复错误会造成训练异常，但需要与数据和数值因素区分。本节从学习率、衰减与 optimizer state 核验。

### 9.8.1 学习率过大

过大步长可能造成 loss spike、梯度扩大或参数越界。本小节说明应结合更新幅度和对照验证。

### 9.8.2 学习率过小

过小步长可能让 loss 长期停滞，即使梯度存在。本小节说明检查实际学习率、参数变化与调度器计数。

### 9.8.3 optimizer state 恢复错误

错误或丢失的动量、方差和 scheduler 状态会改变恢复后更新。本小节说明 checkpoint 字段及连续性对照。

## 9.9 混合精度溢出

低精度格式的动态范围和缩放流程会影响梯度有效性。本节检查 FP16/BF16/FP8、loss scaling 和 clipping 顺序。

### 9.9.1 FP16、BF16 和 FP8

格式范围、精度和 scale 机制不同。本小节说明须按具体运算及设备检查。

### 9.9.2 Loss scaling

Loss scaling 可缓解下溢，但需检测溢出并正确调整 scale。本小节说明过度缩放造成跳步的证据。

### 9.9.3 unscale 后再 clipping

梯度裁剪阈值应作用于未缩放的实际梯度。本小节说明先裁剪再 unscale 会改变阈值意义。

## 9.10 分布式同步错误

各 rank 的控制流、数值状态和全局 loss 口径必须一致。本节说明分布式 hang、偏差和逐级缩小路径。

### 9.10.1 控制流与数值差异

不同 rank 走入不同 collective 或使用不同有效 batch 会造成停滞/不一致。本小节说明两类异常的区别。

### 9.10.2 逐级缩小

从单卡、少 rank、单一并行维度逐步扩大可定位问题来源。本小节说明控制变量的诊断顺序。

### 9.10.3 全局加权 loss

不同 rank token 数不等时需使用全局加权平均。本小节说明 rank 平均和 token 平均差异。

## 9.11 Checkpoint 恢复与连续性

恢复后的训练偏差可能来自状态、数据位置或分布式布局。本节说明完整状态、对照运行和产物完整性。

### 9.11.1 完整状态

模型、优化器、调度器、随机数、数据游标和混合精度 scaler 共同决定恢复轨迹。本小节列明需核查状态。

### 9.11.2 连续性对照

连续训练与保存重启的对照可发现状态遗漏或顺序偏差。本小节说明比较参数、loss 和数据消费。

### 9.11.3 checkpoint 完整性

文件存在和能够加载不一定证明所有分片、索引和配置完整。本小节说明校验摘要及恢复探针。

## 9.12 最小可运行训练诊断示例

诊断示例将有限值检查、梯度观测和更新日志组合成一个小流程。本节说明代码只演示检查路径，不代表完整集群稳定性。

## 9.13 把排查结果写成可复盘记录

复盘记录需保存首次异常时间、影响范围、证据、假设、对照、修复及剩余风险。本节说明如何让后来者能够重现判断。

## 9.14 资料边界与延伸阅读

延伸资料按数值稳定、loss spike、分布式调试和 checkpoint 恢复组织，并说明实验适用条件。

## 9.15 章节练习：把现象变成证据

练习要求读者建立基线、定位首个异常并设计针对性反事实。

### 练习一：建立基线

读者应记录定义明确的 step、token 分母、优化指标和系统基线。

### 练习二：定位第一个坏张量

读者应按计算阶段缩小非有限值的出现位置。

### 练习三：loss spike 反事实

读者应设计能区分数据、学习率和恢复因素的对照。

### 练习四：mask 审计

读者应从 decode 样本和 loss 分母检查监督范围。

### 练习五：变长梯度累积

读者应判断不同 micro-batch token 数下的正确归一化。

### 练习六：分布式 hang

读者应结合 rank 日志和 collective 顺序定位阻塞。

### 练习七：恢复连续性

读者应列出恢复对照需保留的模型、优化器和数据状态。

### 练习八：区分两种 Adam loss spike 假设

读者应把优化器机制假说转成可比较的更新/状态观察。

### 练习九：比较 spike 缓解方案

读者应对齐不同研究的模型、数据、检测口径和修复条件。

### 练习十：从层间信号判断是否是架构问题

读者应利用激活/梯度层级分布判断何时回查结构与初始化。

## 9.16 本章小结

总结诊断要从异常现象转向首发对象和可证伪原因，并引向第十章的评估与实验治理。

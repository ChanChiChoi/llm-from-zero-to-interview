# 第十七章 On-Policy Distillation：让学生在自己的分布上学会教师的行为

## 本章定位与中心

本章定义 OPD 的监督对象和教师契约，推导 token、序列与行为级训练信号，并讨论可靠性、采样、稳定化、成本、迁移评估和安全。它区别于静态离线蒸馏：学生访问状态是监督设计的核心；公开实现或个别模型案例不构成普遍最优结论。

## 一、从分布错位到教师监督契约

先解释离线样本与学生实际状态的错位，再明确教师要回答什么、看见什么以及如何验证。

### 17.0 先理解离线蒸馏为什么会失效

通过学生偏离教师演示轨迹后的状态说明误差累积与监督覆盖不足。

### 17.1 OPD 解决什么，不能解决什么

界定 on-policy 状态监督的优势和不能自动保证正确、泛化或安全的边界。

### 17.2 一条样本的状态契约

规定 prompt、学生采样、历史上下文、教师版本、tokenizer 与标签对齐等样本字段。

### 17.3 蒸馏目标的层次

从局部 token 分布扩展到序列偏好、工具动作和交付 artifact。

#### 17.3.1 Token-level 目标

说明教师在学生前缀上的下一 token 分布或 logits 如何监督学生。

#### 17.3.2 Reverse-KL 与 sampled token 信号

解释采样策略对 KL 估计方向、模式覆盖和偏差方差的影响。

#### 17.3.3 序列、动作和 artifact 目标

区分生成轨迹、工具调用和最终可执行产物的监督目标。

### 17.4 On-policy 训练循环

串联学生 rollout、教师请求、对齐目标、损失计算、更新和新策略采样。

### 17.5 教师信号的可靠性

评估教师在学生访问状态上的不确定性、错误倾向、拒答和版本变化。

### 17.6 一个代码 Agent 的 on-policy 例子

通过代码任务说明学生运行状态、教师建议、测试结果和补丁验收之间的关系。

### 17.7 教师调用策略与成本

比较全量调用、按难度或不确定性调用、缓存和批处理等成本策略及其偏差。

### 17.8 教师缓存、版本与隐私

定义缓存键、教师模型与提示版本、保留周期和敏感数据处理。

## 二、从采样估计到稳定策略更新

讨论教师信号怎样从采样分布进入策略梯度，并控制长轨迹与高方差风险。

### 17.9 OPD 的数学视角：从 KL 到 token reward

推导分布距离、逐 token 信号和策略梯度的关联，并为符号和近似设定边界。

### 17.10 为什么长轨迹后段的教师信号更危险

说明误差累积、上下文偏离和信用分配为何会在长轨迹放大。

### 17.11 稳定 OPD 的几种思路

比较限制更新区域、利用不确定度、裁剪信号和改进采样的稳定化方向。

#### 17.11.1 可信区域与信赖域

介绍限制学生与参考策略偏移的方式及需要校准的范围。

#### 17.11.2 置信度与熵

将教师置信度和分布熵作为信号筛选依据，并讨论置信度失准。

#### 17.11.3 奖励裁剪、动态采样与基线

说明裁剪、重采样和基线可改善某些估计但也改变目标分布。

### 17.12 多 rollout 与 verifier 的结合

说明多条学生轨迹和外部 verifier 如何补充教师分布监督，并保持两类信号职责清晰。

## 三、把教师信号接入可控训练系统

将教师调用和学生生成纳入安全、可计费、可复放的系统流程。

### 17.13 数据和环境的安全边界

定义教师可访问数据、工具副作用、沙箱权限与输出留存规则。

### 17.14 评估：学生是否真的学会恢复

用扰动状态、未见错误和环境变化测试学生恢复能力，而非仅比较答案相似度。

### 17.15 成本收益的计算

比较教师调用、采样、验证与学生部署成本，并以任务成功率或节省人工量衡量收益。

### 17.16 一个轻量的教师调用选择 demo

示例以可检查规则展示何时请求教师，明确它只是调用策略原型。

### 17.17 常见失败与排查

从教师答非所问、token 不对齐、缓存错误、策略不稳定和调用成本异常定位问题。

### 17.18 训练阶段如何组合

讨论 OPD 与 SFT、偏好优化、RLVR 等阶段的先后和职责边界。

### 17.19 学习目标的冲突

分析教师风格、任务正确性、工具效率和安全约束之间可能冲突的情况。

### 17.20 代表性研究分别解决了什么

按方法问题和监督信号说明研究贡献，避免将不同目标的工作混为一个算法。

#### 17.20.1 厂商技术报告、工程文章与训练器文档

分别标注技术披露、实践经验与接口文档能支持的主张范围。

#### 17.20.2 2026 年 11 月的三项新诊断

总结当期关于教师信号、采样和评估的三项诊断，给出其验证状态与待检验边界。

## 四、验证迁移能力并解释失败边界

以常见误区检查 OPD 的训练定义、评估主张和实际迁移。

### 17.21 常见误区与诊断路径

把 on-policy、RL 关系、教师能力和效果证明拆成可验证的问题。

#### 17.21.1 学生生成状态不等于训练始终是 on-policy

检查 rollout 策略版本、更新频率和缓存数据，确认样本与当前策略的距离。

#### 17.21.2 OPD 与 RL 有联系，但优化对象不同

比较行为分布匹配和任务奖励优化的目标差异。

#### 17.21.3 更强的教师不一定在学生状态上更有用

评估教师在实际学生状态上的可答性、可靠性和成本。

#### 17.21.4 教师调用减少不等于蒸馏成功

结合成功率、错误恢复和独立评测判断调用策略变化的质量后果。

#### 17.21.5 如何证明 OPD 带来了能力，而不是风格相似度

设计任务结果、反事实和基线对照，而非只测文本相似。

#### 17.21.6 tokenizer 不一致时，数值对齐可能掩盖语义错误

检查词表映射、分词边界和语义等价，防止比较错位 logits。

### 17.22 小结

回收状态契约、监督层次、教师可靠性、系统安全与迁移评估。

## 17.23 资料与进一步阅读

按基础研究、方法论文和工程实现资料组织来源，明确可复现信息与证据边界。

### 基础研究与公开技术报告

提供蒸馏理论和公开模型披露的入口，区分研究设计与工业案例。

### 代表性方法论文

按采样状态、分布目标、教师选择和策略稳定化列举论文。

### 综述、工程文章与框架文档

补充系统实现和接口说明，不将工具文档当作效果证据。

## 17.24 练习

要求构造状态契约、选择 token 或序列目标、设计教师调用策略并提出迁移评估。

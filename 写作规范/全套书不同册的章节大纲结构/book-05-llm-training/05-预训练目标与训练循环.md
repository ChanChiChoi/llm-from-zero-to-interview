# 第五章：预训练目标与训练循环：从一个 batch 到一次更新

本章沿着一个 batch 的数据流解释自回归目标如何变成一次可复现的参数更新。读者应能对齐输入、目标、mask、loss、梯度、优化器和验证状态，区分训练主循环与 checkpoint/评估决策；优化器细节由第六章主讲，分布式和数值机制由第七至九章展开。

## 5.0 从一条预测看一次训练更新

一次训练更新始于上下文和目标 token，经过概率预测、损失计算和梯度更新改变模型参数。本节建立全章跟踪的样本对象和训练状态。

## 5.1 自回归语言模型的概率目标

自回归语言模型通过每一步预测下一个 token 来拟合序列概率。本节说明目标函数、teacher forcing 与因果可见性的关系。

### 5.1.1 联合概率分解

序列联合概率按 token 条件概率的乘积进行分解。本小节说明该分解如何对应逐位置训练。

### 5.1.2 Teacher forcing

训练时模型以前文真实 token 作为后续位置的条件上下文。本小节说明它与生成时使用模型自身输出的差异。

### 5.1.3 Causal mask 的必要性

因果 mask 阻止位置读取未来目标，避免训练泄漏。本小节说明可见性约束如何维持预测任务定义。

### 5.1.4 其他预训练目标先放到主线之后

Span corruption、prefix 或多目标训练会改变可见上下文和监督区域。本小节将这些目标留作后续扩展，避免混淆主线目标。

## 5.2 Label shift：模型到底在每个位置预测什么

因果模型的 logits 与下一个 token 标签必须按位置正确对齐。本节明确 label shift、张量形状和文档边界。

### 5.2.1 一个具体序列

短序列示例用于逐位置核对输入 token 与目标 token 的配对。本小节说明首尾位置如何处理。

### 5.2.2 张量形状

Batch、sequence length、词表维度和标签 shape 决定 loss 的索引关系。本小节说明常见维度错配如何改变训练。

### 5.2.3 文档 block 的边界

打包文档可能共享张量序列，但是否共享注意力上下文需由目标协议决定。本小节说明 EOS 与 attention reset 的不同作用。

## 5.3 Cross Entropy：最大似然的可计算形式

交叉熵把模型对目标 token 的概率转为可优化标量。本节说明单位置损失如何扩展到有 mask 的 batch，并联系困惑度。

### 5.3.1 单个位置

单 token 交叉熵取目标类别的负对数概率。本小节说明 logits、softmax 概率和损失值的联系。

### 5.3.2 Masked batch loss

Batch loss 应按有效监督位置加权汇总，而不是无条件平均所有张量格点。本小节明确 sum、mean 与 mask 分母。

### 5.3.3 Ignore index

Ignore index 让指定标签不参与 loss，但不一定跳过模型对该位置的前向计算。本小节区分监督计算与模型计算成本。

### 5.3.4 困惑度

困惑度是平均 token-level 交叉熵的指数变换。本小节说明适用的数据和分母口径，以及不可直接跨协议比较的情形。

## 5.4 三种 mask 不是一回事

Causal mask、padding attention mask 和 label mask 分别控制信息可见性、无效输入与监督范围。本节建立三者的独立职责。

### 5.4.1 Causal mask

Causal mask 限制位置间的信息流，确保不能读取未来 token。本小节说明其作用域和实现形式。

### 5.4.2 Padding attention mask

Padding mask 阻止填充位置作为有效上下文参与注意力。本小节说明它与序列真实内容的区别。

### 5.4.3 Label mask

Label mask 决定哪些预测目标参与损失。本小节说明它不等价于模型是否读取对应输入位置。

## 5.5 Packing：提高 token 利用率但保留边界

Packing 减少 padding 但可能让不同文档进入同一计算序列。本节说明边界语义与 token 利用率之间的关系。

### 5.5.1 为什么 packing

固定长度 batch 遇到变长样本会产生填充浪费。本小节说明 packing 如何提升硬件利用率。

### 5.5.2 EOS 不会自动切断 attention

EOS 是序列中的 token，是否重置注意力由具体 mask 和实现决定。本小节区分终止标记与上下文隔离。

### 5.5.3 Packing 利用率和截断

Packing 与截断策略共同改变有效 token、文档完整性和监督比例。本小节说明效率指标需要与目标损失一起看。

## 5.6 一个 optimizer update 的完整顺序

一次更新按固定顺序执行前向、loss、反向、梯度处理、参数更新和状态清理。本节说明每个阶段的输入状态和产物。

### 5.6.1 Gradient clipping

梯度裁剪在优化器应用更新前限制异常梯度幅度。本小节说明裁剪对象、阈值及其不能替代根因诊断的边界。

## 5.7 Gradient accumulation：用时间换显存

梯度累积把多个 micro-batch 合成一次更新，降低单次前向的内存需求。本节说明有效 batch 和变长样本的全局归一化。

### 5.7.1 Effective batch

有效 batch 由并行副本、micro-batch 和累积步数共同决定。本小节说明样本数与 token 数口径的区别。

### 5.7.2 等 token micro-batch

Micro-batch 处理相同有效 token 数时，简单平均可对应一致的 token-level 目标。本小节说明等量条件及实现要求。

### 5.7.3 变长 micro-batch 的分母

变长批次需按整个累积窗口的有效目标数归一化。本小节说明局部均值再平均为何会改变样本权重。

## 5.8 Mixed precision：速度和数值范围的交换

混合精度在不同运算和状态中使用不同数值格式，以兼顾吞吐、内存与稳定性。本节说明主要格式及其监控路径。

### 5.8.1 FP16 与 BF16

FP16 和 BF16 的指数/尾数范围不同，因而溢出风险和精度分布不同。本小节说明格式差异与硬件支持。

### 5.8.2 Loss scaling

Loss scaling 暂时放大反向信号以减少 FP16 下溢，再在更新前还原梯度。本小节说明动态缩放和跳步行为。

### 5.8.3 数值监控

训练需记录缩放因子、非有限值、梯度范数和更新幅度等信号。本小节说明如何把指标连接到故障诊断。

## 5.9 Validation：按有效 token 汇总，而不是平均 batch

验证指标应按有效监督 token 汇总，以保持不同 batch 长度下的口径一致。本节说明验证与训练 loss 的区别。

## 5.10 日志：让一次更新可解释

日志需能把数据位置、更新状态、优化信号、系统吞吐和评估结果关联起来。本节说明关键字段如何支撑复现和异常定位。

## 5.11 Checkpoint：保存权重和保存训练状态

推理权重与继续训练所需状态并不相同。本节明确 checkpoint 组件和恢复验证。

### 5.11.1 三类状态

模型参数、优化器/调度器状态以及数据与随机状态构成不同恢复层次。本小节说明各自作用。

### 5.11.2 恢复验证

恢复验证需确认重启后训练轨迹按预期继续。本小节说明配置、步数、数据游标和数值状态的检查范围。

## 5.12 Checkpoint 选择：损失、能力、风险和成本

Checkpoint 选择需要结合 validation loss、任务能力、回归风险和保存成本。本节说明选择规则应匹配交付目标。

## 5.13 一个最小 causal LM 训练步

最小训练步把 batch 输入、标签 shift、masked loss、梯度更新和日志字段连成完整对象。本节限定示例代码所能验证的流程范围。

## 5.14 常见故障：从 loss 反查训练链

训练故障需从目标定义、输入数据、梯度、数值和运行状态分层回溯。本节将症状关联到待验证的因果假设。

### 5.14.1 Loss 不下降

持续不降可能由标签错位、数据问题、优化配置或参数未更新造成。本小节提出逐层验证方向。

### 5.14.2 Loss 虚假地很低

数据泄漏、mask 错误或分母处理问题可能制造低损失。本小节说明如何检验目标是否被正确监督。

### 5.14.3 梯度累积后训练变慢或发散

累积步数、归一化、同步和有效 token 分母错误都可能改变训练行为。本小节区分数学目标和系统实现问题。

### 5.14.4 NaN 或 Inf

非有限值需定位首次产生的张量和更新阶段。本小节说明数值范围、损坏输入及优化器状态等候选原因。

### 5.14.5 吞吐下降

吞吐变化可能来自数据加载、padding、通信或设备执行。本小节要求与有效 token 和硬件观测共同解释。

### 5.14.6 Validation 变化异常

验证曲线变化需区分模型行为、评估协议、样本构成和数据污染。本小节说明复核步骤。

## 5.15 其他预训练目标：目标变了，监督也要跟着变

Span corruption、FIM、MTP 或扩散式目标有不同输入可见性和监督结构。本节概览目标变化如何改变样本构造与 loss 解释，不替代各专题机制深讲。

## 5.16 资料边界与延伸阅读

延伸资料用于核对语言建模目标、框架训练行为和 checkpoint 状态约定。本节区分教材公式与特定实现。

## 5.17 章节练习：从公式到可复现训练

练习要求读者从 token 对齐和 loss 分母走到恢复、评估与目标选择。

### 练习一：手工完成 label shift

读者应为一个 token 序列构造正确的输入目标对。

### 练习二：区分三种 mask

读者应判断不同 mask 分别控制信息流、无效输入还是监督位置。

### 练习三：验证 packing 假设

读者应审计 packing 的效率收益与文档边界语义。

### 练习四：梯度累积的分母

读者应按有效目标总量计算变长累积窗口的损失缩放。

### 练习五：FP16 更新顺序

读者应说明 loss scaling、unscale、clipping 和 optimizer step 的先后关系。

### 练习六：checkpoint 恢复测试

读者应设计连续运行与保存恢复运行的状态对照。

### 练习七：选择 checkpoint

读者应结合损失、能力、风险和成本制定选择条件。

### 练习八：选择预训练目标

读者应根据输入输出任务定义说明何时需要改变监督协议。

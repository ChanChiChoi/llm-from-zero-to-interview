# 第六章：优化器与学习率策略：从梯度到可验证的参数更新

本章围绕优化器如何将带噪梯度转为带状态的参数位移展开，并进一步说明学习率、衰减、裁剪和 batch 预算如何共同决定训练轨迹。读者应能复算常见更新规则，区分优化算法、状态存储和调度策略，并设计公平比较与恢复实验；数值稳定的异常诊断由第九章主讲。

## 6.0 训练中的“下一步”究竟由谁决定

每次参数更新由当前梯度、优化器状态、超参数和学习率共同决定。本节把优化器定位为更新规则，而非只比较名称或排行榜。

## 6.1 先建立参数、梯度和状态账本

优化器需要处理参数、梯度及历史统计状态，训练过程也存在多个不同步数口径。本节统一后续推导的对象。

### 6.1.1 梯度是一个带噪声的估计

Mini-batch 梯度估计总体目标梯度，数据采样影响其方差和方向。本小节说明 batch 和数据分布如何进入更新。

### 6.1.2 三种容易混淆的步数

样本读取、micro-step 和 optimizer update 并非同一单位。本小节说明步数差异如何影响学习率、训练预算和 checkpoint 解释。

### 6.1.3 参数之外还保存什么

一阶/二阶矩、调度器计数、master weights 和随机状态可能参与后续更新。本小节说明状态既决定内存，也影响恢复轨迹。

## 6.2 SGD：把梯度直接变成位移

SGD 以学习率缩放当前梯度，形成最基础的参数更新。本节通过简单几何解释学习率、梯度方向和随机批次影响。

### 6.2.1 基本更新

基本 SGD 更新按负梯度方向移动参数。本小节明确符号、目标和学习率的作用。

### 6.2.2 一个二维山谷

各方向曲率不同的目标会使梯度下降出现之字形轨迹。本小节用二维例子说明条件数与步长的关系。

### 6.2.3 Momentum：积累方向而不是只看当前一步

Momentum 用指数加权历史梯度形成速度状态。本小节说明其平滑噪声和累积方向的机制。

## 6.3 Adam：为每个参数估计自己的步长

Adam 用梯度的一阶和二阶矩构造参数级自适应缩放。本节解释状态更新、偏置修正和数值稳定项。

### 6.3.1 一阶矩和二阶矩

一阶矩平滑梯度方向，二阶矩估计梯度平方尺度。本小节说明两个状态如何调节有效更新。

### 6.3.2 为什么必须做偏置修正

零初始化的指数滑动平均在早期偏向较小值。本小节说明偏置修正如何恢复初期估计尺度。

### 6.3.3 $\epsilon$ 不是装饰参数

$\epsilon$ 影响分母下界和小梯度区域的更新尺度。本小节说明其位置和实现口径会改变数值行为。

### 6.3.4 Adam 的代价

Adam 需保存额外逐参数状态并执行相应运算。本小节量化内存代价并说明状态精度与通信需求。

## 6.4 AdamW：把权重衰减从自适应梯度中分离

AdamW 将 weight decay 作为独立参数缩减项，区别于梯度中的 L2 正则。本节说明二者为何在自适应优化器下不等价。

### 6.4.1 L2 正则与 weight decay 的差别

L2 惩罚进入梯度，weight decay 直接衰减参数。本小节比较两种作用路径。

### 6.4.2 Decoupled weight decay

解耦衰减使正则项不经 Adam 的动量和方差缩放。本小节说明更新式和参数变化。

### 6.4.3 AdamW 为什么成为强基线

AdamW 具有成熟实现、广泛使用和相对清晰的调参经验。本小节说明其作为比较基线的理由及任务依赖。

### 6.4.4 Adam 与 AdamW 的最小反例

简单参数例展示将衰减并入梯度和单独衰减会产生不同更新。本小节限定反例能说明的数学差别。

## 6.5 优化器状态的显存、精度和分布方式

优化器状态在大模型训练中可能是重要内存开销，并可采用不同精度或分片布局。本节连接更新规则与系统资源。

### 6.5.1 一个粗略的训练显存公式

参数、梯度和优化器状态可构成训练状态显存估算。本小节说明公式省略激活、临时张量和对齐开销。

### 6.5.2 状态放在哪里

状态可驻留设备、主机内存或以分片形式分散在设备间。本小节说明存储位置对通信、吞吐和容错的影响。

### 6.5.3 状态精度也会改变轨迹

状态量化或低精度累积会改变估计与参数更新。本小节说明精度变化需要同时评估内存收益和质量/稳定性。

## 6.6 Adafactor：用分解统计降低二阶状态

Adafactor 以行列统计近似完整的二阶矩，降低大矩阵参数的状态存储。本节说明近似机制和配套 recipe。

### 6.6.1 从逐元素二阶矩到行列统计

矩阵的行列二阶统计用于估计每个元素的缩放因子。本小节说明近似结构及其节省内存的来源。

### 6.6.2 原始 recipe 的其他部分

Adafactor 的原始训练方案还涉及相对步长、参数尺度和更新裁剪等选择。本小节区分优化器核心与完整 recipe。

### 6.6.3 它适合解决什么问题

Adafactor 主要针对状态内存压力及特定训练设置。本小节说明适用条件和不能直接外推的范围。

## 6.7 Lion：只保留动量、用符号决定方向

Lion 使用较轻的状态并以更新方向符号构造步长。本节说明其机制、超参数匹配和证据限制。

### 6.7.1 更新结构

Lion 将两种指数平均组合后取符号作为更新方向。本小节说明参数更新和状态递推。

### 6.7.2 为什么不能照搬 AdamW 学习率

Lion 与 AdamW 的更新尺度和状态结构不同，因此相同学习率并不代表相同有效步长。本小节说明公平调参的必要性。

### 6.7.3 适用边界

Lion 的资源和质量表现依赖模型、数据、训练规模与实现。本小节要求以目标任务验证而非仅凭论文加速数字决策。

## 6.8 Sophia：让轻量曲率信息参与更新

Sophia 引入 Hessian 对角近似等曲率信息以调节更新。本节说明其计算来源和方法假设。

### 6.8.1 为什么想用二阶信息

曲率信息可能帮助按局部目标几何调整步长。本小节说明二阶信息的动机及额外估计成本。

### 6.8.2 教学形式

简化更新式展示梯度、曲率估计和裁剪如何共同作用。本小节说明简化式与实际算法实现的区别。

### 6.8.3 证据应如何表述

Sophia 的实验结论绑定其模型、token 预算、硬件和比较基线。本小节限定结果可支持的判断。

## 6.9 Muon：把矩阵参数当作矩阵来更新

Muon 利用矩阵几何信息变换更新方向，与逐元素自适应规则不同。本节说明机制直觉、参数分组和公开比较证据。

### 6.9.1 元素视角与矩阵视角

元素级优化逐项缩放梯度，矩阵级优化则考虑整体方向结构。本小节说明二者作用对象和尺度归一化的差异。

### 6.9.2 为什么通常需要参数分组

二维矩阵权重与 embedding、bias、norm 等张量具有不同结构。本小节说明分组策略和遗漏/重复参数的实现风险。

### 6.9.3 矩阵几何路线的分工与公开证据

不同矩阵优化器在正交化近似、状态和计算上存在差异。本小节对比公开证据的模型规模、任务和复现范围。

## 6.10 GaLore：降低状态维度，而不是冻结参数

GaLore 在低秩子空间存储/更新梯度信息，同时仍可训练全量参数。本节区分其与参数高效微调及矩阵分解优化器的目标。

### 6.10.1 它解决的不同问题

GaLore 关注训练状态内存，不是冻结底座或只训练小型适配器。本小节明确其优化对象。

### 6.10.2 GaLore、LoRA 和 Adafactor 的区别

三者分别改变梯度状态、可训练参数子空间或二阶统计表示。本小节按目标、状态和参数更新范围对照。

### 6.10.3 论文数字应该绑定条件

显存节省、吞吐和质量结果依赖具体规模、频率与硬件。本小节说明比较数字需要保留的实验上下文。

## 6.11 参数分组：不是每个张量都应使用同一规则

不同参数类型常需要不同优化器、衰减或学习率。本节说明分组的语义依据及配置实现约束。

### 6.11.1 常见分组

矩阵权重、embedding、norm、bias 和特殊模块可能采用不同规则。本小节说明分类依据需对应训练 recipe。

### 6.11.2 参数分组的实现陷阱

参数遗漏、重复注册和共享权重冲突会导致不一致更新。本小节说明分组覆盖率和实际 optimizer 参数集需要审计。

## 6.12 Warmup：让训练从小步开始

Warmup 在训练早期逐步增大学习率，以控制初始状态不稳定。本节说明常见调度及其适用条件。

### 6.12.1 线性 warmup

线性 warmup 按训练进度从低学习率过渡到目标值。本小节说明步数和 token 预算口径。

### 6.12.2 warmup 的长度不是固定比例

Warmup 长度依赖 batch、模型、初始化和优化器状态。本小节说明固定百分比不能替代实验诊断。

### 6.12.3 恢复训练时的 warmup

断点恢复可能选择沿用、重启或调整 warmup。本小节说明决策需与 optimizer state 和实际训练阶段一致。

## 6.13 Cosine、线性和其他衰减策略

学习率衰减决定训练后段的更新尺度与收敛行为。本节比较 cosine、线性和恒定策略。

### 6.13.1 Warmup 后 cosine decay

Cosine schedule 在预定训练进度内平滑降低学习率。本小节说明起止值、周期和预算依赖。

### 6.13.2 线性衰减和 constant schedule

线性与恒定调度分别提供逐步缩小和维持固定步长的策略。本小节比较它们与持续训练预算的关系。

### 6.13.3 调度器的边界问题

训练中断、恢复、末尾超步和配置变更可能让调度器计数失配。本小节说明如何审计 scheduler state。

## 6.14 Warmup-Stable-Decay：让调度器适应持续训练

WSD 将学习率安排为 warmup、稳定训练和衰减阶段，支持更灵活的续训窗口。本节解释其设计和证据条件。

### 6.14.1 三个阶段

Warmup、stable 和 decay 分别承担启动、主体训练和末段收敛职责。本小节说明阶段边界和学习率状态。

### 6.14.2 它和普通 cosine 的关系

WSD 与 cosine 的预算曲线和恢复使用场景不同。本小节说明何时二者可比较以及需要固定的实验条件。

### 6.14.3 公开资料的证据边界

公开 WSD 结论来自特定模型、数据和持续训练设置。本小节保留作者实验限制。

## 6.15 Weight decay：参数规模控制与学习率绑定

Weight decay 影响参数范数与泛化行为，其有效强度还与学习率和参数分组相互作用。本节说明配置和后训练阶段的差异。

### 6.15.1 衰减强度的实际含义

衰减率与更新次数、学习率和参数值共同决定累计收缩。本小节说明不能只比较一个 decay 数字。

### 6.15.2 预训练和后训练不能直接复用

后训练的数据量、目标和更新步数与预训练不同，衰减 recipe 可能需要重新选择。本小节说明复用配置的风险。

## 6.16 Gradient clipping：限制单次更新的异常幅度

Gradient clipping 控制梯度范数过大时的更新幅度。本节说明全局裁剪、混合精度顺序和裁剪频率的诊断意义。

### 6.16.1 Global norm clipping

全局范数裁剪按梯度整体范数同比缩放。本小节说明向量化范数和裁剪阈值的含义。

### 6.16.2 混合精度中的顺序

混合精度下需先还原缩放梯度，再按实际梯度裁剪。本小节说明执行顺序错误造成的尺度偏差。

### 6.16.3 clipping ratio 是诊断信号

持续触发裁剪可能说明数据、学习率或模型稳定性问题。本小节说明报告触发率和幅度而非只记录裁剪阈值。

## 6.17 Batch scaling：学习率应跟 token 预算一起看

Batch 大小改变梯度噪声、每步 token 数和总更新步数。本节说明学习率缩放规则只能作为实验起点。

### 6.17.1 有效 token batch

有效 token batch 汇总并行度、micro-batch 和梯度累积中的目标 token。本小节说明 mask 与变长样本对分母的影响。

### 6.17.2 线性缩放只是起点

线性学习率缩放基于特定优化和 batch 假设。本小节说明需根据目标任务与稳定性验证调整。

### 6.17.3 相同 steps 不等于相同训练量

不同 batch 和长度配置在相同步数下处理的有效 token 不同。本小节要求比较时报告 token 与更新预算。

## 6.18 优化器与调度器的公平实验

优化器比较要控制数据、训练 token、调参预算和评估条件。本节说明如何将质量、效率、稳定和恢复纳入同一实验。

### 6.18.1 先固定什么

数据顺序、模型、token 预算、硬件和评测协议构成可比实验的基础。本小节明确哪些变量需固定、哪些需单独搜索。

### 6.18.2 同时看四种曲线

Loss、学习率/更新、系统吞吐和能力评估分别显示不同训练结果。本小节说明单一曲线不能支撑整体优胜结论。

### 6.18.3 质量不能只用 PPL

PPL 反映特定语料上的预测损失，不能代替任务和安全评估。本小节说明多目标验证。

### 6.18.4 按瓶颈选择优化器路线

优化器选择需由状态内存、收敛质量、系统吞吐和实现维护成本共同决定。本小节建立条件化选择逻辑。

## 6.19 一个可运行的优化器审计示例

示例通过小型参数更新检查状态、参数分组、调度和日志之间的一致性。本节说明代码验证范围，不能将玩具运行当作大规模收敛证据。

## 6.20 Checkpoint：优化器实验必须可以继续

公平比较和中断恢复都要求保存与优化器轨迹相关的状态。本节说明 checkpoint 字段和连续性对照。

### 6.20.1 需要保存的字段

模型、optimizer、scheduler、scaler、step、随机数和数据游标共同支持训练恢复。本小节按恢复目标确定必要字段。

### 6.20.2 连续运行和恢复运行的对照

受控对照比较 uninterrupted run 与 checkpoint 恢复轨迹。本小节说明允许差异、比较指标和拓扑限制。

## 6.21 从 loss spike 反查优化器链

Loss spike 可能与优化器相关，但须通过时间线和反事实验证。本节逐步区分其他原因与超参数候选。

### 6.21.1 第一步：确认是否真的是优化器问题

检查样本、mask、数值和分布式状态，避免将所有异常归因于学习率。本小节规定首轮假设区分。

### 6.21.2 学习率过大或 warmup 太短

过大的有效步长或启动阶段过快可能造成更新异常。本小节说明学习率轨迹和梯度/参数变化的联合证据。

### 6.21.3 $\beta$、eps 或 decay 不合适

矩估计平滑、分母稳定项和参数衰减都会改变更新轨迹。本小节说明单变量对照及配置依赖。

### 6.21.4 clipping 持续触发

高裁剪频率可能是更新幅度、数据异常或模型结构问题的结果。本小节说明区分根因的观测信号。

### 6.21.5 换新优化器却没有收益

新算法可能只是换了一组未调好的有效步长和状态规则。本小节说明需要匹配调参预算并报告质量/效率 Pareto 取舍。

## 6.22 资料边界与延伸阅读

延伸阅读按优化器原论文、学习率 recipe、实现文档与独立比较资料组织，并保留实验口径。

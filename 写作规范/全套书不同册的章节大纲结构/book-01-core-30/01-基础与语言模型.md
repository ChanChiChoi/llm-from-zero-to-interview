### 模型是在背诵，还是在泛化

这不是二选一。固定短语、重复文本或罕见字符串可能被模型记住；语法、常见事实关系和任务格式则可能以可泛化的模式被学到。

### 概率不是事实核验

模型给出的 P_{\theta}(x_{t}\mid x_{1:t-1}) 是模型在给定参数和上下文时，对下一个 token 的条件分布。它不是“这个事实为真的概率”，也不会自动查验外部证据。

### 输入和标签为什么要错开

最容易在实现中出错的地方，是让第 t 个位置预测错了 token。若输入是 [x_{1},x_{2},x_{3},x_{4}]，显式构造时应比较前缀 [x_{1},x_{2},x_{3}] 与目标 [x_{2},x_{3},x_{4}]，而不是让 x_{t} 去预测自己。

### 在语言模型训练中的位置

放回语言模型里，一次训练 step 是：取 token 和对齐后的标签，前向得到 logits，按目标位置计算交叉熵，再从 loss 反向求梯度，最后由优化器使用梯度更新参数。loss.backward() 做梯度计算，optimizer.step() 才改变参数；框架通常把梯度累加在参数的 .grad 中，因此进入下一次更新前还要按训练方案清空或有意累积。

### 梯度为什么会消失或爆炸

反向传播要把梯度从输出一层层传回去。每经过一层，梯度都会乘上该层在当前状态下的局部导数；多层连乘后，如果许多方向都持续缩小，传到前面层的梯度就可能接近零，这叫梯度消失。

### 训练不稳定时，沿着梯度这条路排查

梯度描述的是当前参数和当前 batch 附近的局部变化，不是模型能力分数；一个 batch 的 loss 降了，也不保证验证集表现会提升。梯度下降的基本更新是，具体表达见下式。

### 把梯度变成稳定的训练轨迹

梯度下降给出了最基本的更新方向，但真实模型的梯度尺度会随参数、层和训练阶段而变化，小批量（mini-batch）还会带来噪声。优化器需要在方向、步长、自适应缩放和正则化之间做取舍；权重衰减（weight decay）控制参数收缩，学习率调度（learning rate schedule）则把步长安排到训练生命周期中。

### 为什么 AdamW 常被用作基线

本讲选 AdamW 做比较起点，因为它保留 Adam 按坐标调整更新的做法，同时把参数衰减单独处理。这个选择不代表它对所有 LLM 都最好：AdamW 原论文报告的是特定图像分类任务上的泛化改进；DeepSeek LLM 则给出一项具体例子，预训练采用 AdamW，并用多阶段调度（multi-step schedule）替换余弦调度（cosine schedule）。

## 本章小结

语言模型从 token 序列的条件概率开始，通过 next-token prediction 获得语言、知识和任务模式的底座能力；交叉熵把真实 token 的概率变成可优化的损失，最大似然解释了它的统计来源，perplexity 提供了受限条件下的预测不确定性指标。反向传播把 loss 转成参数梯度，梯度下降和 AdamW 决定参数怎样移动，warmup、decay、裁剪、精度和 checkpoint 管理决定训练是否稳定。

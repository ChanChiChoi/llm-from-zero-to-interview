## 第 6 讲：Tokenization——文本怎样变成离散编号

本讲从“模型接收的是编号，不是字符串”切入，再通过“为什么常见做法是子词或字节级切分”“更换 tokenizer 要同步词表与 embedding”逐步展开。

### 模型接收的是编号，不是字符串

神经网络不能直接把“我喜欢模型”当作文本对象处理。Tokenizer 按固定规则切分文本并映射词表 ID；下例对照字符串、token 和整数编号。

### 为什么常见做法是子词或字节级切分

表格按“切分粒度、好处、代价”组织本节要核对的对象和差异。

### 更换 tokenizer 要同步词表与 embedding

训练和推理应使用兼容的 tokenizer、词表、特殊 token 配置和模型 embedding。若 tokenizer 新增或重排词表项，模型的 embedding 行也必须按约定同步；仅仅重新编号会改变每个 ID 对应的向量。

## 第 7 讲：Embedding 与位置信息——编号怎样变成表示

本讲从“查表把离散 ID 变成向量”切入，再通过“为什么还需要位置”“位置方案改变的是计算路径”逐步展开。

### 查表把离散 ID 变成向量

ID 是词表里的地址，不是词义本身。嵌入（embedding）是一个可训练矩阵 E \in \mathbb{R}^{V \times D}；输入 ID 为 i 时，模型取出第 i 行。

### 为什么还需要位置

只查表会让相同 token 在任何位置都拿到同一行。例如 ID 12 出现在句首还是句尾，单看 E_{12} 是无法区分的。

### 位置方案改变的是计算路径

“加入位置”不是一种固定操作。比较时先问它改动了哪一步，而不是只背方法名称，涉及对象和取舍见下表。

## 第 8 讲：Self-Attention 直觉——当前位置怎样读取上下文

本讲从“表示需要依赖上下文”切入，再通过“从匹配到加权汇总”“为什么它适合并行，也为什么代价随长度上升”逐步展开。

### 表示需要依赖上下文

同一个 token 在不同上下文中的作用可能不同。比如“苹果”可以指水果，也可以指公司；单看 token 本身无法确定当前语境。

### 从匹配到加权汇总

对某个 Query，模型计算它与所有可见 Key 的匹配分数，把分数归一化成权重，再按这些权重混合 Value。Query 和 Key 决定“从哪儿取多少”，Value 决定“取回来的内容是什么”。

### 为什么它适合并行，也为什么代价随长度上升

在一层的训练前向中，整条序列的 token 表示已经给定，所以 Q、 K、 V 可以一次投影；所有 Query 与 Key 的点积也能组成矩阵乘法并行计算。这和标准 RNN 必须先得到第 t-1 步状态才能计算第 t 步不同。

## 第 9 讲：Scaled Dot-Product Attention——从公式到数值

本讲从“张量怎样变成 Query、Key、Value”切入，再通过“手算一个 Query 的输出”“因果 mask 怎样改变可见位置”逐步展开，最后以“计算量与实现优化不是同一问题”收束。

### 张量怎样变成 Query、Key、Value

令输入表示 X \in \mathbb{R}^{B \times T \times D}，其中 B 是 batch 大小、 T 是序列长度、 D 是隐藏宽度。沿最后一维做线性投影生成 Q、 K、 V，再将投影后的通道拆成头，具体表达见下式。

### 手算一个 Query 的输出

取一个 Query q=(1,0)，两个 Key k_{1}=(1,0)、 k_{2}=(0,1)，两个 Value v_{1}=(2,0)、 v_{2}=(0,4)，令 d_{h}=2。

### 因果 mask 怎样改变可见位置

自回归语言模型在每一位置只允许读取当前及之前的位置，防止目标位置获得未来 token。原始 Transformer 将非法位置的分数在 softmax 前设为负无穷。

### 计算量与实现优化不是同一问题

标准全连接 scaled dot-product attention 的主要计算量约为 O(BT^2D)；常见朴素实现会显式保存 O(BHT^2) 的注意力分数或权重矩阵。随着序列长度增长，点积计算和中间状态都会变贵。

## 第 10 讲：Multi-Head Attention——多个子空间与共享 KV

本讲从“多头做的是并行投影，不是复制同一个判断”切入，再通过“KV Cache 为什么受 KV 头数影响”逐步展开。

### 多头做的是并行投影，不是复制同一个判断

Multi-Head Attention（MHA）用多组独立投影，让不同头在各自学到的子空间里计算注意力。不同头可以形成不同的读取方式，但结构本身不会给某个头指定“语法”或“事实”这样的语义标签。

### KV Cache 为什么受 KV 头数影响

提示词 prefill 会先为各层所有输入位置生成 K/V；之后每生成一个新 token，各层再追加该位置的 K/V，供下一步复用。由于每层输入表示和投影不同，每层有自己的缓存。

## 第 12 讲：Transformer Block——Attention 与 MLP 如何组合

### 一个 Block 怎样更新每个位置的表示

Attention 解决 token 之间如何交换信息：位置 t 根据允许读取的上下文，汇入其他位置的内容。MLP 解决单个位置的特征怎样重组：它对每个 token 分别做相同的非线性变换，不直接读取其他位置。

### 残差支路为何有助于深层优化

一个残差子层把输入表示保留下来，再叠加本层学到的更新，具体表达见下式。

### LayerNorm 和 RMSNorm 怎样重标定表示

在常见的 Transformer 输入形状 [B,T,D] 中， B、 T、 D 分别是 batch、序列位置数和隐藏维度。若 Norm 配置为仅归一化 D 维，那么每个样本、每个 token 独立计算统计量，不会把其他 token 或 batch 样本混进同一组统计。

### Pre-LN 和 Post-LN 改变残差路径

残差加法与 Norm 的先后顺序会改变每层的计算图。Pre-LN 在子层输入处归一化，把变换结果加回原始表示；Post-LN 则先相加，再归一化总和，具体表达见下式。

## 第 14 讲：RoPE 与长上下文——位置关系不等于长度能力

本讲从“RoPE 怎样让 Q/K 点积感知相对位移”切入，再通过“扩展位置范围会改变模型看到的距离”“窗口上限不等于长上下文使用能力”逐步展开。

### RoPE 怎样让 $Q$/$K$ 点积感知相对位移

RoPE（Rotary Position Embedding，旋转位置编码）把位置信息施加到 Attention 的 Query 和 Key 上。先看一个二维特征对子空间：位置 m 将向量旋转 m\theta，其中 \theta 是每个位置步进的角度。

### 扩展位置范围会改变模型看到的距离

位置关系公式本身没有给出“训练 4K 就会理解任意长度”的保证。推理时直接把位置索引送到远超训练范围的位置，等于把模型放到训练时未见过的旋转相位。

### 窗口上限不等于长上下文使用能力

需要分开检查三件事：位置编码把距离送进模型的方式、模型或服务实际接受的 token 上限、模型在真实任务中定位并使用证据的能力。假设一个服务一次请求的总 token 预算是 8,192，并预留 1,024 个 token 生成答案，那么输入可用空间至多约 7,168；系统提示、聊天模板、检索片段和图像编码还会占掉输入预算。

# 第 7 章 RAG 项目实战

**正文对应：** [文档与检索](../../../book-03-practical-handbook/chapters/07-rag项目实战-1-文档与检索.md)、[重排与证据](../../../book-03-practical-handbook/chapters/07-rag项目实战-2-重排与证据.md)、[评估与失败归因](../../../book-03-practical-handbook/chapters/07-rag项目实战-3-评估与失败归因.md)

本章围绕“回答能否由有权限的资料支持”建立 RAG 项目链路。读者从解析、切块和召回开始，经过 reranker、上下文组织、引用与拒答，再用分层指标定位失败并核算成本；相似度分数、引用编号和自动评估分数都不能单独证明答案正确。

## 7.1 文档准备：从原文件到稳定的检索片段

本节将文件解析、结构保留、chunk 粒度和来源元数据连起来，建立可回溯且可授权的检索语料。

### 7.1.1 文档读取和清洗

说明格式解析、表格/标题/页码保留、清洗规则与原文位置映射。

### 7.1.2 Chunk 不是任意长度的字符串

界定 chunk 的边界、语义完整性、来源引用和父子文档关联。

### 7.1.3 Chunk size 的取舍

比较较小片段的精确召回与较大片段的上下文完整性、成本和噪声。

## 7.2 检索与上下文：从查询到有限候选

本节解释 embedding、向量相似度、稀疏检索、过滤与上下文预算，强调召回分数只是候选排序依据。

### 7.2.1 Embedding 与相似度

说明查询/文档向量、归一化和相似度排序的含义及边界。

### 7.2.2 Sentence Transformers 和 FAISS 接口

核对模型编码与索引查询的输入、向量维度、距离语义和版本约定。

### 7.2.3 无依赖的稀疏向量 RAG demo

以小型可解释词项表示展示从 query 到 chunk 排名的过程。

### 7.2.4 查询改写与过滤

讨论 query normalization/rewriting 与元数据、权限过滤各自的责任。

### 7.2.5 上下文预算

将候选数量、token 预算、去重和顺序组织与生成质量/延迟关联。

### 7.2.6 失败模式与诊断顺序

沿解析、召回、过滤、上下文截断和提示输入定位最早偏差。

### 7.2.7 资料与证据边界

明确特定检索库接口、相似度机制与业务检索质量的验证范围。

## 7.3 Reranker：把候选排序做得更细

本节比较双编码器和交叉编码器的打分路径，评估候选规模、重排收益和延迟成本。

### 7.3.1 Bi-encoder 与 Cross-encoder

比较向量离线编码与 query-document 联合打分的质量、计算和召回角色。

### 7.3.2 外部模型接口

说明重排服务的输入输出、批量、错误、数据权限和版本记录。

### 7.3.3 无依赖精排 demo

通过构造候选得分演示排序变化，限定为排序逻辑示例。

### 7.3.4 候选数和最终上下文数

区分召回候选 K 与送入生成器的最终上下文 N，并分析预算取舍。

### 7.3.5 失败模式

覆盖错排、召回缺失、重复候选、过长上下文与分数漂移。

### 7.3.6 用同一组问题看排序收益和成本

建立配对测试集，对比排序质量、任务成功和端到端延迟。

### 7.3.7 资料与证据边界

限定公开模型报告、服务文档与本地候选集效果的推断范围。

## 7.4 证据与引用：让回答中的主张可以核验

本节建立回答 claim、候选证据、引用编号和权限边界之间的映射，并说明引用存在与语义支持是两个判断。

### 7.4.1 本次回答内的引用编号

说明短编号如何映射到当前请求内的文档片段，避免跨请求误用。

### 7.4.2 Cited prompt 的边界

界定提示中证据呈现、来源编号和模型可见上下文的关系。

### 7.4.3 结构化答案协议

规定回答字段、claims/citations 结构及解析失败处理。

### 7.4.4 引用合法性和缺失引用

分别检查 citation ID 是否存在、是否引用了可用证据及必需引用是否缺失。

### 7.4.5 从引用合法到引用支持

说明合法编号不代表内容蕴含 claim，需要语义支持判定。

### 7.4.6 把一句回答拆成可审计的证据关系

将复合句拆成原子主张，并把每条 claim 映射到支持、矛盾或缺失证据。

### 7.4.7 资料不足与选择性回答

连接召回不足、证据缺失、置信与拒答/澄清策略。

### 7.4.8 失败模式

覆盖伪引用、引用错段、过度断言、证据冲突与来源版本失配。

### 7.4.9 资料与证据边界

区分检索召回结果、引用结构检查和人工/裁判语义支持证据。

## 7.5 评估协议：分别测量检索、生成与证据

本节将检索标签、回答正确性、忠实性、引用支持和拒答行为拆成分母清晰的独立指标。

### 7.5.1 评估样本需要包含什么

明确 query、gold evidence、允许拒答标记、任务标签、预测和版本字段。

### 7.5.2 Hit@k、Recall@k 和 MRR

比较是否命中、相关证据覆盖率和首个相关结果位置的统计含义。

### 7.5.3 答案正确性、忠实性和完整性

区分答案是否正确、是否受上下文支持及是否涵盖必要要点。

### 7.5.4 引用与支持率

分开记录引用存在、编号合法和 claim 语义支持率及其分母。

### 7.5.5 选择性回答和拒答

并列回答准确率、coverage、abstention precision、unsafe answer 和错误拒答。

## 7.6 从失败样本到可复查的实验报告

本节从最早失败环节出发，生成可复查指标、成本和逐样本改进计划。

### 7.6.1 按最早出错环节分类

区分解析、召回、排序、上下文、生成、引用、权限与协议失败。

### 7.6.2 无依赖的分层评估 demo

以结构化标签展示早期失败归因，并限定关键词代理和引用代理不能替代语义核验。

### 7.6.3 评估报告与成本

联合报告版本、分层质量、延迟、token、权限和人工复核成本。

### 7.6.4 用分层结果决定下一轮改什么

按任务、风险、权限和失败阶段识别先修问题，并用配对样本检查回归。

### 7.6.5 资料与证据边界

说明自动评估框架、judge 和本地标注/系统事实之间的限制。

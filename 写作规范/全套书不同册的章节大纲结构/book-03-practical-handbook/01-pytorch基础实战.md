# 第 1 章 PyTorch 基础实战

**正文对应：** [01-pytorch基础实战](../../../book-03-practical-handbook/chapters/01-pytorch基础实战.md)

本章围绕“一个训练步骤怎样改变模型参数”建立可复算的 PyTorch 基础。读者从输入、预测和目标出发，沿损失、梯度、优化器状态、精度和调度追踪一次更新，并能从张量形状、训练状态与日志中定位常见错误；不把 API 记忆当作理解目标。

## 1.1 从线性回归开始：一个参数更新到底改变了什么

本节以可手算的回归任务连接数据、预测、误差和参数更新，让读者先明确训练中哪些量是输入、目标、模型参数与观测结果。

### 1.1.1 先写清楚输入、目标和预测

通过小型数值样例区分特征、目标、预测值与参数，说明张量形状和样本对应关系如何表达任务。

### 1.1.2 从误差算到梯度，再看参数怎样移动

覆盖平方误差、链式法则与梯度下降的方向关系，并区分梯度的数值、学习率和实际参数变化。

### 1.1.3 梯度默认会相加：独立更新前要清零

说明 PyTorch 梯度累积语义、`zero_grad` 的位置，以及漏清梯度如何使更新偏离预期。

### 1.1.4 广播可以自动配形状，却不知道样本是否配对

说明广播规则的便利与风险，重点检查 `[B]`、`[B,1]` 等形状意外组合后造成的跨样本误算。

### 1.1.5 把公式写成循环，看看框架替你省了什么

用手写标量更新和张量自动微分建立对应关系，区分数学目标、计算图和框架执行。

## 1.2 MLP 分类器：从连续预测到类别分数

本节将连续回归扩展为分类，说明分类器学习的是类别 logits，网络层、激活函数及训练/推理模式各自承担什么作用。

### 1.2.1 分类模型先输出分数，而不是类别

解释 logits、softmax 概率和最终类别的关系，并说明训练时为何保留连续分数。

### 1.2.2 为什么需要隐藏层和 ReLU

通过线性可分边界的限制引出隐藏层与非线性，明确多层线性变换仍可合并为单一线性变换。

### 1.2.3 写一个可观察的 MLP

范围包括输入/隐藏/输出张量形状、初始化、前向结果与一次更新中值得打印核对的值。

### 1.2.4 `train()` 和 `eval()` 改变的是模块行为

区分模块模式与梯度开关，说明 Dropout、BatchNorm 等层在训练和推理时的行为差别。

### 1.2.5 MLP 与 Transformer 前馈网络的联系

建立逐 token 前馈子层与普通 MLP 的联系，同时指出序列混合由注意力等模块承担。

## 1.3 交叉熵：分数怎样变成可优化的目标

本节解释分类交叉熵从最大似然而来，连接 logits、概率、标签与梯度，并说明 reduction、掩码和语言模型 token 统计口径。

### 1.3.1 从最大似然得到负对数似然

围绕目标类别概率的负对数说明交叉熵为何惩罚低概率的正确类别。

### 1.3.2 数值稳定性来自先平移 logits

解释 log-sum-exp 的平移不变性及其避免指数溢出的作用，区分稳定实现与改变目标。

### 1.3.3 logits 的梯度为什么是“概率减去 one-hot”

呈现 softmax 交叉熵对 logits 的梯度结构，说明梯度如何把目标类别分数推高、其他分数压低。

### 1.3.4 `reduction`、类别权重与无效标签

说明逐样本损失、求和/平均、类别加权和 ignore index 对分母及梯度尺度的影响。

### 1.3.5 语言模型中的 `[B,T,V]`

连接 batch、时间步与词表维度，解释 logits/labels 如何对齐以及忽略位置怎样进入损失。

### 1.3.6 从平均 token loss 到 perplexity

说明按有效 token 聚合平均负对数似然并取指数得到困惑度，同时限定其可比较条件。

## 1.4 反向传播：计算图、局部导数与梯度的路径

本节从计算图解释反向传播和 autograd 的关系，聚焦梯度存储、张量生命周期及数值核验，帮助读者判断梯度为何缺失或异常。

### 1.4.1 反向传播不是“把公式倒着算一遍”

说明计算图节点、局部导数与链式法则如何共同计算标量目标对参数的导数。

### 1.4.2 标量损失与非标量输出

解释 `backward()` 默认隐含标量目标，以及对向量输出求导时必须明确的向量-Jacobian 种子。

### 1.4.3 叶子张量、`.grad` 与中间结果

区分叶子参数与中间激活的梯度保留规则，说明如何正确检查某层中间值的梯度。

### 1.4.4 `detach()`、`no_grad()` 和参数更新

区分从计算图断开、关闭梯度记录与原地更新参数的用途，并指出它们对后续反向传播的影响。

### 1.4.5 原地操作为什么可能破坏反向传播

说明 autograd 为反向计算保存中间值的机制，以及原地修改为何会触发版本冲突或错误梯度。

### 1.4.6 用有限差分检查一个梯度

将解析/自动微分结果与小扰动数值近似对照，说明步长、精度与检查规模的适用边界。

## 1.5 优化器：梯度告诉方向，状态决定怎样走

本节比较 SGD、Momentum、Adam 和 AdamW 的更新状态，进一步把梯度清零、累积、混合精度与训练循环顺序放进可审计流程。

### 1.5.1 SGD 是一个更新规则，不是训练的全部

明确基础 SGD 更新式及其依赖的目标、梯度与学习率。

### 1.5.2 Momentum 为什么能平滑小批次噪声

说明速度状态的递推及其对连续同向梯度和短期噪声的不同反应。

### 1.5.3 Adam 的一阶矩、二阶矩和偏差修正

覆盖动量估计、平方梯度估计与早期偏差修正，明确优化器状态也需要随训练保存。

### 1.5.4 Adam 与 AdamW：L2 正则和 weight decay 不总是同一件事

解释耦合 L2 惩罚与解耦权重衰减在自适应优化器中的差异及参数分组边界。

### 1.5.5 一个可靠的训练循环需要明确顺序

围绕前向、损失、反向、梯度处理、优化器更新和日志，界定每一步读写的状态。

### 1.5.6 梯度累积与有效批次大小

说明微批次累积怎样模拟更大的有效 batch，关注损失缩放、更新频率及样本数分母。

### 1.5.7 混合精度改变的是数值路径，不是数学目标

说明低精度计算、梯度缩放和参数精度的关系，以及溢出跳步对实际更新次数的影响。

## 1.6 学习率调度：让更新尺度与训练阶段相匹配

本节把调度器视作与优化器更新步耦合的状态，覆盖 warmup、衰减、checkpoint 恢复和日志验收。

### 1.6.1 学习率是时间的函数

解释学习率随训练进度变化的含义，并区分训练步、epoch 与 scheduler step。

### 1.6.2 线性 warmup 的含义

说明 warmup 如何逐步放大更新尺度及其依赖的总步数和起始学习率。

### 1.6.3 常见衰减函数

比较线性、余弦等调度的形状与末端行为，强调曲线名称本身不足以定义实验。

### 1.6.4 调度器的步长必须与参数更新对齐

说明 scheduler 应在何时推进，怎样避免梯度累积或 AMP 跳步时计数错位。

### 1.6.5 `LambdaLR` 与分段策略

界定自定义学习率函数的输入步数、返回系数及边界条件。

### 1.6.6 checkpoint 必须包含训练状态

列出模型、优化器、调度器、随机数与训练进度等恢复所需状态，并区分推理权重与可续训快照。

### 1.6.7 用日志判断调度是否真的生效

说明记录学习率、更新步和损失有助于发现调度器未推进或恢复步数错误。

### 1.6.8 从六个机制回到一条训练链

把目标、梯度、优化器、精度、调度和 checkpoint 汇总为一次可复核的训练过程。

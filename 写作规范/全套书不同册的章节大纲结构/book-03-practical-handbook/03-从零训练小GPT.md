# 第 3 章 从零训练小 GPT

**正文对应：** [数据与训练](../../../book-03-practical-handbook/chapters/03-从零训练小gpt-1-数据与训练.md)、[生成与评估](../../../book-03-practical-handbook/chapters/03-从零训练小gpt-2-生成与评估.md)

本章围绕“从文本到下一 token 预测，再到可检查的生成结果”形成完整训练实验。读者应理解 tokenizer、样本切片、因果模型、损失、更新状态、解码和实验比较之间的依赖，并能复现配置、检查失败与限定结论。

## 3.1 Token 数据约定：从文本到 next-token 样本

本节确定预测目标和数据边界，比较教学用字符 tokenizer 与连续 token 流接口，并检查标签位移、batch 构造和数据切分。

### 3.1.1 先确定模型究竟预测什么

说明自回归训练中上下文与下一个 token 标签的对应关系。

### 3.1.2 字符级 tokenizer：简单，但要明确代价

说明字符级词表构造的透明性及其序列长度、Unicode 和词表规模限制。

### 3.1.3 先切分独立文档，再编码和拟合词表

围绕文档边界和训练/验证切分说明如何避免词表与文本信息泄漏。

### 3.1.4 向右移动一位的标签

用输入/目标偏移关系核对每个位置预测的 token，定位 off-by-one 错误。

### 3.1.5 从随机起点构造 batch

说明固定窗口、随机采样起点和 batch shape 如何构成训练样本。

### 3.1.6 Dataset 接口与连续流接口

比较预先切分样本与连续 token 流的取数方式、边界行为和复现要求。

### 3.1.7 数据管线的局部验证

检查 token 解码、窗口/目标对齐、切分隔离和 batch 统计是否符合协议。

## 3.2 最小 GPT：从 token id 到训练 loss

本节把嵌入、因果 attention、Pre-LN block、输出头和交叉熵组成小模型，追踪训练前向与一次参数更新。

### 3.2.1 一次前向传播经过哪些形状

贯通 token ID、embedding、block hidden state、logits 与目标张量形状。

### 3.2.2 因果 attention 的数学对象

说明 query-key 分数、因果可见性和 value 汇聚如何实现下一 token 条件预测。

### 3.2.3 Pre-LN block 与参数量估算

建立最小 block 结构、残差路径和参数规模的可复算估算。

### 3.2.4 一个完整的最小模型实现

明确模型组件、配置、前向返回值与生成所需接口之间的契约。

### 3.2.5 交叉熵与 token 数量

说明损失对有效预测位置求平均的口径及 padding/无效位置的处理。

### 3.2.6 训练循环：每一步究竟更新了什么

连接梯度、优化器、随机 batch、梯度清零与日志，解释更新步的实际含义。

### 3.2.7 生成是另一个计算协议

区分训练时并行预测所有位置与推理时逐 token 生成的状态和停止条件。

## 3.3 解码控制：Temperature、Top-k 与 Top-p

本节把输出 logits 转成采样分布，比较温度、截断候选集与随机种子对生成行为的影响。

### 3.3.1 logits、概率和选择规则

说明 logits 到 softmax 概率再到贪心/采样决策的关系。

### 3.3.2 Temperature 改变分布尖锐程度

解释缩放 logits 如何改变分布熵，而不改变模型训练权重。

### 3.3.3 Top-k 保留固定数量的候选

说明固定候选数截断及小词表/边界情况。

### 3.3.4 Top-p 保留概率质量

解释按排序累计概率截断的动态候选数量与采样差异。

### 3.3.5 一个可验证的采样实验

通过固定 logits 与种子观察采样参数改变分布和输出的方式。

### 3.3.6 找出解码问题出在哪一步

区分模型 logits 异常、温度/截断配置错误与生成停止条件问题。

## 3.4 Checkpoint、日志与可恢复评估

本节说明模型快照、优化器状态、训练进度与评估记录如何组成可恢复实验。

### 3.4.1 checkpoint 不是只有模型权重

列明续训恢复所需的优化器、调度器、随机数、step 与数据状态。

### 3.4.2 best 与 last 是两个不同对象

区分按验证指标选出的最佳快照和训练结束时最后状态。

### 3.4.3 保存与加载的实现

界定序列化字段、版本元数据与加载后结构核验。

### 3.4.4 step 的定义必须写进代码

明确优化器更新次数与 micro-batch、epoch 等计数的区别。

### 3.4.5 日志和生成样例

连接数值曲线、固定提示样例和配置版本，避免只保留终点 loss。

### 3.4.6 保存策略与恢复验收

检查从快照继续运行是否恢复步数、优化器状态、随机采样与输出轨迹。

## 3.5 训练曲线与生成行为：从 loss 到证据

本节解释训练/验证 loss 与生成质量各自能回答的问题，并通过曲线和样例定位异常。

### 3.5.1 loss 的定义、估计与 perplexity

说明 token 平均损失、估计样本与困惑度变换的统计口径。

### 3.5.2 四种曲线形态与不同原因

围绕不下降、震荡、训练降而验证升及异常尖峰区分候选原因。

### 3.5.3 生成样例和 loss 观察不同对象

区分分布预测误差与实际解码输出，解释为何两者需要并列检查。

### 3.5.4 一个零依赖的曲线诊断实验

以小型数值数据检查曲线统计与异常标记逻辑的边界。

### 3.5.5 从异常现象找到最早出问题的位置

把数据、模型前向、损失、梯度、优化器和生成阶段映射到诊断顺序。

### 3.5.6 报告一次训练而不是只报告一个数字

界定需要保存的训练设置、数据切分、日志、样例与限制。

## 3.6 从字符级迁移到 BPE：tokenizer 与 checkpoint 的兼容性

本节解释 BPE 改变分词与词表而不改变自回归目标，分析序列长度、模型头和 checkpoint 的联动迁移。

### 3.6.1 BPE 改变的是 token 化，不是自回归目标

区分 token 单位变化与下一 token 预测任务本身。

### 3.6.2 序列节省与词表开销需要同时计算

比较更短序列与更大 embedding/output vocab 参数之间的资源影响。

### 3.6.3 使用现成 tokenizer 的接口

说明编码、解码、特殊 token 和版本固定需要核对的接口。

### 3.6.4 special token、padding 与 loss mask

明确边界 token、填充位置和监督目标之间的不同语义。

### 3.6.5 模型和 checkpoint 的迁移点

检查词表大小、embedding/output head、tokenizer 文件与权重之间的兼容性。

### 3.6.6 一个零依赖的 BPE 合并演示

用简化合并过程说明频率合并的直觉，同时限定其非生产 tokenizer 性质。

### 3.6.7 BPE 迁移时的验证顺序

沿编码往返、特殊 token、模型 shape 与旧实验可比性检查迁移结果。

## 3.7 公平比较与可复现实验：把“小 GPT”变成可复查的实验

本节把数据、tokenizer、预算、消融与证据等级纳入对比协议，避免将不等条件下的结果归因于单一改动。

### 3.7.1 训练步数不是完整预算

说明 token 数、batch、训练时长、硬件与推理配置共同影响比较。

### 3.7.2 一个最小消融矩阵

界定单变量对照与基线设置，支持判断组件变化的局部作用。

### 3.7.3 证据等级

区分手算、静态检查、玩具运行和目标任务实测支持的结论强度。

### 3.7.4 读者可以复现所需的实验材料

列出数据版本、配置、依赖、快照、随机种子及评估脚本等复现资产。

### 3.7.5 一次完整的复盘问题

将实验目标、对照条件、失败与可迁移边界转成复盘检查项。

### 3.7.6 把观察写成有边界的结论

说明结论必须指向实际运行过的设置、测量指标和仍未验证条件。

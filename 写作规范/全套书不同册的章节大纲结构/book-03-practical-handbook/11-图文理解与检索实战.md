# 第 11 章 图文理解与检索实战

**正文对应：** [CLIP 检索与对比学习](../../../book-03-practical-handbook/chapters/11-图文理解与检索实战-1-CLIP检索与对比学习.md)、[VLM 问答、数据与图文 RAG](../../../book-03-practical-handbook/chapters/11-图文理解与检索实战-2-VLM问答数据与RAG.md)

本章围绕图像与文本如何共享表示、视觉语言模型怎样回答图片问题，以及图像证据如何进入训练与检索展开。读者需要区分跨模态相似度、生成回答和任务正确性，能检查数据切分、图像 token 预算、证据来源和不同任务的评估指标。

## 11.1 使用 CLIP 做图文检索

本节以图文双编码表示建立检索基线，说明对比目标如何形成共享空间以及检索系统需要保存哪些版本与标签。

### 11.1.1 从“图片像什么”到“图片与文字是否对应”

区分图像分类标签与图文匹配目标，界定 CLIP 分数的语义。

### 11.1.2 对比学习为什么能支持 zero-shot 分类

说明正负图文对、相似度 logits 和候选文本比较的关系。

### 11.1.3 最小检索实验

构造图像/文本向量、计算排名并按命中率或 Recall@K 检查结果。

### 11.1.4 从一次查询到可维护索引

覆盖嵌入版本、索引构建、元数据关联、更新和查询日志。

### 11.1.5 资料与证据边界

限定 CLIP 论文/模型卡主张、公开检索指标和目标图片分布效果。

## 11.2 从零实现 mini CLIP 损失

本节将双向图文对比损失还原为相似度矩阵、配对标签和批次负样本，揭示训练目标与检索目标的差距。

### 11.2.1 相似度矩阵的标签结构

说明批内正例对角关系、行列方向和温度缩放的目标含义。

### 11.2.2 纯 Python 版本与反事实检查

用小规模矩阵展示标签错位/文本错配后损失变化，明确简化计算边界。

### 11.2.3 大 batch、跨卡负样本与标签一致性

讨论更多负样本、跨设备 gather 与数据配对顺序对监督信号的影响。

### 11.2.4 训练目标与检索目标不完全相同

说明对比损失下降不保证目标领域 Recall、细粒度属性或业务检索质量。

### 11.2.5 资料与证据边界

区分原论文损失、实现细节与本地数据上的检索验证。

## 11.3 使用开源 VLM 做图片问答

本节区分检索表示与视觉生成职责，建立问答基线并按任务类别评估图像证据使用。

### 11.3.1 检索模型与生成模型的分工

说明 CLIP 式对比表示适合候选匹配，而 VLM 生成回答涉及不同能力与风险。

### 11.3.2 图像 token 预算是系统约束

将分辨率、裁块、视觉 token、上下文长度和延迟/内存联系起来。

### 11.3.3 以 Qwen2.5-VL 演示调用与接口边界

界定具体 checkpoint、processor、视频/图像输入和生成 API 的版本范围。

### 11.3.4 按任务类型评估，比只看平均分更有用

按 OCR、空间关系、计数、图表等任务拆分指标和失败样本。

### 11.3.5 一个不依赖模型的 VQA 评估样例

用给定答案演示规则/人工判断字段，限制 lexical match 的正确性结论。

### 11.3.6 资料与证据边界

区分模型文档、公开 benchmark、模型调用样例和本地图片任务证据。

## 11.4 构造多模态 Instruction Tuning 数据

本节组织图像、对话、监督目标和数据切分，明确训练消息真正包含的媒体对象及其标注边界。

### 11.4.1 一条训练样本的真正对象

定义消息文本、图片内容/引用、角色和目标回复间的关系。

### 11.4.2 任务设计与拒答样本

覆盖可回答、证据不足、不可见内容和安全边界样本的标注要求。

### 11.4.3 assistant-only loss 与图像占位符

区分文本序列占位符和视觉输入表示，并说明哪些 token 参与损失。

### 11.4.4 图片级切分和数据泄漏

要求同源图片、裁剪、增强或近重复样本在切分时保持组级隔离。

### 11.4.5 一个可回放的数据构造器

界定规范化样本转换、媒体引用和可复现数据版本的接口。

### 11.4.6 资料与证据边界

明确特定模型训练格式与多模态监督有效性必须按实际运行核验。

## 11.5 构建图像 + 文本 RAG

本节将图片原件、OCR/caption/视觉 embedding 和文本资料组织成带权限、版本与来源的证据检索路径。

### 11.5.1 图片证据为什么不能只保存成一句 caption

说明摘要文本可能遗漏布局、局部细节、数值和原始来源信息。

### 11.5.2 三种架构与选择条件

比较图像向量检索、OCR/文本索引和生成式视觉处理的组合方式及适用限制。

### 11.5.3 融合分数、上下文预算与证据图

说明跨模态候选排序、证据引用和有限上下文组织问题。

### 11.5.4 纯 Python 证据融合实验

以可控分数与来源记录演示跨模态候选合并，限定为融合逻辑样例。

### 11.5.5 评估不能只看最终答案

分别检查图片/文本检索、权限、引用支持、任务答对和失败恢复。

### 11.5.6 资料与证据边界

区分通用 RAG 研究、特定视觉模型实现和业务图片语料实测。

# 第 5 章 偏好优化实战

**正文对应：** [05-偏好优化实战](../../../book-03-practical-handbook/chapters/05-偏好优化实战.md)

本章围绕人类比较信号如何改变模型回答来组织偏好数据、奖励模型和 DPO。读者需要分清 SFT 的目标、偏好标签、模型相对分数及策略更新，并能从 token log-prob、训练状态和固定任务评估解释一次偏好优化实验支持什么结论。

## 5.1 把“更喜欢哪一个”写成数据

本节说明偏好比较成立的条件和数据记录要求，强调 chosen/rejected 的意义依赖同一输入、明确准则和完整标注过程。

### SFT 和偏好优化分别教什么

区分模仿示范答案与比较两个候选回答的监督信号。

### 一条偏好记录应该让人看得懂

界定 prompt、chosen、rejected、来源和元数据字段及一致性要求。

### 评审者比较的标准也属于数据

说明标注 rubric、偏好维度和评审说明会改变标签含义。

### 偏好对从哪里来，比较过程要留下什么

覆盖人工/合成候选来源、采样、盲评与版本追踪边界。

### 分歧、平局和偏好强度要单独记录

区分明确偏好、平局、标注冲突与偏好置信，不将差异粗暴二值化。

### 长度和截断会改变训练器真正看到的回答

说明序列长度与截断对 chosen/rejected 相对比较的影响。

### 用小脚本先挡住明显的数据错误

界定去重、空字段、同文比较、编码与长度检查能发现的结构性问题。

## 5.2 先看奖励模型：从偏好标签到回答分数

本节将偏好排序映射为奖励分数，解释分数的相对尺度、训练目标及与 PPO 策略更新的接口。

### RM 和 PPO 怎样接在一起

说明奖励模型提供回答评分信号，而策略优化还需参考策略、采样和约束机制。

### 进阶实作：把偏好对变成奖励模型的一步更新

范围包括成对比较损失、reward 差及一次梯度更新的可解释数值链。

## 5.3 DPO：从回答概率推到偏好目标

本节从回答 token 概率、参考模型和 KL 约束关系建立 DPO 目标，说明偏好标签如何进入策略梯度。

### 一条回答的概率怎样由 token 组成

解释自回归序列对数概率由有效 token log-prob 累加形成。

### 参考模型解决什么问题

说明 reference policy 在相对概率比和约束策略漂移中的作用。

### DPO 把比较直接写成策略的 loss

连接 chosen/rejected 相对 log-ratio 与 logistic 偏好损失。

### 用一组数字手算 DPO

用小型数值例核对策略/参考模型概率差如何进入损失。

### loss 怎样决定策略更新方向

说明降低损失对应的相对偏好移动及梯度含义。

### 三个模型角色要分清

区分训练 policy、冻结 reference 与偏好数据生成/评分中可能出现的模型。

## 5.4 从序列公式到 token 级计算

本节从序列级表达落到 causal LM token log-prob 张量，明确移位、mask、求和/平均及模型批次对齐。

### policy 和 reference 怎样完成一轮前向

说明两模型对同一 chosen/rejected token 序列计算条件概率的 shape 和状态。

### 求和还是平均，会改变什么

比较序列 log-prob 求和与按长度平均对回答长度偏差及目标尺度的影响。

## 5.5 用 TRL 训练一个 DPO policy

本节把明确版本的偏好数据、训练起点、TRL 配置、LoRA 和 checkpoint 连接为可追踪训练过程。

### 先准备明确的训练和验证数据

规定同输入配对、样本切分、字段格式与训练外验证集。

### 加载 SFT 起点并启动训练器

说明基座与 tokenizer 版本、DPO trainer 接口和主要配置字段。

### LoRA 与 QLoRA 改变的是更新方式

区分偏好损失与参数高效更新参数化，避免混淆算法目标和资源策略。

### 保存模型和恢复训练不是一回事

界定部署 adapter/权重与恢复优化器、进度等完整训练状态的差别。

## 5.6 训练后，怎样知道回答有没有变好

本节以固定比较条件和任务相关指标检验行为变化，并将训练日志与实际回答结果分开解释。

### 固定比较条件

固定模型、提示词、tokenizer、解码设置和测试样本以减少混杂。

### 指标要贴着任务走

按预期业务行为选择正确性、安全、格式或偏好指标并明示分母。

### 训练指标能说明什么

限定 loss、reward margin 等训练观测对最终行为和泛化的证据范围。

### 把结果写成有边界的结论

要求结论包含样本、基线、变化、失败、成本和未覆盖条件。

## 5.7 DPO 适合什么问题，又留下什么问题

比较 DPO 的数据和训练需求、可解释优势与偏好噪声、长度、分布偏移等局限。

## 本章实践：留下可复核的偏好优化记录

汇总数据版本、训练配置、模型角色、评估样例与结论边界等交付字段。

## 资料与实现边界

将 DPO 理论来源、TRL 固定版本接口与目标任务上的本地评估分开，说明接口更新不改变优化目标的数学含义。

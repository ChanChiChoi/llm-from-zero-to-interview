# 第七部分：长上下文、RAG 与 Agent

本部分追踪信息如何进入模型上下文、如何从外部证据检索，以及语言模型如何通过工具改变外部状态。主线从长上下文训练和评估开始，经过 RAG 检索与归因，再进入工具调用、计划、可靠性、安全和记忆，最后以端到端业务案例收束。

## 讲次大纲

### 第 76 节：长上下文训练——把“能装下”变成“会使用”

比较上下文扩展路线、训练分布和资源账本，指出窗口长度不等于有效利用能力。

### 第 77 节：长上下文评估——从最大窗口走向有效使用

用 needle、多证据、抗干扰、引用和成本切片检查长输入能力，连接离线基准与目标任务。

### 第 78 节：RAG 基础架构——从文档到可追溯回答

沿解析、索引、检索、上下文构造和生成拆分 RAG 流水线，定位端到端错误来源。

### 第 79 节：Embedding 与向量检索——表示、相似度和近似搜索

解释向量表示与相似度几何，比较 ANN 的速度—召回权衡并建立检索指标。

### 第 80 节：Reranker——从“召回候选”到“选择证据”

比较 bi-encoder、cross-encoder 与 late interaction，分析排序、权限过滤、去重和下游收益。

### 第 81 节：RAG 幻觉与 Attribution——让每个声明都能回到证据

把回答拆成 claim/evidence 关系，区分检索命中、引用存在和引用真正支持结论。

### 第 82 节：Tool Use 与 Function Calling——把自然语言动作变成受约束的接口调用

定义工具 schema、参数校验、权限和执行返回，区分结构化调用与自然语言描述。

### 第 83 节：Agent Planning——把开放任务组织成可检查的行动序列

拆解目标、步骤、状态、观察与重规划，比较计划可执行性和任务预算。

### 第 84 节：Agent 可靠性与安全——让不可信内容不能直接改变外部世界

建立来源信任、权限门控、沙箱、确认和回滚边界，测试 prompt injection 与工具副作用。

### 第 85 节：Memory-Augmented LLM——管理跨任务信息，而不是把一切都永久记住

比较短期上下文与持久记忆，处理来源、冲突、时效、删除和召回成本。

### 第 86 节：贯通案例——从长文档调研到可审计的业务动作

把检索、证据、计划、工具执行和人工确认整合成完整交付案例，并通过轨迹定位失败。

# 第十一部分：图像与视频生成模型

本部分以生成任务和表示路线为主线，比较扩散、自回归和 latent 生成，再扩展到视频的时空一致性。重点不是背模型名称，而是理解训练目标、推理成本、条件控制和评估协议，并限定从连贯生成到“世界模型”能力的推断边界。

## 讲次大纲

### 第 114 讲：图像生成模型总览

比较像素、连续 latent 和离散 token 表示，搭建图像生成路线、条件方式和质量指标的地图。

### 第 115 讲：Diffusion Model 基础

从前向加噪和反向去噪推导扩散训练目标，分析采样步数、噪声调度和条件引导。

### 第 116 讲：Latent Diffusion 与 Stable Diffusion

解释压缩空间中去噪、文本条件和解码器的职责，核算 latent 分辨率、质量与算力之间的关系。

### 第 117 讲：DALL·E 路线与自回归图像生成

比较离散视觉 token 的自回归生成与扩散路线，分析序列长度、词表和生成效率。

### 第 118 讲：视频生成模型基础

把时空 token、逐帧/联合建模和时序一致性放进模型设计及评估，识别单帧指标的遗漏。

### 第 119 讲：Sora 类视频世界模型直觉

区分连贯视频生成、状态预测、动作条件与闭环控制，设计对象持久、因果和反事实测试。

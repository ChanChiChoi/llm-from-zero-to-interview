# 第四部分：大规模训练系统进阶

本部分把前一部分定义的训练目标映射到设备、通信和故障恢复。讲次按“单步梯度语义—参数/状态分片—张量和流水线切分—序列维度—混合并行—显存—通信重叠—测量—事故恢复”递进，使读者能够判断吞吐数字代表什么，也能提出可恢复的运行方案。

## 讲次大纲

### 第 41 讲：DDP：同步数据并行的梯度语义

从各副本梯度如何聚合解释 DDP 的数学语义、有效 batch 和通信成本。

### 第 42 讲：ZeRO 与 FSDP：把训练状态从复制变成分片

比较优化器状态、梯度和参数分片的显存收益，以及 gather、通信和恢复成本。

### 第 43 讲：Tensor Parallel：把单层矩阵切给多个设备

沿线性层计算图追踪列并行、行并行及 collective 通信，判断切分是否匹配设备拓扑。

### 第 44 讲：Pipeline Parallel：按层切分并填充流水线

解释微批次、气泡、激活传输与调度，估算流水线利用率及其适用场景。

### 第 45 讲：Sequence Parallel 与 Context Parallel：沿序列维度分摊压力

比较序列切分和上下文并行怎样分配长序列计算，并核对注意力通信与边界条件。

### 第 46 讲：3D 与混合并行：把并行维度映射到集群

把数据、张量和流水线并行组合到集群拓扑，衡量通信域、显存与吞吐的联合效果。

### 第 47 讲：Activation Checkpointing：用重计算换显存

量化保存激活与重计算的显存—算力折中，并说明如何按层选择检查点。

### 第 48 讲：通信与计算重叠：隐藏等待而不是删除通信

解释异步通信、依赖关系和 overlap 的条件，区分可隐藏延迟与仍然存在的传输成本。

### 第 49 讲：训练吞吐与性能分析

建立样本吞吐、token 吞吐、MFU 与阶段耗时之间的账本，通过 trace 识别真实瓶颈。

### 第 50 讲：大规模训练事故：从保留现场到可恢复系统

设计故障检测、状态保存、弹性恢复和复盘流程，确保异常处理不会覆盖最后一个健康状态。

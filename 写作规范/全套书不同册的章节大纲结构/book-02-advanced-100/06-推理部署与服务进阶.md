# 第六部分：推理、部署与服务进阶

本部分把训练完成的模型放入真实请求路径，沿 prefill、decode、缓存、调度、推测解码、量化和服务协议拆解时延、显存、吞吐、成本与可靠性。读者最终应能从负载和硬件条件提出可测量的部署选择，而不是把单卡 benchmark 当作服务结论。

## 讲次大纲

### 第 66 讲：Prefill 与 Decode——一次生成请求的两种时间结构

追踪输入处理与逐 token 生成的计算差异，建立 TTFT、TPOT 和端到端延迟基线。

### 第 67 讲：KV Cache——把上下文变成显存账本

推导缓存容量和增长方式，说明长度、并发、精度与 KV 头数如何共同限制服务容量。

### 第 68 讲：PagedAttention 与 Prefix Cache——显存管理本身也是算法

解释块式 KV 分配、前缀复用和命中条件，区分 attention kernel、缓存管理器与调度器职责。

### 第 69 讲：连续批处理与请求调度——让动态请求共同前进

说明请求长度差异和动态到达下的调度策略，量化吞吐、等待时间和公平性的折中。

### 第 70 讲：推测解码——用便宜候选减少目标模型的等待

解释 draft 与 target 的接受机制，估算加速依赖和额外成本，明确正确性与分布条件。

### 第 71 讲：量化——把精度、内存和误差放进同一本账

比较权重量化与激活/缓存精度选择，建立任务级质量回归和硬件实测要求。

### 第 72 讲：推理服务架构——从模型调用变成可观察的协议

拆解 API、队列、模型执行、流式响应和错误处理，定义服务协议和观测点。

### 第 73 讲：容量规划与成本——吞吐数字必须落到单位有效任务

按请求分布估算容量、尾延迟与单位成功任务成本，并比较扩容和路由方案。

### 第 74 讲：线上可靠性——把模型失败和系统失败分开处理

区分超时、服务降级、模型错误和安全失败，设计重试、回退、监控及事故复盘。

### 第 75 讲：端侧模型与端云协同——把推理放进真实设备

比较本地与云端执行的隐私、时延、能耗和更新约束，设计按任务与网络状态切换的边界。

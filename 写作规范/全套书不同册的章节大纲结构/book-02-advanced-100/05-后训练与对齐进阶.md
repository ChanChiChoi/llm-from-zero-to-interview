# 第五部分：后训练与对齐进阶

本部分回答：如何把 Base Model 的续写能力转为受任务、偏好和安全约束的助手行为。主线从行为目标与 SFT 数据开始，经过偏好建模、奖励模型和策略优化，再比较直接偏好方法、AI 反馈和安全机制，最终形成多维评估与线上迭代方法。

## 讲次大纲

### 第 51 讲：从 Base Model 到 Assistant Model 的行为转换

定义助手行为变化的目标和可观察结果，区分模型权重变化、对话模板和推理时系统控制。

### 第 52 讲：SFT 数据设计是行为接口设计

从任务覆盖、答案结构、对话格式和数据治理设计监督样本，说明数据决定助手被教会什么。

### 第 53 讲：SFT 的泛化、过拟合与灾难性遗忘

比较训练与验证行为，识别窄任务拟合及通用能力退化，并设计回归切片。

### 第 54 讲：Preference Data 的构造、噪声与偏差

解释偏好比较的标注单位、噪声和群体差异，评估排序信号能否代表目标行为。

### 第 55 讲：Reward Model 如何学习、校准与失效

追踪奖励模型的输入、比较目标和分数校准，展示过拟合、奖励黑客和分布外误判。

### 第 56 讲：PPO 在 RLHF 中如何把偏好变成策略更新

拆解策略、奖励、价值估计和 KL 约束的更新路径，连接目标函数与工程资源。

### 第 57 讲：RLHF 的不稳定性与诊断闭环

围绕奖励漂移、KL、熵和输出质量建立故障信号，形成可回退的训练诊断流程。

### 第 58 讲：DPO 的数学推导与实现边界

从偏好概率和参考策略推导 DPO 目标，核对序列 log-prob、长度效应与数据条件。

### 第 59 讲：IPO、KTO、ORPO 与偏好优化的取舍

按数据形式、目标假设、更新路径与稳定性比较替代方法，避免凭名称或单次分数选型。

### 第 60 讲：RLAIF 与 Constitutional AI 的反馈链

区分人工与 AI 反馈的来源、筛选和偏差，检验原则文本如何转为可评估行为。

### 第 61 讲：安全对齐数据与有边界的拒答

设计安全样本、拒答和安全完成行为，兼顾风险控制与正常请求的可用性。

### 第 62 讲：Truthfulness、Honesty 与 Calibration

区分事实正确、表达诚实和置信校准，建立能测量不确定回答的任务切片。

### 第 63 讲：Jailbreak、Prompt Injection 与系统鲁棒性

区分模型指令遵循、输入信任边界与系统权限，构建攻击—防护—回归闭环。

### 第 64 讲：Model Spec 与行为规范的工程化

把行为原则转为可实现的指令层级、策略测试和版本化接口，说明规范文本不是自动保证。

### 第 65 讲：后训练的多维评估、选择与线上闭环

将任务质量、安全、校准、成本和分布变化纳入候选选择，定义发布门槛与线上回流。

# 第十七章：AI Control 与不可信 Agent 的运行时监督

训练和对齐主要试图让模型愿意遵循期望；AI Control 研究另一种问题设定：即使 Agent 可能尝试绕过监督，系统能否在保留正常任务效用的同时，把危险动作拦截、延迟、交给可信组件复核或留下可审计证据。这里的“不可信”是压力测试采用的威胁假设，不是对某个具体模型具有隐蔽意图的事实判断。

本章承接[第六章](06-red-teaming与危险能力评估.md)的红队和危险能力评估、[第十三章](13-goat自动化对抗评估.md)的自动化攻击探索，并与[第十五章](15-risk-calibrated-access.md)的权限决策和[第十六章](16-fallback-routing与安全降级.md)的故障处置相互衔接。重点是运行时监督协议本身：威胁模型如何表示，红队如何适应监控策略，何时交由可信模型或人工处理，以及安全收益和正常任务效用怎样一起测量。

2025 年的 SHADE-Arena 工作将主任务、隐藏副任务、攻击策略和监控器放入多步模拟环境；后续的协议比较研究发现，部分依赖重采样的防线会被更强的自适应攻击削弱，而对关键动作直接升级处理在其测试环境中更稳健。这些结果说明应把协议放进有适应性红队的环境中比较，但不能直接外推为真实 Agent 部署的安全率。可从[协议评估论文](https://arxiv.org/abs/2511.02997)和[AISI/Redwood 的 ControlArena 文档](https://control-arena.aisi.org.uk/)进入研究与实现细节。

本章会区分三类证据：模型在给定任务中的能力、监督协议在特定攻击策略下的效果，以及部署系统的权限和副作用控制。模拟环境中的高安全分数不替代网络隔离、最小权限、事务确认、事故响应或目标业务的独立验收。

# 第十四册简介：PyTorch 与深度学习工程

## 本书回答的问题

读者已经见过模型公式或训练脚本，但还不确定一个张量的 shape、梯度从哪里来、数据怎样组成 batch、训练循环如何保持正确，或模型变慢/出现 NaN 时该从哪里查。本册沿着一次小型深度学习实验，从张量和自动微分走到模型、数据、训练循环、资源管理、调试与 Transformer 组件，让读者能把数学和模型结构落实为可检查的 PyTorch 实现。

## 目标读者与前置知识

本册面向会读 Python、接触过基本机器学习或神经网络，但 PyTorch 程序还写得不稳的读者；也适合准备模型实现、训练脚本和故障定位问题的算法/工程求职者。开始前应会使用 Python 函数、类、列表和字典，理解基本线性代数、损失和梯度下降概念。若张量/矩阵概念不熟，可先读[第十三册第一章《线性代数》](../book-13-math-foundations/chapters/01-线性代数.md)；若想先看可运行的小项目，可与[第三册实战手册](../book-03-practical-handbook/目录.md)配合。

## 学完后应具备的能力

1. 追踪 tensor 的 shape、dtype、device、stride 和广播关系，定位常见维度与数据类型错误。
2. 解释 Autograd 如何记录前向操作、沿计算图传播梯度，并正确组织 `nn.Module`、参数、buffer 和状态。
3. 把样本变成 batch，写出包含训练、验证、梯度处理、日志和 checkpoint 的基本实验循环，并检查恢复是否连续。
4. 选择和排查混合精度、梯度累积、activation checkpointing 等资源手段；用受控测量和 profiler 区分计算、数据和通信瓶颈。
5. 从 rank、进程组和数据分片推到 DDP 梯度同步、全局 token 分母与 `no_sync()`；能判断 sampler 补齐/丢尾、checkpoint 本地状态和 collective 步调风险，并实现规模可控的 decoder-only Transformer 前向、损失和生成组件。
6. 面对工程现象先定义验收指标，再设计最小区分实验，依据证据判断修复是否有效。

## 范围与边界

本册以 PyTorch eager 编程和规模可控的教学实验为主，覆盖张量、自动微分、模块组织、数据管线、训练与验证循环、精度/显存、单机多卡入门、debug/profiling，以及 Transformer 组件实现。重点是理解数据如何流动、状态怎样变化、如何验证实现和定位问题。

本册不替代第十三册的数学推导；不负责第三册从需求到结果的完整项目路径；不展开第五册所承担的大规模分布式训练、集群拓扑、吞吐优化和训练系统。多机并行、FSDP、编译器及底层 kernel 等主题只在读者判断和基础排查所需处给出入口；具体 API 会随 PyTorch 版本和设备变化，正文代码应注明验证版本与环境。

## 阅读路径

建议按目录顺序阅读并逐章保留一个小型实验：先掌握 tensor、autograd 和模块，再接入数据与训练循环，随后处理精度、显存和多卡问题，最后实现 Transformer 并用故障案例练习判断。准备第三册项目时，优先完成第一至第六章，再把相应章节作为实现手册查阅；需要系统掌握分布式训练时，读完第七章后转第五册。

## 各章在主线中的作用

1. **PyTorch 张量基础**：沿 token id、embedding、线性投影和 next-token loss 手算并核对 shape、类别轴、dtype、device、mask 与内存布局，建立后续章节共用的 tensor contract。
2. **Autograd 与反向传播**：手算链式法则与向量—雅可比积，再解释计算图、梯度累积和有效 token 归一化；区分 `detach`、两种无梯度上下文及 hook、checkpoint、DDP 的 Autograd 边界。
3. **nn.Module 与模型组织**：从注册树说明参数、子模块和 buffer 如何被 optimizer、device 迁移与 checkpoint 管理；再区分 `state_dict`、`train/eval`、受限加载和分布式/编译边界，产出可检查、可恢复的小型模型。
4. **Dataset 与 DataLoader**：沿单样本→batch contract 手算 padding、shift 后有效标签和 loss mask；再追踪 sampler、worker、rank 的分片、随机种子、尾部补齐/丢弃，以及预取与顺序设置对内存和吞吐的影响。
5. **训练循环工程**：沿有效 loss 分母、梯度累积与裁剪、optimizer/scheduler 更新次序，走到 token 加权验证、完整 checkpoint、安全保存和恢复后的下一步核验；为后续精度优化、分布式与故障诊断建立状态边界。
6. **混合精度与显存优化**：比较 FP16/BF16 数值边界，沿 GradScaler、梯度累积与 checkpoint 重算追踪真实更新；手算 batch/序列长度对应的显存量，并按失败阶段定位 OOM。
7. **分布式训练入门**：从 rank、进程组和样本分片推导 DDP 的平均梯度与 token 分母；比较 `no_sync()`、DDP/FSDP 状态边界和 rank 0 checkpoint，并用各 rank 日志定位数据重复、collective 步调与通信故障。
8. **Debug 与 Profiling**：将数据/shape/grad/loss/NaN/OOM 故障转为最小实验和可读测量；用 profiler、同步计时和 `torch.compile` 的正确性/稳态测量定位性能瓶颈。
9. **实现 Transformer 组件**：复用前述张量、模块、训练和调试能力，连接 attention、因果 mask、右移语言模型损失与生成状态；特别检查非方阵 cache mask、RoPE 位置偏移及 prefill/decode 一致性。
10. **工程问题与判断**：用综合案例练习定义成功条件、定位候选原因、选择最小实验和说明证据，交接到第三册项目和第十二册面试表达。

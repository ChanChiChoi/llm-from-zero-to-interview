# 第二十九章：状态空间模型 SSM 的数学直觉

## 29.1 状态空间方程描述状态如何演化

状态空间模型（state space model，SSM）用一个随时间更新的隐藏状态表示系统内部信息。对固定参数的连续线性系统，输入、状态和输出分别满足：

~~~math
\dot{\mathbf{x}}(t)=\mathbf{A}\mathbf{x}(t)+\mathbf{B}\mathbf{u}(t),
\qquad
\mathbf{y}(t)=\mathbf{C}\mathbf{x}(t)+\mathbf{D}\mathbf{u}(t).
~~~

这里，状态、输入、输出的维数以及四个矩阵的形状分别为：

~~~math
\mathbf{x}(t)\in\mathbb{R}^{n},\quad
\mathbf{u}(t)\in\mathbb{R}^{m},\quad
\mathbf{y}(t)\in\mathbb{R}^{p},
~~~

~~~math
\mathbf{A}\in\mathbb{R}^{n\times n},\quad
\mathbf{B}\in\mathbb{R}^{n\times m},\quad
\mathbf{C}\in\mathbb{R}^{p\times n},\quad
\mathbf{D}\in\mathbb{R}^{p\times m}.
~~~

| 矩阵 | 作用 |
| --- | --- |
| $\mathbf{A}$ | 描述状态如何自行演化 |
| $\mathbf{B}$ | 描述输入如何写入状态 |
| $\mathbf{C}$ | 描述如何从状态读出结果 |
| $\mathbf{D}$ | 提供输入到输出的直接通路 |

可以先把它想成一个连续滤波器：旧状态由状态转移矩阵控制，当前输入经输入矩阵写入状态，输出由读出矩阵映射；直接通路不经过状态，因此不会形成长期记忆。这里讨论的是序列层的局部线性动力学；它不是完整的神经网络定义，也不等同于所有 RNN 或某个 S4、Mamba block。S4 原论文也从这组连续方程出发，再分别写出离散递归与卷积表示（[原论文 §2](https://arxiv.org/abs/2111.00396)）。

## 29.2 离散化把连续动力学变成逐 token 更新

神经网络接收的是离散序列。令 $\Delta>0$ 表示相邻采样点间隔，并约定第 $t$ 个输入在一个区间内保持不变。这个区间假设称为零阶保持（zero-order hold，ZOH）。对连续线性方程在一个区间内精确积分，得到：

~~~math
\mathbf{x}_t=\bar{\mathbf{A}}\mathbf{x}_{t-1}
+\bar{\mathbf{B}}\mathbf{u}_t,
\qquad
\mathbf{y}_t=\mathbf{C}\mathbf{x}_t+\mathbf{D}\mathbf{u}_t,
~~~

~~~math
\bar{\mathbf{A}}=\exp(\Delta\mathbf{A}),
\qquad
\bar{\mathbf{B}}=\int_{0}^{\Delta}\exp(\tau\mathbf{A})\mathbf{B}\,\mathrm{d}\tau.
~~~

因此，状态每步保留多少旧信息、当前输入写入多少，都随采样步长而变化。ZOH 的精确性是相对于“每个区间内输入恒定”这一假设而言。前向 Euler 则是另一种近似：

~~~math
\bar{\mathbf{A}}\approx\mathbf{I}+\Delta\mathbf{A},
\qquad
\bar{\mathbf{B}}\approx\Delta\mathbf{B}.
~~~

不同离散化可以得到不同的离散系统。[S4 原论文](https://arxiv.org/abs/2111.00396)采用双线性变换；不能把 ZOH、Euler 或某一种参数化说成所有 SSM 实现的固定做法。ZOH 与 Euler 的推导和差异可参见 [Dive into Deep Learning 第 12.4 节](https://d2l.smola.org/chapter_recurrent-modern/ssm.html)。

看一个单状态例子。令连续系统满足 $\dot{x}(t)=-x(t)+u(t)$ 这一关系；采用 ZOH 后得到：

~~~math
x_t=e^{-\Delta}x_{t-1}+(1-e^{-\Delta})u_t.
~~~

若采样步长取十分之一，旧状态和当前输入的系数分别为：

~~~math
e^{-0.1}\approx 0.905,
\qquad
1-e^{-0.1}\approx 0.095.
~~~

缩小步长会让每一步衰减更慢，但这本身不能说明某项任务就能记住更久；还要看系统的其他状态、输入以及读出方式。

## 29.3 递归展开后成为同一个系统的因果卷积

离散递归可以逐步计算。从零初始状态出发，把前面各步代回去，就得到：

~~~math
\mathbf{x}_t
=\sum_{i=0}^{t}\bar{\mathbf{A}}^{\,t-i}\bar{\mathbf{B}}\mathbf{u}_i.
~~~

记第 $j$ 步的状态响应核为：

~~~math
\mathbf{K}_j=\mathbf{C}\bar{\mathbf{A}}^{\,j}\bar{\mathbf{B}}.
~~~

再将状态代入输出式，可得：

~~~math
\mathbf{y}_t
=\sum_{j=0}^{t}\mathbf{K}_j\mathbf{u}_{t-j}
+\mathbf{D}\mathbf{u}_t.
~~~

这就是因果卷积：状态响应核描述某次输入经过若干步转移后对当前输出的影响；直接通路把当前输入绕过状态送到当前输出。若将直接通路并入卷积核，零延迟项写为：

~~~math
\mathbf{D}+\mathbf{K}_0.
~~~

这时直接通路和状态响应都计入当前步。递归展开为卷积的推导可在 [S4 原论文 §2.3–2.4](https://arxiv.org/abs/2111.00396) 中核对。

| 表示 | 它突出什么 | 成立条件 |
| --- | --- | --- |
| 连续方程 | 状态按单位时间如何演化 | 连续线性系统及其参数 |
| 离散递归 | 每个 token 到来时如何更新状态 | 给定离散化方法、步长和初始状态 |
| 因果卷积 | 每个历史输入如何影响各个输出 | 零初始状态（或另计初态响应），且状态转移和读出参数不随序列位置变化 |

三种写法描述的是同一固定线性时不变系统的不同视角，不是三个不同模型。卷积为并行处理整段序列提供了路径，但“可以写成卷积”不等于卷积核容易生成，也不保证任意长度、状态结构和硬件下都比递归更快。S4 的技术贡献之一正是高效计算特定结构下的卷积核；本章不把该算法细节提前替代第 31 章。

## 29.4 衰减时间尺度、稳定性与任务记忆是不同概念

取满足 $0<a<1$ 的标量 $a$ 作为每步衰减系数。旧状态经过 $k$ 步后的线性影响随 $a^k$ 衰减。把系数降到初始值一半所需的步数称为半衰期：

~~~math
\tau_{1/2}=\frac{\ln 0.5}{\ln a}.
~~~

| 每步衰减系数 $a$ | 线性影响半衰期（约） |
| --- | ---: |
| $0.9$ | $6.6$ 步 |
| $0.99$ | $69$ 步 |
| $0.999$ | $693$ 步 |

这说明改变衰减系数可以改变单一状态模态的时间尺度。多个不同的模态可以覆盖多个衰减速度；若模态包含复数特征值，还可能出现振荡。但这些只是线性影响的尺度，不代表旧 token 被保存成可按位置访问的记录，也不证明输出层能准确恢复其中的事实。

还要把这种衰减与系统稳定性分开。对连续齐次系统，所有特征值实部小于零时，状态在没有新输入时渐近衰减；对离散齐次系统，谱半径小于一时，状态也渐近衰减。若 $\bar{\mathbf{A}}$ 来自稳定连续系统的精确 ZOH 离散化，其特征值会落在单位圆内；显式 Euler 在步长过大时则可能破坏稳定性。稳定性描述齐次状态的长期演化，不等于模型能否记住任务需要的信息；对非正规矩阵，谱半径小于一也不排除短期范数放大。

## 29.5 固定状态提供压缩动力学，不承诺任意历史检索

固定参数 SSM 会把此前输入的影响累积到状态中，再由读出矩阵映射为输出。它不像逐 token 保存的 KV 序列那样天然提供一个与每个历史位置对应的显式槽位。由此可以提出一个需要实测的问题：当任务要求精确复制远处数字、区分多个实体或选择冲突版本时，当前状态和读出层是否仍能提供足够、可分辨的信息？答案取决于具体模型、训练和任务，不能从“状态固定”或“影响仍非零”直接推出。

复杂度也要说明状态维数和结构。若 $n$ 表示状态维数，只计算状态转移这一项时，稠密矩阵的单步矩阵向量乘法约需 $O(n^2)$ 运算；对角转移的这一项则随 $n$ 线性增长。因此固定状态表示的是单条序列的状态大小不随长度 $T$ 增长，而不是无条件保证整层成本、训练吞吐或生成速度为某个固定值。S4 如何利用结构化矩阵降低特定计算成本，由第 31 章展开。

最后，递归与单一固定卷积核的等价关系依赖参数不随 token 位置变化。若状态更新参数随输入变化，就不再由同一个平移不变卷积核直接表示；Mamba 的选择性更新与 selective scan 留给[第三十二章](32-Mamba与Selective-Scan.md)。理解本章后，可先在[第三十章](30-SSM-RNN-CNN-Attention信息流对比.md)比较 SSM、RNN、CNN 和 Attention 各自的信息流，再进入[第三十一章](31-S4核心思想.md)的结构化状态矩阵。

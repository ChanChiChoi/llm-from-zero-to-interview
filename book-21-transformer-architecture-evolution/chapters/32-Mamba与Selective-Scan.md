# 第三十二章：Mamba：Selective State Space 与 Selective Scan

前几章分别建立了状态空间模型的递归表示、它与注意力的信息流差别，以及 S4 如何利用结构化状态参数计算长序列。本章继续回答一个具体问题：如果每个位置都按同一套规则更新状态，模型怎样根据当前内容决定“写入什么、保留什么、读出什么”？Mamba 的回答是让部分离散状态参数依赖当前输入，再用可并行组合的扫描计算这些逐位置更新。读完本章，读者应能从输入依赖的参数生成追到状态递归，再解释 Selective Scan 为什么既保留递归语义又能并行计算；硬件实现和性能边界留给[第三十三章](33-Mamba训练推理与硬件效率.md)，任务能力边界见[第三十四章](34-Mamba局限与证据边界.md)，Mamba-2 的状态空间对偶见[第三十五章](35-Mamba-2与State-Space-Duality.md)，跨架构证据由[第三十六章](36-SSM替代Transformer的证据与争议.md)讨论。

## 32.1 固定状态传播为何需要内容选择

在线性时不变状态空间模型（LTI SSM）中，状态按照固定的转移和输入写入规则逐位置更新。同一位置规律无论遇到普通词、分隔符还是要保留的实体，都使用相同的参数。这样的模型可以累积历史，却没有直接的机制让当前 token 改变“这一步该记什么”。这正是从 S4 走向 Mamba 的问题起点；前置的递归形式和卷积形式见[第二十九章](29-SSM数学直觉.md)与[第三十一章](31-S4核心思想.md)。

考虑一个受控的 selective-copying 任务：输入中夹有随机干扰，只有带有目标标记的 token 需要在序列末尾按原顺序输出，而目标 token 出现的位置并不固定。固定间隔的状态衰减规则不能只靠位置判断哪些内容重要；理想的更新应读取当前内容，再决定是否把它写入有限状态。Mamba 原论文用这类合成任务说明选择性机制所针对的缺口，并进一步测试 induction-head 类合成任务。这里的任务是机制探针，不是对任意历史检索或通用语言理解的证明。[Mamba 原论文 §3.1、§4.1](https://arxiv.org/abs/2312.00752v2)

## 32.2 输入依赖的 Δ、B、C 如何改变状态递归

先把每个位置的状态更新写成离散形式。以下用单个通道的记号说明关系；多通道实现会把这些量扩展到模型维度和状态维度。

~~~math
h_t=\bar{A}_t h_{t-1}+\bar{B}_t u_t,\qquad
y_t=C_t h_t+D u_t
~~~

式中的 $D u_t$ 是输入到输出的直接通路。固定参数 LTI SSM 在时间上共享状态转移以及输入、输出映射；Mamba 则从当前 SSM 层输入生成随位置变化的时间步长 $\Delta_t$、输入映射 $B_t$ 和读出映射 $C_t$。结构化参数 $A$ 仍是模型学习的参数，输入投影得到的时间步长再经 softplus 变为正值。这里的 $B_t$ 决定当前输入如何进入状态，$C_t$ 决定当前输出如何从状态读取，$\Delta_t$ 则改变连续动力学离散到当前 token 时的时间尺度。原论文将输入依赖的参数生成与离散化合在一起，得到逐位置变化的递归。[Mamba 原论文 §2、§3.2](https://arxiv.org/abs/2312.00752v2)

原论文用零阶保持（ZOH）离散化展示这一关系。对一个位置内保持不变的输入，离散转移为：

~~~math
\bar{A}_t=\exp(\Delta_t A),\qquad
\bar{B}_t=(\Delta_t A)^{-1}\bigl(\exp(\Delta_t A)-I\bigr)\Delta_t B_t
~~~

这组式子说明，$\Delta_t$ 同时影响旧状态衰减和当前输入写入的离散权重；它不是简单地在状态更新外乘一个任意门。若用最简单的稳定单状态例子令 $A=-1$、连续输入系数为 $1$，更新可化为：

~~~math
h_t=e^{-\Delta_t}h_{t-1}+\bigl(1-e^{-\Delta_t}\bigr)u_t
~~~

由于 $\Delta_t$ 为正，较大的步长会更快衰减旧状态，并让更新更多靠近当前输入；较小的步长会保留更多旧状态。这个单状态特例帮助看出时间尺度的作用，但 Mamba 实际有多通道、多维状态，选择性还体现在 $B_t$ 对状态的写入和 $C_t$ 对状态的读出，不能把它概括成一个二值开关。[Mamba 原论文 §3.5.1](https://arxiv.org/abs/2312.00752v2)

从数据形状看，序列层输入可写作 $(B,L,D)$，其中 $B$ 是批大小、$L$ 是序列长度、$D$ 是模型宽度；这里的批大小 $B$ 与输入映射 $B_t$ 是不同对象。原论文把输入相关的 $\Delta$ 写作 $(B,L,D)$，把 $B_t,C_t$ 写作 $(B,L,N)$，把状态参数 $A$ 写作 $(D,N)$，其中 $N$ 是状态维度。离散系数按通道和状态维组合时会涉及 $(B,L,D,N)$ 的展开形状；这些形状用于说明哪些量随 token 变化，不代表每个实现的存储布局都相同。[Mamba 原论文 §3.2、Algorithm 2](https://arxiv.org/abs/2312.00752v2)

因此，固定卷积表示的前提不再成立：输入一旦改变了每个位置的转移、写入或读出系数，就不存在一条对所有输入都相同的卷积核，能把整个序列映射到输出。计算仍能从递归转为扫描，但要利用的是逐位置更新之间的代数关系，而不是固定 LTI 卷积等价。

## 32.3 仿射更新的结合律与 Selective Scan

把第 $t$ 个位置的状态更新记作仿射变换 $T_t(h)=A_t h+b_t$，其中 $b_t$ 汇总了该位置写入状态的输入项。连续执行两个位置，必须保持时间顺序：

~~~math
T_2\bigl(T_1(h)\bigr)
=A_2(A_1h+b_1)+b_2
=(A_2A_1)h+(A_2b_1+b_2)
~~~

因此可以把一段更新压缩成一对参数，并按下面的规则合并：

~~~math
(A_2,b_2)\circ(A_1,b_1)
=(A_2A_1,\;A_2b_1+b_2)
~~~

这个合并满足结合律，因为它对应函数复合；但通常不满足交换律。也就是说，算法可以重新安排括号和并行计算一组前缀结果，却不能把 token 的先后顺序随意调换。Selective Scan 正是利用这一点：先为每个位置构造状态更新，再用并行前缀扫描计算从序列起点到各位置的组合，得到与逐步递归相同的状态。

并行 scan 改变了训练时怎样计算整段序列，不会把自回归生成变成可并行地产生未来 token。生成到新 token 时，仍要读取上一步状态、计算本步输入相关参数并更新状态；对历史 token 的处理可以压缩在固定形状的状态中。Mamba 原论文给出 selective scan 的结合计算，并针对硬件实现采用融合与内存管理策略；本章只需要理解代数路径，具体 kernel、读写量和实测吞吐留给[第三十三章](33-Mamba训练推理与硬件效率.md)。[Mamba 原论文 §3.3](https://arxiv.org/abs/2312.00752v2)

## 32.4 Mamba block 的整体数据路径

Selective SSM 是 block 中处理序列历史的一条支路，并不是完整的 Mamba block。以原论文图示的 Mamba block 为参照，输入投影分出主计算支路和门控支路：主支路经过短因果卷积和 SiLU 激活，生成选择性状态参数并运行 SSM；门控支路经 SiLU 后与状态输出逐元素相乘，结果再经输出投影回到模型宽度。外层网络还可使用归一化和残差连接。图中概括数据关系，具体层配置会随模型变体变化。[Mamba 原论文 §3.4、Figure 3](https://arxiv.org/abs/2312.00752v2)

~~~mermaid
flowchart LR
  x["层输入"] --> split["输入投影与分支"]
  x --> residual["外层残差路径"]
  split --> main["主支路"]
  split --> gate["门控支路"]
  main --> conv["短因果卷积"]
  conv --> act["SiLU"]
  act --> ssm["Selective SSM"]
  ssm --> mul["逐元素门控"]
  gate --> gateact["SiLU"]
  gateact --> mul
  mul --> outproj["输出投影"]
  outproj --> add["与残差合并"]
  residual --> add
  add --> y["block 输出"]
~~~

短卷积提供局部混合，Selective SSM 汇总并选择性更新跨位置状态，门控支路调节状态输出如何影响当前位置的表示。三者分工不同：卷积不是状态递归的替代物，门控也不负责保存完整历史。把这些部件区分开，才能正确比较 Mamba block 与 Transformer block；本章不展开训练吞吐、解码状态维护或服务调度，相关问题分别见第三十三章。

## 32.5 选择性机制的证据和边界

Mamba 原论文报告了 selective-copying 和 induction-head 等合成任务上的实验，用来检验输入依赖状态更新能否处理特定的内容选择模式。这些结果支持的结论是：在论文定义的任务与模型设置中，选择性状态机制改善了相关任务表现。它们不能单独证明固定大小状态能精确保存任意长历史，也不能推出 Mamba 在所有检索、上下文学习或语言建模任务上优于注意力。更广的能力边界由[第三十四章](34-Mamba局限与证据边界.md)讨论，跨方法结果需按任务、模型规模、训练数据和评测设置对齐后再比较，见[第三十六章](36-SSM替代Transformer的证据与争议.md)。[Mamba 原论文 §4.1](https://arxiv.org/abs/2312.00752v2)

本章的主线可以收束为三个相连的变化：当前输入产生 $\Delta_t,B_t,C_t$，使固定 LTI 更新变为内容相关的时变递归；每个位置的更新仍能表示为仿射变换，其结合组合让前缀 scan 得以并行；这些状态计算嵌入带局部卷积和门控支路的 Mamba block。选择性改变的是有限状态如何接收、保留和读取信息，并不等于无限记忆，也不自动保证任务成功。硬件成本、长程检索能力及 Mamba-2 的后续结构分别由后续章节承接。

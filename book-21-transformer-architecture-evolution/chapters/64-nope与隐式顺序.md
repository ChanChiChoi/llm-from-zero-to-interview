# 第 64 章 NoPE：没有显式位置变换，不等于没有顺序

## 64.1 NoPE 描述的是显式位置路径

读到 NoPE（No Position Encoding）时，先确认它描述的是哪条计算路径。绝对位置嵌入可以加到 token 表示上，RoPE 会按位置旋转 query 和 key，相对位置偏置则会改 attention score。本文把某条 attention 路径称为 NoPE，指该路径没有把显式位置特征加到 token 表示，也没有对 query、key 或 score 施加位置变换。不同论文可能采用更窄的术语口径，读模型时应以对应报告的定义为准。

### 64.1.1 省略显式信号，不等于抹掉已有线索

NoPE 说的是某种位置注入没有发生，不意味着该层输入里不存在与顺序有关的信息。因果 mask 仍会限制可见位置；更早的局部 attention 或递归模块也可能已经把相邻关系写进 hidden state。因而“这一层没有 RoPE”与“整个模型没有位置线索”不是同一个判断。

### 64.1.2 先看路径范围，再描述整个模型

NoPE 可以只用于某类层或某条分支，也可以用于更多 attention 层。若模型用 NoPE 的全局 attention 与带局部窗口或递归更新的层交错，前者的 query/key 虽不直接带位置变换，输入却可能已包含前序层传来的顺序线索。报告模型结构时，应说清哪些层或投影采用 NoPE，而不把局部分支的配置推广到整网。

## 64.2 无位置 attention 的置换性质与因果 mask

理解 NoPE 的关键，是把 attention 的内容交互与“哪些位置可见”分开。标准自注意力根据 token 表示计算 query、key、value；位置变换和 mask 则是额外进入计算的信号。

### 64.2.1 没有位置差异时，attention 对输入置换等变

令 $X\in\mathbb{R}^{T\times d}$ 表示 $T$ 个 token 的行向量，$M$ 表示加到 attention score 上的 mask 或偏置，$P$ 表示重排 token 行的置换矩阵。记带 mask 的 attention 计算为 $A(X;M)$，则同步重排输入和 mask 时，输出也随之重排：

```math
A(PX;PMP^\top)=P A(X;M)
```

当 $M=0$ 且没有其他位置特征时，任意重排都不会改变 token 间的内容交互关系，输出只会按同样的方式重排。这叫置换等变：输出不是完全不变，而是跟着输入位置一起移动。逐 token 的前馈层、归一化和残差连接也保留这一性质。

### 64.2.2 因果 mask 固定了前缀方向

自回归模型使用因果 mask 阻止位置 $t$ 读取未来的 $j>t$。可以把 mask 写成：

```math
(M_{\mathrm{causal}})_{t,j}=
\begin{cases}
0,&j\le t,\\
-\infty,&j>t.
\end{cases}
```

位置越靠后，可见的前缀越长。此时若只交换 token 内容而保持三角 mask 不动，输入置换不再与 mask 同步，原来的任意置换对称性便不成立。因果结构提供了“哪些 token 已经在当前 token 之前”的线索；但它不是一项直接按 $t-j$ 调整 score 的相对距离偏置。模型能否从这些可见集合学出稳定的位置表示，仍取决于训练和具体架构。

## 64.3 顺序线索怎样进入 NoPE 层

纯全局 NoPE attention 与混合架构中的 NoPE attention，可能依赖不同的信息路径。阅读或比较时，应分别问：线索来自因果可见性，还是来自前序层处理过的表示？

### 64.3.1 因果可见性可以形成隐式位置表示

Haviv 等人在因果语言模型上移除显式位置编码后，使用 probing 从中间层表示预测 token 的绝对位置，并报告模型在其训练设置中逐层获得了位置感知。作者推测，因果 attention 让模型可以估计当前 token 前面有多少个可见 token。[原论文](https://aclanthology.org/2022.findings-emnlp.99/)的 probing 结果支持“显式位置编码缺席时，hidden state 仍可能带有位置线索”；它没有证明所有 NoPE 模型都能精确恢复任意长度下的绝对索引，也没有单独证明因果 mask 是唯一来源。

### 64.3.2 局部混合与递归更新能传递近期性

滑动窗口 attention 等局部混合会让相近 token 的表示共同汇入后续 hidden state；递归模块则按 token 顺序更新并通过门控或衰减保留部分历史。之后的全局 NoPE attention 可以从这些表示中读取内容相关的近期性或距离线索。2026 年一项 arXiv 预印本在其滑窗混合模型中分析了“局部混合产生残差流近期性，再被全局 NoPE 的 query/key 投影读取”的机制，并在附录讨论 KDA 变体；这是特定训练设置下的理论与实验结果，不能外推为所有混合模型的固定机制。[论文 v1](https://arxiv.org/abs/2609.38109v1)

## 64.4 NoPE 能做什么，必须按任务区分

“模型能处理顺序”过于笼统。顺序、相对距离或近期性、绝对位置是不同任务，不能用一个短序列的成功率互相代替。

### 64.4.1 顺序、距离和绝对位置需要不同的测量

| 要测的能力 | 一个能区分该能力的任务 | 不能由此自动推出 |
| --- | --- | --- |
| 顺序判断 | 交换两个事件的先后，询问哪个先出现 | 对任意长间隔都能可靠读取 |
| 相对距离或近期性 | 固定事件内容并改变其间干扰长度，询问距离区间或哪个更近 | 能输出精确 token 坐标 |
| 绝对位置 | 对重复出现的内容要求返回指定位置索引，并按位置误差统计 | 能依据该索引可靠追溯外部来源 |

对照实验需要控制事件词汇和模板，改变位置、距离与干扰量，并分别报告每种任务结果。若还要解释线索来自何处，应在结构已知的模型上对 mask、局部层或递归状态做匹配消融；单看一次回答无法反推出模型内部用了哪条路径。

### 64.4.2 NoPE 的长度泛化不是无限外推

Wang 等人在长序列语言建模、passkey retrieval 和若干长上下文任务上研究因果 NoPE，报告其在特定设置中比常见显式位置方法更能延伸到未见长度，但也观察到能力会在更长输入下退化，并将失败与 attention 分布受到干扰联系起来。[ACL Findings 2024 论文](https://aclanthology.org/2024.findings-acl.834/)给出的结论绑定论文中的模型、训练长度和评测任务；它既不说明所有 NoPE 都优于 RoPE，也不说明省略显式位置特征就解决了长上下文。RoPE 与其他位置扩展方法的配方和位置外推，由[第 67 章](67-irope与超长上下文位置机制.md)展开。

## 64.5 Kimi K3：MLA 的 NoPE 与 KDA 的位置路径

Kimi K3 展示了“某些全局 attention 层用 NoPE”如何与带顺序状态的层共存。这个案例适合说明位置线索的层间分工，不应被概括为模型整体不含位置信息。

### 64.5.1 MLA 不直接给 query/key 施加位置变换

Kimi K3 v2 报告说明，其 MLA 层使用 NoPE，不对这些层的 query 和 key 施加显式位置编码；交错的 KDA 层提供 position-sensitive、recency-aware 的序列混合，而 MLA 保留全局内容交互。[Kimi K3 技术报告 v2 §2.1.2](https://arxiv.org/html/2607.24653v2#S2.SS1.SSS2) 因此准确的说法是“MLA 路径没有直接的位置变换，KDA 路径参与位置信息处理”，而不是“Kimi K3 没有位置机制”。MLA 的潜变量与输出门见[第 63 章](63-gated-mla门控潜变量注意力.md)，局部与全局层的整体组合见[第 65 章](65-hybrid-attention局部全局与递归状态.md)。

### 64.5.2 一百万 token 窗口不能归因于 NoPE 单项

Kimi K3 报告将其长上下文位置处理与 KDA 的递归门控和衰减联系起来；同一长上下文章节还描述了长文本数据处理、任务构造和逐阶段扩展训练。[技术报告 v2 §3.4](https://arxiv.org/html/2607.24653v2#S3.SS4)披露的是该模型的设计与训练路线，不是 NoPE 单项的受控消融。因此一百万 token 的窗口不能作为“NoPE 单独带来长上下文能力”的证据；完整模型案例由[第 88 章](88-kimi-k3-kda-stable-latentmoe与百万token-agent.md)负责。

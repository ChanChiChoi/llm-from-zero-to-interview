# 第四十一章：卷积序列模型在 LLM 中的复兴可能性

卷积在 LLM 中不是一条单一架构路线：它可以在 attention 前补充局部上下文，可以用长核承担一层序列混合，也可以与门控和 attention 组成混合主干。读者读完本章，应能区分这三种角色，理解因果卷积怎样处理历史信息，以及现有论文和模型发布究竟证明了什么。Hyena 的长核与门控递归见[第三十九章](39-Hyena隐式长卷积.md)；Mega、GSS、H3 等早期混合路线见[第四十章](40-Mega-Gated-State-Space与H3.md)；跨架构取舍由[第四十二章](42-替代架构横向对比.md)统一比较。

## 41.1 卷积复兴的三个层级

先看一个短语：“neural network optimization”。在读到最后一个 token 时，短卷积可以把它和左边相邻的 token 一起变换。这个操作在序列各位置复用相同的相对位移权重，因而直接表达“邻近位置值得一起处理”的先验。

卷积进入语言模型主要有三种位置：

| 形式 | 处理范围 | 在模型中的作用 |
| --- | --- | --- |
| 短程因果卷积 | 当前 token 与有限个前序 token | 在 Transformer 的表示流中加入局部混合；attention 仍可访问更远位置 |
| 长卷积 | 覆盖大段或整段序列的因果滤波器 | 让每个输出沿固定滤波路径汇总远处历史；有时替换 SSM 序列层 |
| 卷积混合主干 | 卷积层与 attention、状态层或门控层共同组成模型 | 按层或分支分配局部混合、长程传播和内容相关读取 |

因果卷积按“相隔几步”使用同一组核权重；attention 则根据当前 query 与各位置 key 的内容计算读取权重。卷积的感受野可以很长，但这并不自动让当前 query 能像指针一样从任意历史位置取出指定字段。更深的网络、非线性和门控可以学习更复杂的关系，因此这一区别说明的是信息路径，而不是卷积模型做不到某类任务的结论。

第三十九章已说明 Hyena 怎样组合长卷积与门控。本章把视角放宽到卷积家族在 LLM 中承担的不同职责，而不是重讲 Hyena 的算子递归。

## 41.2 局部深度卷积怎样为 attention 注入邻域信息

深度卷积（depthwise convolution）在每个通道内独立处理时间邻域，不在卷积这一步混合不同通道。设 $z_{t,c}$ 是时刻 $t$、通道 $c$ 的输入，$a_{r,c}$ 是相对位移 $r$ 的卷积权重，核宽为 $k$。一种残差因果深度卷积可写为：

~~~math
\widetilde{z}_{t,c}
=z_{t,c}+\sum_{r=0}^{k-1}a_{r,c}z_{t-r,c}.
~~~

求和只读取当前位置和过去；序列开头缺少的历史位置按实现约定补齐。残差项保留原表示，卷积项为它加入邻域信息。跨通道组合仍由 Q/K/V 投影和前馈层等已有线性层完成。

一项 2026 年技术报告在 Qwen3 block 的 17 个位置中比较 Conv1D 插入点，最好的位置是在 Q/K/V 投影后、attention 前。也就是说，卷积先让 query、key、value 表示带上邻近 token 的特征，随后标准 attention 仍负责更广范围的内容交互。其模块消融选出核宽 $k=3$ 的残差深度卷积，没有额外 normalization 或 activation。作者把结果解释为卷积提供局部先验；位置消融支持这一设计在所测设置中有效，但不能单独证明更普遍的语言机制。[论文](https://arxiv.org/html/2607.18413)

这类局部卷积不会把 Transformer 变成纯卷积网络。它改变的是进入 attention 的表示，模型仍保留全局 attention 路径。因果深度卷积的单通道含义和 ShortConv 例子可参见 [Short Convolution 讲解](https://www.sebastianraschka.com/llm-architecture-gallery/shortconv/)；该讲解中的模型配置不等同于 Qwen3 实验。

## 41.3 长卷积怎样进行全序列混合

把核宽扩到整段序列后，因果卷积可让远处位置沿滤波路径影响当前输出。对逐通道核，记输入序列为 $x_t$、核为 $K_r$，可写为：

~~~math
y_t=\sum_{r=0}^{R-1}K_r\odot x_{t-r}.
~~~

$R$ 是核宽，序列起点之前的输入按因果 padding 规则处理。若核覆盖整个输入，模型就能把远程历史汇入当前表示；但同一相对位移仍使用同一核系数，历史各处不会像 attention 那样由当前 query 分别计算内容匹配分数。长感受野是信息可传播的范围，不是内容寻址能力的同义词。Hyena 如何用隐式位置函数生成长核、再交替执行卷积与门控，见[第三十九章](39-Hyena隐式长卷积.md)。

长卷积核可以直接学习，也可以由结构化参数或位置函数生成。直接学习长核时，核的平滑性会影响模型质量。Fu 等人在长卷积研究中发现，对核权重使用 Squash 正则化后，Long Range Arena 六项任务的平均准确率从未正则化设置的 $69.5$ 提高到 $86.1$，与该实验中的 S4 平均分相同。这是特定长序列任务上的结果，不是 LLM 困惑度结论；作者的[教程](https://hazyresearch.stanford.edu/blog/2023-02-15-long-convs)用核的时间和频率响应解释了正则化的作用。

在语言模型中，同一研究将 H3 的 SSM 核替换成长卷积核，同时保留原模型的两层 attention。这个模型后面会与局部卷积和 StripedHyena 的证据一起比较。它说明长卷积可以进入语言模型主干的一部分，不能被改写成“纯卷积语言模型击败 Transformer”。[ICML 2023 论文](https://proceedings.mlr.press/v202/fu23a.html)

## 41.4 混合主干中的门控卷积：StripedHyena-7B

卷积也可以与 attention 共同构成完整语言模型。Together AI 在 2023 年发布 StripedHyena-Hessian-7B base 模型和 StripedHyena-Nous-7B chat 模型；作者将 StripedHyena 描述为 attention 与 Hyena operator 中门控卷积的混合。[官方发布文章](https://www.together.ai/blog/stripedhyena-7b)

这里的门控卷积不是单独一条固定核路径：Hyena operator 交替使用长卷积和由输入控制的逐位置乘法门控；模型还保留 attention 层。卷积负责的传播路径与 attention 的内容相关读取可以互补，但混合模型的结果不能只归因于卷积。第三十九章已推导 Hyena 的门控算子，本节只用 StripedHyena 说明这种组合确实进入了公开的 7B 级模型。

发布文章还按 FIR（有限冲激响应）和 IIR（无限冲激响应）讨论滤波器的推理表示：FIR 可保存有限长度的滑动窗口，IIR 可用递归方式更新定长状态。这是 StripedHyena 的模型表示选择，不意味着任意一个长卷积核都天然拥有定长状态。具体 serving 性能也需保留模型、序列长度、硬件和实现条件，本章不把作者报告的系统数字推广为所有卷积架构的属性。[官方文章中的 FIR/IIR 说明](https://www.together.ai/blog/stripedhyena-7b)

## 41.5 全序列训练与逐 token 生成的计算差异

对固定核宽 $k$ 的深度因果卷积，每个位置只需组合 $k$ 个输入。训练时可以在已知的整段序列上并行计算各位置；自回归生成时，新增一个 token 只需当前输入和保存的最近 $k-1$ 个输入。每个位置的工作量随 $k$ 增长，而不随已生成的总长度增长；不过 Transformer 的 attention 和 KV cache 仍然存在。

长卷积的直接计算会对每个输出检查最多 $R$ 个历史 tap。设 batch 大小为 $B$、通道数为 $d$、输入长度为 $L$、核宽为 $R$，对逐通道核，其直接计算和 FFT 线性卷积的序列项可分别写成：

~~~math
\mathrm{Direct}: O(BdLR),\qquad
\mathrm{FFT}: O(BdN\log N),\quad N\ge L+R-1.
~~~

$N$ 是为了得到线性卷积而选取的补零长度；将输入和核直接做同长度 FFT 会得到循环卷积，可能让序列尾部绕回开头。若 $R$ 与 $L$ 同量级，直接计算约为 $O(BdL^2)$，而 FFT 约为 $O(BdL\log L)$；这里没有计入投影、核生成、工作区和硬件常数，因此不能推出任意长度下都更快。关于多项式乘法、FFT 与因果边界的直观解释见 Hazy Research 的[长卷积教程](https://hazyresearch.stanford.edu/blog/2023-12-11-conv-tutorial)。

生成时的状态也取决于核的表示。有限核需要保存其有效窗口；核越长，窗口状态越大。具有特定结构的滤波器可改写为递归状态，状态大小便不必随上下文长度增长。StripedHyena 对 FIR 与 IIR 的处理展示了这类差别，但不能据此把长卷积一概说成固定状态或低延迟。于是，“训练可并行”“全序列 FFT 复杂度较低”和“逐 token 生成便宜”是三个不同判断，必须分别看待。

## 41.6 现有证据支持什么，尚未证明什么

三类代表证据覆盖的是不同设计问题。Qwen3 实验测试局部卷积插入点；H3+LongConvs 测试长卷积替换混合模型中的 SSM；StripedHyena 发布展示卷积与 attention 的完整混合模型。它们不是在相同模型、训练预算和评测任务下进行的架构竞赛。

Qwen3 技术报告从头训练 Qwen3-1.7B 和 Qwen3-4B，使用 FineWeb-100B 及其 30B、60B、100B token 预算，context length 为 4096，global batch 为 256 条序列。论文在 ARC-Challenge、ARC-Easy、BoolQ、HellaSwag、PIQA、WinoGrande、WSC 七项任务上报告平均准确率；下表的变化按百分点计算：

| Backbone 与训练 token | Transformer 平均准确率 (%) | 加入 Conv1D 后 (%) | 变化 (百分点) |
| --- | ---: | ---: | ---: |
| Qwen3-1.7B，30B | 52.71 | 54.70 | +1.99 |
| Qwen3-4B，30B | 57.13 | 58.70 | +1.57 |
| Qwen3-4B，60B | 58.78 | 60.69 | +1.91 |
| Qwen3-4B，100B | 58.65 | 62.41 | +3.76 |

平均分在这些设置中都上升，但部分单项下降；100B 设置更大的平均增益还需要更多训练预算和重复实验，不能外推成一般 scaling 规律。[实验表与条件](https://arxiv.org/html/2607.18413)

该报告的参数比例还有一个未解决的内部差异：摘要称新增参数低于 $0.01\%$，但插入位置表的基线为 $1720.57$M、P5 为 $1721.15$M，按表中数字相差约 $0.034\%$；残差 shortcut 模块表报告 $1721.03$M，约相差 $0.027\%$。论文没有解释这些数值为何与摘要比例不一致，因此本章只说参数增量较小，不将摘要中的比例当成已核实的精确值。表示相似度分析也只展示了一个 WSC 案例，不能单独证明卷积普遍解决变量绑定。

LongConv 论文在 Pile 上报告的 test perplexity 如下。该模型保留两层 attention，并将 H3 中的 SSM 核换成长卷积核：

| 训练 token | Transformer | H3 | H3 + LongConvs |
| --- | ---: | ---: | ---: |
| 5B | 12.7 | 11.8 | 11.9 |
| 10B | 11.3 | 10.7 | 10.7 |
| 15B | 10.7 | 10.2 | 10.3 |

这些结果说明指定设置下的 H3+LongConvs 接近 H3，且在这张表上优于 Transformer baseline；它不能拆出卷积单独带来的效果，也不代表无 attention 的纯卷积主干。[论文语言建模实验](https://proceedings.mlr.press/v202/fu23a.html)

StripedHyena 官方文章报告其与 Mistral 7B 在 ZeroScrolls 零样本长上下文任务上的 F1：

| 任务 | StripedHyena 7B (0-shot F1) | Mistral 7B (0-shot F1) |
| --- | ---: | ---: |
| GovReport | 27.9 | 17.5 |
| NarrativeQA | 25.8 | 24.7 |
| Qasper | 28.8 | 30.3 |
| 三项平均 | 27.5 | 24.2 |

其中 Qasper 分数较低，结果由模型发布方报告，且比较没有隔离 attention、门控卷积、训练数据或其他实现因素的单独贡献。[官方 ZeroScrolls 表](https://www.together.ai/blog/stripedhyena-7b)

因此，“卷积复兴”目前更准确地描述为三类结构用途：为 attention 添加邻域先验、在混合模型中承担长程滤波，以及和全局读取路径一起组成主干。现有材料支持研究这些互补设计，不足以证明纯卷积主干普遍替代现代 Transformer。判断某个新模型时，应先确认卷积插在哪里、核如何生成、是否保留全局读取路径，再按其真实训练和评测条件解释结果。

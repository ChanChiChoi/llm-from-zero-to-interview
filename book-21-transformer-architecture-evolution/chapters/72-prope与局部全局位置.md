# 第 72 章 P-RoPE：周期性 RoPE 与局部/全局注意力

本章讨论一种把 RoPE 位置表限制在窗口范围内循环复用的方法。`P-RoPE` 在这里是 **Periodic RoPE**，而不是有些论文所称的 partial RoPE：后者通常表示只旋转 attention head 的一部分维度，二者不是同一个机制。[Periodic RoPE 论文 v2](https://arxiv.org/html/2605.27980v2)还提出了 Harmonic Periodic RoPE（HP-RoPE），用与窗口宽度对齐的频率消除周期边界上的旋转不一致。

先记住两个不同的问题：位置编码决定 query 和 key 怎样携带位置关系；attention mask 决定 query 可以读取哪些 key。P-RoPE 修改前者，滑动窗口注意力（SWA）限定后者。论文把两者和全局 NoPE 层组合在 MiniWin 中；这种组合不等于无限容量，也不表示只靠 P-RoPE 就能读取窗口外内容。

## 72.1 位置索引与可见范围是两个设计轴

### 72.1.1 RoPE 把相对偏移带入注意力分数

RoPE 将每个 attention head 的 query 和 key 切成二维向量对。每一对使用自己的频率 $\theta_i$，token 位置则决定这对向量旋转多少。常见频率表可写为：

```math
\theta_i=\Theta^{-2i/d_h},
\qquad i=0,1,\ldots,\frac{d_h}{2}-1.
```

这里 $d_h$ 是 head dimension，$\Theta$ 是 RoPE 的频率基数，具体取值取决于模型配置。令 $R_t$ 表示位置 $t$ 对所有维度对施加的分块旋转，$\tilde{q}_t$ 与 $\tilde{k}_s$ 表示旋转前的 query 和 key。暂不写标准 attention 中的 $1/\sqrt{d_h}$ 缩放和 mask，旋转后的 query-key 点积只依赖二者的相对位置：

```math
\alpha_{t,s}
= (R_t\tilde{q}_t)^{\mathsf T}(R_s\tilde{k}_s)
= \tilde{q}_t^{\mathsf T}R_{t-s}\tilde{k}_s.
```

因此，RoPE 在 softmax 前的点积分数里提供相对偏移线索。它没有规定某个 query 是否能看见某个 key；这件事由 attention 的可见集合决定。若想复习频率和旋转如何产生相对位置关系，可以回到第 18 章，或参考[面向初学者的 RoPE 可视讲解](https://simondong1.github.io/rope.html)。

### 72.1.2 滑动窗口 mask 限定单层可以直接读取的位置

若 causal SWA 的窗口宽度为 $W$，位置 $t$ 在该层可以直接读取的位置集合是：

```math
\mathcal{V}_t
=\{s\mid \max(0,t-W+1)\le s\le t\}.
```

这条规则限制 query 与哪些 key 计算注意力。窗口外的 token 即使存在于更长的输入里，也不能通过这一层的直接 attention 被读取。把 RoPE 的位置表改为周期形式，不会改变集合 $\mathcal{V}_t$；要让窗口外信息进入后续计算，模型还需要其他路径，例如全局 attention 层。

### 72.1.3 P-RoPE、partial RoPE 与 iRoPE 名称不同

本章讨论的 **P-RoPE** 是周期性复用位置表；[partial/fractional RoPE 研究](https://arxiv.org/abs/2603.11611)讨论的是只对 head 的部分维度施加旋转。名称相近，但一个改变位置索引的周期，另一个改变被旋转的维度数。

它也不同于第 67 章讨论的 **iRoPE**。后者按 Meta 的公开口径涉及局部 RoPE 与全局 NoPE 层的安排；P-RoPE 本身则是对窗口内的位置索引取模。MiniWin 同时使用周期局部 RoPE 和全局 NoPE，但这不意味着两个缩写指向同一个算法。

## 72.2 P-RoPE 复用窗口内的位置旋转表

### 72.2.1 用周期索引代替不断增长的位置索引

标准 RoPE 在位置 $t$ 使用旋转 $R_t$。P-RoPE 对宽度为 $W$ 的局部窗口改用周期位置：

```math
\varphi(t)=t\bmod W,
\qquad
R_t\longrightarrow R_{\varphi(t)}.
```

位置索引因此只取 $0$ 到 $W-1$。即使输入序列继续变长，局部层也只重复使用这 $W$ 个相位。P-RoPE 的目的，是避免局部 RoPE 必须对不断增大的绝对位置索引继续外推；它没有取消位置关系，也没有扩大 SWA 的可见范围。

### 72.2.2 未跨周期边界时，编码偏移仍是真实距离

令 query 在位置 $t$、key 在位置 $s$，并令滞后距离 $d=t-s$。如果二者处于同一周期，模运算前后的相位差不变：

```math
\varphi(t)-\varphi(s)=d.
```

此时 P-RoPE 为这一对位置使用的相对旋转，与普通 RoPE 相同。表项被重复使用并不自动造成误差；差别出现在同一局部窗口里的 query/key 对恰好跨过周期边界时。

### 72.2.3 跨边界时，相对偏移会从 $d$ 变成 $d-W$

取一个宽度为 $W=4$ 的玩具窗口。位置对 $(t,s)=(3,0)$ 的真实间距是 $d=3$，其周期相位差也是 $3$。把同一真实间距移到窗口边界另一侧，即 $(t,s)=(4,1)$，相位分别变成 $0$ 和 $1$，两者的差是 $-1=d-W$。因此，同样相隔三个 token 的两个位置对，会因所在窗口相位不同而得到不同的旋转。

一般地，跨边界时 P-RoPE 使用 $R_{d-W}$，而不是普通 RoPE 的 $R_d$。两者相差一个整窗口的旋转：

```math
R_{d-W}=R_dR_{-W}.
```

若某一维度对满足 $W\theta_i\notin 2\pi\mathbb{Z}$，则该维度的 $R_{-W}$ 不是单位旋转。常见的几何 RoPE 频率表通常不满足所有维度都在一个窗口后恰好转整数圈，所以 P-RoPE 会留下一个与窗口相位相关的 **wrap error**。[论文 v2 对这一差异作了推导](https://arxiv.org/html/2605.27980v2#S2)。这是位置旋转层面的不一致；它说明 attention 分数可能变化，但不单独决定整个模型在某项任务上是否成功。

## 72.3 HP-RoPE 让旋转周期与窗口宽度对齐

### 72.3.1 让一个窗口宽度对应单位旋转

要让跨边界前后的相对旋转相同，只需让整窗口的旋转等于单位矩阵：

```math
R_W=I.
```

满足该条件时，$R_{-W}=I$，于是：

```math
R_{d-W}=R_dR_{-W}=R_d.
```

这样一来，窗口内某对 query/key 是否跨过周期表的起点，不会再改变它们对应的相对旋转算子。

### 72.3.2 谐波频率使每个窗口完成整数圈

HP-RoPE 将每个二维旋转对的频率设为：

```math
\theta_i'=\frac{2\pi m_i}{W},
\qquad m_i\in\mathbb{Z}.
```

位置前进 $W$ 步后，第 $i$ 对向量转过 $2\pi m_i$，所以旋转表回到相同状态。论文给出的配置例子是 $W=256$、head dimension $d_h=96$，并取 $m_i=48-i$，使频率编号从 $48$ 递减到 $1$。最快的维度对在一个窗口内转 $48$ 圈，最慢的一对转一整圈。

这个频率表与通常按几何级数排列的 RoPE 频率不同：它把周期边界的一致性直接写进位置表，而不是让模型自行适应边界跳变。局部频率的分布也随之改变，因而边界恒等式不能代替对实际语言建模质量的评估。

### 72.3.3 边界误差消失，不代表所有长程困难都消失

HP-RoPE 消除的是 $d$ 与 $d-W$ 之间的旋转差异。它没有改变局部窗口大小，也没有使局部层直接看见窗口之外的 token；更没有证明模型会在任意长输入中保留每个事实。跨窗读取、远程信息保真、训练分布和资源成本仍由整套模型路径决定。

所以要把结论分成两层：$R_W=I$ 是位置变换本身的代数性质；困惑度、检索准确率或语言理解是否改善，则是模型与评测共同决定的经验问题。论文的边界诊断能验证前者，端到端任务才涉及后者。

## 72.4 MiniWin 组合周期局部位置与全局 NoPE

### 72.4.1 局部层用 SWA 与一种 RoPE 变体配合

MiniWin 的局部层将窗口 mask 和位置旋转结合起来。实验分别在这些窗口层使用标准 RoPE、P-RoPE 或 HP-RoPE；查询依然只从窗口内的位置聚合 value。P-RoPE 和 HP-RoPE 改变的是窗口内用于 query/key 的旋转相位，不改变局部层的 token 可见集合。

### 72.4.2 全局 NoPE 层负责跨窗口直接交互

局部窗口无法直接读取窗口之外的 key/value。MiniWin 因而交错加入全局 causal attention 层，在该路径上不施加显式 RoPE，让当前 query 可以与更长的可见前缀交互。**NoPE 不等于整网没有顺序线索**：因果 mask 规定了前缀方向，前序局部层形成的 hidden state 也可以携带位置信息。已有研究观察到，因果语言模型在某些训练设置下能从因果可见性中学到隐式位置线索；这不是任意模型都能无限泛化的保证。[Haviv 等人](https://aclanthology.org/2022.findings-emnlp.99/)与[长度泛化比较研究](https://papers.neurips.cc/paper_files/paper/2023/file/4e85362c02172c0c6567ce593122d31c-Paper-Conference.pdf)都显示，NoPE 表现须绑定训练条件与任务。

局部 RoPE 与全局 NoPE 的交错是已有混合路线，[SWAN-GPT](https://arxiv.org/abs/2504.08719)也研究了类似的层间组合。MiniWin 在这一架构上进一步研究窗口局部位置表是否周期复用，以及 HP-RoPE 是否能修正边界处的旋转。

### 72.4.3 论文比较的是一个具体的八层配置

论文 v2 的 MiniWin 使用八层结构，每三层局部 SWA 后接一层全局 attention，重复两次，即 `SSSL × 2`：六个局部层和两个全局层。窗口宽度为 $W=256$，attention head dimension 为 $96$。这些配置界定了论文评测发生的模型结构，不是对所有模型都适用的局部/全局层比例。

### 72.4.4 有限位置表不等于无限资源

周期位置表解决的是局部 RoPE 索引持续增长的问题。MiniWin 的全局层仍需处理完整因果前缀；对 dense global attention，prefill 的注意力计算仍随序列长度呈二次增长，逐 token 解码仍要访问保留的历史表示。P-RoPE 本身不会消除 KV 存储，也不会让显存或每步计算变成常数。

因此，“无限上下文”要谨慎理解：周期索引可以无限重复，但这不等于模型能在有限内存和计算下保留、定位并正确使用无限多 token 的信息。上下文长度、可见范围、记忆容量和任务质量是不同问题；更广的局部/全局成本比较见第 65、67 章。

## 72.5 v2 实验说明了什么

### 72.5.1 控制比较把差异限定在局部位置编码

作者基于 MiniMind3 训练 MiniWin 变体，主训练长度为 $768$，训练约 $840$ 万篇文档并留出 $5\%$，优化器为 AdamW，精度为 bf16。另有一阶段继续预训练（CPT），使用约 $10\%$ 的 packed tokens，将长度扩展到 $1536$。对照保持模型结构、训练数据和日程一致，只改变局部窗口层的位置编码；RoPE 的 NTK/YaRN 类处理是在测试期应用，P-RoPE 与 HP-RoPE 沿用窗口表而不做该类插值。

评测长度从 $512$ 到 $16\mathrm{k}$，包括训练数据的 packed hold-out、约 $760{,}000$ token 且未用于训练的连续《西游记》文本，以及英文和中文 passkey 任务。passkey 每个长度报告 $200$ 次试验，候选打分任务的随机 top-1 基线为 $12.5\%$。这些设置比单一“最大上下文”数字更具体，但仍只覆盖有限模型、语料和检索任务。[论文 v2](https://arxiv.org/html/2605.27980v2#S3)给出完整实验协议。

### 72.5.2 16k 结果属于 MiniWin 的实验条件

对只在 $768$ 长度训练的模型，论文报告的 $16\mathrm{k}$ 结果如下。YaRN 栏的 passkey 数字按论文对相关测试期插值设置给出的最高报告值呈现；其余指标是相同测试设定下的所报值。

| 16k 指标 | RoPE | YaRN 系列 | P-RoPE | HP-RoPE |
| --- | ---: | ---: | ---: | ---: |
| Packed hold-out perplexity | 62.9 | 20.7 | 8.07 | 7.15 |
| 训练外连续文本 perplexity | 390 | 421 | 118 | 113 |
| 英文 passkey top-1 | 13% | 最高 22% | 99% | 100% |
| 中文 passkey top-1 | 14% | 最高 42% | 100% | 99.5% |

在这一组测试中，P-RoPE 和 HP-RoPE 的长度外推结果明显优于所测 RoPE/YaRN 对照。表格不能证明它们在其他模型尺寸、语种、文档理解、复杂多证据任务或生产负载上同样占优；作者也报告了在 $1536$ 长度继续预训练后的比较，但不应把不同训练阶段的数字混在同一行里。[原论文图表与正文](https://arxiv.org/html/2605.27980v2#S3)是这些数值的来源。

### 72.5.3 边界移动诊断支持 HP-RoPE 的代数解释

论文还固定训练后窗口层的 query、key 和 value，只改变周期表的起点，再比较 attention logits 和权重分布。P-RoPE 的最大 logit 变化约为 $21$，最大注意力行 total variation 位于 $0.31$ 到 $0.81$；HP-RoPE 的对应变化处于约 $10^{-6}$ 到 $10^{-7}$ 的浮点噪声范围。该结果符合 $R_W\ne I$ 与 $R_W=I$ 的代数预测。

作者另将真实答案放在滞后 $160$ 的位置、干扰项放在滞后 $24$，再改变 prompt 长度使真实答案跨越周期边界。P-RoPE 窗口层落在真实答案上的注意力占比由 $7.5\%$ 降至 $5.4\%$；HP-RoPE 的相应数值为 $7.7\%$ 与 $7.6\%$。这说明经过训练的局部层确实会受周期边界影响，也显示 HP-RoPE 在这项特定诊断中减少了变化；它仍不是对任意长文本检索能力的独立证明。

### 72.5.4 有限实验不等于无限上下文结论

截至该论文的 2026 年 11 月 v2，核心模型是八层 MiniWin，主要训练长度为 $768$，最长报告评测到 $16\mathrm{k}$。证据由一份 arXiv 预印本提供，尚待作者所说的更大模型和更广 benchmark 验证。论文的受控对照支持这样的窄结论：在 MiniWin 结构和所测任务中，周期局部位置编码比该实验中的 RoPE/YaRN 对照更稳；HP-RoPE 还减少了其局部窗口层的边界旋转误差。

它没有证明“任意长文档都可正确理解”，也没有证明收益来自一个脱离全局 NoPE 路径的 P-RoPE 单项。把论文标题中的 `infinite context` 转述为效果时，应同时说明局部位置索引可以循环、全局路径仍受计算与存储约束、已测质量仅覆盖特定模型和任务。

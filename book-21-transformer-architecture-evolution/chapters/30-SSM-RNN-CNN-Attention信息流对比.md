# 第三十章：SSM、RNN、CNN、Attention 的信息流对比

本章比较因果序列预测中的四种信息流。假设我们读到一条长日志：较早位置记录了错误码，末尾的问题要求报出它。真正要比较的不是架构名字或单个复杂度符号，而是三件事：旧信息存在哪里，末尾位置通过什么路径接触它，以及这条路径能保证什么。

后文默认位置 $t$ 只能依赖当前及过去的输入。若任务允许双向读取或使用其他 mask，可见范围会改变；因此比较 attention 和卷积时，必须先说明各位置允许看见什么。还要把“图中存在一条路径”“信息仍保留在表示里”和“模型正确读出答案”分开。原始 Transformer 论文也分别讨论每层计算量、串行操作数和长程依赖的路径长度，三者不能压成一个速度结论（[Vaswani 等，§4](https://arxiv.org/abs/1706.03762)）。

## 30.1 RNN 与 SSM：通过递归状态传递历史

RNN 在每一步把前一时刻的隐藏状态和当前输入合并，形成新状态。最一般的写法是：

~~~math
h_t=f(h_{t-1},x_t)
~~~

函数 $f$ 在各时间步共享参数。普通 RNN 的状态更新是非线性的；LSTM、GRU 等变体加入门控或额外状态，仍然通过递归状态向后传递信息。读到早先的错误码后，后续位置不会自动获得一个按原位置索引的存储槽，而是反复更新同一个固定形状的状态。因而旧信息能否继续区分，取决于更新规则、状态表示和训练任务，不能只凭“存在隐藏状态”判断。RNN 的时间展开和跨步参数共享可参见 [Dive into Deep Learning 的 RNN 章节](https://d2l.ai/chapter_recurrent-neural-networks/)。

固定参数线性时不变（linear time-invariant，LTI）SSM 也使用递归状态，但更新受到线性状态转移结构约束。记 $(s_t,u_t,y_t)$ 分别表示状态向量、当前输入和当前输出；固定矩阵组 $(\bar{A},\bar{B},C,D)$ 依次控制状态转移、输入写入、状态读出和当前输入到输出的直接通路。其更新为：

~~~math
s_t=\bar{A}s_{t-1}+\bar{B}u_t,\qquad y_t=Cs_t+Du_t.
~~~

这和一般非线性 RNN 不是同义词。[第二十九章](29-SSM数学直觉.md)已经说明，固定参数条件下同一个 SSM 既能逐步更新状态，也能展开为因果卷积。卷积视图会改变整段序列的计算路径，却没有把每个旧 token 变成可以由 query 按位置读取的独立槽位。[S4 原论文 §2.3–2.4](https://arxiv.org/abs/2111.00396)给出了这一递归—卷积对应关系；第 31 章再解释 S4 如何利用结构化参数高效计算卷积核。若状态更新参数随输入变化，固定卷积核不再能直接描述该更新，第 32 章负责讨论 Mamba 的选择性机制。

回到日志例子：RNN 或固定状态 SSM 可以把早先错误码的相关信息带到末尾，也可能在持续更新中改变或覆盖它。这里的结构事实是信息要经过递归状态路径；是否保留了足以回答问题的细节，仍需按具体任务判断。

## 30.2 CNN 与 Attention：有限感受野和显式可见历史

因果时序 CNN 通过卷积核连接当前位置和前一层的一组过去位置。用第 $\ell$ 层参数组 $(k_\ell,d_\ell,\{W_j^{(\ell)}\})$ 分别表示核宽、膨胀率和各 tap 的通道映射。将上一层在时刻 $t$ 的特征向量作为输入，其中 $z_t^{(\ell-1)}$ 表示该向量。该层可写成：

~~~math
z_t^{(\ell)}=\sum_{j=0}^{k_\ell-1}W_j^{(\ell)}z_{t-jd_\ell}^{(\ell-1)}.
~~~

越过序列开头的项由左侧 padding 处理。单层只读取有限 taps；多层叠加后，信息才可能沿中间特征继续传播。对于 stride 为一且每层只有一个因果卷积的情形，令 $R_L$ 表示从当前时刻到最远结构可达位置的覆盖跨度（包含当前位置），并以 $L$ 表示卷积层数。该跨度为：

~~~math
R_L=1+\sum_{\ell=1}^{L}(k_\ell-1)d_\ell.
~~~

这个式子给出到最远位置的覆盖跨度，跨度内部是否每个位置都可达，还要看各层 tap 的组合。增大核宽、增加层数或采用 dilation 都能扩大感受野，但超过当前网络感受野的输入没有到达该输出的计算路径。[Bai 等的 TCN 论文 §3.2–3.3](https://arxiv.org/abs/1803.01271)通过因果卷积和 dilation 展示了这种构造；论文对若干基准上 TCN 与 RNN 的结果仅适用于其任务、模型和训练设置，不构成 CNN 普遍优于 RNN 的结论。

Attention 采用另一种路径：当前位置用 query 对 mask 允许读取的历史 key 打分，再按权重汇总对应 value。用符号 $V_t$ 表示位置 $t$ 允许读取的位置集合，并将 query、key、value 向量及 key 维数合并记作 $(q_t,k_i,v_i,d_k)$ 元组。元组内四项依次表示当前位置的 query、可见历史位置的 key、对应 value 和缩放维数。Attention 对权重和输出的计算为：

~~~math
\begin{aligned}
a_{t,i}&=\mathrm{softmax}_{i\in V_t}\left(\frac{q_t^{\mathsf T}k_i}{\sqrt{d_k}}\right),\\
y_t&=\sum_{i\in V_t}a_{t,i}v_i.
\end{aligned}
~~~

在标准因果 self-attention 中，可见位置集合记作 $V_t$ 并由因果 mask 和当前上下文共同决定。只要早先位置仍在可见范围内，图上就可以存在从它到当前位置的直接读入边；query 还会根据当前表示和 key 计算不同权重。和递归状态或有限感受野相比，这提供了显式的逐位置访问路径，但不能保证权重会选中正确证据，也不能保证信息经层层表示后仍未混淆。Attention 是“可以查询可见位置”，不是外部原文档案或正确引用的保证。

## 30.3 远处信息经过什么路径

沿用早先记录错误码、末尾询问错误码的任务，四种结构的路径差异可以归纳如下：

| 路线 | 历史主要保存在 | 末尾位置怎样取得旧信息 | 结构上的访问边界 |
| --- | --- | --- | --- |
| RNN | 每步递归传递的隐藏状态 | 当前输入与前一状态不断合并 | 没有独立的历史位置槽；保留细节取决于状态更新和读出 |
| 固定 LTI SSM | 固定形状的线性状态 | 通过状态转移累积输入影响；整段也可用同一因果卷积计算 | 卷积核由固定参数决定，不会随末尾 query 临时改写历史权重 |
| 因果 CNN | 各层时间特征及其感受野 | 沿卷积 tap 和中间层传播 | 只有网络感受野中存在的过去位置能影响当前输出 |
| 因果 Attention | 可见历史位置的逐层 key/value 表示 | 当前 query 对可见 key 计算权重并读取 value | 可见性受 mask 和上下文限制，权重是否适合任务仍由表示与训练决定 |

若用递归形式计算 RNN 或 SSM，早先输入的影响要沿后续状态更新传播；固定 LTI SSM 的卷积形式则可以按整段序列计算同一个算子。CNN 的远程影响要由层叠卷积提供路径。Attention 在允许读取的位置之间建立直接的层内路径。路径长短是分析计算图的一项坐标，不等同于记忆准确率、证据可分辨性或训练效果；原始 Transformer 论文对不同层路径的比较也受其卷积和注意力设定约束（[§4 与 Table 1](https://arxiv.org/abs/1706.03762)）。

因此，看到“错误码位置到问题位置可达”还不够。要判断模型是否能回答，仍需检查状态或逐位置表示是否保留了码值、读出是否区分相近实体，以及训练任务是否教会模型使用它。若需要在不同的未来问题中反复选择不同历史位置，显式 query—key 路径提供了不同于固定递归状态的访问原语；这也不等于每次注意力都能准确检索。

## 30.4 训练并行与生成状态不是一回事

给定整段训练输入时，因果卷积可以按位置并行计算同一层输出；因果 Attention 也能在 mask 限制下同时计算多个位置的 query、key 和 value。常见非线性 RNN 的状态依赖前一时间步，标准递归前向因此沿时间展开。固定 LTI SSM 多了一条卷积计算路径，可在训练整段序列时改用卷积；同一个模型在逐步解码时仍可使用递归状态。[The Annotated S4](https://srush.github.io/annotated-s4/)把这两种计算视图和具体实现对应起来，但它展示的是 S4 教程实现，不代表所有 SSM 都使用相同训练代码。

对自回归生成而言，下一 token 依赖已经生成的前缀，所以四类架构都不能把 token 生成顺序简单消掉。它们每步携带的历史状态不同：RNN 保存隐藏状态；按递归方式执行的 SSM 保存状态向量；固定层数的因果 CNN 可缓存后续卷积需要的有限历史激活；标准 full causal attention 通常为各层保留已处理位置的 key/value 表示，缓存随上下文增长。具体容量还随层数、宽度、卷积结构、KV head 数和精度变化，本节不据此给出速度或显存排名。

可用四个问题概括本章：旧信息以递归状态、有限感受野还是逐位置表示保存；当前输出有哪些结构路径可以读取它；这些路径在完整序列计算和逐步生成时是否相同；图上的可达是否被误说成任务能力。[第三十一章](31-S4核心思想.md)转向 S4 的结构化状态矩阵，[第三十二章](32-Mamba与Selective-Scan.md)解释输入相关的 Mamba 更新，[第四十二章](42-替代架构横向对比.md)比较架构的复杂度、表达力、硬件和生态，[第四十三章](43-Attention与SSM混合架构.md)讨论 Attention 与 SSM 如何组合。

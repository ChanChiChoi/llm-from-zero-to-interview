# 第三十一章：S4：Structured State Space 的核心思想

## 31.1 S4 如何连接长记忆与可计算性

第二十九章已经说明，固定参数的线性时不变状态空间模型可以写成逐步递归，也能在零初始状态下展开为因果卷积。S4 要继续回答的问题是：当状态转移矩阵有长程记忆所需的结构时，怎样高效地算出状态更新和卷积核？

这两个目标并不会自动同时成立。若状态矩阵 $A$ 是一般稠密矩阵，逐步递归每次都要执行稠密矩阵与状态向量的乘法；若为整段序列预先生成卷积核，则直接计算一连串矩阵幂也很贵。反过来，把 $A$ 简化成容易处理的对角矩阵，虽然能降低计算量，却可能丢掉原来有用的状态结构；对 HiPPO 矩阵直接做特征分解还会遇到数值稳定问题。

S4 的方法由此分成两件相互配合的工作：用 HiPPO 相关矩阵承载经过设计的历史投影状态，再把该矩阵写成可计算的低秩结构，并据此生成卷积核。S4 因而不只是“用了更大的状态向量”，也不只是“把递归改成卷积”。它针对的是状态表示和有限序列计算之间的连接问题。[S4 原论文](https://arxiv.org/abs/2111.00396)将这条路径写成连续、离散递归和卷积三种视图，并把结构化核生成作为主要技术贡献。

## 31.2 HiPPO 将历史压缩为有限维投影

把历史记忆想成一排 token 槽位，容易误解 HiPPO：它不是给每个过去 token 分配固定地址，而是把截至当前时刻的输入历史视为一个函数，再用有限个基函数去近似这段函数。

令 $f_{\le t}$ 表示截至时刻 $t$ 的输入历史，$\mu^{(t)}$ 表示定义于这段历史上的时间测度。测度决定近似误差如何加权，也就是历史中哪些时间位置在当前投影目标里更重要。选定有限维多项式子空间，并使用按该测度正交归一的基函数 $p_n^{(t)}$，投影系数与重建近似可写为：

```math
c_n(t)=\left\langle f_{\le t},p_n^{(t)}\right\rangle_{\mu^{(t)}},\qquad
\hat f^{(t)}(s)=\sum_{n=0}^{N-1}c_n(t)p_n^{(t)}(s)
```

这里 $N$ 是保留的系数个数，$\hat f^{(t)}$ 是当前历史的有限维近似；$s$ 表示历史中的一个时间位置。在给定测度和多项式子空间后，这种投影使该子空间内的加权平方误差最小；改变测度会改变模型重视的历史区域，改变子空间也会改变能表达的函数范围。[HiPPO 原论文](https://arxiv.org/abs/2008.07669)将这一过程定义为在线函数近似，并从系数的连续变化推导相应的状态动力学。

“最优”只针对这个明确定义的投影误差。它不表示状态能够无损还原任意历史 token，也不表示下游模型一定能从系数中读出某个离散数字或实体。系数是基函数投影的结果，不是一维一个 token 的存储槽；对不同测度而言，同一系数所概括的历史范围也不同。S4 使用 HiPPO 相关的状态矩阵作为长记忆结构来源，HiPPO 自身的近似目标和 S4 的快速核计算则是相连但不同的问题。

## 31.3 从 NPLR 到 DPLR：保留低秩结构的坐标变换

得到一个适合表达历史投影的状态矩阵，还不等于已经得到便宜的计算路径。若直接计算状态矩阵的高次幂，生成长卷积核仍然昂贵。纯对角矩阵的幂容易计算，但把一般 HiPPO 矩阵直接对角化会引入病态特征向量。S4 原论文具体展示了所讨论 HiPPO 矩阵的特征向量矩阵含有随状态维度 $N$ 指数增长的元素，因此朴素特征分解在数值上不可行。

S4 利用 HiPPO 矩阵可写成“正规矩阵加低秩修正”的性质，称为 NPLR（normal plus low-rank）。正规矩阵满足 $AA^{*}=A^{*}A$，因此可以由酉矩阵对角化。把低秩修正一同变换到这个坐标系后，得到 DPLR（diagonal plus low-rank）形式：

```math
A=V\Lambda V^{*}-PQ^{*},\qquad
V^{*}AV=\Lambda-(V^{*}P)(V^{*}Q)^{*}
```

其中 $\Lambda$ 是对角矩阵，$P$ 和 $Q$ 是低秩因子，$V^{*}$ 表示 $V$ 的共轭转置。若 $P$ 和 $Q$ 各有 $r$ 列且 $r\ll N$，低秩修正的秩至多为 $r$。令 $\tilde P=V^{*}P$、$\tilde Q=V^{*}Q$，变换后的矩阵就是 $\Lambda-\tilde P\tilde Q^{*}$。这里的低秩表示保留了对角部分之外的耦合。

这一步是状态坐标变换，不是近似丢弃状态。对整个系统同时变换状态、输入和读出矩阵：

```math
x=Vz,\qquad A'=V^{*}AV,\qquad B'=V^{*}B,\qquad C'=CV
```

代回状态方程后，输入到输出的映射保持不变，只是内部状态改用坐标 $z$ 表示。S4 的好处来自 NPLR 矩阵中正规部分可用酉基稳定处理，而低秩修正有专门的求逆公式；它不是说 DPLR 结构下每个矩阵运算都免费，也不意味着数值条件和实现精度可以忽略。[原论文 §3.1—3.2](https://arxiv.org/abs/2111.00396)说明了朴素对角化为何不稳定，以及 NPLR/DPLR 表示如何接上后续算法。

## 31.4 从生成函数与 resolvent 高效得到有限卷积核

S4 原论文对连续系统采用双线性离散化。采样步长记作 $\Delta$，连续状态矩阵与输入矩阵记作 $A$ 和 $B$，离散递归中的矩阵为：

```math
\bar A=\left(I-\frac{\Delta}{2}A\right)^{-1}
       \left(I+\frac{\Delta}{2}A\right),\qquad
\bar B=\left(I-\frac{\Delta}{2}A\right)^{-1}\Delta B
```

其中 $I$ 是与 $A$ 同阶的单位矩阵。离散后，对长度为 $L$ 的序列，令 $C$ 为状态读出矩阵，状态部分的卷积核第 $j$ 项为 $K_j=\bar C\bar A^j\bar B$，其中 $0\le j<L$；在 S4 的离散约定中 $\bar C=C$。若输出还含有直接输入项 $D u_t$，其中 $D$ 是直接通路系数、$u_t$ 是当前输入，它与状态响应分开处理；第二十九章已解释这项直接通路。

直接逐项求 $\bar A^j$ 要反复处理状态矩阵，无法充分利用 DPLR 结构。S4 改为考虑有限生成函数；令 $z$ 为复数求值点：

```math
\hat K_L(z)=\sum_{j=0}^{L-1}K_jz^j
=\bar C\left(I-\bar A^Lz^L\right)
  \left(I-z\bar A\right)^{-1}\bar B
```

这个等式把有限次矩阵幂组成的多项式改写成矩阵逆，也就是 resolvent。取满足 $z^L=1$ 的 $L$ 个单位根后，截断因子 $I-\bar A^Lz^L$ 成为固定项，可以吸收到读出向量 $\tilde C=\bar C(I-\bar A^L)$ 中。此时要在每个单位根处计算的是 $\tilde C(I-z\bar A)^{-1}\bar B$，而不是逐个生成所有矩阵幂。

DPLR 结构让这个求逆继续化简。双线性离散化把 $\bar A$ 的 resolvent 联系到原始矩阵 $A$ 的有理函数；把 $A=\Lambda-PQ^{*}$ 代入后，Woodbury 恒等式将“对角矩阵加低秩项”的求逆拆成对角矩阵求逆与一个低维修正。对角求逆中的分母具有 $w_j-\lambda_i$ 形式，其中 $\lambda_i$ 是 $\Lambda$ 的第 $i$ 个对角元，$w_j$ 是由求值点变换得到的节点，因此相关乘积归结为 Cauchy 核运算。完成全部单位根处的核值后，用逆快速傅里叶变换恢复 $K_0,\ldots,K_{L-1}$。

整个计算链可以压成三个相连的阶段：

1. **生成函数取代逐项幂计算。** 把长度为 $L$ 的核视为截断多项式，在 $L$ 个单位根处求值；离散系统的 resolvent 提供这些函数值。
2. **DPLR 结构把大矩阵求逆化小。** Woodbury 恒等式负责低秩修正，对角部分归结为 Cauchy 核运算。
3. **逆 FFT 取回时域核。** 将单位根处的函数值变回有限核序列，供整段卷积使用。

原论文将其卷积核生成归约为四次 Cauchy 乘法，并在所讨论的低秩规模与快速 Cauchy 算法假设下给出约 $\widetilde{O}(N+L)$ 的计算量和 $O(N+L)$ 的空间量。这里 $N$ 是状态维度、$L$ 是核长度，$\widetilde{O}$ 隐去对数因子。这是论文算法的渐近结论，不能直接当作整个网络的运行时预测；核生成、核与输入序列的卷积、单步递归是不同计算阶段，实际耗时仍受具体算法、实现和硬件影响。[S4 原论文 §3.3 与 Algorithm 1](https://arxiv.org/abs/2111.00396)给出这一复杂度结论；《[The Annotated S4](https://iclr-blog-track.github.io/2022/03/25/annotated-s4/)》把生成函数、Woodbury 与 Cauchy 核的关系拆成教学步骤，其 JAX/Flax 代码只对应文章当时的教学实现。

## 31.5 卷积与递归是 S4 的两种计算视图

核生成完毕后，可以对完整序列应用因果卷积；同一离散系统也可以每次读入一个输入，并更新状态。若两条路径使用相同参数、步长、初始状态、核截断与边界约定，它们描述同一个固定 LTI 系统。实际计算可能因有限精度、卷积 padding、核长度截断或状态初始化不同而出现数值差异，因此“数学上等价”不等于每份代码逐位相同。

卷积视图暴露了整段输入之间的固定线性关系，适合并行处理完整序列；递归视图则维护一个有限状态，适合逐步处理输入。哪种路径在具体训练或推理配置中更合适，要看对应实现。第三十三章专门讨论 Mamba 的训练、推理与硬件路径，本章不从渐近式推断实际速度。

还要区分单层与整个网络。S4 的核心序列映射是线性的；原论文所述深层网络会在不同特征通道上使用 SSM 映射，通过逐位置线性变换混合通道，并在层间加入非线性，因此整体模型并非一个固定线性卷积。[原论文 §3.4](https://arxiv.org/abs/2111.00396)描述了这一层级关系。

最后，S4 的转移和读出参数在一条序列内固定，不会像 Mamba 那样让状态更新参数随当前输入变化。Mamba 的输入依赖选择性与 selective scan 留给[第三十二章](32-Mamba与Selective-Scan.md)；Mamba 具体硬件效率见[第三十三章](33-Mamba训练推理与硬件效率.md)，能力局限及证据边界见[第三十四章](34-Mamba局限与证据边界.md)，Mamba-2 的状态空间对偶见[第三十五章](35-Mamba-2与State-Space-Duality.md)，SSM 是否替代 Transformer 的比较证据见[第三十六章](36-SSM替代Transformer的证据与争议.md)。S4 原论文报告了若干特定任务与设置的结果；这些结果说明该方法在论文实验中的表现，不足以推出所有任务、模型规模或硬件上的普遍优势。

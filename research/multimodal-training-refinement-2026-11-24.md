# 多模态训练方法与证据边界

更新时间：2026-11-24

适用主题：图文对齐、视觉语言桥接、文档理解、视频与全模态训练配方。

## 可复核事实

### Donut 的 OCR-free 推理与 OCR 伪标签预训练

- **证据等级：A，原始论文。** Donut 以文档图像为输入，自回归生成阅读顺序文本；其预训练数据包括 1,100 万张英文扫描文档，文本标签由 CLOVA OCR API 生成。论文还报告 SynthDoG 用英文、中文、日文、韩文 Wikipedia 文本各生成 50 万份合成文档。
- **边界：** “OCR-free”指模型推理时不依赖外部 OCR 组件，不表示预训练从未使用 OCR 输出。合成文档的覆盖和版式真实性也不能代替目标业务文档的评估。
- **来源：** [Donut 原论文，§2.3](https://arxiv.org/html/2111.15664)。

### Pix2Struct 的预训练消融

- **证据等级：A，原始论文。** Base 配方共 100K 步，先做 30K 步 BooksCorpus 文字阅读 warmup，再做 70K 步 screenshot parsing。保持总步数不变、移除 screenshot parsing 后，DocVQA 验证 ANLS 从完整配方的 67.8 降至 12.2。
- **边界：** 这是 Pix2Struct Base 在论文设置下的预训练组件消融，不是 OCR-free 方法相对 OCR pipeline 的普遍性能保证。
- **来源：** [Pix2Struct 原论文，§5 与表 2](https://arxiv.org/html/2210.03347)。

### LayoutLMv3 的局部对齐目标

- **证据等级：A，原始论文。** 预训练目标由 MLM、MIM、WPA 构成；WPA 根据文字词对应图像 patch 是否被遮蔽预测对齐标签。论文消融中，加入 WPA 对所评测任务均有改善。
- **边界：** 预训练词—patch 对齐不等价于下游字段抽取或业务关系正确；该模型输入仍需要 OCR 文字和位置。
- **来源：** [LayoutLMv3 原论文，§2.2 与消融](https://arxiv.org/html/2204.08387)。

### SigLIP 的批量规模结果

- **证据等级：A，原始论文。** 作者将批量规模扩展到一百万，并报告扩大批量的收益迅速递减、32K 已足以取得大部分收益；sigmoid 损失不要求对全局相似度矩阵做 softmax 归一化。
- **边界：** 32K 是论文实验的经验结论，不是所有数据、模型和硬件的最优批量，也不表示图文相似度计算或分布式通信成本消失。
- **来源：** [SigLIP 原论文](https://arxiv.org/abs/2303.15343)。

### MM1 的预训练数据混合

- **证据等级：A，正式会议论文。** MM1 报告的混合为 45% 交错图文文档、45% 图文配对文档、10% 纯文本；训练 sequence 按这三类数据源的概率采样。
- **边界：** 这是 MM1 的特定数据和消融/配方，不能当作通用最优比例。
- **来源：** [MM1 ECCV 2024 论文 PDF](https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/04237.pdf)。

### 公开的阶段化多模态训练配方

- **证据等级：A，模型技术报告。** Qwen3-VL 报告 S0 仅训练 merger（67B token、8,192 长度），S1 全参数训练约 1T/8,192，S2 约 1T/32,768，S3 100B/262,144；该报告说明阶段目标是从桥接训练逐步扩展到长上下文。
- **证据等级：A，模型技术报告。** Qwen3.5-Omni 报告 S1 在固定 LLM 下先训练视觉/音频 adapter，再训练对应 encoder；S2 的总预算称为约 4T，各模态分项按原文相加为 4.29T；S3 将最大序列长度从 32,768 提到 262,144，并增加长音频、长视频数据占比。正文保留“约 4T”及各分项，指出两种口径的差异，不把分项自行改写成精确总量。
- **证据等级：A，模型技术报告。** Qwen3.5-Omni 的跨条件 on-policy distillation 将文本条件查询生成的回答作为对应音频条件查询的目标；报告按该任务描述回答级目标，不足以推出通用的全词表 logits 蒸馏公式。
- **边界：** 以上是单个模型系列公开披露的训练阶段、长度和 token 配置，不构成其他模型或任务的默认 recipe。
- **来源：** [Qwen3-VL Technical Report v2](https://arxiv.org/html/2511.21631v2)；[Qwen3.5-Omni Technical Report v2](https://arxiv.org/html/2604.15804v2)。

### JEST 的效率数字

- **证据等级：A，原始论文。** JEST 通过联合选择训练 batch，并使用预训练参考模型把筛选引向较小的精选数据分布；论文摘要报告其设置下最多减少约 13 倍迭代、约 10 倍计算。
- **边界：** 这是论文所用模型、数据和评测协议下的最高报告值；实际使用还需核算 super-batch 打分成本及筛选造成的长尾覆盖变化。
- **来源：** [JEST 原论文](https://arxiv.org/abs/2406.17711)。

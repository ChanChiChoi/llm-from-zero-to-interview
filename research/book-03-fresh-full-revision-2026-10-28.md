## 书册契约

- **定位**：给已经具备基础 Python/机器学习知识的读者一条可操作的大模型项目训练路径，连接小模型实现、微调、推理应用、评估、多模态练习和作品集交付。
- **读者完成后的能力**：能从数据和张量约定开始构造一个教学规模实验；能说明关键中间量并手算核心步骤；能用真实运行证据区分代码通过、局部指标改善和目标任务有效；能把实验做成可复核交付物。
- **边界**：第三册是项目教材，不取代第五册完整训练工程、第六册生产部署、第七册评估科学、第十五册多模态/生成模型专题、第十七册 Agent 方法、第二十册 Agent Runtime、第二十二册工具协议以及第十二册求职策略。
- **书系交接**：第一、二册提供原理；第三册完成教学规模项目与证据；相邻专题书承担大规模、生产级和深入算法分析。

## 当前简介与目录审视

当前简介正确承诺了“实现—训练适配—推理应用—评估—作品集”路径，也明确将多模态限定为选读实践，避免与第十五册争夺专题覆盖。当前目录前八章把 RAG 检索回答和 Agent 工具动作合在一章；正文却有两条可独立完成的工作流：RAG 建立外部证据链，Agent 通过受控执行器产生系统副作用。两者共享一个企业政策助手贯通案例，但可以按先证据后动作的依赖顺序分成相邻章节。

## 册级结构决定

将第三册由 14 章调整为 16 章，核心主线由八章变为十章：

1. PyTorch 基础 → Transformer 组件 → 从零训练小 GPT；
2. SFT/LoRA/QLoRA → DPO 偏好实战；
3. 推理服务 → RAG 证据回答 → Agent 受控动作 → 离线评估与训练排障 → Agent 轨迹、线上实验与灰度；
4. 多模态选读仍为图文、Diffusion、语音、多模态交付四章；
5. 作品集证据 → 技术表达与系统设计。

本轮结构变动有两处：第一，旧第七章拆为第七章“RAG 项目实战”和新第八章“Agent 项目实战”；RAG 结束于能回到来源、可评估的回答，Agent 使用第七章检索能力作为可调用组件，重点讲工具状态、权限和动作副作用。第二，旧评估章中离线 benchmark、污染/事实检查、训练排障、能力回归和人工评价留在第九章；Agent trace 与线上 A/B、灰度回退组成新第十章。这样把离线诊断和线上发布按系统生命周期分开，保留 trace → 固定回归集 → 随机化线上实验的连接，也避免第九章同时承担离线方法和线上发布流程。旧第九至十四章顺延为第十一至十六章。

不新增独立的多模态生成、视频、语音大模型或具身/世界模型章节：这些主题超出第三册教学项目的边界，且已有第十五册专题。偏好训练不增加 PPO/GRPO 全流程章节：由第五册负责完整训练工程；第三册在 DPO 实操中说明与 RLHF/PPO 的关系和版本边界。

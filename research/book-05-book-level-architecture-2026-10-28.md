## book_contract

- **读者与前置：** 会使用 Python，理解反向传播、交叉熵和 Transformer 基本数据流；不要求已有多卡训练经验。数学与 PyTorch 前置可分别接第十三、十四册。
- **能力目标：** 能把目标、数据、tokenizer、模型、优化、并行、评估、checkpoint 与事故恢复组织为可复核的训练计划；能按训练目标拆分预算，解释方法收益和失败边界。
- **范围：** 从训练项目定义到训练后评估和恢复；含预训练、后训练、可验证奖励、多模态与资源规划。
- **不承担：** 不替代第九册的数据治理深挖、第十五册多模态方法、第十六册推理模型、第十七册 Agent 训练、第二十一册架构演进；完整评估方法、推理 Serving 和 AI Infra 分别交给第七册、第六/二十四册和第二十三册。
- **书册类型与交接：** 训练工程主线教材，末尾以系统设计和案例收束；理论进入第二册，实践进入第三册，领域专题进入对应专题册。

## discovery_scan

检索日期：2026-10-28。检索问题包括：继续预训练的数据混合是否存在任务间取舍；词表升级能否保留既有 checkpoint 能力；离线示范和在线 RL 如何比较；当前公开分布式训练实现是否改变本册的章节边界。阅读了论文摘要、方法/评估/限制部分及官方框架文档；来源发现入口不作为事实证据。

| 候选 | 证据与读者价值 | 去向与决定 |
| --- | --- | --- |
| 多语言继续预训练的数据混合 | [COLM 2025 论文 v2](https://arxiv.org/abs/2504.04152)比较 3 个多语言底模、30 多种语言和 36 组配置；双语 CPT 在论文设置中提高分类但可能导致生成语言混杂，代码数据也呈现任务取舍。 | 并入第 2 章动态 mixture，不增章；正文要求分类、生成一致性和旧语言回归分开评估。结果不外推为固定比例。 |
| 原 BPE 词表的延续扩展 | [In-Place Tokenizer Expansion](https://arxiv.org/html/2607.15232)披露模型生产方继续原 merge table、保留映射、初始化新 embedding、分阶段训练的路线；LFM2 结果同时有 400B token CPT 成本和旧支持语言解码退化。 | 并入第 3 章词表扩展；将每字符速度写成论文按压缩率和参考设备吞吐合成的估计，并保留单模型家族边界。 |
| 新 token embedding 初始化是否应只看 step-zero loss | [Beyond Initialization Loss](https://arxiv.org/abs/2608.03494)在单一 Hindi/Nemotron 设置中比较 20 多种方法，报告短程 CPT probe 对该设置更有预测力。 | 第 3 章已有该研究入口，本轮保留并与上条区分：前者研究初始化策略，后者研究生产方控制下的 tokenizer 构造与全链适配；两者均不构成通用 recipe。 |
| 离线 SFT 与在线 RL 的共同视角 | [Towards a Unified View of LLM Post-Training v2](https://arxiv.org/html/2509.04419)将 estimator 拆成稳定掩码、参考策略、优势估计和似然梯度，并提出 HPT；实验主要是数学推理和分布外数学套件。 | 作为第 11 章和 `PAPERS.md` 的延伸阅读，不增章、不称为通用训练算法；本册现有 SFT、PPO/GRPO、RLVR 和 OPD 专章已覆盖读者主线。 |
| 分布式训练实现边界 | [PyTorch FSDP2](https://docs.pytorch.org/docs/main/distributed.fsdp.fully_shard.html)当前页面说明 per-parameter `DTensor`、前/后向 all-gather/reshard 和分布式 checkpoint 接口；[Megatron Core User Guide](https://docs.nvidia.com/megatron-core/developer-guide/latest/user-guide/index.html)覆盖 DP/TP/PP/CP/EP、MoE、optimizer 与 checkpoint。 | 不增章。第 7 章已有按 PyTorch 2.14 固定版本的 FSDP1/FSDP2、通信和 checkpoint 讨论；动态 `main/latest` 页面作为部署核对入口，不能替代固定版本或目标拓扑实测。 |

以上候选未改变第五册的核心读者问题、主线或边界，因此不需要拆并章节。外部扫描只界定了已识别候选，不代表穷尽全部训练研究。

- **章节级证据记录：** 第 1、2、4—18 章对应 2026-10-26 `research/training-*-depth-review` 记录；本次主题扫描新增第 2、3、11 章落点。第 3 章的词表扩展补证见 [`training-tokenizer-expansion-depth-review-2026-10-28.md`](training-tokenizer-expansion-depth-review-2026-10-28.md)。

## Research scan

- 经典基础核对 Influence Functions、Data Shapley、Jia 等的高效近似、TracIn、Dataset Cartography、DoReMi 和 LESS。它们分别支持局部扰动、子集边际贡献、近似、训练轨迹、训练动态、混合比例和目标调优数据选择的背景；并不证明精确全量 LLM 预训练归因。
- 扩展到模型级归因和规模化估值：TRAK 使用随机投影 after-kernel；DataInf 面向 LoRA 等参数高效微调的 influence 近似；LoGra 使用梯度投影，作者报告在 Llama-3-8B-Instruct 与 1B-token 实验中相对可运行基线最高 6,500 倍吞吐、5 倍显存下降。以上结果均绑定方法实现、模型、任务和基线。
- 预训练数据选择方面，PreSelect 使用 fastText scorer，作者报告 1B/3B 设置下 30B 选择 token 超过其 300B vanilla 对照；BLISS 使用多步小型 proxy 更新训练双层 score model，在 410M/1B/2.8B Pythia 和 0.5B LLaMA 设定中评估，作者报告 1B 配置的 1.7 倍达到同等表现速度；OPUS 在优化器诱导更新空间做动态选择，作者报告额外计算开销 4.7%。三种方法的模型、数据、阶段、基线和预算不可拼成统一排行榜。
- 纳入两类 2026 年新方向：Convex Dataset Valuation 使用梯度空间的 kernel mean matching 联合考虑目标对齐和数据冗余，面向受预算限制的 LLM 后训练数据集选择；Mechanistic Data Attribution 在 Pythia 系列将 influence 线索用于可解释单元的训练来源追踪，并通过定向增删高影响样本与随机干预比较。后者是指定机制单元的干预证据，不是总体能力的通用来源分解。
- 纳入 RISE 的 2026 arXiv 预印本：输出 readout sketch 将 attribution 与 prospective valuation 分成回溯检索和前瞻评分，并报告 OLMo/Pythia 上索引存储最高 112 倍压缩及扩展至 32B。正文明确其预印本身份、假设和目标任务的复核限制。
- 所有新近论文均以作者摘要/正式 proceedings 或 arXiv 公开页面核对。候选结果只说明相应模型和实验设置中的可行性；本章不将其倍数写成行业保证、生产收益或统一排名。

## Example status

- 二维 Influence 手算输入为 $g_i=(1,0)^\top$、$g_*=(1,2)^\top$、$H=\begin{bmatrix}2&0\\0&1\end{bmatrix}$，得 $H^{-1}g_i=(0.5,0)^\top$、$I_{\mathrm{up}}=-0.5$；解释限定为局部二阶近似的 loss 单位。
- `math_verified` 的加权变化为 `0.35×0.080 + 0.25×0.010 + 0.20×0 + 0.20×0.015 = 0.0335`；代入质量、覆盖、cosine、风险和归一化成本得到 `0.1808`，900 有效 token 换算为每千 token `0.2009`。
- Shapley 玩具效用定义了 M/C/T 三个二元参与者、M+C 的 `+0.08` 协同和 T 先于 M 的 `-0.05` 冲突。六种顺序的边际平均分别为 `0.365/0.260/-0.085`，总和 `0.540` 等于全体效用。
- 固定预算例在 3,200 token 下选数学、代码、安全和中文领域数据，耗用 3,120 token；数学、代码、安全和通用指标分别变化 `0.085/0.080/0.065/0.070`，proxy 合计 `0.5897`。以上均为固定教学合成数值，不是实际训练测量、价格或选择策略基准。

# AI Research Agent 与自动化研究评估：来源证据

记录日期：2026-11-03；AIRS-Bench 版本复核：2026-11-04
资料时间窗：2024—2026  
范围：AI research agent、机器学习研究复现与自动化科学发现的原始论文。以下只保存来源支持的知识事实、版本和证据边界。

## 1. RE-Bench：研究工程任务与人类时间预算对照

- **来源与版本：** [RE-Bench: Evaluating frontier AI R&D capabilities of language model agents against human experts](https://arxiv.org/abs/2411.15114)，arXiv:2411.15114，2024-11-20 页面所列版本；核阅摘要、引言、结果概述及 §6.3—6.4 的限制讨论。
- **来源支持的事实：** 基准包含 7 个开放式机器学习研究工程环境，并收集 61 名人类专家的 71 次、每次 8 小时尝试。论文报告，在总预算为每个环境 2 小时的比较中，最佳 AI agent 得分约为人类专家的 4 倍；增加预算后人类收益更快，在 32 小时总预算下人类最佳得分约为最佳 agent 的 2 倍。
- **证据等级：** 研究基准与受控人机比较；结果仅适用于论文所选环境、被测模型/agent、时间预算、计算资源和评分函数。
- **边界：** 作者指出，环境需可在数小时内产生可计分进展且较易构造和评估，因而不代表真实研究中模糊目标、缓慢反馈或长周期工作的全部情况；环境数较少导致 agent 结果有较大方差，任务也未覆盖许多前沿研究活动。该比较测量特定研究工程任务，不等于完整研究岗位自动化评估。

## 2. PaperBench：从论文独立实现并复现经验结果

- **来源与版本：** [PaperBench: Evaluating AI’s Ability to Replicate AI Research](https://arxiv.org/abs/2504.01848)，arXiv:2504.01848，2025-04-02；核阅摘要、§§1—2、§5 的实验设置和人类基线。
- **来源支持的事实：** 任务取自 20 篇 ICML 2024 Spotlight/Oral 论文；agent 需要理解论文、从头建立代码库并运行实验，不能查看原作者代码。作者为每篇论文编制并与原论文作者共同核对分层 rubric，包含 8,316 个可独立评分的结果项；提交物在新的执行环境中运行。论文另报告了 JudgeEval，用于比较自动评分与人工标注。
- **证据等级：** 论文复现基准与初始模型基线。原实验中的模型和 scaffold 是 2025 年配置，不代表 2026 年模型能力；人类比较只覆盖少量论文子集。
- **边界：** 该基准评估所选论文的经验结果复现及其工具/执行过程，不单独测量开放式选题、理论创新或整个研究周期。论文报告不同 agent 对提示和 scaffold 敏感；人类基线在小型子集上执行，不能由一个平均分推导普遍的人机研究能力差距。

## 3. ScienceAgentBench：数据驱动科学任务中的代码生成

- **来源与版本：** [ScienceAgentBench: Toward Rigorous Assessment of Language Agents for Data-Driven Scientific Discovery](https://arxiv.org/abs/2410.05080)，arXiv:2410.05080；论文发表于 ICLR 2025。核阅摘要、任务定义、实验结果及 Appendix A “Limitations”。
- **来源支持的事实：** 基准从 44 篇同行评审论文中整理 102 个任务，涉及生物信息学、计算化学、地理信息科学、心理与认知神经科学四个领域，并由九名相关领域专家参与验证。任务要求 agent 在给定自然语言指令和数据后生成可独立执行的 Python 程序。论文报告，在每个任务最多三次尝试的设置下，最佳被测 agent 在提供专家知识时解决率为 34.3%。
- **证据等级：** 同行评审会议论文中的跨领域任务基准；报告数字属于论文指定模型、agent framework、数据和重复次数。
- **边界：** 作者明确把任务收窄为数据驱动发现中的代码生成，不覆盖文献综述、提出新问题或完整实验规划等全部研究能力。论文指出，成功执行、程序质量和成本等需分别检查；不能把任务解决率解释成科学发现自动化比例。

## 4. AIRS-Bench：无基线代码的机器学习研究流程任务

- **来源与版本：** [AIRS-Bench: a Suite of Tasks for Frontier AI Research Science Agents](https://arxiv.org/abs/2602.06855v3)，arXiv:2602.06855v3；arXiv 版本记录标记 v3 于 2026-02-16 提交。2026-11-04 复核官方版本页、HTML 正文、方法与实验 §§3—6、任务检查 §6.2 和结论。
- **来源支持的事实：** 基准包含 20 个来自机器学习研究的任务，覆盖七类任务和多个领域；不提供基线代码，agent 需经历问题/方案生成、实验分析和迭代改进。论文比较不同基础模型与顺序/并行 scaffold，结果显示性能高度依赖模型、scaffold 和任务。作者总结有四个任务至少在部分 agent run/seed 中超过所列 human-SOTA 数值，另有十六个任务未匹配；正文逐项分析的超越案例来自指定 Agent 配置，不能理解为每个任务都稳定超过人类结果。
- **版本核对说明：** 当前 arXiv 版本元数据显示 v3（2026-02-16），但 v3 HTML 正文另出现内部日期 “August 24, 2026”。两者不一致；本记录以 arXiv 官方版本历史标注为版本锚点，不据正文内部日期推断存在更新版本。
- **结果范围：** 这些超越是论文指定 task score、数据、模型、scaffold 和运行设置下的结果；所列 human-SOTA 并非这项实验中的等时间预算人类参与者对照。四个 task-level 超越不能外推为总体研究能力或完整流程自动化率，基准整体也未饱和。
- **证据等级：** 2026 年预印本中的基准和实验；任务、模型、scaffold、预算及归一化口径均会影响解释。
- **边界：** 结果不构成对长期、开放式研究工作的总体人类基线。论文讨论数据污染、环境标准化、实验成本、任务 onboarding 和长 agent trace 的问题；特定 benchmark 上的 state-of-the-art 分数不直接代表新知识质量或研究过程可靠性。

## 5. The AI Scientist：端到端研究生成的受限示例

- **来源与版本：** [Towards end-to-end automation of AI research](https://doi.org/10.1038/s41586-026-10265-5)，Nature 651, 914–919 (2026)，2026-03-25 版本记录；核阅 Nature 版本记录及牛津大学机构库托管的论文全文和限制部分。
- **来源支持的事实：** 系统把研究方向/假设提出、代码编写、实验执行、结果分析、论文写作和自动评阅连接成流程。论文报告三篇 AI 生成稿中有一篇在 ICLR 2025 的 ICBINB workshop 审稿中得到 6、7、6 的评审分数，超过该 workshop 的平均录用阈值；按照预先约定的流程，该稿因 AI 生成而撤回。另两篇未达到门槛。作者团队认为这三篇均未达到 ICLR 主会标准。
- **证据等级：** 同行评审期刊中的系统案例和研究者报告；该案例展示了受限 workshop 场景中的部分可行性。
- **边界：** 一篇稿件越过某 workshop 的平均评分阈值，不等于论文已被正式接收，也不证明系统能持续产出高质量研究。作者列出的失效包括问题过浅、实现错误、实验执行错误、方法学不严谨、重复图表和错误引用；结果不能外推到主会论文、其他科学领域或无人监督的研究流程。

## 跨来源未决边界

- 不同基准测量的任务不同：短时研究工程、从论文复现、领域数据代码生成、机器学习任务优化和端到端论文生成不能用一个总分互相替代。
- agent 得分受到模型版本、scaffold、工具、时间/算力预算、提示方式、数据污染控制、评分者和任务集影响；跨论文比较前须重新对齐这些条件。
- “超过 human SOTA”“达到人类评审一致性”或“论文进入 workshop 评审门槛”分别是特定分数/评分/流程中的结果，不能单独证明新颖性、科学正确性、重复可得性或独立发现能力。
- 目前来源仍不足以给出跨学科、长周期、资源等价的总体研究自动化能力结论；需区分单项辅助、研究工程、经验复现和端到端研究。

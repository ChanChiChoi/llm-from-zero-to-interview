## 已能确认的机制

普通残差把前面的变换输出以单位权重累加。AttnRes 则在深度方向对之前的表示做 softmax 加权。这里的“注意力”选择的是不同层或块的表示，不是在序列中重新选择 token；正式章节需要首先用两个坐标轴把这两类注意力分开。

仓库给出的伪代码将候选表示堆叠成 `[N+1, B, T, D]`，归一化后作为 key，以每层可学习的伪查询向量计算分数，再沿第 0 维做 softmax，使用未归一化的候选表示作为 value 求加权和。查询参数本身不依赖输入，但 key 依赖输入，因此权重仍依赖输入。不能把“固定的可学习查询”误解为“固定聚合权重”。

Block AttnRes 在块内部继续累加，只在块级表示之间选择，以降低存储与通信开销。官方将完整形式的表示存储记为 O(Ld)，分块形式记为 O(Nd)；这省略了批量和序列维度，也不是整个训练系统的总显存复杂度。

## 实验结论的限定

仓库称 Block AttnRes 在其 scaling 实验中达到使用 1.25 倍计算量的基线损失；不能写成所有模型和任务都节省 20% 成本，更不能把该倍数当作 Kimi K3 的独立消融结果。展示的下游实验使用 Kimi Linear 48B、激活 3B、1.4T 训练 token，与 K3 不是同一实验对象。

## 正文章节设计

1. 用不断叠加修改意见的草稿举例，说明残差累加与选择历史表示的区别，并解释类比边界。
2. 从两层残差逐步展开到多层，定义每个中间表示；再引入深度方向的加权和。
3. 手算三个二维表示的归一化、打分和 softmax，展示改变查询方向如何改变选中的信息。
4. 编写自包含数值例子，再给 PyTorch 模块；验证零查询时均匀平均、权重和为 1、输入变化影响权重以及梯度可传播。
5. 单独讲 Block AttnRes 的完成块与当前部分和，避免只贴伪代码而不解释更新顺序。
6. 分析存储、通信、初始化、数值稳定性与实验外推限制；以消融实验设计作为专家层练习。

## 论文源码核验补充

已从 arXiv e-print 源码读取 `3-attnres.tex` 与 `4-infra.tex`。论文把残差流和序列建模作“时间—深度”类比：深度方向的表示也可以像 Transformer 沿时间维访问历史 token 一样做选择性聚合。

Full AttnRes 的定义是：

```math
h_l=\sum_{i=0}^{l-1}\alpha_{i\to l}v_i,
```

其中 `v_0` 是 token embedding，其他 `v_i` 是前层变换输出；权重来自层专属可学习伪查询 `w_l` 与 `RMSNorm(k_i)` 的内积后做 softmax。论文明确指出，查询参数与该层前向计算解耦，因此同一块内的查询可以批量计算。

Block AttnRes 将层分为 `N` 个块，每块内部把层输出求和为块表示；层输入在块间对 token embedding 和已完成块表示做注意力，块内后续层还可访问当前块的部分和。论文给出 `N=L` 恢复 Full AttnRes、`N=1` 退化为标准残差（embedding 单独保留）的连续谱解释。

源码还明确区分两种开销：普通小规模训练中激活本来就要为反向传播保存；大规模训练的主要问题转为流水线跨 stage 的通信。跨 stage caching 只传递新增块，减少重复传输。推理采用两阶段策略：先批量做块间注意力，再顺序处理块内部分和，并用 online softmax 合并两组统计量。这里的合并公式依赖 max 与 log-sum-exp，正式实现要单独验证数值稳定性。

论文给出其自身实验设置和工程测量：约 8 个块在展示实验中保留大部分收益；流水线训练端到端开销报告低于 4%，推理延迟报告低于 2%。这些是论文实验语境，不应外推为所有硬件和模型的保证。论文还给出 128K 示例中块表示显存以及序列分片后的估算，正式章节必须标注维度、精度和并行设备假设。

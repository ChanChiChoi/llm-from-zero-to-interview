# 第一册简介：大模型工程主线——从入门到项目判断

## 这本书要带你完成什么

第一次接触大模型工程，常见的卡点不是记不住模型名字，而是问题一落到项目里就不知道从哪里判断：模型回答错了，是数据、训练目标、检索、解码还是评估出了问题？多加一个模型或换成更低精度，究竟能省多少资源，又会影响什么？资深工程师追问“你怎么知道”，需要拿出什么证据？

本书沿着一条可追踪的工作主线回答这些问题：输入怎样变成 token，Transformer 怎样产生预测，训练信号怎样改变参数和回答行为，服务怎样生成结果，团队又怎样检查质量、成本、延迟和风险。读者不必先有大模型经验；每个主题都从它解决的问题讲起，再进入关键机制、工程决策和可验证的失败边界。

全书用一个**假设性的企业知识助手**串联主要工程问题：员工询问流程或设备问题，系统从经过整理的资料中找证据，回答时说明依据；资料不够时，允许它澄清、查询或说明无法确认。示例资料和指标都是教学构造，不代表真实企业部署。这个场景帮助读者把算法和系统部件放回同一个任务里，不要求读者使用真实公司数据或购买 GPU。

## 适合谁读，需要哪些基础

本书面向刚开始系统学习大模型的读者，也适合会调用模型、但还不能解释训练和服务决策的开发者。无需预先掌握 Transformer、SFT、分布式训练或多模态模型。

建议能读写基础 Python：变量、函数、列表/字典和简单循环。数学上只需能处理比例、求和、概率和简单函数；遇到向量、矩阵、梯度或概率符号时，正文会说明它们在当前计算里代表什么。若线性代数、微积分或 PyTorch 完全陌生，可按需要转到第十三册或第十四册补课，再回到本书对应讲次。

全书代码与数字例子用于观察机制和排查思路，不要求训练大模型，也不声称一个玩具脚本就是生产系统。读者可以用纸笔、CPU 和合成数据完成大多数推演；涉及多卡训练、线上压测或大规模数据的内容，会说明所需资源以及小规模读者能够验证到哪里。

## 读完后应能做什么

1. 从一条输入和目标 token 追到 loss、梯度与一次参数更新，并解释训练结果为什么不等同于事实正确。
2. 追踪 Transformer 的张量形状与信息流，定位 tokenizer、mask、attention、缓存或位置处理可能造成的问题。
3. 面对一个具体任务，比较提示、检索、SFT、偏好优化或量化等候选方案，先说清数据、成本、约束和验收标准。
4. 设计小规模可复核的对照：固定哪些条件、记录哪些指标、如何按错误切片定位根因，何时回退或继续实验。
5. 在面试追问中讲清一个选择的机制、适用条件、失败方式、替代方案和证据，而不是只报方法名或背优缺点。

这些是通过本书学习和练习可以建立的知识与表达能力，不等于生产项目经历，也不能保证通过某个岗位面试。面试范围取决于团队和职位；若要声称做过项目，仍需自己完成可复现的实现或实验。

## 五部分如何连接成一项工作

| 部分 | 核心问题 | 用贯穿项目形成的产物 |
| --- | --- | --- |
| 基础与语言模型 | 模型在预测什么，预测差距怎样改变参数？ | 写清任务目标、目标 token、loss 与训练前后要测的行为 |
| Transformer 核心 | 输入怎样经过网络形成下一 token 分布？ | 画出数据流与张量形状，能检查 mask、位置和缓存边界 |
| 训练、对齐与推理 | 怎样得到助手行为，又怎样在服务约束下生成回答？ | 比较训练/检索候选，列出资源账本、服务指标和回归方案 |
| 多模态基础 | 图片、语音和视频加入后，哪些接口与风险发生变化？ | 为截图或录音场景确定表示、证据与延迟检查点 |
| 综合复习与技术表达 | 怎样诊断陌生问题并向工程师说明判断？ | 完成一份有基线、反事实、失败分析、成本和回退条件的项目复盘 |

文本主线从基本预测开始，逐步经过表示、预训练、后训练、推理和验收。多模态部分复用同样的判断方式，但只建立系统地图和代表机制；大规模训练实现、生产部署、完整安全治理与各模态专项方案由相应专题书接手。

## 建议怎么读

第一遍按目录顺序建立全链路。每讲读完都试着回答四个问题：它解决什么问题？数据或状态如何变化？工程师会观察什么？结果不好时先做哪个区分实验？先用自己的话讲通，再回看公式、代码和论文。

不要把“读完 38 讲”当成面试准备完成。建议同时维护一页贯穿项目档案：需求和失败定义、数据来源与切分、方案对比、评估集、资源估算、失败样本和回退条件。模拟交流时，让同伴或自己连续追问“为什么选它、怎么验证、代价是什么、什么结果会让你换方案”。答案以机制和证据为核心，不以背诵固定模板为目标。

## 与书系其他册的关系

第二册补充理论与研究深度，第三册负责把机制写成代码并完成实战项目，第四册用于概念速查。第五至第二十四册承担训练、部署、评估、安全、数据、多模态、Agent 和 AI Infra 等专题深入。第一册帮助读者把专题放回大模型工作链路，也明确何时需要继续查阅专题或官方文档。

# 第一册简介：大模型算法岗核心主线

## 本书在书系中的位置

第一册是整套书系的主线入口。它只承担一项核心任务：带读者走完一次大模型工作的基本闭环——文本如何变成 token，模型如何据此预测下一个 token，训练如何改变模型参数，后训练如何改变回答行为，推理如何生成回答，以及怎样验证回答是否可靠。

本书建立共同语言和整体心智模型，不承担百科全收、前沿研究深挖或生产系统实战的任务。读者完成本书后，应能沿着“输入—表示—计算—学习—生成—验证”解释主要机制，能复核一个小型示例，也知道遇到更深问题时该转向哪一本专题书。

这项定位让第一册与其他书各有分工：第二册负责进阶理论和研究深度；第三册负责把机制变成代码和项目；第四册负责概念速查；第五至第二十四册分别深入训练、部署、评估、安全、数据、研究、多模态、Agent、AI Infra 等专题。第一册为这些路径提供主干和入口，不代替专题书。

## 适合读者与前置知识

适合有基本机器学习或深度学习背景、但还没有形成大模型整体图景的读者。建议熟悉向量、矩阵乘法、概率和梯度的基本含义；数学细节或 PyTorch 操作不熟悉时，可分别借助第十三册和第十四册补齐，不需要在第一册里展开成另一套基础课程。

## 学完后应具备的能力

1. 能从一段输入文本出发，说明 token ID、向量表示、位置、Transformer 计算和下一 token 概率之间的关系。
2. 能用一个小例子解释交叉熵如何形成训练信号，梯度和优化器如何更新参数。
3. 能区分预训练、指令微调、偏好优化和推理各自改变了什么，并说明它们如何连接成一个可用助手。
4. 能画出最小的生成与验证路径，指出质量、延迟、显存和安全上的主要约束，以及需要什么证据才能判断问题。
5. 能把一个陌生问题放回这条主线，给出下一步检查或专题阅读入口，而不是只复述术语。

## 五部分的阅读递进

| 部分 | 核心问题 | 本部分结束时的产物 |
| --- | --- | --- |
| 基础与语言模型 | 模型在预测什么，预测误差怎样变成参数更新？ | 从目标 token 到 loss、梯度和一次更新的解释 |
| Transformer 核心 | 输入 token 怎样经过网络，形成下一 token 分布？ | 一次小型 GPT 前向计算的数据流和 shape 路径 |
| 训练、对齐与推理 | 基础模型怎样变成助手，回答怎样生成并接受检查？ | 从数据到回答的训练/服务/验证链路图 |
| 多模态基础 | 图像、语音和视频接入后，主线中的输入与输出发生了什么变化？ | 模态表示和任务差异的概览，及专题学习入口 |
| 综合复习与技术表达 | 如何用这套主线拆解陌生问题、设计验证并说明判断依据？ | 一份可复核的问题分析与技术表达方案 |

“基础与语言模型”部分从 next-token 目标出发，依次建立概率、损失、梯度、优化器和学习率调度之间的联系，为下一部分从 token 表示推到 Transformer 输出分布提供训练目标与参数更新的背景。

第三部分按“预训练与规模化—后训练与对齐—推理、部署与评估—研究与综合实验”分成四个阅读单元，避免把模型训练、回答行为和线上服务压在同一个超长文件里。第四部分先讲多模态理解与表示，再讲生成与交互；它们是同一主线在不同模态上的分支，不是要求读者在本册掌握六套完整技术栈。讲次编号继续用于题库和配套资料定位，目录中的文件边界负责提示阅读任务和章节交接。

## 阅读建议

第一遍按目录顺序阅读，并持续追问三个问题：当前讲解在主线的哪一步？它接上了前面哪个结果？它为下一步提供了什么条件？每完成一部分，试着不看正文画出本部分的数据流或决策路径，并用一个例子说明发生了什么。

不要把“读完 38 讲”当作学习完成。至少要能从一个 token 序列走到一次参数更新，再从一个输入走到生成结果和验证动作。第一次遇到细节时先掌握机制和边界；需要推导、代码、研究证据或生产设计时，再沿目录中的专题入口深入。多模态部分用于扩展主线的视野，不要求读者在第一册里掌握每种模态的完整技术栈。

## 与其他书的关系

第一册回答“大模型从输入到输出怎样连成一条主线”。第二册沿核心主题增加研究和理论深度，第三册通过可运行代码和项目训练实现能力，第四册用于快速查概念。训练、部署、评估、安全、多模态、Agent、系统设计等专题书则分别接手本册留下的深入问题。遇到专题内容时，本书负责说明它在主线中的位置，专题书负责把它讲透。

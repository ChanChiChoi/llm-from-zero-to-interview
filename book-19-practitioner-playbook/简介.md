# 第十九册简介：资深大模型工程师实战宝典

## 本书定位

这是一册面向真实工程问题的排障与决策手册。它从异常现象和现场证据出发，带读者沿数据、训练、评估、推理服务、RAG、Agent、多模态和安全治理等链路定位问题，再把结论整理成可复核的实验、事故记录和工程决策。它不按概念顺序重讲一遍模型知识，也不把某个团队的经验写成到处适用的固定阈值。

## 读者起点

读者应已理解基础机器学习和大模型的输入、训练、生成过程，能够阅读常见训练日志、请求记录和系统指标。做过项目会更容易对照现场；没有生产经验的读者也可以从书中的合成案例开始，先练习区分观察事实、待验证假设和已经确认的根因。本书不要求读者先读完第十八册、第二十册或特定框架手册。

## 学完以后

读者应能把一次失败还原成有范围、有时间线、有基线的证据链；沿数据、tokenizer、训练、分布式、后训练、评估和服务链路找出第一处分歧；判断 RAG、Agent、多模态和安全控制中哪个环节需要先修；并说明修复怎样验证、风险怎样控制、哪些结论仍未知。做项目负责人或参加技术评审时，还能把实验、事故、取舍和下一步行动讲成团队可以接手的记录。

## 怎样读

第 1 章建立通用排障方法。之后按当前问题进入第 2—12 章对应的工程领域；第 13—15 章帮助项目负责人组织协作、复盘和传达决策。目录提供训练、线上应用和项目协作等入口，不要求把全书当成一门必须逐章顺读的课程。

## 与其他书的关系

第三册带读者实现和交付项目；第五至第九册分别深入训练、部署、评估、安全和数据工程；第十七册讲 Agent 的行为与工具调用，第十八册讲产品价值和运营决策，第二十册讲 Agent Runtime/Harness，第二十二册讲工具协议生态。本书聚焦这些系统在实际工作中怎样失效、如何排查以及怎样把判断交接给团队，必要的机制和实现细节会回链专题书，不重复整套课程。

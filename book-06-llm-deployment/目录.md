# 第六册：大模型部署与推理工程

本册研究如何把已训练模型或受管 API 变成满足质量、延迟、吞吐、容量、可靠性、安全和成本要求的服务。核心路径是第 1—14 章；第 15—18 章按低精度部署和托管 API 预算两个专题分支阅读。相邻书册的分工及读者能力目标见[本册简介](简介.md)。

## 核心阅读路径：从 workload 到生产服务

建议按目录顺序完成第 1—14 章：

1. **定义问题和测量对象（第 1—4 章）**：先描述 workload、SLO 和请求链路，再学习推理阶段、性能测量、KV 状态与生成控制。
2. **选择 runtime 并组织执行（第 5—8 章）**：在相同 workload 下比较引擎，继而设计批处理/调度、压缩方案和多 GPU 拓扑。
3. **接入实际应用请求（第 9—10 章）**：分别处理 RAG/Agent 工具链和多模态请求的服务边界、状态、容量与发布。
4. **运营、优化并综合（第 11—14 章）**：建立监控、质量、安全和成本闭环，最后完成系统设计与故障复盘。

## 章节目录与职责

### 核心路径

1. [部署总览：从模型 artifact 到可运营服务](chapters/01-部署总览.md)：从 workload 和 SLO 建立部署决策地图。
2. [推理基础：一个 token 如何生成，以及性能数字从哪里来](chapters/02-推理基础.md)：从首 token 阶段边界和指标口径起步，用 roofline、请求 trace 与压测推导容量约束。
3. [KV Cache 与内存管理：把每个 token 的状态放在哪里](chapters/03-kv-cache与内存管理.md)：估算活跃 cache 与可复用前缀工作集容量，并设计分页、复用和淘汰。
4. [解码策略与生成控制：从 logits 到可交付输出](chapters/04-解码策略与生成控制.md)：理解请求级生成参数及其质量、延迟和成本取舍。
5. [推理引擎：把模型前向变成可运营的执行系统](chapters/05-推理引擎.md)：按 workload、协议、硬件和运行要求比较 runtime。
6. [批处理与调度](chapters/06-批处理与调度.md)：设计请求排队、continuous batching、长短请求隔离、token 预算与阶段调度。
7. [量化与模型压缩](chapters/07-量化与模型压缩.md)：形成精度、质量、校准与部署性能的通用压缩决策框架。
8. [并行推理与多 GPU 服务](chapters/08-并行推理与多gpu服务.md)：比较多卡拓扑、P/D 资源切分、通信、负载均衡和请求状态所有权。
9. [RAG 与 Agent 部署](chapters/09-rag与agent部署.md)：管理文档与索引版本、检索服务容量、请求权限、工具状态及灰度回滚。
10. [多模态部署](chapters/10-多模态部署.md)：处理 OCR 证据、语音流、视频预算及多阶段服务的容量和发布。
11. [监控、评估与安全](chapters/11-监控评估与安全.md)：把请求 trace、质量/安全分母、隐私边界和灰度发布门禁接成可复盘的运行闭环。
12. [成本优化](chapters/12-成本优化.md)：区分物理资源与账单口径，按单位成功成本组织路由、缓存、压缩和带质量/尾延迟/安全门槛的实验。
13. [生产系统设计](chapters/13-生产系统设计.md)：从 workload 与不同 SLO 形态出发，推导容量、请求链路、可靠性、观测和成本方案。
14. [部署方案的推导与故障复盘](chapters/14-部署方案推导与故障复盘.md)：用完整案例练习容量估算、方案比较和故障诊断。

### 专题分支：低精度部署

建议先读第 3、5、7 章，再按关注对象进入相应章节；第 15—17 章补充部署案例，不替代第 7 章的通用概念。

15. [FP4、MXFP4 与 NVFP4：四位浮点不是一个统一开关](chapters/15-fp4-mxfp4-nvfp4.md)：比较低位浮点格式、scale、artifact 与 kernel 的边界。
16. [FP8 KV Cache：用低精度换长上下文并发](chapters/16-fp8-kv-cache.md)：分析 KV 状态的容量收益、分页协作、质量和回滚。
17. [Native INT4：原生量化权重为什么不等于部署时再量化](chapters/17-native-int4与原生量化部署.md)：检查原生低精度 artifact 的执行与兼容性契约。

### 专题分支：托管模型 API 与工具预算

建议先读第 2、4、9、11、12 章。模型、接口功能和价格会变化，按正文注明的官方文档访问日期理解；本专题讨论 API 使用合同，不代表自托管 runtime。

18. [GPT-6 Astra：长上下文、推理档位与工具预算](chapters/18-gpt-6-astra长上下文与工具预算.md)：推演公开 context/output 与价格门槛，设计整项工具 job 预算，并区分工具、steering、后台响应、compaction 与安全监控状态。

## 本册要回答的问题

- 如何根据请求分布和 SLO 降低延迟、提升合格吞吐？
- 如何估算和管理活动 KV、权重与其他运行时内存？
- 如何选择引擎、批处理策略、量化 artifact 和并行拓扑？
- 如何安全地部署 RAG、Agent 和多模态工作流？
- 如何监控质量与故障，并在质量、安全和单位成本之间作出可复核的决策？

# 第四册简介：大模型百科全书

## 本书定位

第四册是术语、公式、方法和对比关系的速查工具书，也是全书系的导航层。

它不是按顺序阅读的课程，而是一个持续扩展的知识库。学习第一册、第二册、第三册或任何专题书时，遇到不熟悉的术语，都可以回到本书查阅。

本书中的“条目”有意保持短小：它负责给出定义、最小直觉、关键公式、容易混淆的边界，并把读者带到真正的专题正文。条目不是把一个重要知识点压缩成几句结论，也不替代训练、部署、评测或系统设计章节。遇到新模型暴露出的架构、推理、Agent 或治理问题，应沿着条目中的链接继续阅读独立章节。

## 为什么需要这本书

大模型领域术语密集，同一个概念还常常有不同论文、不同框架、不同工程系统中的叫法。百科全书的作用是建立统一词典，帮助读者快速确认定义、直觉、公式、适用场景和常见误区。

## 适合读者

1. 学习过程中需要快速查概念的读者。
2. 面试前需要复习术语和高频对比的候选人。
3. 想把零散概念串成知识网络的人。

## 学完后应具备的能力

1. 能快速解释大模型核心术语。
2. 能比较容易混淆的方法，例如 Adam/AdamW、MHA/MQA/GQA、SFT/DPO/RLHF。
3. 能把术语和对应章节、代码、面试问题连接起来。
4. 能形成自己的知识索引，而不是只靠搜索。

## 内容结构

本书有 19 章，按查询主题分为基础概念、训练与系统、应用与评估、证据索引、多模态，以及前沿更新。以下摘要用于判断入口和后续阅读方向，不替代各章的机制讲解：

1. [数学与机器学习](chapters/01-数学与机器学习.md)：查线性代数、概率统计、优化与实验分析，为后续模型和评估条目补足前置。
2. [深度学习组件](chapters/02-深度学习组件.md)：梳理张量、网络层、损失、优化器和训练环路，衔接 Transformer 的实现部件。
3. [NLP 与 Tokenization](chapters/03-nlp与tokenization.md)：从文本表示、语言建模任务到 tokenizer 和 token ID，说明字符串如何进入模型。
4. [Transformer 架构](chapters/04-transformer架构.md)：查注意力、位置机制、结构变体和长序列问题，再进入完整 LLM 与架构专题。
5. [大语言模型基础](chapters/05-大语言模型基础.md)：解释语言建模目标、上下文学习、规模、评估与产品边界，为训练和推理章节定词。
6. [预训练与数据](chapters/06-预训练与数据.md)：查语料、过滤、混合、打包、合成数据和训练阶段，衔接训练专题。
7. [后训练与对齐](chapters/07-后训练与对齐.md)：比较 SFT、偏好优化、强化学习和可验证反馈，通向生成策略与对齐专题。
8. [推理与解码](chapters/08-推理与解码.md)：从 logits 和概率分布查采样、搜索与解码行为，衔接服务优化。
9. [推理优化与部署](chapters/09-推理优化与部署.md)：查 batching、KV cache、量化、运行时和服务指标，并转向部署与推理框架正文。
10. [分布式训练系统](chapters/10-分布式训练系统.md)：比较并行策略、通信和训练平台，连接训练基础设施与集群运维。
11. [长上下文、RAG 与 Agent](chapters/11-长上下文rag与agent.md)：查上下文组织、外部检索、工具调用和 Agent 状态，连接算法、评估与运行时专题。
12. [Reasoning 与评估](chapters/12-reasoning与评估.md)：整理推理时计算、搜索、验证器和评测口径，帮助区分能力主张与测量结果。
13. [安全与治理](chapters/13-安全与治理.md)：查威胁、隐私、安全评估与治理框架，连接技术机制和部署责任。
14. [重要论文索引](chapters/14-重要论文索引.md)：按主题建立论文入口和阅读顺序，为前面各章的关键概念提供证据路径。
15. [面试高频对比表](chapters/15-面试高频对比表.md)：围绕机制、假设、成本和失败边界比较易混方法，供复习并回链专题正文。
16. [多模态学习](chapters/16-多模态学习.md)：查跨模态表示、对齐、融合和感知任务，区分理解与生成的接口。
17. [图像生成与视频生成](chapters/17-图像生成与视频生成.md)：比较视觉生成路线、控制方式和评估问题，衔接生成模型专题。
18. [语音大模型](chapters/18-语音大模型.md)：查语音理解、生成与实时交互的模型路径和指标，连接多模态系统。
19. [前沿架构与模型更新](chapters/19-frontier-architecture-updates.md)：记录有来源支撑的代表性机制与模型披露；深入架构转到第二十一册，接口与工程问题转到对应专题。

## 阅读建议

不要从头硬读。建议先在本书确认术语和最小公式，再进入链接的专题正文；如果只需要面试前复习，读完条目的对比和误区即可。把自己反复混淆的概念加入复习清单，但不要把复习清单当成完整学习材料。

阅读一个重要概念时，可以按三层推进：先看本书条目建立词义，再看所属专题书中的机制、例子和工程边界，最后用评估或实战章节验证自己是否真的会用。这样可以避免把“知道名词”误认为“掌握方法”。

## 与其他书的关系

第四册是全书系的索引层。正式章节中的重要概念应能在这里找到简洁条目，而本书的简洁条目不应被误读为完整正文。训练、推理框架、Agent、协议、评估和 AI Infra 等高影响主题，均以对应书册的独立章节为主要学习材料。

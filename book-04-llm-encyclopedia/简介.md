# 第四册简介：大模型百科全书

## 本书定位

第四册用来查大模型术语、公式和方法差异，也帮你找到相关专题的完整讲解。

本书适合按需查阅，不必从第一章读到最后一章。学习第一册、第二册、第三册或专题书时，遇到不熟悉的术语，可以回到这里确认含义和相关章节。

每个条目先用简明定义和直观说明帮你认清概念，再列必要公式、容易混淆的地方和深入阅读入口。完整推导、操作步骤、部署评估和系统设计请读对应专题章节。遇到新模型带出的架构、推理、Agent 或治理问题，也可以沿链接去专题章节查具体解释。

## 为什么需要这本书

大模型领域术语很多。不同论文、框架和工程系统有时会用不同名称描述相近概念，也可能用同一个名称指不同做法。本书帮助读者查清术语的含义、公式、适用场景和常见误解。

## 适合读者

1. 学习过程中需要快速查概念的读者。
2. 面试前需要复习术语和易混方法的候选人。
3. 想把零散概念整理成知识体系的读者。

## 学完后应具备的能力

1. 能快速解释大模型核心术语。
2. 能比较容易混淆的方法，例如 Adam/AdamW、MHA/MQA/GQA、SFT/DPO/RLHF。
3. 能把术语和对应章节、代码、面试问题连接起来。
4. 能整理出自己的知识索引，知道每个术语接着去哪学。

## 内容结构

本书有 19 章，按查阅主题分为基础概念、训练与系统、应用与评估、论文索引、多模态和前沿更新。下面简要说明每章提供什么入口、相关内容可以接着去哪里看：

1. [数学与机器学习](chapters/01-数学与机器学习.md)：查线性代数、概率统计、优化与实验分析，为后续模型和评估条目补足前置。
2. [深度学习组件](chapters/02-深度学习组件.md)：梳理张量、网络层、损失、优化器和训练环路，衔接 Transformer 的实现部件。
3. [NLP 与 Tokenization](chapters/03-nlp与tokenization.md)：从规范化、预切分和子词算法追踪到 token ID、特殊 token 与对话模板，并说明 token 预算和评测口径。
4. [Transformer 架构](chapters/04-transformer架构.md)：按数据流速查注意力、位置机制、结构变体和长序列问题，并沿导航进入第二十一册与推理专题的完整讲解。
5. [大语言模型基础](chapters/05-大语言模型基础.md)：沿概率目标、训练后行为、上下文生成与产品评估建立概念地图，并链接训练、推理、安全和系统设计主讲。
6. [预训练与数据](chapters/06-预训练与数据.md)：按训练流程查数据来源和许可、质量风险、去重、采样、packing、数据版本记录、训练预算与恢复，并链接第五、七、八、九册的深入讲解。
7. [后训练与对齐](chapters/07-后训练与对齐.md)：梳理 SFT、偏好数据、PPO/DPO、RLVR 与安全评估，标出数据/奖励证据边界和跨册主讲入口。
8. [推理与解码](chapters/08-推理与解码.md)：从 logits 和概率分布查采样、搜索与解码行为，衔接服务优化。
9. [推理优化与部署](chapters/09-推理优化与部署.md)：查请求怎样进入服务、如何经过调度和 KV cache、量化与并行怎样影响运行，以及准入保护、流式协议、发布观测和 Agent 服务，并链接部署专题。
10. [分布式训练系统](chapters/10-分布式训练系统.md)：比较并行策略、通信和训练平台，连接训练基础设施与集群运维。
11. [长上下文、RAG 与 Agent](chapters/11-长上下文rag与agent.md)：查怎样组织长上下文、从外部资料检索信息、调用工具和记录 Agent 状态，并链接算法、评估与运行时专题。
12. [Reasoning 与评估](chapters/12-reasoning与评估.md)：整理推理时计算、搜索、验证器和评测口径，帮助区分能力主张与测量结果。
13. [安全与治理](chapters/13-安全与治理.md)：了解常见攻击和数据风险，查隐私、安全评估与治理框架，并连接技术措施和部署责任。
14. [重要论文索引](chapters/14-重要论文索引.md)：按主题建立论文入口和阅读顺序，为前面各章的关键概念提供证据路径。
15. [面试高频对比表](chapters/15-面试高频对比表.md)：围绕机制、假设、成本和失败边界比较易混方法，供复习并回链专题正文。
16. [多模态学习](chapters/16-多模态学习.md)：查跨模态表示、对齐、融合和感知任务，区分理解与生成的接口。
17. [图像生成与视频生成](chapters/17-图像生成与视频生成.md)：比较视觉生成路线、控制方式和评估问题，衔接生成模型专题。
18. [语音大模型](chapters/18-语音大模型.md)：查语音理解、生成与实时交互的模型路径和指标，连接多模态系统。
19. [前沿架构与模型更新](chapters/19-frontier-architecture-updates.md)：按模型结构的变化点和公开证据查找代表性架构与模型资料；深入学习架构可读第二十一册，接口和工程问题可读相应专题。

## 阅读建议

按需查阅即可。遇到术语时，先在本书确认含义和必要公式，再沿链接阅读专题解释。面试前复习时，可以重点看条目中的方法对比和常见误解；反复混淆的概念可以加入自己的复习清单。

学习一个重要概念时，可以分三步：先读本书条目确认术语，再看专题书里的机制、例子和工程边界，最后用评估或实战章节检查自己是否会用。只记住名词还不等于掌握方法。

## 与其他书的关系

第四册是全书系的概念索引。重要概念可以在这里找到简要说明和深入入口；要学习训练、推理框架、Agent、协议、评估和 AI Infra 的完整机制，应继续阅读对应书册的专题章节。

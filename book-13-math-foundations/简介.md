# 第十三册简介：大模型数学基础

## 本书定位

本册是大模型算法学习中的数学支撑教材，沿着线性代数、概率、信息论、优化、统计学习和强化学习，解释这些数学对象怎样出现在模型表示、训练、对齐、不确定性和评估中。重点是让读者能读懂公式、复算关键步骤、检查假设并据此做工程判断，不是收集孤立公式，也不替代完整的大学数学课程。

## 为什么需要这本书

训练损失、生成概率、低秩更新、奖励优化和 benchmark 分数都由数学对象定义。只记住术语或公式，容易把 token 概率当成事实可信度，把一个更高分数当成普遍能力提升，或把低秩近似误当成任务质量保证。本册把定义、推导、数值例子和适用边界放在同一条解释链上，帮助读者判断一个结论究竟由什么假设支持。

## 适合读者与前置知识

本册适合数学基础不稳、读大模型论文时容易卡在公式，或希望把数学概念用于训练和评估判断的读者。建议具备基本代数、函数、指数与对数运算，以及基础 Python 阅读能力；不要求预先掌握线性代数、概率统计或强化学习。遇到梯度、矩阵形状和概率归约时，应跟着例子逐步计算，而不是只看最终公式。

## 学完后应具备的能力

1. 用向量、矩阵、投影和子空间解释 Transformer 表示、相似度及低秩更新，并区分矩阵近似误差与任务误差。
2. 从条件概率和链式法则解释语言模型的序列概率、最大似然、交叉熵、KL 与 perplexity，并指出比较口径的限制。
3. 解释 SGD、Momentum、Adam/AdamW、学习率调度和梯度裁剪分别改变什么，定位常见优化不稳定现象。
4. 区分经验分数、泛化证据和分布变化；使用概率校准、不确定性与选择性预测来表达结论边界。
5. 用 MDP、return、advantage、policy gradient、PPO 和偏好目标读懂后训练数学，并把具体推理训练算法留在相应专题册深入学习。
6. 根据评测对象、独立单位、配对关系、区间和多重比较判断模型差异是否足以支持决策。
7. 在面试或研究讨论中从对象和假设开始推理，给出可复算例子、反例及适用范围。

## 范围与边界

本册覆盖理解大模型机制和实验判断所需的数学基础及代表性推导。它不承担完整的微积分、概率论或统计学课程；不替代第十四册的 PyTorch/autograd 实现训练，不重讲第五册和第二册的训练系统与后训练全流程，也不替代第七册的评测协议设计。第十六册深入推理模型、RLVR、GRPO 和 test-time compute；本册负责读懂其所依赖的概率、优化与策略梯度概念，并在对应章节建立数学入口。

## 阅读方式

- **完整路径：** 按第一至第十章顺序学习。前九章建立数学对象与应用，第十章用综合问题和练习检验能否迁移。
- **线性代数与低秩：** 读第一、第五章；第一章建立表示和几何直觉，第五章系统展开 SVD、PCA、低秩压缩、LoRA/QLoRA 及 rsLoRA、DoRA 的数学差异，完整训练显存细节转第五册。
- **训练与偏好优化：** 读第二至第四章和第八章；需要具体训练流程时转第五册、第二册，需要推理模型及 RLVR 细节时转第十六册。
- **不确定性与评估：** 读第六、第七和第九章；评测任务、协议和线上实验设计转第七册。
- **代码验证：** 数学例子先手算，再用第十四册的 PyTorch/autograd 工程内容辅助检查实现；代码是验证工具，不能替代推导。

## 各章概要

1. **线性代数：** 用向量、矩阵形状、Attention、检索和 KV 缓存算例解释模型表示；SVD/LoRA 深推导转第五章，注意力架构演进转第二十一册。
2. **概率论：** 从条件分布和期望走到自回归生成、最大似然、校准与概率的适用边界。
3. **信息论：** 推导熵、交叉熵、perplexity、KL、互信息与信息瓶颈，说明 InfoNCE、DPO、RAG 和表示压缩中的用途及边界。
4. **优化基础：** 解释梯度估计、SGD、Momentum、Adam/AdamW、调度、裁剪、故障诊断和训练状态恢复。
5. **矩阵分解与低秩：** 深入 SVD、PCA、压缩和矩阵误差边界，再从 LoRA 推到 rsLoRA、DoRA、QLoRA 与秩消融；用 LoRA-α 预印本说明缩放系数仍需结合任务验证，量化训练显存账本转第五册。
6. **统计学习与泛化：** 从风险和数据划分推到过拟合、记忆、重复样本、benchmark 污染检测及分布外/组合泛化，并说明分数与排名证据的边界。
7. **贝叶斯与不确定性：** 用贝叶斯更新和不确定性信号分析证据；区分 token 与语义答案置信，计算校准和覆盖率—风险取舍，并用 conformal prediction、RAG 引用与工具状态决定回答、验证或弃答。
8. **强化学习数学：** 从 MDP、价值和优势推导策略梯度与 PPO，补入 GRPO 组内相对优势的数学入口；偏好优化、结果奖励和验证器建立在统一的策略学习主线上，完整 reasoning/RLVR/GRPO 训练专题转第十六册。
9. **评估统计与显著性：** 区分题目抽样、重复生成、训练运行和评分误差，沿配对比较、区间、检验、功效、bootstrap、多重比较和 judge 校准走到发布决策。
10. **数学判断：** 沿训练指标、参数更新、行为代理与不确定性、统计发布四条推理链，把前九章的对象与推导用于综合案例、反例和可复算实验；逐题回到前文核对条件。

## 与其他书的关系

- 第一、第二册建立 LLM 与进阶研究主线；本册提供阅读其中训练、对齐和评估公式所需的数学基础。
- 第五册、第二册负责训练和后训练流程；本册解释其优化、概率和策略学习所依赖的数学对象。
- 第七册负责评估设计与实验方法；本册集中解释统计量、抽样误差和显著性推断。
- 第十四册负责 PyTorch 与 autograd 的工程实现；本册侧重推导和手算。
- 第二十一册深入 Transformer 架构与注意力 serving 取舍；本册只用缓存 shape 和元素计数建立线性代数入口。
- 第十六册负责 reasoning、RLVR、GRPO 和测试时计算专题；本册提供进入这些内容的概率与优化基础。
- 第十二册和题库承接面试表达；读者应从第十章回到对应知识章节，而不是把本册当成背诵答案集。

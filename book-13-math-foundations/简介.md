# 第十三册简介：大模型数学基础

## 本书定位

第十三册系统补齐大模型算法岗需要的数学基础。它不是泛泛学习数学，而是沿着模型训练和系统评估中的真实问题，展开线性代数、概率论、信息论、优化、低秩、统计学习、贝叶斯不确定性、强化学习数学和评估统计，并把这些概念连接到 LLM 的训练、对齐、检索、工具调用和发布判断。

## 为什么需要这本书

大模型很多问题背后都有数学直觉：交叉熵和 KL、SVD 和低秩微调、Adam 和优化动态、贝叶斯证据更新、Reward Model 和偏好学习、PPO 与 DPO、显著性和 A/B 测试。如果数学薄弱，训练曲线、模型分数和线上现象很容易只停留在术语层；真正的工程判断还需要知道公式的假设、指标的边界和证据是否足够。

## 适合读者

1. 数学基础不稳但想准备大模型算法岗的人。
2. 想把公式和代码、实验、模型行为和面试表达联系起来的人。
3. 需要补齐优化、概率、信息论和统计评估的人。

## 学完后应具备的能力

1. 能解释向量、矩阵、投影、SVD 和低秩近似。
2. 能理解概率建模、MLE、交叉熵、KL 和 perplexity。
3. 能解释梯度下降、Adam、AdamW、学习率调度和优化稳定性。
4. 能理解统计显著性、置信区间和实验设计。
5. 能区分 token 概率、任务成功概率和系统证据，并据此设计校准、拒答、验证和发布评估。

## 阅读建议

建议先按章节顺序建立基础，再按短板回读。不必把公式当成孤立结论；每学一个数学点，都要回到 LLM 训练、对齐、检索、工具调用、评估或部署中的具体用法，并尝试用数值例子和失败案例检验自己的理解。

## 与其他书的关系

第十三册是第一册、第二册、第五册、第七册和第十册的数学支撑层。

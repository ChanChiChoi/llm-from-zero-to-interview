# 第五册简介：大模型训练全流程

## 本书定位

第五册专门讲大模型训练全流程，覆盖数据、tokenizer、模型架构、预训练、优化器、学习率策略、后训练、对齐强化训练、分布式训练、数值稳定性、评估、实验管理和训练事故排查。

它回答的问题不是“某个训练概念是什么”，而是如何把目标、数据、模型、系统、评估和故障恢复组织成可验证的训练工程。

## 为什么需要这本书

训练是大模型能力形成的源头。只理解 Transformer 结构还不够，算法岗候选人还需要知道数据如何进入训练系统，AdamW/Muon 等优化器如何影响收敛，loss 如何变化，checkpoint 如何选择，分布式并行如何组织，训练异常如何排查。

## 适合读者

1. 想系统学习大模型训练工程的读者。
2. 已理解预训练、SFT、DPO 基础，但缺少 PPO、GRPO、GSPO、DAPO、DCPO 等现代后训练方法视角的人。
3. 想把训练事故、debug 和实验管理讲清楚的候选人。

建议读者会使用 Python，理解反向传播、交叉熵和 Transformer 的基本数据流；不要求已有多卡训练经验。数学和 PyTorch 前置薄弱时，可先配合[第十三册数学基础](../book-13-math-foundations/简介.md)和[第十四册 PyTorch 与深度学习工程](../book-14-pytorch-deep-learning-engineering/简介.md)补齐。

## 学完后应具备的能力

1. 能设计训练数据 pipeline 和 tokenizer 方案。
2. 能组织预训练、SFT、RLHF/PPO、DPO、GRPO、GSPO、DAPO、DCPO 和多模态训练流程。
3. 能解释 DDP、FSDP、ZeRO、TP、PP 等分布式策略。
4. 能比较 Adam、AdamW、Adafactor、Lion、Sophia、Muon 等优化器的目标和 trade-off。
5. 能排查 loss spike、NaN、梯度爆炸、吞吐异常和评估异常。
6. 能估算训练成本、资源需求和实验风险。

## 阅读建议

先沿目录主线阅读第 1—14 章，建立从训练目标、数据与模型，到更新、稳定性、评估和系统设计的完整闭环；再按需要选读第 15—18 章的领域训练、RLVR、on-policy distillation 和 DeepSeek-V4 案例。建议在学完第一册训练部分后阅读，并与第三册微调项目、第七册评估方法和第十九册事故排查交叉学习。

## 章节地图

### 全流程主线：第 1—14 章

1. [训练总览](chapters/01-训练总览.md)：从目标和交付物建立全流程地图，用有效 token、FLOPs、吞吐、更新数和 checkpoint 存储完成一组可复算账本，并为后续机制章节标出主讲入口。
2. [数据工程](chapters/02-数据工程.md)：从训练视角追踪数据契约、有效 token、领域曝光和消融解释；采集、质量、去重与治理方法可接第九册深讲。
3. [Tokenizer 与数据格式](chapters/03-tokenizer与数据格式.md)：把原文、消息、媒体载荷和标签组织成可回放的 token、模板、监督与 packing 协议；算法和 tokenizer 指标深讲见第二册，格式故障排查见第十九册。
4. [模型架构与初始化](chapters/04-模型架构与初始化.md)：把能力、数据、算力和服务约束写成训练前配置，手算参数、token、KV 与 MoE 预算，并为初始化和结构变更设计稳定性回归；架构机制深讲见第二册与第二十一册，完整成本计划接第十三章。
5. [预训练目标与训练循环](chapters/05-预训练目标与训练循环.md)：从 causal LM 的目标、label shift 和有效 loss 分母推到完整参数更新，并对照 T5/UL2/FIM、MTP 与离散扩散，再连接验证、日志和 checkpoint。
6. [优化器与学习率策略](chapters/06-优化器与学习率策略.md)：从 AdamW 状态与参数分组延伸到矩阵/低秩优化器、warmup 与衰减调度；用有效 token、裁剪、衰减和恢复实验判断训练质量与成本。
7. [分布式训练](chapters/07-分布式训练.md)：从全局有效目标分母出发，组织 DDP、ZeRO/FSDP、TP/PP、SP/CP 和 EP；用通信重叠、rank 级观测与 checkpoint 重分片判断布局取舍，并区分研究中的在线并行切换。
8. [显存优化与数值精度](chapters/08-显存优化与数值精度.md)：核算训练状态、激活与瞬时峰值，比较混合精度、分片、重计算、卸载和低比特训练；区分 FP4 全量训练与 QLoRA 底座存储，并按证据边界定位 OOM 和数值异常。
9. [训练稳定性与调试](chapters/09-训练稳定性与debug.md)：以健康账本锁定首个异常，沿有效 token、梯度与预条件、数值精度、rank collective 和 checkpoint 连续性建立可复核假设。
10. [Checkpoint、评估与实验管理](chapters/10-checkpoint评估与实验管理.md)：从保存状态、频率、容量和恢复探针建立 checkpoint 闭环；用 token 加权 loss、domain、benchmark、回归和污染审计形成评估证据，再以版本血缘、公平对照和多目标门槛选择可用模型。
11. [后训练与对齐训练](chapters/11-后训练与对齐训练.md)：从 SFT/RM、PPO-RLHF 与离线偏好优化推到 GRPO/RLVR，手算优势、ratio 和 loss reduction；比较 DAPO、DrGRPO、GSPO、DCPO 及早期 DHPO/GAPO 候选，并讨论 verifier、异步 rollout、安全与能力回归。
12. [多模态训练](chapters/12-多模态训练.md)：覆盖图像、文档、ASR 与语音生成、视频和连续生成任务的数据配比、训练目标、阶段化对齐、资源账本与证据评估；多模态架构和任务机制由第十五册专题深讲。
13. [训练成本与资源规划](chapters/13-训练成本与资源规划.md)：把 token、FLOPs、吞吐、GPU、存储与重跑风险转成阶段化预算，连接训练方案和平台约束。
14. [训练系统综合设计与故障诊断](chapters/14-训练系统综合设计与故障诊断.md)：综合前述账本设计训练方案，再从事故、回归和证据缺口倒推排查顺序。

### 后训练专题：第 15—18 章，按需选读

15. [领域专家 SFT 与 RL](chapters/15-领域专家sft与rl.md)：从专业任务、专家数据和可验证工作流设计领域适配，并与通用能力回归一起验收。
16. [RLVR 与可验证奖励](chapters/16-rlvr与可验证奖励.md)：判断任务何时可验证，构造 verifier、奖励与沙箱，并检查奖励投机和跨环境泛化。
17. [On-Policy Distillation](chapters/17-on-policy-distillation.md)：让学生在自己的 rollout 状态上吸收教师信号，并分析教师质量、分布覆盖、稳定性和成本。
18. [DeepSeek-V4 领域专家与统一蒸馏](chapters/18-deepseek-v4领域专家与统一蒸馏.md)：沿公开报告中的领域 SFT/GRPO、GRM 与 reasoning effort 进入学生状态上的多教师全词表 OPD，并标明系统披露和未知项。

## 与其他书的关系

本册负责把训练目标、数据、模型、优化、并行、评估和恢复组织成训练工程闭环。第一册建立大模型共同主线，第二册深入算法原理，第三册提供可运行的训练与微调项目；第九册深入数据治理，第十五册深入多模态任务，第十六册深入推理模型训练，第十七册深入 Agent 训练与工具反馈，第二十一册深入架构演进。推理服务、通用评估和 AI Infra 的完整设计分别由第六/二十四册、第七册和第二十三册承担；本册只保留训练方案所需的交接与成本边界。

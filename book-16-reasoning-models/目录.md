# 第十六册目录：Reasoning Model 专题

## 本册定位

本册讲推理模型如何提出候选、使用 verifier 或执行反馈筛选、通过训练信号改进，并在推理时分配搜索和计算预算。可见 CoT、API thinking 字段和模型内部推理不混为一谈；provider-specific 接口案例不构成跨模型通用能力标准。

### 专题路径一：预算、控制档位与自适应策略（第 13、18、14 章）

先读[第 13 章](chapters/13-reasoning-effort与推理预算.md)建立预算单位和成本账本，再读[第 18 章](chapters/18-adaptive-thinking与动态预算.md)理解动态分配策略，最后读[第 14 章](chapters/14-thinking-levels.md)比较具体模型的离散接口档位。三个主题分别处理计量、策略和 API 控制字段；档位标签依 provider 和版本而异。

### 专题路径二：thinking 状态与工具交错（第 15、19 章）

[第 15 章](chapters/15-preserve-thinking与推理状态.md)讨论跨轮 thinking 状态及兼容条件；[第 19 章](chapters/19-interleaved-thinking与工具协议.md)沿模型输出、工具执行、观察和验证追踪事件。完整 Agent 工作流、Runtime 和工具协议分别见第十七、二十、二十二册。

### 专题路径三：高级并行推理与长任务案例（第 16、20 章）

[第 16 章](chapters/16-multi-agent与ultra-test-time-compute.md)从额外 test-time compute 角度讨论并行候选和验证；[第 20 章](chapters/20-glm-5.3长任务环境与验证器.md)审读 GLM-5.3 长任务环境与 verifier 的发布方披露。前者不代替 Agent 架构教材，后者不把单一发布方案推广成通用训练配方。

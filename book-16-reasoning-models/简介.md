# 第十六册简介：Reasoning Model 专题

## 本书回答的问题

推理模型怎样从问题生成候选解答，借助验证、搜索或执行反馈找到可靠结果？训练阶段如何使用结果奖励、过程监督和可验证任务信号？推理时多花的计算何时能提高成功率，预算、延迟、安全与状态协议又如何影响整个系统？

本册把推理看成一条可审计的能力链：模型提出候选，选择器或环境检查候选，训练信号塑造未来行为，推理控制器分配资源，评估再检验结果是否可信。可见的 Chain-of-Thought（CoT，思维链）是某种输出或接口内容，不等于对模型内部推理的完整读取；provider 的 effort、thinking level 和状态字段也是具体接口合同，不是跨模型通用的算力单位。

## 目标读者与前置知识

本册面向准备 reasoning、数学/代码模型、verifier、test-time compute 和推理接口方向岗位的读者。建议具备 Python、概率、优化及 Transformer 基础，并能理解分类、语言模型训练和基本评估。

- 数学基础需要补齐时，可参考[第十三册数学基础](../book-13-math-foundations/简介.md)；需要熟悉 PyTorch 训练接口时，可参考[第十四册](../book-14-pytorch-deep-learning-engineering/简介.md)。
- 想运行数学推理增强或代码反馈项目，可配合[第三册实践教材](../book-03-practical-handbook/简介.md)；大规模训练方法和系统转到[第五册](../book-05-llm-training/简介.md)。

## 学完后应具备的能力

1. 区分推理任务、可见轨迹、最终答案和可验证的外部结果，不把 CoT 文本直接当作忠实内部过程。
2. 设计候选采样、self-consistency、verifier、reward model 和过程监督，并分析其收益条件与失效方式。
3. 将搜索表示为状态、动作、扩展、评分、剪枝和停止，比较串行、并行与多路径计算。
4. 为数学和代码任务选择训练信号，说明答案检查、单元测试、隐藏测试及执行环境能证明什么。
5. 设计 reasoning 专项评估，检查任务版本、污染、方差、轨迹忠实性、安全和拒答边界。
6. 建立推理 token、候选数、工具轮次、延迟和单位成功成本账本，并判断额外计算是否值得。
7. 阅读具体 provider 的 reasoning effort、thinking level、跨轮 thinking 状态和工具交错协议，避免把 API 行为推成通用模型机制。
8. 将 DeepSeek-R1、GLM-5.3 等公开路线作为限定条件的案例，区分论文结果、发布方披露、接口能力和未验证推断。

## 范围与书系分工

本册讲推理机制、测试时策略、可验证训练、数学与代码任务、推理评估/安全，以及 reasoning API 的控制与状态边界。它不是完整训练手册、Agent Runtime 手册或 provider API 参考大全。

- [第五册](../book-05-llm-training/简介.md)负责通用预训练、后训练和训练系统；本册讲推理任务使用的监督与验证信号。
- [第七册](../book-07-evaluation-experiments/简介.md)负责通用实验设计和统计方法；本册讲推理任务、轨迹和 verifier 的专项评估。
- [第八册](../book-08-ai-safety-alignment/简介.md)负责安全控制与治理；本册说明推理行为的风险面及如何测量。
- [第十七册](../book-17-agent-tool-use/简介.md)负责 Agent 模式、工具使用和协作；[第二十册](../book-20-agent-harness-runtime/简介.md)负责 Harness、Runtime 和长任务执行。本册聚焦推理计算与 verifier，不重复完整宿主编排。
- [第二十二册](../book-22-tool-protocol-ecosystem/简介.md)负责工具协议和生态；本册只解释 reasoning 与工具事件交错时的状态语义。
- [第六册](../book-06-llm-deployment/简介.md)和[第二十四册](../book-24-llm-inference-engine/简介.md)负责部署与 Serving 测量；本册给出推理预算的决策框架，不替代目标系统的成本和延迟实测。
- [第十册论文研究](../book-10-paper-reproduction-research/简介.md)提供论文精读与复现方法；本册引用其领域论文并限定结论边界。

## 阅读路径

**核心路径：** 第 1—7 章建立推理、验证、搜索和测试时计算概念；第 8—9 章分别落到数学和代码任务；第 17 章用 DeepSeek-R1 串起可验证后训练与蒸馏案例；第 10—12 章完成评估、安全和综合判断。读者可先读完第 1—12 章，再回看第 17 章，也可以在第 8—9 章后插入第 17 章。

**按需专题：** 想做预算路由，读第 13、18、14 章，依次理解预算口径、动态分配和具体 thinking level 接口；想理解跨轮状态与工具协作，读第 15、19 章；想研究并行推理，读第 16 章；想分析长周期代码任务环境和 verifier，读第 20 章，并与第十七、二十册对照。

## 各章在主线中的作用

1. [Reasoning 总览](chapters/01-reasoning总览.md)：以合同付款案例串联答案、轨迹、能力以及模型、策略、环境三层，建立生成、验证、预算、评估和安全的共同框架，交给后续机制章与专题案例。
2. [Chain-of-Thought](chapters/02-chain-of-thought.md)：解释 CoT、scratchpad 与外部解释的差别，检验轨迹忠实性、训练和路由成本，衔接多候选采样与过程监督。
3. [Self-Consistency 与采样](chapters/03-self-consistency与采样.md)：从单次回答转向多候选生成与聚合，为 verifier 和搜索提供输入。
4. [Verifier 与 Reward Model](chapters/04-verifier与reward-model.md)：比较候选评分和奖励信号，连接过程监督与测试时选择。
5. [过程监督](chapters/05-process-supervision.md)：把步骤级反馈变成训练信号，衔接数学和 RLVR 路线。
6. [搜索与 Tree-of-Thought](chapters/06-search与tree-of-thought.md)：以状态空间组织候选探索，为测试时扩展和并行搜索铺路。
7. [推理时计算扩展](chapters/07-test-time-compute-scaling.md)：用质量—预算关系比较增加计算的策略，为预算控制专题打基础。
8. [数学推理训练](chapters/08-数学推理训练.md)：围绕可判定数学任务分析数据、奖励和验证，并与第十三册数学衔接。
9. [代码推理与执行反馈](chapters/09-代码推理与执行反馈.md)：用规格、运行环境、测试和修复轨迹解释代码推理，交给第三册项目和第二十册 Runtime。
10. [Reasoning 评估](chapters/10-reasoning评估.md)：从分数回到任务、版本、污染、方差和过程证据。
11. [Reasoning 安全与局限](chapters/11-reasoning安全与局限.md)：检查推理轨迹、过度自信和系统边界，再交给第八册治理。
12. [Reasoning 综合复习](chapters/12-reasoning面试题.md)：把候选、验证、搜索、预算、评估和安全整合成可复核判断。
13. [Reasoning Effort 与推理预算](chapters/13-reasoning-effort与推理预算.md)：定义推理成本的组成和预算账本，为动态策略提供计量基础。
14. [Thinking Levels](chapters/14-thinking-levels.md)：比较离散思考档位与接口能力，强调字段含义依模型和版本而变。
15. [Preserve Thinking 与推理状态](chapters/15-preserve-thinking与推理状态.md)：讨论跨轮状态如何延续，以及协议保留不等于公开隐藏思维。
16. [Multi-Agent 与 Ultra Test-Time Compute](chapters/16-multi-agent与ultra-test-time-compute.md)：分析多路径、并行计算与协调成本，交接给 Agent 和 Harness 专题。
17. [DeepSeek-R1 的 RLVR 与蒸馏路线](chapters/17-deepseek-r1的rlvr与蒸馏路线.md)：用指定模型案例连接结果验证、强化学习和蒸馏。
18. [Adaptive Thinking 与动态预算](chapters/18-adaptive-thinking与动态预算.md)：讨论按任务难度或反馈调整预算的控制思路，与第十三章账本区分。
19. [Interleaved Thinking 与工具协议](chapters/19-interleaved-thinking与工具协议.md)：沿推理、工具调用、观察和验证追踪事件顺序与状态恢复。
20. [GLM-5.3 长任务环境与验证器](chapters/20-glm-5.3长任务环境与验证器.md)：审读一个发布方披露的长周期环境案例及其 verifier 证据边界。

完成本册后，可沿具体数学/代码任务返回第三册实践；若工作转向 Agent 工作流、Runtime、工具协议、统计评估、安全治理或生产 Serving，应沿上面的跨册入口继续，而不把这些领域压缩成本册的附录。

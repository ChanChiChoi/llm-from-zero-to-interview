# 第十五册目录：多模态与生成模型专题

## 本册定位

本册解释多模态输入如何形成模型表示，理解和生成任务如何使用这些表示，以及如何核验媒体证据、输出质量和请求预算。全书是机制教材，不是多模态 API 清单或端到端项目手册；项目实现、通用评估、安全治理和生产 serving 分别与第三、七、八、六/二十四册衔接。

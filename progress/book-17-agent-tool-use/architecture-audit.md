## 书册契约

- **定位：** Agent、工具使用和任务执行模式的专题教材。中心问题是：模型提出动作后，系统怎样维护任务状态、检查权限、执行动作、利用可信观察恢复，并证明任务达到验收条件？
- **读者起点：** 读者已了解基本大模型输入/输出；熟悉 JSON、API 或做过 RAG/工具调用 demo 会有帮助但不是硬性前置。无需预先掌握某一 Agent 框架。
- **能力目标：** 读者能把任务写成状态/动作/观察/完成条件清晰的契约，设计工具调用与恢复路径，选择计划、记忆、检索、代码或界面操作模式，评估多 Agent 的净收益，并按模型、Harness、环境和 verifier 分层解读结果。
- **组织类型：** 按概念和系统机制递进的专题教材。第 1—12 章形成主学习路径，第 13—15 章是环境、并行协作和模型证据的进阶专题；此划分为架构阶段决定，逐章阅读后若发现前置或承诺不实再复核。
- **书系分工：** 第三册通过有限项目练习 Agent；第十六册深挖推理模型、test-time compute 与推理状态；本册解释通用 Agent 决策和执行模式。第二十册深入 Runtime/Harness 组件实现、权限和长任务运行机制；第二十二册深入 Function Calling、MCP、A2A、Skill/Plugin 等协议生态。本册只保留核心理解所需的接口概念，并提供明确交接。

## 本章契约与读者路径

- **读者前置：** 理解基本大模型输入/输出和第二章结构化动作、工具结果与宿主控制边界；无需熟悉特定 Agent 框架。
- **对书册目标的贡献：** 让读者能把一次工具调用扩展成受观察、状态、预算、权限和完成条件约束的多步反馈控制循环。
- **中心问题：** 工具或环境返回的观察怎样改变状态、计划和下一步动作，系统又如何判断继续、追问、安全停止或完成？
- **预期结果：** 读者能解释 ReAct 与 Plan-Act-Observe 的关系，定义一条可追溯的动作/观察轨迹，选择重规划时机，识别无进展循环和过早结束，并区分任务成功、轨迹质量、安全恢复与计划更新覆盖。
- **读者路径：** 从一次性生成的局限进入闭环直觉；比较 ReAct、PAO 和相近研究；形式化目标、动作、观察、状态与停止；再读计划控制、失败恢复和 trace；最后用指标与六条合成轨迹定位错误，并接到第四章的任务分解。

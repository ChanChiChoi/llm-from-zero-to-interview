## 本章契约与读者路径

- **读者前置：** 理解第三章的任务循环和第四章的计划/状态；不要求掌握特定框架。
- **对书册目标的贡献：** 使读者能判断哪些状态或经验应保留、怎样安全检索和更新，并让长期记忆进入 Agent 决策时有来源、权限、时效和退出路径。
- **中心问题：** 一个 Agent 怎样把交互和工具观察转成以后可以安全复用、校正和撤回的信息？
- **预期结果：** 读者能区分 context、任务状态、会话历史、长期记忆和 RAG；设计带主体/范围/来源/时间的记忆记录；拆解写入、检索、更新、删除管线；为事实召回、旧值误用、工具动作、越权和删除残留设计分项评测。
- **读者路径：** 从 Python 版本记录混淆导致的 CI 建议错误开始；先区分记忆的时间边界、功能和载体，再建立事实 schema；接着说明写入、权限过滤、上下文组装、更新/删除和反思；随后比较研究与评测；用安全链及框架接口检查实现边界；最后回到 CI 案例，追踪证据如何支持建议及何时必须重读当前 workflow。

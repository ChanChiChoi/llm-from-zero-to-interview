- 综合门槛与代码检查逐项对齐：任务成功、配对收益、角色匹配、子任务成功、消息 schema、证据支持、冲突解决、正确解决、重复工作、权限违规、不必要的多 Agent 和平均成本。公式补入 R_assign、R_perm、R_unnecessary 和平均单次成本 C̄_multi。
- 收尾公式复核补齐目标角色、重复判定、单次成本与阈值定义，并区分消息有效率和证据支持率各自的统计集合；空运行集和空配对集均记为未定义。冲突解决率只衡量已识别真实冲突的处理，不代替冲突发现召回率；权限违规按出现违规的分配记录计数。
- 对四条合成 trace 静态手算：14 个分配、14 条消息、2 个已检测冲突、4 组配对 baseline；任务成功 3/4=0.75，配对收益 0.75−0.25=0.50，角色匹配 13/14=0.929，子任务成功 12/14=0.857，消息有效 13/14=0.929，证据支持 10/14=0.714，冲突解决 1/2=0.50，正确解决 1/2=0.50，重复工作 2/14=0.143，权限违规 1/14=0.071，不必要编排 1/4=0.25，平均合成成本 1.325。
- 阈值判断：任务成功、消息有效、证据支持、两项冲突指标、重复工作、权限、不必要编排未通过；配对收益、角色匹配、分配成功和平均成本通过。综合结果仍为 False。失败 trace 和排序后的原因列表不变；原样本没有“已解决但错误”的冲突，因此新增失败类别计数为 0。

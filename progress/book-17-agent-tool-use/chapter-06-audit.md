## 本章契约与读者路径

- **读者前置：** 理解第二至五章中的工具调用、Agent 反馈循环、任务拆解和 Memory 基本边界；不要求掌握特定 RAG 框架。
- **对书册目标的贡献：** 让读者能把外部检索纳入有状态的 Agent 循环，记录证据与约束，验证答案 claim，判断何时继续或停止，并保持来源、时效、权限和安全边界。
- **中心问题：** Agent 如何检索、检查证据，并判断材料是否足以回答当前问题？
- **预期结果：** 读者能区分固定 RAG、Agentic RAG、GraphRAG 和 Memory；为多轮检索保存原始问题、子问题和证据状态；拆分相关性、claim 支持、引用与权限检查；定义停止、冲突处理和拒答路径；分层评估检索器、中间能力和端到端回答。
- **读者路径：** 从固定 top-k 流程的局限进入 Agent 控制循环和证据状态；再展开主动/多轮/多跳检索及工具选择，区分图索引与控制器；随后学习证据阅读、引用、停止、恢复、成本和 Memory 边界；通过评估指标与静态 demo 手算检查；最后把证据账本、安全约束和完整研究循环交给 Code Agent。

- 在 demo 之后加入逐轮手算表：14 个查询—文档返回对中 7 个命中 7 个黄金相关对，precision `7/14=0.5`、recall `7/7=1.0`；五个非空轮次的新证据增益依次为 `1, 2/3, 0, 0, 1`，均值 `0.533`。五个 claims 中四个通过 toy proxy（`0.8`）；7 个唯一文档中 1 个被标为过期（`0.143`）；阈值前 21 个正相似候选中各拦截 1 个注入和越权候选（各 `0.048`）。这些数值均来自合成输入和代码逻辑的静态逐项推算，没有运行程序。

## 本章契约与读者路径

- **读者前置：** 理解第二章的工具动作接口，以及第三章的观察、状态更新、重规划和停止条件；无需掌握特定 Agent 框架。
- **对书册目标的贡献：** 让读者能把复杂目标表示为有依赖、有验收、有风险和预算约束的任务结构，并判断它怎样进入长期执行。
- **中心问题：** 怎样把复杂目标拆成可执行、可验证、能恢复的子任务，同时不丢失原始限制？
- **预期结果：** 读者能定义子任务契约和目标覆盖，表示 DAG/状态机/分层计划，判断依赖顺序、关键路径和可并行部分，选择静态/动态/混合规划，评估重规划、恢复、风险确认和任务结果。
- **读者路径：** 从复杂请求引入计划必要性；再定义任务契约、需求和验收传播；随后形式化覆盖、依赖与关键路径；比较计划表示、粒度和重规划方式；用并行调查例子推演关键路径，再连接长期任务状态与 Memory；最后比较 planner 类型、成本收益，并以五份合成计划审计指标。

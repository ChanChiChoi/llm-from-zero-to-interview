## 章节职责地图

1. **部署总览**：从 workload 和 SLO 建立模型工件到可运营服务的决策地图。
2. **推理基础**：解释 prefill/decode、KV 状态和性能指标口径，接到压测与容量判断。
3. **KV Cache 与内存管理**：核算逐 token 状态与并发显存，解释分页、复用、量化和淘汰。
4. **解码策略与生成控制**：连接 logits、采样、结构化生成、停止条件、质量与输出预算。
5. **推理引擎**：按 workload、协议、硬件和维护要求选择 runtime；实现细节连到第二十四册。
6. **批处理与调度**：管理 runtime 内队列、continuous batching、长短请求争用、KV/token 预算和抢占。
7. **量化与模型压缩**：提供跨精度方案的表示、校准、质量和性能比较方法。
8. **并行推理与多 GPU**：比较 TP/PP/EP、P/D 分离、通信、KV 所有权和副本服务。
9. **RAG 与 Agent 部署**：接入文档、索引、检索、工具状态、权限和灰度回滚。
10. **多模态部署**：处理 OCR、ASR/TTS、视频、多阶段容量与评估。
11. **监控、评估与安全**：统一 trace、SLO、质量/安全分母、隐私和发布门槛。
12. **成本优化**：在质量、安全和尾延迟约束下比较资源、账单与单位成功成本。
13. **生产系统设计**：将 workload 转成容量、链路、可靠性、观测和多租户方案。
14. **部署方案推导与故障复盘**：应用前述方法做资源决策、方案比较和故障定位。
15. **FP4/MXFP4/NVFP4**：比较低位浮点权重格式、scale、artifact 和 kernel。
16. **低精度 KV Cache**：以 FP8 工程实践为主，按实验和预印本证据呈现 FP4 KV 的成熟度与限制。
17. **Native INT4**：核验量化 artifact、runtime、kernel、硬件与质量门禁的兼容合同。
18. **GPT-6.2 Astra API**：讲长上下文预算、mode/effort、费用和多轮工具任务状态；不延伸为自托管推理引擎说明。

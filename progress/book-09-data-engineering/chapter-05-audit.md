## 正文修改与篇幅

- 校准配比效果的因果措辞：数据曝光增加不等于能力必然增加；质量、重复、预算、tokenizer、目标任务与评估方式共同决定结果。自然分布明确为当前数据快照基线，而非互联网真实世界的无偏分布。
- 重写 §4.1 的池级数学定义：区分 token 曝光概率、文档抽样、能力/风险代理和项目设定权重；定义能力维度集合 `M`、归一化基线 `p_0`、空池支持集、整数预算取整、KL 支持集和并列检查向量。线性覆盖只作为可解释代理，不能预测模型能力。
- §20 将 `D_k` 定义为预处理后上下文—目标 token 训练位置的分布，将损失限定为非 padding 目标 token 的 next-token NLL；补充文档长度和按序列聚合时应重新定义目标，并用同一参数位置的合成梯度手算解释训练方向如何随比例变化。
- 对多语言、专业、代码、数学、合成数据及各训练阶段的建议均补充目标与评估条件；§13 的阶段调度明确是待验证假设。SampleMix 的步数效率用相对基线口径表达，QuaDMix 的 benchmark proxy 与独立验收集分开。
- **length_status：** 静态统计连贯中文解释性文字，排除标题、表格、代码、行内代码、公式、引用链接文本和空白。四个核心单元分别为：开篇—§§0—4 **3,574** 字；§§5—12 **2,729** 字；§§13—20 **3,283** 字；§§21—23 **1,931** 字。均达到核心单元 1,800 字下限。分组依据是连续教学任务，不以单个分类性小标题虚增篇幅。

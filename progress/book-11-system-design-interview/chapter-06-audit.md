## 章级扫描与候选去向

- **扫描问题：** Agent 和工作流的责任边界是否清楚；任务、步骤、尝试和工具版本由谁持有；暂停、重试和恢复时怎样避免重复副作用；权限是否绑定主体、资源、动作、环境、租户和当前策略；审批后是否重新授权；工具协议与业务授权是否分离；外部内容能否影响控制平面；隔离、秘密、预算、停止和审计是否由平台负责；成功率、成本和灰度门槛是否可复算、可观测。
- **资料范围与日期：** 2026-11-05；定向核阅 MCP 2026-07-28 规范、A2A v1.0.1、OpenID AuthZEN Authorization API 1.0 及 COAZ-MCP 工作组草案，OWASP GenAI LLM Top 10 2026 与 OWASP Agentic Top 10 2026、RFC 9110 §9.2.2、AWS SDK retry behavior、Kubernetes Pod Security Standards、OpenTelemetry traces，并参照 ReAct、Toolformer、AgentBench、WebArena、SWE-bench 和 τ-bench 原始资料。新来源、阅读范围、版本事实和证据边界见[Agent 工具调用安全证据记录](../../research/agent-tool-calling-security-2026.md)。此扫描用于检查系统设计重要问题，不代表穷尽 Agent 研究、实现或部署实践。

## 主要修订

1. 在开篇补充第十七册工具使用与计划、第二十册 runtime/权限/trace/checkpoint，以及第二十二册企业工具协议入口，明确本章只讲系统设计责任边界。
2. 更新 MCP 规范引用至 2026-07-28，加入 A2A v1.0.1；分别说明协议能力发现/消息交换和业务授权的不同职责。
3. 为委托权限交集补充共同授权项的归一化前提、资源命名映射和具体集合例子；审批完成后仍需按当前策略重新授权。
4. 补充 AuthZEN API 1.0 final 与 AARP/COAZ-MCP 工作组草案状态，避免把接口互操作和策略成熟度混为一谈。
5. 将原有文字任务流改为 Mermaid 状态机，补出等待审批、批准后重新校验、拒绝、过期、暂停、取消、成功/失败终态和恢复路径；说明 `approved` 是审批事件，不是任务状态。
6. 修正重试公式为带上限的 full-jitter 形式，并以 base 0.2 秒、cap 0.8 秒和抽样等待 0.14、0.31、0.62 秒算得累计 1.07 秒；限定为安全的瞬时失败，指出 AWS SDK 的行为受版本、配置与 opt-in 状态影响。
7. 将风险预算从单纯按工具名计数改为按动作、资源与环境加权，并给出 0.05+0.05+0.40=0.50 及再加入 1.00 后为 1.50、超过 0.70 上限的例子。
8. 新增控制面/任务面 Mermaid 架构图，展示模型提议、参数验证、PDP、人工审批、executor、工具、状态存储和审计；审批事件写入状态并返回授权重算路径，不存在模型直达 executor 的边。
9. 补充 OpenTelemetry trace 引用和采集边界，区分调试日志、审计事实及敏感数据最小化。
10. 修正单位成功任务成本口径并给出 500 个请求、400 个成功、分项总成本 600 元、每个成功任务 1.50 元的算例；成功概率使用链式条件概率而不假设独立，示例乘积约 79.6%。
11. 将注入章节的安全边界改为保留来源/信任标记、限制外发和服务端授权；新增 OWASP GenAI 与 Agentic Top 10 2026 官方入口及第八、十七册链接，不把语义过滤写成安全边界。
12. 为贯穿案例加入明确教学假设：3000 次请求的 0.8% 基线对应 24 个错误，18.4% 观测率对应 552 个，差 528 个、约为基线 23 倍；明确相关性不能证明发布变更导致错误率升高。
13. 加入 100 个脱敏任务的假设发布门槛及结果（至少 90% 完成、未授权高风险执行为 0、P95 不超过 10 分钟；例子为 93/100、0 次、8.4 分钟），并说明阈值不是行业标准，需按租户、任务类型、未知写入和人工接管分层监控。
14. 用 Kubernetes PSS 说明 Pod 安全配置基线，同时明确其无法独立证明内核逃逸防护、多租户隔离或任意代码安全。
15. 完善幂等键中的确定性规范化输入哈希、审批参数绑定、超时后的 unknown 查询，以及 RFC 9110 对非幂等重试的边界；不声称平台天然具备 exactly-once。
16. 更新证据表和参考资料入口；AWS SDK retry 与 Kubernetes PSS 新来源记入 PAPERS.md，研究事实与边界记入 research，修改决定和状态留在本审计记录。

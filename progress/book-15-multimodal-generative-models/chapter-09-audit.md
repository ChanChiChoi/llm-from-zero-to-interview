- **扫描日期与窗口：** 2026-11-12；集中核对 ASR 流式条件、语义关键字段、长 prompt/长文/场景 TTS、实时对话测量端点和音频注入。复用现有原始论文、官方规范和 `research/` 来源记录，不追求穷尽模型、API 或音频产品。

## example_status 与 formula_status

- **第一条链：** 16 kHz × 3.2 秒得 51,200 个单声道样本；25 ms 窗口为 400 点、10 ms hop 为 160 点，不补齐有效帧数为 318，center-padding 教学口径为 320；参考 5 词、1 次删除得到 WER=0.2，参考 22 个非空格字符、1 次删除得到 CER≈0.0455。解释采样/帧率、分母、空参考和规范化边界。
- **第二条链：** RVQ 输入 `[1.2, 0.1]`，两层码本重建为 `[1, 0.1]`，平方残差从 0.05 降到 0.04；3.2 秒、50 Hz、4 个码本产生 640 个 token，按 1,024 码本条目和定长索引假设得到理想 2 kbit/s、6.4 kbit。明确这是玩具输入和固定索引预算，不是 codec 质量或真实文件大小。
- **第三条链：** 四个串行假设阶段 30+180+220+190 ms 得 620 ms；限定为配置阶段串行和，排除采集尾块、网络、播放缓冲及流水线重叠。实时 latency 的公式变量、起终点及 TTFT/TTFC/TTFP/TTFA 已分别解释；RTF 不替代首包端点。
- **公式检查：** 33 个 display-math 围栏花括号平衡；围栏外 68 个未转义 `$` 标记配成 34 对。公式中的变量和单位在邻近正文定义；核心数值例子手算后再与教学代码相对照。

## code_status

- §9.17 唯一可独立执行的 Python 标准库代码块标为“已验证（2026-11-12；Python 3.12.9，标准库）”。整册复读发现尺寸/速率整数检查会接受 bool，duration/latency 也会把 bool 当数值，文本和 speaker-prompt token 计数未验证；现加入非负整数检查与有限实数检查，授权状态仍是显式 bool 字段。
- 验证方法：从 Markdown 提取完整 `~~~python` 代码块，以 `exec(compile(...))` 执行，并将 stdout 与紧邻 `~~~text` 预期结果逐字节比较；匹配。无模型、音频文件、GPU 或第三方依赖。
- 输入：单声道 16 kHz、3.2 秒、25 ms window、10 ms hop、80 mel bins；50 Hz、4 码本、每 code 10 bit、16-bit PCM；五词参考/假设文本、四个教学延迟值、2.4 秒 TTS 输出与授权布尔值。

- 边界：检查空参考的未定义指标、短音频无完整有效窗口、零采样率/非法窗口/每 hop 少于一个采样点、负延迟与未授权 speaker 状态。它不测真实 ASR/TTS/codec、听感、许可凭证或服务时间；示例阈值不是产品门槛。

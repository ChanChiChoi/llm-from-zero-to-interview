## 书册契约（book_contract）

- **读者问题：** 图像、音频和视频进入模型后如何表示，模型如何理解或生成这些媒体，怎样判断输出确实使用了输入证据，以及请求预算和质量受什么条件限制？
- **目标读者与前置：** 具备 Python、机器学习和神经网络基础，能理解矩阵运算、概率、交叉熵及 Transformer 基本结构；不要求预先熟悉多模态架构。数学按需回第十三册，PyTorch 工程按需回第十四册。
- **能力目标：** 能解释 CLIP 对比目标、视觉编码器和 VLM 连接器、多模态指令监督、Diffusion/文生图、视频生成与 world model、ASR/TTS/codec/实时对话、统一多模态架构、媒体预算及模态专属评估/安全边界；能区分架构声明、接口能力、评估结果和本地实测。
- **纳入范围：** 图文表示与对齐、视觉输入、VLM、instruction tuning、图像扩散和控制、视频生成/交互式 world model、语音和音频生成、统一多模态路线、评估与安全、encoder-free 路线及请求级多模态 token/context 预算。
- **不承担范围：** 第三册负责端到端项目；第五册负责完整规模化训练；第七册负责通用评估设计与统计；第八册负责安全控制和治理；第六/二十四册负责部署与 serving engine；第十六册负责通用 reasoning/search/test-time compute；第十八册负责产品、ROI 和运营。通用机器人/VLA 控制、服务 API 手册及产品发布门禁不扩成本册主线。
- **书册类型与独特价值：** 多模态技术教材，以“输入—表示—任务—输出—证据”连接理解和生成路线；重点解释媒体特有的时间/空间结构，而非按模型名编成索引。
- **前后交接：** 第三册多模态项目提供实现入口；第七、八册分别接评估科学与安全治理；第十六册接通用推理算法；第十八册接产品落地。模型预算相关结论交第六、二十四册核算目标服务条件。

3. 第 10 章讲各类“统一”发生在何种系统层次；第 13 章只深化 encoder-free 表示/序列路线及术语边界；第 14 章统一媒体预算核算，不复述各模型的架构机制。
4. 第 8 章说明视频生成、world model 状态转移、交互与 rollout 的机制边界；第 11 章说明相关评估协议和安全证据。WBench、物理测量评估等候选待章级定向扫描后再决定纳入位置。
5. 第 9 章围绕连续音频—离散 codec—文本/语音联合生成—实时会话组织；项目和生产 streaming runtime 交第三册/第六册/第二十四册。
6. 机器人/VLA、真实环境控制、生产 API 契约和商业化 ROI 不因世界模型、GUI/音视频 agent 等新案例而扩成本册主干；以边界和跨册链接处理。
7. 稳定后的读者承诺落入[简介](../../book-15-multimodal-generative-models/简介.md)和[目录](../../book-15-multimodal-generative-models/目录.md)；章节精修中若发现职责变化，回到本审计重新评估骨架。

# 第一册“说人话”复审：2026-11-17

## 范围与判断标准

本轮依照当前《写作规范》重新复读第一册，重点检查读者能不能跟着一段解释走完一次过程，而不是只看到术语、定义或最终结论。目标读者仍是具备基本机器学习或深度学习知识、但第一次系统学习大模型的读者。

本轮把“说人话”落实为一个可检查的问题：读者能否看见对象从什么状态开始，作者对它做了什么，关键中间结果为什么变化，最后得到什么；随后能否把例子对应到术语、规则、必要公式和限制。对适合数值演示的机制，优先使用真实技术对象的小例子；公式和代码按理解需要出现，不为形式配额增删。

此前的册级定位、逐讲扫描、来源核验和 2026-11-16 按新版规范的正文重整仍然有效。本轮复用这些证据记录，只在发现新的教学断点时补改；没有加入新的时效性技术结论，因此未另做联网扫描。

## 全册结构与阅读路径

第一册仍由五部分、九个正文文件、38 讲组成：从语言模型的预测目标开始，经 Transformer 的计算路径进入预训练、后训练、生成和评估，再扩展到多模态，最后用开放问题和学习迁移收束。简介与目录中的读者定位、章节次序和正文职责一致。复审没有发现需要调整册级架构或拆分章节的理由。

本轮沿目录顺序复核九篇的解释主线和跨篇交接，并回看需要修改的段落是否仍能接上前后文。判断重点是例子是否解释了各自的机制，不能用其他章节里一个好例子替代当前机制的讲解。

## 正文改动与例子复核

### 第二、四篇：用自然过渡代替重复的路线清单

- 第二篇把几个显式的“交接”句改为紧接前文计算的下一步，例如 ID 序列如何变成向量、当前位置怎样读取上下文、注意力权重如何得到、多个头之后回到因果预测，以及最后如何把机制合到小 GPT。变化是让读者看见“为什么接下来讲这个”，没有改变讲次和机制覆盖。
- 第四篇把重复的七项问题清单压成具体阅读路线：SFT 从一条对话样本和 label mask 进入；RLHF 从一对 chosen/rejected 回答跟踪 reward 到 policy 更新；DPO 从同一 prompt 下的回答对看 policy 相对 reference 的概率。对应细节仍在后文逐步展开。

### 第一篇：优化器先演算，再命名

- Momentum 例子取 `g₁=g₂=1`、`β=0.9`、`η=0.1`。普通 SGD 两步共移动 `0.20`；累积梯度得到 `u₁=1`、`u₂=1.9`，两步共移动 `0.29`。正文先展示这次状态变化，再命名动量并给出递推式。
- Adam 例子取两个初值均为 `1`、梯度为 `(1,10)`、学习率 `0.1`，并明确两组历史量从零开始且首步暂时忽略 `ε`。偏差修正后 `m̂=(1,10)`、`v̂=(1,100)`，所以首步两坐标更新量都约为 `0.1`。正文明确这只说明首步归一化如何工作，不代表后续所有参数总走相同距离。
- 权重衰减例子取 `θ=2`、`η=0.1`、`λ=0.1`；先把梯度更新设为零，单独计算 `2×(1-ηλ)=1.98`，避免读者误把这一项当成完整 AdamW 更新。

### 第三篇：把并行名称变成一次能跟着走的计算

- 数据 mixture：总预算 100 万 token，网页/代码从 80%/20% 改为 70%/30%，份额从 80 万/20 万变为 70 万/30 万；说明这是训练时见到的 token 份额，不是能力涨幅保证，也不一定等于原始语料比例。
- DDP：两张卡各持 `w=0` 的同一模型副本，各算一条样本的平方误差梯度 `-4`、`-16`；按等样本权重平均得到 `-10`，学习率 `0.1` 后两份模型都更新到 `w=1`。同时说明本地 batch 大小或 loss reduction 不同时不能不加区分地平均。
- TP：`x=[1,2]`、`W=[[1,2],[3,4]]`，单卡结果为 `[7,10]`；按列分给两卡，分别算出 `7` 和 `10`，再拼回原结果。正文说明这只是列切分例子，真实 Transformer 的通信还受相邻层切分布局影响。
- PP：两张卡放前后两个 stage，一批数据拆成两个 micro-batch；时序表展示前向、反向、等待与 pipeline bubble，并注明表格忽略通信时延和 stage 不均衡，不是性能预测。
- DP/PP/TP：先在 8 卡例子中把 DP 解释为两份各处理不同数据的模型布局；每份里按 PP 分成两个前后接力的 stage，每个 stage 再由两张 TP 卡共同计算。随后说明训练更新时相同 PP stage、相同 TP 位置的卡会同步对应分片的梯度。`2×2×2=8` 数的是卡数，不暗示三种并行在同一层级上做同一件事。

### 第五篇：把 GPTQ/AWQ 的抽象说法落到数值变化

- GPTQ 教学例输入为两权重线性层 `y=x₁w₁+x₂w₂`、原权重 `(1,1)` 和两条等权校准输入 `(1,1)`、`(2,1)`。假设量化后 `w₁=0.8`，两条输出分别从 `2,3` 变成 `1.8,2.6`，欠差 `0.2,0.4`。因两条输入的 `x₂` 都为 `1`，把 `w₂` 增加 `δ=(0.2+0.4)/2=0.3` 后，输出变成 `2.1,2.9`；等权平方误差和从 `0.20` 降为 `0.02`。正文标明 0.8 是教学设定，不是对 GPTQ 真实量化刻度的声明；这个两权重例子也没有复现 Hessian 补偿算法。
- AWQ 教学例取输入 `(100,1)`、权重 `(0.02,1)`，原输出为 `3`。在共用 `1/7` 刻度的对称 INT4 示例中，`0.02` 被舍入为 `0`，量化输出只剩 `1`。把第一通道输入缩小十倍、权重放大十倍后，浮点输出仍为 `3`；量化权重约为 `(0.1429,1)`，输出约为 `2.429`。正文说明十倍只是用于演示的构造值，真实缩放由校准统计和实现决定。

上述数字都是教学输入，作用是让读者复算状态变化；它们不是论文结果、模型性能保证或真实量化配方。关键公式出现在例子提出的问题之后，解释仍保留必要条件和方法边界。

## 正文修改与数值例子

- §1.4 明确本章的输入理解、证据定位和长材料主线，并链接生成式多模态评估职责；§9.1 链接本册第 13 章的 1M 有效能力评测。
- §3.2 将简化 soft accuracy 说明改为官方 VQA leave-one-out 聚合，并补充其条件规范化分支和来源边界。十位标注员中 `dog` 两票、`puppy` 八票：预测 `dog` 为 `[2×(1/3)+8×(2/3)]/10=0.60`；预测 `puppy` 为 1。仅当固定规范化协议明确合并同义词时才合并答案。
- §4.1、§7.1 说明 corpus CER/WER 的 micro 口径是汇总编辑数除以总参考单元，macro 是先逐样本求率再平均；§4.5 将 ANLS 编辑距离记号改为 `\mathrm{Lev}`，并以 `8/13≈0.615>0.5` 手算说明多余答案前缀可能触发零分。
- §9.3 保留长度×位置二维切片，避免合并不同长度后掩盖退化；§15.1 与 §15.3 补充长视频基准的互补性、rubric verifier 校准和限制。
- §14 demo 更新为 toy leave-one-out VQA、语料级 CER/WER、按长度分层的 needle 召回；零参考分母在报告中保留为 `None`，汇总字段也增加空值保护。可执行语句已变更；按本轮静态路径阅读和手算检查预期，不执行 Python demo。
- 关键手算：OCR micro CER 为 `1/27≈0.037`，逐样本 macro CER 为 `0.042`；语音 corpus WER 为 `1/11≈0.091`，逐录音 macro WER 为 `0.084`。VQA toy 三切片分数为 `(1,1,0)`、均值 `0.667`；字段准确率 `2/3`；grounding IoU 为 `1368/1672≈0.818` 与 `0`；视频 tIoU 为 `0.818` 与 `0.125`；图表相对误差为 `0.01` 与 `0.28`；针测在 32K、128K 两长度的 start/middle/end 命中均为 `1/0/1`；多证据覆盖为 `1` 和 `0.5`、均值 `0.75`。按代码的 toy 阈值，预期动作是修订评测后再比较；这些数字仅为给定合成输入的手算，不是模型或 benchmark 实测。

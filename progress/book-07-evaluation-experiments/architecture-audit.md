# 第七册架构审视

审视日期：2026-11-02—2026-11-03  
范围：册级定位、简介、目录、章节地图与册级研究扫描；未通读本册章节正文。

## Book contract

- **定位：** 大模型评估、实验与科学方法教材，回答如何判断模型、应用或完整系统在指定任务与条件下是否真实改进。
- **目标读者：** 模型评估、实验平台、算法研究、应用验证和上线实验岗位的学习者，以及需要比较模型/应用版本和分析 bad case 的工程师。
- **前置知识：** Python、机器学习/深度学习基础、概率统计入门；了解 LLM 生成、RAG 与工具调用会有帮助。无需预先掌握高级统计推断，本册第 10 章提供对应主线。
- **能力目标：** 将目标转为任务、数据、指标与协议；使用人工、pairwise 与 LLM judge；检查污染、偏差和饱和；设计统计比较与 A/B 测试；分析错误并限定证据结论；评估前沿模型和 model–harness–environment 组合。
- **范围：** 评估任务是否测到目标、样本/判分/协议是否可信、差异是否稳定，以及结果能够支持什么决策和结论。正文使用模型、系统与 Agent 案例，但不重讲它们的完整实现。
- **类型：** 12 章连续方法主线，后接长上下文、前沿模型证据、专业任务簇 3 个专题。
- **书系分工：** 第六册负责推理服务、运行时指标、生产 SLO、容量与成本；第八册负责 safety/alignment 风险、控制和治理；第十册负责论文阅读、复现和研究方法；第十五册负责多模态模型机制；第十七册负责 Agent 任务循环与工具使用；第二十册负责 harness/runtime 实现；本册讲这些对象的评测协议和结果推断。第三册提供项目验证练习，本册补足其方法依据。

## 架构决定

**保留现有 12 章核心路径与 3 个专题章节，不增章、不重排。** 核心路径从任务定义、判分与可信度，推进到领域评估、线上实验、统计推断、错误分析和评估系统；三个专题分别深化长上下文有效能力、前沿模型证据审计和专业任务簇。册级扫描发现的新方法和风险都能落入现有章节，且目录没有显示缺少一个独立的能力链。

第 15 章现有标题明确包含 benchmark 饱和、任务/环境/轨迹、专业评测簇、harness、轨迹指标、部分成功与危险失败、污染抽样、统计稳定性、发布动作、失败归因和复现包；第 13 章覆盖长上下文任务、有效长度、预算与对外声明；第 14 章覆盖来源、条件、复现、证据冲突和结论边界。因此不以新增重复专题替代逐章精修。若后续章节正文暴露实质覆盖缺口或边界冲突，再回到本架构步骤复审。

## 待逐章核验的风险

1. 第 13 章涉及 KV、prefill、Serving 和生产服务，需要维持“评估条件/有效能力”与第六册“运行时/容量工程”的边界。
2. 第 8 章讨论安全评估，应保持测试协议和风险控制/治理的边界，与第八册对齐。
3. 第 15 章主题跨度大，逐章审阅需验证各任务簇具有足够机制、指标、例子和证据，而非停留在案例清单。
4. 第 15 章的 harness 和 Agent 失败归因要区分完整配置的观察结果、候选机制和已验证因果解释，并与第十七、二十册分工。
5. OpenAI Evals 等服务状态会变化；正文涉及动态工具时按当时官方文档核验，不把单一供应商界面当成稳定方法。
6. 旧外链和代码状态要按逐章门禁审查；未执行代码不能记成已运行。本轮没有运行代码、测试、模型、benchmark 或 PDF 构建。

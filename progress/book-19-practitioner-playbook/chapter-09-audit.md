## 证据、公式与例子状态

- **evidence**：RAG 原始论文用于参数/非参数记忆的设计来源，不能代表企业知识库生产质量；Lucene 10.3.1 文档用于 BM25 词频、长度归一化和 IDF 解释，参数/分词器仍依实现；Järvelin 与 Kekäläinen 2002 论文支持分级相关性、排名折扣及理想排序归一化，本章固定一套线性增益/log2 折扣手算口径。Ragas 官方文档说明其 `Context Precision` 使用排序位置；FORCEBENCH、RAG-Safety-Bench 和 USENIX Security 2026 结果均限定于各自测试条件。OpenAI Retrieval API 的 metadata filter 不构成用户身份验证或 ACL 保证；OWASP 2026 是威胁建模入口而非认证。细节与来源状态见两份研究记录。
- **example_status**：E1427 的 error 文档与通用登录文档是教学构造，说明稀疏精确词项和稠密语义近邻可能不同，不表示固定排序。nDCG 样例等级 `[1,2,0]` 对照理想 `[2,1,0]`，按线性增益和 `log2(j+1)` 折扣得到约 `0.860`。9.16 账本手算：retrieval Recall 宏平均 `2/3`、MRR `0.625`；最终 context 集合召回/精确率均 `5/12≈0.417`；claim 支持 `5/8=0.625`；旧证据出现率 `2/9≈22.2%`；权限泄露为证据条目口径 `1/9≈11.1%`、请求口径 `1/6`；正确拒答 `1/2`、误拒 `0/4`；超预算 `1/6`、超出 60 token；六条耗时按第八章零起始线性插值得 P95 `1,687.5 ms`；总成本 `0.125`、两项成功，单位成功任务成本 `0.0625`。所有数据为教学构造，不估算线上比例或发布目标。

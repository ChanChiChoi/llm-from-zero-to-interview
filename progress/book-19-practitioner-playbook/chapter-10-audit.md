## 证据、公式与例子状态

- **evidence**：ToolSandbox 用于说明有状态工具和中间/最终里程碑评估；AgentDojo 用于说明工具输出注入的测试设计；`Ignored, Not Refused` 用于支持同时记录攻击行为和任务结果，正文明确其两个合成单 Agent benchmark、小型开源模型和静态攻击等局限。Agentic CLEAR、OpenAI Agent eval、OWASP Transaction Authorization、OpenAI Structured Outputs、Agents SDK tracing 与 OpenTelemetry GenAI 约定分别用于其论文/公开接口/工程指导范围；详细版本和证据边界见研究记录。没有来源能证明本地系统安全或本章构造数据代表生产表现。
- **example_status**：E-81、O-17/U-81、销售计划、网页注入、`JOB-42` 和五条审计记录均为合成教学构造。五条记录共 12 次动作：工具状态为 success 5、empty 4、failed 1、blocked 2；独立任务成功 1/5，误报完成 1/5；允许工具选择 11/12，schema+业务检查 10/12；两次未允许提议均被阻断，实际未授权副作用 0；三个高风险提议均未确认，确认覆盖 0/3；超预算任务 1/5；外部执行日志确认 12 次动作，trace 可还原 10 次；注入样本 `S=0,U=0`。这些比例只描述构造样本，不是线上风险率或通用门槛。
- **formula_status**：共 8 个 `math` 围栏，覆盖任务状态元组、工具选择、参数有效率、确认覆盖、预算超限、任务成功、误报完成和 trace 完整性；逐一核对定义域、分母和 `unknown/not_applicable` 语义。授权拒绝次数与已发生的未授权副作用不合并成比例；注入行为用 S/U 分类而不把两种结果混成单一 ASR。未检查 GitHub 页面实际 MathJax 渲染。
- **code_status**：旧约 400 行演示审计脚本已删除，正文不含 Python 或其他可执行代码；代码/公式围栏均为说明性格式。未运行书中代码、测试、模型、API 或 benchmark。

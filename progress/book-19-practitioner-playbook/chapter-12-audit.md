## 章级扫描与候选去向

扫描与核验日期：2026-11-17。扫描问题：安全控制在模型应用的数据流、工具副作用、数据用途和外部服务边界上如何失效；如何不把“没证据”算作安全通过，也不让指标代替法律判断？来源事实和证据边界单独保存在[安全数据生命周期与治理来源记录](../../research/security-data-lifecycle-and-governance-sources-2026-11-17.md)；相关对抗评估分类和 OWASP 2026 事实沿用[安全审核系统与对抗评估证据](../../research/safety-review-system-evidence-2026-11-05.md)。

| 候选主题 | 去向与判断 |
| --- | --- |
| Prompt injection、外部内容与 Agent 副作用 | 保留 12.3、12.5；将“攻击句是否被拒绝”扩为模型计划、工具提议、执行侧权限和最终副作用四层。OWASP 只能支持风险分类与缓解建议，不能证明有单一完备防御。 |
| RAG 与派生对象 ACL | 保留 12.4；明确未授权 chunk 不应进入模型上下文，权限变化要沿 OCR/embedding/cache 等派生对象传播，缓存键绑定主体、租户、权限和知识版本。机制细读交第九章及相关专题。 |
| Agent 身份、对象归属与动作确认 | 保留 12.5；将工具 schema 合法、当前主体获准、精确动作已确认、后端副作用成功分别记录；确认不扩大权限。Runtime 沙箱回链第二十册，工具权限协议回链第二十二册。 |
| 日志、hash 与删除请求 | 保留 12.6—12.7；补充稳定 hash 可能被枚举/关联，删除审计也需目的、访问和保留规则；删除数据集副本与改变既有模型参数是不同技术问题。 |
| 训练、反馈和用户同意 | 保留 12.7；修正“训练 consent”口径：处理依据不一概等同于同意，GDPR Article 6 中同意只是一个可能依据；仅在依据字段缺失时将法律状态记 unknown，仍阻断内部准入，不把未知处理状态伪装成已证明违法。 |
| 外部服务、DPA 与跨境传输 | 保留 12.8；补充签订处理协议本身不能证明某次传输符合适用条件；具体角色、地区和机制须由责任人核验，运行门禁失败与法律状态 unknown 可以同时存在。 |
| 过度拒答、版权和多模态风险 | 保留 12.9—12.11；正常请求误拒与危险样本漏拒分别统计；内容来源凭证不等于授权；媒体派生文本继续继承来源和 ACL。 |
| 风险评估、删除与响应指标 | 保留 12.12—12.18；分别定义越权暴露、精确确认、日志敏感字段、训练候选、审计事件和正常请求误拒的单位。审计分母从独立必需事件清单构造，避免只看日志表现存行。移除不支持的通用性能成本指标和跨项发布分数。 |
| 原 12.16 长 Python 审计器 | 删除约 490 行示例代码、硬编码阈值、`assert` 和自动 `release_decision`；用 10 条构造事件手工复算彼此独立的控制，更符合本章的事故诊断任务，也不将教学自设阈值包装成法规或行业门槛。 |

# 第六章《终端执行与命令安全》精修审计

审计日期：2026-11-18。状态：完成章级扫描、正文重构、配套题目同步和静态文档检查；第二十册第 7—24 章待逐章处理。

## Reader path 与章节结果

- **读者前置：** 能读简单命令、工作区路径和退出码；无需熟悉某一 Agent 产品的权限配置或特定操作系统 API。
- **书册贡献：** 将第四、五章的工具调用合同和文件版本边界推进到进程执行层；让读者分清命令提议、策略判断、用户确认、OS 执行边界、进程回执和任务验收。后续权限/沙箱由第八章展开，trace 由第九章展开，命令输出如何进入下一轮上下文交第七章。
- **中心问题：** 怎样让 Coding Agent 使用终端完成必要工作，同时把可触及的文件、网络、凭据和资源限制在明确范围内？
- **预期结果：** 读者能检查一条执行请求的主体、参数、工作区、预期效果和预算；解释命令规则、确认、OS 沙箱、网络策略和资源限制各自保护什么；区分进程结束状态与任务成功；在超时、截断或副作用未知时给出可复核的后续步骤。
- **主要任务与讲解路径：** 系统/工程机制解释。沿第五章显示名修改任务建立一条独立的合成终端执行分支：假设目标测试返回 4 项通过、1 项失败，解释退出码 1、输出截断和任务未验收之间的关系；明确该结果未在本地运行，与第五章的合成结果都不是实测。

# 第五章《文件系统与代码编辑》精修审计

审计日期：2026-11-18。状态：本轮章级扫描、正文精修与静态检查完成；第二十册第 6—24 章待逐章处理。

## Reader path 与章节结果

- **读者前置：** 能读文件路径、简单代码片段和 Git diff；无需熟悉文件系统内核或生产级代码 Agent。
- **书册贡献：** 把第四章交出的工具合同落实到文件访问与编辑层，明确 workspace 路径、文件版本、并发写入、实际 diff、验证和回滚的边界；交第六章命令执行、第八章授权/沙箱和第九章 trace。
- **中心问题：** Agent 怎样找到正确文件、基于仍有效的内容做最小修改，并在用户并发编辑后保护最新状态？
- **预期结果：** 读者能区分路径字符串与真实文件对象、搜索命中与语义目标、patch 提议与写入事实、写入回执与任务验收；能解释 stale-write 冲突、说明 diff 基线，并设计不覆盖用户新改动的回滚。
- **主要任务与讲解路径：** 系统/工程机制解释。贯穿一条输入限定为字符串或 None 的显示名修改教学构造：rev-17 有两个相同文本命中；用户加上 None 分支令文件变为 rev-18；基于 rev-17 的 patch 被拒且不写入；重读后仅修改目标行得到 rev-19；合成测试回执为 $4/5$，不能报告验证通过；用户后续改至 rev-20 后，旧版本回滚请求也被拒绝。

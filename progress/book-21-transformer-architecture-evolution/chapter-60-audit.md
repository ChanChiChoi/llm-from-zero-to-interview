# 第六十章精修审计

## 章节职责与旧稿诊断

本章承接第五十九章的历史模型案例综合，回答读者遇到新模型或架构论文时如何判断“变化了什么、证据支持到哪里”。第四十二章继续负责 Attention、SSM、卷积等序列架构家族比较；第五十章讨论替代与组合设计的开放问题；第五十九章综合第五十一至五十八章的固定版本历史案例。本章聚焦新主张的结构对象、信息路径、资源预测和证据边界，不重复这些章节的知识主线，也不承担第六、十七、二十、二十四册的推理服务或 Agent 操作手册。

旧稿有 27 个二级标题，堆入模型评估表、统一资源账本、单位成功成本、训练—推理一致性、kernel/回滚、安全和 Agent 生命周期检查等内容。它同时把 MLA、MoE、SSM、memory、retrieval、推理与工具放在通用新模型审计清单中，未区分它们改变的是 attention 缓存、参数路由、递归状态还是外部信息源；“下一代系统很可能如何组合”等判断也超出当前证据。正文缺少有效章节大纲，旧标题与第四十二、第五十、第五十九章及其他书册职责交叉。

## 结构与正文决定

- 将标题修订为“读懂新架构主张：信息路径、资源变化与证据边界”。新章以架构主张为判断对象，采用六节、十六个编号小节：从版本和变化层级出发，拆解机制与预测；对照 MLA、MoE、递归状态、内部/外部记忆和 Agent 闭环；再联系资源、任务压力点、来源与因果证据，最后给出有限的未来判断。
- 新建[现行章节大纲](../../写作规范/全套书不同册的章节大纲结构/book-21-transformer-architecture-evolution/60-新架构主张的信息路径资源与证据.md)，逐节定义中心思想和范围；保留原章节文件路径。正文跟随大纲重新组织，使用 DeepSeek-V2 与 Mamba/Mamba-2-Hybrid 研究展示“整体模型结果不等于单组件因果收益”及“任务切片会改变比较结论”，并以 RETRO、Titans、ReAct 区分外部检索、模型内可更新记忆和 action-observation 系统。
- 删去通用生产回滚、安全门、API/runtime 运行手册和 unit-success 公式；正文无数学公式、代码、Mermaid 或图片。资源表和证据表仅用来解释结构对象与可观察主张之间的对应关系，不生成模型总分或无条件推荐。

## 范围与研究问题

- 完整阅读本章，保留 22 个连续一级编号和专题分支位置。章级问题是：架构论文究竟改变了哪条信息、计算或状态路径；论文是否将架构变化与训练数据、模型规模、token 预算、kernel、硬件和评测协议分开；注意力、MoE、SSM 和混合结构应怎样用可复算账本比较；作者实验的收益能支持到哪一层结论。
- 定向扫描 2024—2026 年注意力缓存压缩、稀疏注意力、状态空间/递归更新和混合架构研究。核阅 DeepSeek-V2 v5、Mamba-2/SSD、Jamba v2、NSA v2、Gated Delta Networks 与 Mamba-3 的原始论文及相关实验段落；复核 Gated DeltaNet-2 v1 的方法、设置和结果边界。Kimi Linear v2 与 DeepSeek-V4 的混合结构使用已建研究记录中的原文证据。来源版本、阅读位置、证据等级和限制见 [`transformer-architecture-research-2026.md`](../../research/transformer-architecture-research-2026.md)。
- 本轮扫描聚焦本章主问题，不是对所有架构论文的穷尽检索。深度残差聚合、log-linear 递归状态、mHC、激活函数替换等相邻候选保留在研究资料中，没有扩展成新的独立教学单元：它们改变的是深度方向聚合、状态尺度或 FFN/残差子结构，超出本章以序列交互、缓存、路由和递归状态为主的解释链；后续章节或专题入口可按读者需求再纳入。

## 候选主题与处置

| 候选主题/缺口 | 判断与证据边界 | 去向 |
| --- | --- | --- |
| 只记架构名称，难以从论文问题出发筛查瓶颈 | 架构变化可能影响表达路径、计算、状态、通信和维护成本；模型名称本身不构成可检验主张。 | §1 增加 workload 到瓶颈变量的 Mermaid 初筛图，并强调 MoE、稀疏注意力和混合架构可同时命中多个分支。 |
| Attention 复杂度、分数矩阵物化和 kernel 内存优化常被混为一谈 | 标准 self-attention 的位置对交互仍是二次规模；FlashAttention 类方法减少中间矩阵物化与访存，不自动把信息依赖改为线性。 | §2.4 用 batch=1、32 heads、BF16 手算 2,048 token 的 256 MiB 和 8,192 token 的 4 GiB，并说明只计单层完整分数矩阵。 |
| GQA 之外缺少潜变量缓存路线及归因边界 | DeepSeek-V2 附录 D.2 的两组 MLA/MHA attention 变体比较比摘要中的全系统 93.3% 缓存降幅更接近组件证据；仍有激活参数等差别，且只覆盖论文配置和所选 benchmark。 | §9.4 解释 MLA 的低秩 KV latent 与独立 RoPE key；区分附录消融和整模型比较，并给 §14 的独立缓存账本提供机制入口。 |
| 稀疏注意力只有算法描述，缺少硬件和测量条件 | NSA 同时报告层级稀疏路径、原生训练和硬件对齐实现；最高速度属于其 64K、8×A100、Triton、配置和基线条件，不能外推为通用加速。 | §5.5 将 NSA 作为带条件的实验阅读例子，速度数字和长上下文能力保持分离。 |
| MoE 仅用 active parameters 代表便宜 | 总参数、每 token 激活参数、路由偏斜、capacity、token overflow、通信和权重驻留回答的是不同资源问题。 | §§10、15 补齐负载 skew、容量和静态存储手算；公平比较要求对齐训练预算、质量切片和部署拓扑。 |
| SSM 线性复杂度容易被写成 attention 等价或长上下文全面胜出 | SSD 的对偶只适用于定义明确的结构化子类；递归状态、训练分块算法和真实检索能力属于不同层次。Gated DeltaNet 和 Mamba-3 的结果也绑定各自模型、数据、评测与硬件。 | §11 解释 Mamba-2 SSD，加入 Delta rule 两维单步写入算例、Gated DeltaNet 结果边界和 Mamba-3 特定对照；Gated DeltaNet-2 仅作追踪入口。 |
| attention、递归状态和压缩注意力混合时容易把整模型结果归因给单个模块 | Jamba 的层比例属于指定模型和训练预算；Kimi Linear 与 DeepSeek-V4 披露了各自状态路径，但组合模型结果不能证明每个组件的单独因果贡献。 | §12.3 加入 Jamba、Kimi Linear、DeepSeek-V4 的结构例子，要求追踪各自状态、消融和调度成本，不推广固定混合比例。 |
| 资源算式和架构讨论缺少能互相核对的案例 | 缓存字节数、专家负载和任务切片需要显式输入、中间量、分母与目标工作负载。 | §§14—16 分别用同一模型形状比较 MHA/GQA/MQA/MLA、构造 MoE 负载案例、构造 attention/SSM 分层任务与资源例；所有示例数字标明是教学输入。 |

## 修改决定与正文结果

1. 保留全章 22 个一级主题及原有论证顺序，以“先找瓶颈—说明机制—复算资源—核验证据—限定部署结论”为贯穿主线；不新增独立章节。
2. §8.3 将“开放模型/开源”拆成论文、代码、权重和许可等不同公开层次，避免从 LLaMA 的公开资料过度推断其可复现性。
3. §9.4 新增 MLA 的内容 key/value 潜变量、解耦 RoPE key 和缓存宽度关系；分别说明论文附录两尺度比较与 DeepSeek-V2 对 DeepSeek 67B 的系统级摘要数字，避免将 93.3% 缓存降幅归因于 MLA 单项。
4. §11 补入 SSD 的递归与分块矩阵计算视角，明确不是标准 softmax attention 与任意 SSM 的等价定理；补 Delta rule 的 2×2 单步状态更新手算，并将 Gated DeltaNet、Mamba-3、Gated DeltaNet-2 的证据限制在其来源模型、数据、任务和硬件。
5. §12.3 将层间比例、递归状态与全局/压缩 KV 路径作为实验变量；Kimi Linear 和 DeepSeek-V4 是结构入口，不用模型总结果证明某一算子单独有效。
6. 扩写 §§14—16 三个独立案例和 §§17—20 的连续证据卡、资源账本、代码、证据等级及讨论表达单元。第 18 节 demo 复用 §14 参数，只核算缓存与固定状态 proxy，不声称测得质量、kernel 吞吐或真实模型状态。
7. 新研究事实与来源边界写入 research 记录；`PAPERS.md` 架构来源列表新增 DeepSeek-V2 MLA、Mamba-2 SSD、Gated Delta Networks、Mamba-3、Jamba 和 NSA。简介与目录中的第七章问题和产物仍准确，未修改简介、目录、题库、练习或 `plan.md`。

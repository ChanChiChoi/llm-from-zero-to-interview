## 例子、公式、代码和链接状态

- **例子**：构造短问答和长 RAG 两类请求，单位分别为 req/s、input/output token；手算 `D_in = 10×500 + 2×6,000 = 17,000 token/s`，`D_out = 10×100 + 2×300 = 1,600 token/s`。长 RAG 占 2/12 ≈ 16.7% 请求、12,000/17,000 ≈ 70.6% 输入、600/1,600 = 37.5% 输出。数值明确标为假设输入；不推导 GPU 数、延迟或实测性能。
- **公式**：workload vector 中请求类、到达率、长度期望/分位、服务目标、质量安全与失败规则均有定义；输入/输出需求公式按请求类求和，单位与后面的手算一致。尖括号数学下标、`\operatorname` 和 `\text` 下划线检查无命中。
- **代码**：改后本章没有代码块；旧版 Python demo 因重复而移除。本轮未运行、未测试任何章节代码。
- **图示**：保留文本请求路径图和决策/验收表；没有 Mermaid，故无需目标平台 Mermaid 渲染门禁。
- **链接/格式**：简介、目录和本章合计 50 个相对 Markdown 链接目标均存在；10 个代码围栏标记为偶数、成对；`git diff --check` 通过。外部链接未全量在线核查。

审计日期：2026-11-02。当前阶段：书册定位、简介/目录审视、册级扫描与骨架决定完成；第 1—18 章均已完成通读、章级扫描、正文精修和静态门禁。第六册沿阅读路径的连续复读与全册最终门禁尚待完成。本记录只追踪审阅决定、修改状态与交接；联网发现的技术事实及来源证据记录在 `research/`。

## 1. 书册契约

- **定位**：解释如何把已训练模型或受管模型 API 变成满足目标质量、延迟、吞吐、容量、可靠性、安全和成本约束的在线/离线推理服务。本册主讲服务工程决策与运行边界，不是训练教材，也不是推理框架源码逐行导读。
- **目标读者与前置**：面向准备 LLM serving、推理优化、部署/后端和应用系统设计岗位的读者。建议知道 Transformer 自回归推理、Python 与基本 GPU/服务概念；第一至第四章补足本册需要的推理和服务测量基础，不要求已有 vLLM/SGLang 源码经验。
- **读者所得**：能从请求分布和目标 SLO 出发，定义测量口径，估算显存/活动 KV/副本需求；比较引擎和量化 artifact；设计批处理、请求调度、多 GPU 和多模态/RAG/Agent serving 路径；根据指标定位瓶颈；评估质量/安全发布门槛与单位成功成本；把容量、故障、回滚等条件纳入生产方案。
- **纳入范围**：推理阶段和测量、请求与 KV 状态、生成参数、runtime 选型、continuous batching 与 prefill/decode 调度、权重与 KV 低精度部署、多 GPU serving、RAG/Agent/多模态的服务集成、运行时观测与发布、成本账本和生产设计/故障分析。
- **不承担的范围**：模型训练与量化算法研究详见第五册；基准设计、统计检验与模型能力评估方法详见第七册；多模态建模方法详见第十五册；Agent 协议/规划/评测/安全主体详见第十七、二十、二十二册；AI 平台、集群资源调度、存储/网络和平台治理详见第二十三册；vLLM/SGLang 调度器与执行路径的源码级实现详见第二十四册。第六册只在部署问题所需的粒度解释接口、状态和方案取舍，并交叉指向主讲册。
- **类型与读法**：面向服务工程师的递进式工程教材，1–14 章为核心路径；15–17 章是低精度部署专题分支，18 章是绑定官方公开合同的托管 API 预算案例。可沿完整路径阅读，也可从核心路径进入专题；专题不取代前置章节。
- **前后交接**：从第五册训练产物、artifact 与发布审计接入；为第七册评估科学和第二十三册 AI Infra 提供运行时测量及系统边界；需要内部实现时下接第二十四册。

# 第九册简介：大模型数据工程与数据智能

## 书册契约

本册面向负责训练语料、后训练样本、评估集和数据平台的工程师、研究人员与技术负责人。读者通常具备基础 Python、表格/文件处理、SQL 或 ETL 概念，并了解 Transformer、大模型预训练和 SFT 的基本流程；缺少这些前置时，可先读[第五册训练全流程](../book-05-llm-training/简介.md)的入门部分。本册不要求读者预先掌握数据治理法规或多模态模型结构。

本册是一部沿数据生命周期展开的应用型教材。它从来源登记和采集开始，依次讨论解析、质量过滤、去重与污染控制、训练分布设计、专项与合成数据、偏好/安全数据、多模态数据、数据价值、版本治理，最后以综合系统设计收束。读者可以按完整主线学习，也可以从目标数据类型进入专题分支。

## 学完后应具备的能力

1. 为训练或评估任务定义数据契约，说明来源、用途、结构、风险、权限和验收标准。
2. 设计可回放的采集与解析流程，保留原始对象、处理版本、样本血缘和拒绝原因。
3. 按语言、领域、任务和风险切片校准清洗、质量、去重与污染策略，并用抽样或小规模模型实验检查误删和漏删。
4. 将能力目标转成有约束的 data mixture，区分自然比例、采样比例、训练阶段和有效 token 暴露量。
5. 为代码、数学、领域、合成、偏好、安全、语音和视频样本定义各自的结构、验证器与错误边界。
6. 用有限预算比较数据源或样本对目标任务的边际价值，区分相关性线索、消融证据和可支持的因果结论。
7. 建立数据集版本、manifest、权限、删除回放和发布文档之间的可追踪关系。
8. 诊断数据变更怎样影响训练、评估和模型行为，并给出回滚或重新评估条件。

## 范围与边界

本册主讲数据对象、来源与转换、样本质量、数据分布、评估污染、版本血缘和治理流程。第五册主讲训练目标、优化和训练系统；第七册主讲评测设计与统计；第八册主讲安全行为和安全治理；第六册主讲多模态模型与部署系统；第二十册主讲 Agent harness 和 runtime。相关主题在本册以数据接口和证据交接为主，不重复相邻书册的完整算法或系统实现。

许可、隐私和 AI 监管部分用于解释数据工程需要保存哪些证据、建立哪些流程，不构成任何司法辖区的法律意见。benchmark、数据集论文和合成数值只支持其公开条件，不证明本地数据有权使用或目标模型会获得同样收益。

## 阅读建议

- **完整主线**：第一章建立共同的数据对象和生命周期，再读第二至第四章的数据进入、筛选和可信度，接着读第五至第九章的训练分布和数据类型，最后读第十、十一章与综合设计。
- **训练数据平台**：第一至第五章为主线，第六至第九章按数据类型选读，之后读第十至十二章完成估值、治理和系统设计。
- **后训练与对齐数据**：先读第一至第四章，再读第七、第八章；需要媒体监督信号时接第九章，最后读第十至十二章。
- **多模态数据工程**：先读第一至第四章，再读第九章，接第十一、十二章处理血缘、权限、删除和全链路验收。
- **数据估值与治理**：先读第一至第四章建立来源和质量口径，再读第十、十一章，最后用第十二章走一次端到端复盘。

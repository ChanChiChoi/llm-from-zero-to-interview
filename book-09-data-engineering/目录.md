# 第九册：大模型数据工程与数据智能

本册回答一个贯穿训练、评估和发布的问题：怎样把原始数据变成来源清楚、质量可测、分布可控、结果可回放的数据产品？读者可先看[本册简介](简介.md)确认前置和范围。

## 阅读主线

完整路径是“建立对象与生命周期 → 获取和筛选来源 → 控制重复与评估污染 → 设计训练分布 → 构造专项/生成/偏好/多模态数据 → 估值和版本治理 → 端到端诊断”。第一章提供路线图；第二至第四章是所有后续章节共享的数据入口和质量基础；第五至第九章是可按任务选择的并行分支；第十、十一章将实验决策和治理证据收束；第十二章要求读者把各环节接成可回放的系统。

## 按目标选读

- **从零搭训练数据平台**：按第一至第五章顺读，依据目标增加第六至第九章，再读第十至十二章。
- **构造 SFT、偏好或安全语料**：先读第一至第四章，再读第七、第八章；需要视频/音频监督时增加第九章。
- **做去污染、benchmark 或数据价值审计**：重点读第一、第三、第四、第五、第十和第十一章，最后用第十二章设计回放流程。
- **治理多模态或受限来源数据**：重点读第二、九、十一章，并用第十二章检查权限、删除、对齐和发布证据能否闭环。

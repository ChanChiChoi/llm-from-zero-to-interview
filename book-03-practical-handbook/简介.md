# 第三册简介：大模型算法岗实战手册

## 这本书解决什么问题

读者学过模型概念、看过公式，也知道常见框架，但动手时仍可能不知道数据怎样进入模型、一次训练到底改变了什么、评估数字是否可信，更难把这些过程讲成一个经得起追问的项目。本册把这些知识接成一条实作路径：先实现可观察的小模型，再调整回答行为、搭建应用、测量失败，最后形成可复核的项目证据。

它是一册项目训练教材，不是代码片段合集，也不把“程序运行了”当成“模型有效”。每个项目都要回答：输入是什么、处理经过哪些状态、输出如何核验、数字代表什么、失败时先看哪里、结论能推广到哪里。代码让机制可以运行，手算例子让读者知道代码在算什么，评估和失败记录说明结果有什么证据。

## 读者与前置

本册适合具备基础 Python 和机器学习概念、希望把大模型原理转化为代码和项目成果的读者。第一册提供共同技术主线；第十四册可补 PyTorch 工程细节。不会假设读者已熟练掌握大规模训练平台、GPU 集群或 Agent runtime。

## 学完后应能完成

1. 用 PyTorch 检查张量、损失、梯度和优化过程，并实现 Transformer 关键组件。
2. 从 token 数据契约开始训练一个小 GPT，解释曲线、生成样例与 checkpoint。
3. 使用 Hugging Face 工具完成 SFT、LoRA/QLoRA 和偏好优化实验，并审计监督范围与行为变化。
4. 测量模型服务的 KV cache、prefill/decode、延迟、吞吐、成本和多轮负载。
5. 构建带证据引用和受控工具调用的 RAG/Agent 项目，能回放并定位失败。
6. 为语言和多模态任务建立评估、回归与交付报告，知道本地 toy、公开来源和真实线上结果之间的证据差别。
7. 把项目整理成包含代码、数据契约、配置、运行记录、失败样例和本人贡献的作品集，并在面试中解释取舍。

## 本册边界

本册侧重教学规模的代码与项目流程。它不替代第五册的大规模训练、第六册的生产部署、第七册的评估方法、第九册的数据工程、第十五册的多模态生成模型、第十七册的 Agent 方法、第二十册的 Harness runtime、第二十四册的 Serving Engine 或第十二册的求职策略。多模态部分只练习图文理解与检索、Diffusion 数值、语音问答和系统交付；更宽的图像/视频/语音生成、实时多模态交互和统一模型留在第十五册展开。

## 全书主线

前十章构成必读路径：把数学写成训练循环，把组件组成小 GPT，再把模型适配、服务化并接入知识证据和受控工具动作；随后分别检查离线测量、Agent 执行轨迹和线上发布风险。第七章的 RAG 解决“依据什么回答”，第八章的 Agent 解决“允许采取什么动作”；先建立证据，再把证据服务交给执行流程。第九章分析离线评估与训练排障，第十章继续到轨迹回放、线上实验和灰度决策。第十一至十四章是可选的多模态实践支线，分别处理图文、扩散、语音和交付。第十五章把前文项目整理为可复核成果，第十六章练习技术表达和系统设计。

```mermaid
flowchart TD
    A["PyTorch：预测、损失与更新"] --> B1["输入表示：id、embedding 与位置"]
    B1 --> B2["Attention 与 Mask：上下文如何形成"]
    B2 --> B3["Transformer Block：残差与前馈层"]
    B3 --> B4["现代组件：RoPE、RMSNorm、SwiGLU"]
    B4 --> C["小 GPT：数据到生成"]
    C --> D["SFT / LoRA：改变回答行为"]
    D --> E["偏好优化：比较与验证"]
    E --> F["推理：测量服务预算"]
    F --> G["RAG：证据回答"]
    G --> H["Agent：受控动作"]
    H --> I["离线评估与 Debug"]
    I --> J["Agent 轨迹与线上实验"]
    J --> K["作品集：可复核交付"]
    K --> L["面试：从约束和证据作答"]
    B --> M["图文理解与检索"]
    D --> N["Diffusion 数值实验"]
    H --> O["语音识别与问答"]
    M --> P["多模态评估与交付"]
    N --> P
    O --> P

```

每一章都有一个交接产物：代码不只展示“怎么写”，也要带出可核对的中间量、可复算的数值例子和限制说明。完成作品集时，应回看第九章的离线评估、第十章的轨迹与线上验证，以及第十四章的多模态交付要求，为结果补上固定数据、版本、实验条件和失败样例。面试中的指标只能描述自己实际运行并保存证据的范围。

## 各章摘要与衔接

1. [PyTorch 基础实战](chapters/01-pytorch基础实战.md)用一次可检查的预测、损失和参数更新建立数值基线，交给 Transformer 组件复用。
2. Transformer 组件实战分成四个连续部分：[上篇：输入表示](chapters/02-transformer组件实战-1-输入表示.md)从 token id 追到带位置的向量；[中篇：Attention 与 Mask](chapters/02-transformer组件实战-2-attention与mask.md)说明上下文怎样在可见性约束下汇聚；[下篇：Block 骨架](chapters/02-transformer组件实战-3-decoder-block.md)讲清注意力、前馈层、残差与归一化怎样组成一层；[续篇：现代 Decoder 组件](chapters/02-transformer组件实战-4-modern-decoder.md)再把 RoPE、RMSNorm 和 SwiGLU 放回这副骨架。四部分的 shape 与位置账本交给小 GPT 章节复用。
3. [从零训练小 GPT](chapters/03-从零训练小gpt-1-token数据.md)分为五篇：[Token 数据契约](chapters/03-从零训练小gpt-1-token数据.md)、[最小 GPT 与训练](chapters/03-从零训练小gpt-2-model-training.md)、[解码控制](chapters/03-从零训练小gpt-3-decoding.md)、[Checkpoint 与评估](chapters/03-从零训练小gpt-4-checkpoint-evaluation.md)、[Tokenizer 与公平比较](chapters/03-从零训练小gpt-5-tokenizer-comparison.md)。它从训练窗口走到可复核的模型行为，为监督微调交付数据、checkpoint 和评估协议。
4. Hugging Face 微调实战分成七篇：[模型与生成](chapters/04-huggingface微调实战-1-模型与生成.md)先固定基座行为；[SFT 数据](chapters/04-huggingface微调实战-2-sft数据.md)标出哪些回答 token 参与训练；[数据审计与全参数 SFT](chapters/04-huggingface微调实战-3-data-audit-full-sft.md)检查切分、截断和版本，再建立全参数训练基线；[LoRA](chapters/04-huggingface微调实战-4-lora.md)与 [QLoRA](chapters/04-huggingface微调实战-5-qlora.md)比较低秩适配和量化基座；[评估协议与指标](chapters/04-huggingface微调实战-6-evaluation-metrics.md)固定比较条件；[自动评估与报告](chapters/04-huggingface微调实战-7-evaluation-report.md)保留逐样本证据，交给偏好优化继续比较。
5. [偏好优化实战](chapters/05-偏好优化实战.md)把 chosen/rejected 样本转成优化目标，并检查偏好更新是否真的改变输出。
6. 推理优化实战分为七个连续部分：[KV Cache](chapters/06-推理优化实战-1-kv-cache.md)先解释解码状态与容量，[Prefill 与 Decode](chapters/06-推理优化实战-2-prefill-decode.md)定义用户等待时间，[Serving runtime](chapters/06-推理优化实战-3-serving-runtime.md)讲分页缓存和请求调度；[量化](chapters/06-推理优化实战-4-量化.md)与[推测解码](chapters/06-推理优化实战-5-speculative-decoding.md)分别改变数值表示和生成步骤；[长上下文压测](chapters/06-推理优化实战-6-长上下文压测.md)验证容量与有效能力，最后用[实验报告](chapters/06-推理优化实战-7-实验报告.md)把质量、延迟、显存和成本放在同一验收条件下。
7. RAG 项目实战沿证据链拆成六篇：[文档与切分](chapters/07-rag项目实战-1-文档与切分.md)把原文变成带来源、版本和权限的片段；[检索与上下文](chapters/07-rag项目实战-2-检索与上下文.md)召回候选并控制输入预算；[候选重排](chapters/07-rag项目实战-3-候选重排.md)在有限候选中排出优先级；[引用与证据](chapters/07-rag项目实战-4-引用与证据.md)逐项检查主张能否回到当前来源；[评估指标](chapters/07-rag项目实战-5-评估指标.md)分别测量检索、回答、引用和拒答；[失败归因与报告](chapters/07-rag项目实战-6-失败归因与报告.md)把质量、成本、风险和失败样例交给第八章 Agent 项目。
8. Agent 项目实战沿着受控执行闭环拆成五篇：[工具调用协议](chapters/08-agent项目实战-1-tool-calling协议.md)区分模型提议与真实执行；[ReAct 状态循环](chapters/08-agent项目实战-2-react状态循环.md)管理多步任务、预算和恢复；[执行安全与授权](chapters/08-agent项目实战-3-执行安全与授权.md)约束权限、确认和副作用；[轨迹审计与评估](chapters/08-agent项目实战-4-轨迹审计与评估.md)建立可回放事件与有分母的安全指标；[贯通项目验收](chapters/08-agent项目实战-5-贯通项目验收.md)把 RAG 证据、工具回执和终态接成可复核的政策助手。
9. 评估与 Debug 实战分为六篇：[评测协议与 benchmark](chapters/09-评估与debug实战-1-评测协议与benchmark.md)固定样本、配置和评分；[数据污染与泄漏](chapters/09-评估与debug实战-2-数据污染与泄漏.md)检查比较对象是否可信；[事实性与 claim](chapters/09-评估与debug实战-3-事实性与claim.md)逐项核对主张和证据；[训练不收敛](chapters/09-评估与debug实战-4-训练不收敛.md)从数据追到梯度更新；[微调能力回归](chapters/09-评估与debug实战-5-微调能力回归.md)衡量目标收益和保留能力；[人工评测](chapters/09-评估与debug实战-6-人工评测.md)校准开放式质量判断。六篇共同交付一套可复查的离线结论，再交给第十章做轨迹与线上验证。
10. Agent 轨迹与线上评估实战分为三篇：[轨迹诊断](chapters/10-agent轨迹与线上评估实战-1-轨迹诊断.md)区分模型提议、程序判断与真实副作用；[线上 A/B 实验设计](chapters/10-agent轨迹与线上评估实战-2-ab实验设计.md)确定随机化单元、指标和统计证据；[灰度发布与报告](chapters/10-agent轨迹与线上评估实战-3-灰度发布.md)把日志、护栏、切片和回退条件落实为发布决策，并为第十五章作品集整理证据。
11. 图文理解与检索实战是选读支线，分成五篇：[CLIP 图文检索](chapters/11-图文理解与检索实战-1-图文检索.md)先把共享向量用于候选排序，[对比学习损失](chapters/11-图文理解与检索实战-2-对比学习损失.md)再解释表征怎样学得；[VLM 图片问答](chapters/11-图文理解与检索实战-3-VLM图片问答.md)从检索转向生成回答，[多模态指令数据](chapters/11-图文理解与检索实战-4-多模态指令数据.md)检查监督信号，最后由[图文 RAG](chapters/11-图文理解与检索实战-5-图文RAG.md)把候选、权限和证据接起来，交给第十四章做多模态评估。
12. [Diffusion 数值实验](chapters/12-diffusion数值实验.md)从前向加噪、噪声目标和反向均值/方差走到一次完整手算，再用向量代码核对公式，并讨论文本引导、少步采样与生成评估的边界。
13. [语音识别与语音问答](chapters/13-语音识别与问答实战.md)区分 Whisper 长音频转写与实时识别，测量整体文本和关键字段错误，再沿检索证据、回答依据与高风险确认定位误差。
14. [多模态评估与系统交付](chapters/14-多模态评估与交付.md)把媒体输入、转换、证据、权限和评估收束成一份交付报告，再转入作品集整理。
15. [作品集实战](chapters/15-作品集实战.md)把代码、配置、数据、运行证据、失败样例和个人贡献整理成可复核项目。
16. [技术表达与系统设计实战](chapters/16-技术表达与系统设计实战.md)用约束、机制、结果和边界组织技术讲解与方案答辩，完成从项目到面试的迁移。

## 与其他书的关系

第一、二册解释共同原理，第三册负责把原理变成可运行项目。第十四册补 PyTorch 与深度学习工程；第五至第九册和第十五至第二十四册分别深入训练、部署、评估、数据、多模态、Agent 与基础设施。第十二册进一步处理求职材料和面试策略。本册的项目证据可以作为这些专题学习后的练习入口，但不替代专题书的完整解释。
